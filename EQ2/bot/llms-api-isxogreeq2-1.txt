${ISXOgreEQ2.BuildHash}
  kind: member of ISXOgreEQ2
  what: The fingerprint of the ISXOgreEQ2 file this session loaded: the SHA-256 of its code section as 64 hex characters, the same value the session log's first adapter line shows. Two sessions that show the same value run the same build.

  example: echo ${ISXOgreEQ2.BuildHash}

== ISXOgreEQ2.AbilityEfficiency ==

ISXOgreEQ2.AbilityEfficiency:Run[-h]
  kind: method of ISXOgreEQ2.AbilityEfficiency
  what: Scores every ability in your loaded ability export as the damage in its description divided by cast plus recovery time (recast is not counted), writes one Name|Value line per ability best first to Scripts/OgreSave/EQ2/OgreBot/AbilityEfficiency/<name>_<subclass>_<server>_AbilityEfficiency.txt and prints the top 20 (the same as `ogre ae`). With no export loaded it prints an error telling you to run `ogre export`, and any argument other than a help word is refused.
  arg -h (switch): print the usage instead of running (-help, --help, ? and help work too)
  example: ISXOgreEQ2.AbilityEfficiency:Run


== ISXOgreEQ2.AbilityUpgrades ==

ISXOgreEQ2.AbilityUpgrades:Run[minLevel]
  kind: method of ISXOgreEQ2.AbilityUpgrades
  what: With a container window open it reads that one and leaves it open; otherwise it opens each Scroll Depot within 30 units in turn, reads it and closes it, and either way reports which spell scrolls upgrade an ability you already know, both in your console and to your other sessions through the Ogre console with your name in front (the same as `ogre oau`). It is queued, scribes or uses nothing, and is refused with a console line when you are not in the world, no ability export is loaded, a scan is already running or the level is not a whole number from 1 to 1000.
  arg minLevel (int, default: 121): ignore scrolls below this level (1 to 1000); -h prints the usage instead
  example: ISXOgreEQ2.AbilityUpgrades:Run[125]


== ISXOgreEQ2.Analysis ==

ISXOgreEQ2.Analysis:Close
  kind: method of ISXOgreEQ2.Analysis
  what: Closes the window and leaves everything running. :End stops it too.
  example: ISXOgreEQ2.Analysis:Close

ISXOgreEQ2.Analysis:Demo
  kind: method of ISXOgreEQ2.Analysis
  what: Fills the window with sample data and opens it, for looking at the layout. Nothing is saved.
  example: ISXOgreEQ2.Analysis:Demo

ISXOgreEQ2.Analysis:End
  kind: method of ISXOgreEQ2.Analysis
  what: Turns the monitor and the taps off, drops a scan in progress, a + Cursor countdown and the spawn watch, and closes the window, the same as `ogre end analysis` and the window's X. What was recorded stays.
  example: ISXOgreEQ2.Analysis:End

ISXOgreEQ2.Analysis:Export[name]
  kind: method of ISXOgreEQ2.Analysis
  what: Saves the monitored actors and scan results to a file and says where.
  arg name (string): The file name. Optional: with none it is session_ and the date and time.
  example: ISXOgreEQ2.Analysis:Export["My Run"]

ISXOgreEQ2.Analysis:Import[name]
  kind: method of ISXOgreEQ2.Analysis
  what: Loads a saved session, replacing what is in memory and stopping live monitoring. With no name, or one that cannot be read, it prints one warning and changes nothing.
  arg name (string): A session name from :Sessions, or a path; required.
  example: ISXOgreEQ2.Analysis:Import["My Run"]

ISXOgreEQ2.Analysis:Monitor[word,actor]
  kind: method of ISXOgreEQ2.Analysis
  what: The monitor: starts or stops sampling, empties or prints the list, or adds or removes an actor. With no word, or another word, it prints one warning listing the words.
  arg word (string): on and off start and stop sampling, clear empties the list, list prints it, add and remove take an actor; required.
  arg actor (string): For add and remove: an actor id, or target or cursor for the actor you have targeted or are pointing at.
  example: ISXOgreEQ2.Analysis:Monitor[add,target]

ISXOgreEQ2.Analysis:Open
  kind: method of ISXOgreEQ2.Analysis
  what: Opens the Analysis window, the same as bare `ogre analysis`.
  example: ISXOgreEQ2.Analysis:Open

ISXOgreEQ2.Analysis:Rate[ms]
  kind: method of ISXOgreEQ2.Analysis
  what: Sets how often monitored actors are sampled. A value outside 100 to 10000, or none, prints one warning and changes nothing.
  arg ms (int): Milliseconds between samples, 100 to 10000; the default is 250; required.
  example: ISXOgreEQ2.Analysis:Rate[500]

ISXOgreEQ2.Analysis:Scan[terms]
  kind: method of ISXOgreEQ2.Analysis
  what: Snapshots the actors that match, reusing the window's terms if you give none; with none there either it scans the whole zone. It refuses to start while a scan runs or out of the world.
  arg terms (string): Terms like Level>120: a member, then =, < or >, then a value, one argument each; a term that does not read that way prints a warning and is skipped. Optional.
  example: ISXOgreEQ2.Analysis:Scan["Level>120"]

ISXOgreEQ2.Analysis:Sessions
  kind: method of ISXOgreEQ2.Analysis
  what: Prints the names of the saved sessions to the console.
  example: ISXOgreEQ2.Analysis:Sessions

ISXOgreEQ2.Analysis:Status
  kind: method of ISXOgreEQ2.Analysis
  what: Prints the monitor, taps, scan and sample counters to the console, with the last error if there is one.
  example: ISXOgreEQ2.Analysis:Status

ISXOgreEQ2.Analysis:Taps[state]
  kind: method of ISXOgreEQ2.Analysis
  what: Turns the passive event logs on or off and prints the status.
  arg state (string): on or off. Optional: anything but off, or nothing, turns it on.
  example: ISXOgreEQ2.Analysis:Taps[on]


== ISXOgreEQ2.AntiAfk ==

ISXOgreEQ2.AntiAfk:Help
  kind: method of ISXOgreEQ2.AntiAfk
  what: Prints the `ogre afk` usage lines to the console. It changes nothing.
  example: ISXOgreEQ2.AntiAfk:Help

ISXOgreEQ2.AntiAfk:Invites[state]
  kind: method of ISXOgreEQ2.AntiAfk
  what: Turns automatic acceptance of group invites on or off: an invite is accepted from any name on your characters list (every account, auth-only names included), a switch separate from the keepalive that starts off at every load. A missing value is refused with a warning and nothing changes.
  arg state (string): on, 1 or TRUE to accept; off, 0 or FALSE to stop
  example: ISXOgreEQ2.AntiAfk:Invites[on]

ISXOgreEQ2.AntiAfk:Off
  kind: method of ISXOgreEQ2.AntiAfk
  what: Stops the keepalive /who and prints "anti-AFK keepalive OFF" to the console (the same as `ogre end afk`). The group-invite switch set by AntiAfk:Invites is left as it is.
  example: ISXOgreEQ2.AntiAfk:Off

ISXOgreEQ2.AntiAfk:On[silent]
  kind: method of ISXOgreEQ2.AntiAfk
  what: Starts the keepalive, which sends `/who all <your name>` to the game right away and then again after a random 10 to 15 minutes, only while you are in the world, until AntiAfk:Off or the extension unloads.   kind: member of ISXOgreEQ2.CraftingMats
  what: How many crafting-mats lists are loaded: the shipped ones plus your own from OgreSave/EQ2/CraftingMats/custom. Reading it first re-reads the list files if any changed on disk; any load warnings are in Warnings, and Get, Plan and Reload print them.
  returns: int: number of loaded lists; 0 when no list files were found
  example: echo ${ISXOgreEQ2.CraftingMats.Lists}

${ISXOgreEQ2.CraftingMats.Warnings}
  kind: member of ISXOgreEQ2.CraftingMats
  what: The warnings the last load of the list files produced, such as an unreadable file; Get, Plan and Reload also print them each time they run. Re-reads the list files first if any changed on disk.
  returns: string: the warnings joined with " | "; "" when the load was clean
  example: echo ${ISXOgreEQ2.CraftingMats.Warnings}

ISXOgreEQ2.CraftingMats:End
  kind: method of ISXOgreEQ2.CraftingMats
  what: Stops a depot withdraw that a crafting-mats run started (only that one) and closes the editor window; unsaved edits are kept for the next Open. This is what `ogre end craftingmats` and the window's X do.
  example: ISXOgreEQ2.CraftingMats:End

ISXOgreEQ2.CraftingMats:Get[flags...]
  kind: method of ISXOgreEQ2.CraftingMats
  what: Works out the mats for the chosen lists and categories, prints any list-file warnings and the plan, then starts pulling them from the Harvesting Supply Depot and buying any fuel at the Guild Fuel Merchant on the pulse after the call returns (the same as `ogre craftingmats -<flags>`). No flags pulls the Visions of Vetrovia signature line; nothing is pulled when not in world, when another depot errand is running, or when only unknown words were given, and the run stops if no depot is within 11 of you.
  arg flags... (string): Any mix, dash optional, any case: a list key (-vov, -cd, -mm, -pop, -ka or your own list's key), -sig / -s, -daily / -d, -weekly / -w, -plan to print only, help. A list with no category uses its own signature line (daily + weekly for Kunark's Ascending), a category with no list uses Visions of Vetrovia, and unknown words are ignored with one warning.
  example: ISXOgreEQ2.CraftingMats:Get[-vov,-daily,-weekly]

ISXOgreEQ2.CraftingMats:Help
  kind: method of ISXOgreEQ2.CraftingMats
  what: Prints the `ogre craftingmats` usage to the console: the list and category flags, the defaults, the script calls and where to put your own lists so updates never overwrite them.
  example: ISXOgreEQ2.CraftingMats:Help

ISXOgreEQ2.CraftingMats:Open
  kind: method of ISXOgreEQ2.CraftingMats
  what: Opens the Crafting Mats list editor window, where you change a list and save it to your own custom file (the same as bare `ogre craftingmats`). Calling it while the window is open changes nothing, and without the Ogre UI desktop it prints a warning instead.
  example: ISXOgreEQ2.CraftingMats:Open

ISXOgreEQ2.CraftingMats:Plan[flags...]
  kind: method of ISXOgreEQ2.CraftingMats
  what: Prints any list-file warnings and the shopping list Get would use - the mats to pull from the depot and the fuel to buy - and touches neither the depot nor the merchant. Takes the same flags as Get; no flags plans the Visions of Vetrovia signature line.
  arg flags... (string): Any mix, dash optional, any case: a list key (-vov, -cd, -mm, -pop, -ka or your own list's key), -sig / -s, -daily / -d, -weekly / -w, -plan to print only, help. A list with no category uses its own signature line (daily + weekly for Kunark's Ascending), a category with no list uses Visions of Vetrovia, and unknown words are ignored with one warning.
  example: ISXOgreEQ2.CraftingMats:Plan[-ka]

ISXOgreEQ2.CraftingMats:Reload
  kind: method of ISXOgreEQ2.CraftingMats
  what: Re-reads every list file from disk now, prints any warnings the load produced, then "craftingmats: reloaded -" with the list count and keys. Rarely needed: the lists are re-read by themselves whenever a list file changes.
  example: ISXOgreEQ2.CraftingMats:Reload
