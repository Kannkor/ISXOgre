== OgreBotAPI ==

${OgreBotAPI.Abilities}
  kind: member of OgreBotAPI
  what: The Abilities sub-object: the in-memory ability catalog loaded from this character's ability export, the ability reads built on it, and the cast and cancel verbs. Opening OgreBot loads the catalog; without OgreBot open, load it with its :Load before reading abilities from it.
  returns: object: the Abilities sub-object; it always exists, and as text it reads OgreBotAPI.Abilities.
  returns object: OgreBotAPI.Abilities (its members and methods are listed under it)
  example: echo ${OgreBotAPI.Abilities}

${OgreBotAPI.Access}
  kind: member of OgreBotAPI
  what: The Access sub-object: this session's access level (SetLevel) and UnauthPCsNearMe, which reports another player nearby who is not one of your own characters.
  returns: object: the Access sub-object; it always exists, and as text it reads Access[level/highest], this session's level and the account's highest level.
  returns object: OgreBotAPI.Access (its members and methods are listed under it)
  example: echo ${OgreBotAPI.Access}

  kind: member of OgreBotAPI
  what: TRUE while looting is going on: a loot window is open, or OgreBot did loot work (opened a corpse, chest or shiny, or worked a loot window) in the last 3 seconds. It simply runs out 3 seconds after the last loot activity, so a script waiting for looting to finish can poll it.

OgreBotAPI:DoVDebuff[fw, mob, allowMoving=setting]
  kind: method of OgreBotAPI
  what: Queues your archetype's raid debuff on the mob: Demoralizing Swipe (fighter), Slice of Despair (scout), Pall of the Elements (mage) or Divine Despair (priest). It is skipped when the ability is 5 seconds or more from ready, or the mob is out of range and moving is not allowed; a missing mob, ability or archetype echoes a line and does nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg mob (string): The mob: an actor ID, or a name (the nearest actor whose name contains it).
  arg allowMoving (bool, default: setting): TRUE walks into range first when the mob is too far away (the range is the ability export's); FALSE skips the cast instead. Left out, the DoV raid debuff "allow moving" setting decides.
  example: OgreBotAPI:DoVDebuff[all,${Target.ID}]
  oldbot: OgreBotAPI:DoVDebuff

OgreBotAPI:DoVDebuff_Half[fw, mob, archetype=auto, odd=TRUE, allowMoving=setting]
  kind: method of OgreBotAPI
  what: Like DoVDebuff, but only characters of one archetype cast, and only half of them: the odd or even ranks when that archetype's raid members (group members outside a raid) are ordered by character ID. Most refusals are silent - a different archetype, the other half, or no DoV debuff found on the mob when archetype is auto.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg mob (string): The mob: an actor ID, or a name (the nearest actor whose name contains it).
  arg archetype (string, default: auto): fighter, scout, mage or priest - the archetype that casts. auto reads the mob's effects for a DoV raid debuff icon and uses that archetype.
  arg odd (bool, default: TRUE): TRUE: the odd ranks (1st, 3rd, ...) cast; FALSE: the even ranks.
  arg allowMoving (bool, default: setting): TRUE walks into range first when the mob is too far away; FALSE skips the cast instead. Left out, the DoV raid debuff "allow moving" setting decides.
  example: OgreBotAPI:DoVDebuff_Half[all,${Target.ID},auto,TRUE]
  oldbot: OgreBotAPI:DoVDebuff_Half

OgreBotAPI:Prepare_TankSwapping[fw]
  kind: method of OgreBotAPI
  what: Gets the group ready for tank swapping: Guardians turn off Recapture, Bruisers turn off and cancel Hostility and Alternate: Shiftiness, and fighters tick the option to cast no force-target abilities. Everyone also cancels Subtle Strikes, drops the TankSwap no-offensive hold and clears the threat ignore list, all at once (not queued).
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI:Prepare_TankSwapping[igw:${Me.Name}]
  oldbot: OgreBotAPI:Prepare_TankSwapping

  what: Undoes Prepare_TankSwapping: Guardians turn Recapture back on, Bruisers turn Hostility and Alternate: Shiftiness back on in the cast stack (they are not recast), and fighters untick the no force-target option. Everyone also cancels Subtle Strikes, drops the TankSwap no-offensive hold and clears the threat ignore list.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI:Remove_Prepare_TankSwapping[igw:${Me.Name}]
  oldbot: OgreBotAPI:Remove_Prepare_TankSwapping

${OgreBotAPI.Abilities.CanCastOn[ability,target]}
  kind: member of OgreBotAPI.Abilities
  what: Tells you whether you could cast an ability on a target right now, and if not, why. It runs the bot's own castability check (range measured edge to edge, power, cooldown, position, stealth, line of sight, target type), so a script never has to rebuild it.
  arg ability (ability name or id): the ability to check
  arg target (actor name or id): who to cast it on; blank = yourself
  returns: string: "eligible" when it can be cast now. Otherwise the reason: "no ability given", "unresolved" (ability not found), "no valid target" (also when not in the world), "no target", "target gone", "cannot target self", "wrong target type", "target type unreadable", "ability not known", "on cooldown", "just cast this line", "not enough power", "not flanking", "not behind", "position unreadable", "requires stealth", "moving", "distance unreadable", "out of range", "line of sight unknown" or "line of sight blocked".
  example: echo ${OgreBotAPI.Abilities.CanCastOn["Intercept",${Target.ID}]}

${OgreBotAPI.Abilities.CancelCurrentCast}

  example: echo ${OgreBotAPI.Abilities.CancelCurrentCast}

${OgreBotAPI.Abilities.FindCastableHOIconAbilityID[iconId,options...]}
  kind: member of OgreBotAPI.Abilities
  what: Finds an ability you own that matches a heroic opportunity icon and can be cast now, and gives its id without casting it. Your "no stuns"-style settings are honoured; -offensive keeps only hostile abilities, and -ActorID <id> (or -HOTarget <id>) checks against that actor instead of your current NPC target.
  arg iconId (number, default: 0): the heroic opportunity icon id
  arg options... (text): -offensive, -ActorID <id> or -HOTarget <id>, and the -No options, each on top of your settings boxes: -NoStun, -NoDaze, -NoFear, -NoStifle, -NoInterrupt, -NoDispel, -NoRoot, -NoSnare, -NoCures, -NoGroupCures, -NoForceTargets, -NoThreatIncreases, -NoThreatDecreases. The console names any other option once, and it is ignored.
  returns: int64: the id of the ability to cast. 0 when nothing you own matches the icon or can be cast now.
  example: echo ${OgreBotAPI.Abilities.FindCastableHOIconAbilityID[3,-offensive]}
  oldbot: OgreBotAPI.Get_HOIconAbility

${OgreBotAPI.Abilities.FindCastableID[query...]}

  arg query... (text): query terms, each member, comparison, value (such as "IsInterrupt","=","TRUE"), plus options such as -NPCRequired or -ActorID <id> that check against a target
  returns: int64: the id of the matching ability (fastest cast time wins). 0 when nothing matches, when the query is refused, or when no export is loaded.
  example: echo ${OgreBotAPI.Abilities.FindCastableID["IsInterrupt","=","TRUE","-NPCRequired"]}

In the air it pulls, targets and holds nothing (a pull it was working ends, and one console line says so as it takes off), and while it is dead it holds everything as it is.
