== ISXOgreEQ2 console commands (-LogToonIn to -ZoneResetAll) ==

oc !c -LogToonIn <who> <name> <server> <class>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Logs a character in on one box: from the login screen, from character select, or from the world on another character (it camps first). Name the box by its InnerSpace session or its character, and at character select or the login screen by the character it last played: oc !c -LogToonIn MyToon MyToon logs MyToon back in after a zone dropped it to character select.
  arg who (string): The box: its InnerSpace session name or its character's name (at character select, the character it last played). all and groups pick no box.
  arg name (string): The character to log in. It needs a saved login on this PC.
  arg server (string): The server, for a character saved on more than one. Blank uses its default. A short form works: ior, md.
  arg class (string): The class to log in as, like ranger. Blank logs in whatever class it was.
  runs: OgreBotAPI.Session:LogToonIn
  example: oc !c -LogToonIn ${Me.Name} ${Group[1].Name}

oc !c -Move2Area <who> <x> <y> <z> <precision>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  also: -MoveToArea
  what: Tells [Bots] to move to a specific area.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg x (string, default: ${Me.X}): X coordinate (paste ${Me.X}), or the name of a point of interest in this zone
  arg y (float, default: ${Me.Y}): Y/height - IGNORED (2D ground move); pass ${Me.Y} for game-order convenience
  arg z (float, default: ${Me.Z}): Z coordinate (paste ${Me.Z})
  arg precision (float, default: 3): Arrival precision
  runs: OgreBotAPI.Movement:Move2Area
  example: oc !c -Move2Area igw:${Me.Name} ${Me.X} ${Me.Y} ${Me.Z} 3

oc !c -MoveToAreaNoTarget <who> <x> <y> <z> <precision>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  also: -Move2AreaNoTarget
  what: Walks to the given X and Z (Y is ignored) and stops within the precision distance, whether or not the toon has a target. A toon on a campspot stays there until -joustout or -letsgo; nothing moves if X or Z is missing or OgreBot is not open.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg x (string, default: ${Me.X}): X coordinate (paste ${Me.X}), or the name of a point of interest in this zone
  arg y (float, default: ${Me.Y}): Y/height - IGNORED (2D ground move)
  arg z (float, default: ${Me.Z}): Z coordinate (paste ${Me.Z})
  arg precision (float, default: 3): Arrival precision
  runs: OgreBotAPI.Movement:Move2AreaNoTarget
  example: oc !c -MoveToAreaNoTarget igw:${Me.Name} ${Me.X} ${Me.Y} ${Me.Z} 3
