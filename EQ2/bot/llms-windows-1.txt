# OgreBot

> **:bulb: In game - the ? button on this window says**
>
> The small OgreBot window: a quick remote for pausing the bot and showing or hiding the main OgreBot window.
>
> **What you can do here**
>
> - **Pause / Resume** - Pause stops the bot acting on its own (casting, following, camp spot, looting, Auto-Hunt). The button turns yellow and reads Resume.
> - **Hide Main / Show Main** - hides or shows the main OgreBot window. The bot keeps running.
>
> **Good to know**
>
> - The X on this window stops OgreBot completely, the same as the X on the main window. Unsaved changes are lost.
> - A yellow star (*) in the title bar means the profile has unsaved changes.
> - Pause only affects this character. Commands you send still work while paused.

**Open it:** It opens by itself whenever OgreBot loads (type `ogre`), next to the main OgreBot window. `ogre end bot` closes both. Opening it again while it is open does nothing (typing `ogre` reloads the whole bot instead).

## What it is for

The small OgreBot window is a two-button remote for the bot. Pause stops the bot from acting on its own and Resume starts it again. Hide Main hides the big OgreBot window and Show Main brings it back. OgreBot normally loads with the big window hidden, so this small window is what you see.

## Pause and Resume

| Control | What it does | Default |
|---|---|---|
| **Pause / Resume** | Pause stops this character's bot from acting on its own, for example: no new casts from the cast stack, no following, no pulling back to the camp spot, no looting, no auto-targeting, no Auto-Hunt. Commands you send still work. The button turns yellow and reads Resume. Click it to start the bot again.<br>*Only this character pauses, not the group. If something else pauses or resumes the bot, the button updates by itself.* | running (Pause shown) after `ogre`; paused after `ogre -p` or `ogre -ph` |

## Show / Hide the main window

| Control | What it does | Default |
|---|---|---|
| **Hide Main / Show Main** | Hides the big OgreBot window, or shows it again. The bot keeps running either way. Only the window is hidden. | Show Main (the big window starts hidden after `ogre`) |

## Title bar

| Control | What it does | Default |
|---|---|---|
| *** (yellow star)** | The profile has changes that are not saved yet. Save them on the big OgreBot window. | hidden |
| **Title bar close (X)** | Shuts OgreBot down completely, the same as the X on the big window. Both windows close, movement and HUDs stop, the profile is unloaded, and unsaved changes are thrown away.<br>*To just get the big window out of the way, use Hide Main.* |  |

## What the window shows

- Pause (green) = the bot is running. Resume (yellow) = the bot is paused.
- Show Main = the big window is hidden. Hide Main = it is on screen.

## Good to know

- The X on this small window stops OgreBot. It is not a minimize.
- Pause only stops what the bot decides by itself. Commands from you or your group still run.

# Commands

> **:bulb: In game - the ? button on this window says**
>
> Every `ogre` command you can use, in one list. Open it with `ogre ?`, `ogre help` or `ogre commands`.
>
> **What you can do here**
>
> - The first rows are `ogre` itself: loading OgreBot (`ogre`, `ogre -p`, `ogre -ph`) and `ogre ui reload` / `ogre ui windows`.
> - **Search** finds a command by its name, its other names, or any word in its description.
> - **Run** is `ogre <command>`; **End** is `ogre end <command>`, shown when the command has one.
> - A command that takes arguments has a box after its name: type them as you would after `ogre <command>`, then **Run** (or press Enter). The grey text in the box shows what it accepts.
>
> **Good to know**
>
> - The list shows only the commands your access level allows. If you lower your level, the list follows at once.
> - Greyed rows are commands that have not been ported to the new bot yet.
> - The line under the search box says what was sent. Each command's own messages still go to the InnerSpace console.
> - For the exact arguments a command takes, see its documentation.
> - The bottom line names the OgreBot release you are on (the name the What's new page uses) and when the core was built. `ogre version` prints the same.

**Open it:** Type `ogre ?` (or `ogre help`, or `ogre commands`). `ogre end commands` closes it.

## What it is for

Every `ogre` command you can use, in one searchable list. Each row is one command: its name, any other names it answers to, what it does and, when it takes them, what you can type after it. Run does exactly what typing `ogre <command>` does, and End does what `ogre end <command>` does. Each command's own messages still go to the InnerSpace console; this window only tells you what it sent.

## Search and the result line

The count on the right is how many commands you can use. The line under the search box says what the last Run or End sent, or why it was not sent.

| Control | What it does |
|---|---|
| **Search commands...** | Narrows the list as you type. It matches a command's name, its other names, its title, what it takes and its description. While you search, the count shows how many match out of the total. |
| **Result line** | Shows what was sent - for example `ran: ogre perf 10` in green - or, in red, why nothing was sent.<br>*It does not show the command's own output. Look in the InnerSpace console for that.* |

## A command row

| Control | What it does |
|---|---|
| **Run** | Runs the command, exactly as typing `ogre <command>` would - with whatever is in its box after it. |
| **End** | Stops or closes the command, exactly as typing `ogre end <command>` would. Only shown for commands that have something to end. |
| **Argument box (ogre <command> [ ... ])** | For a command that takes something after its name. Type it as you would after `ogre <command>`, then press Run or Enter. The grey text in the empty box shows what the command accepts.<br>*What you type is sent as typed - text with `${` in it is refused rather than worked out. For the exact meaning of each option, see that command's own page.* |

## Not ported yet

Greyed rows marked NOT PORTED are commands the old bot had that the new bot does not have yet. They are listed so you can see what is still to come; they have no buttons.

## What the window shows

- The first rows are `ogre` itself - loading OgreBot (`ogre`, `ogre -p`, `ogre -ph`) and `ogre ui reload` / `ogre ui windows`. They have Run only.
- Bold name = the command (`ogre <name>`). Next to it, its title.
- also: = other names that work the same way, for example `ogre fps` for `ogre perf`.
- The grey line under a row is what the command takes after its name, when it takes something.
- The count = how many commands you can use; while searching, how many match out of that.

## Good to know

- The list only shows the commands your access level allows. If you lower your access level (for testing), the list changes straight away.
- Run is the same as typing the command, so a command that opens a window opens it, and one that prints something prints it in the InnerSpace console - not here.

# OgreConsole

> **:bulb: In game - the ? button on this window says**
>
> Where your sessions talk to each other, and where the bot tells you things. Ctrl + ~ shows or hides it.
>
> **What you can do here**
>
> - **Type and press Enter** to send to every OgreBot session on this PC. Plain text is chat.
> - **Start a line with** `!c` to make every session run it as a command, e.g. `!c -pause igw:${Me.Name}`.
> - **Click a tab** (Chat, Commands, Events...) to see only those lines. A glowing dot means new lines.
> - **The gear** opens settings: time stamps, hide on load, line colours, and Clear text.
>
> **Good to know**
>
> - `ogre` commands go in the InnerSpace console, not here. `oc <text>` there is the same as typing here.
> - Red = command, green = chat, white = bot message, bold yellow on a red band = error, purple = fleet event. Change any of them in the gear's Colours.
> - An orange name at the start of a line is who said it on IRC.
> - **Send typed text to IRC** (gear): what you type here goes to IRC instead, like `irc <text>`, and comes back to your sessions with your IRC name.

**Open it:** Press **Ctrl + ~** (the key left of 1) to show or hide it, or type `ogre console` in the InnerSpace console (if it is already open, that does nothing). It opens by itself when the bot loads unless **Hide on load** is ticked.

## What it is for

OgreConsole is where your sessions talk to each other. Anything typed in the box at the bottom goes to every OgreBot session on this PC: plain text is chat, and a line starting with `!c` is a command that every session runs. It also shows what the bot has to tell you - alerts, unknown commands, and the commands other sessions sent. Lines are sorted into tabs so you can look at just one kind.

## Title bar

| Control | What it does |
|---|---|
| **⚙ (gear)** | Opens and closes the settings drawer at the top of the window.<br>*While the drawer is open it takes the place of the lines; if it does not fit, scroll it (or drag the window's bottom edge to make it taller). Click the gear again to close it.* |
| **Title bar close (X)** | Closes the window. The console keeps collecting lines in the background, and they are all there when you open it again. |

## Tabs

Click a tab to see only its lines. A tab appears the first time a line for it arrives.

| Control | What it does | Default |
|---|---|---|
| **All** | Every line, in the order it arrived. | selected |
| **Chat** | Plain text typed by you or another session (and lines relayed from IRC). |  |
| **Commands** | `!c` commands sent by any session, plus the bot's replies about them (for example an unknown command). |  |
| **Events** | Fleet requests such as a cure-curse call, one line each, showing who asked, who it was for and what for.<br>*Only appears when the OgreBot Debug option CommsEventsDebug is on.* |  |
| **Any other tab (e.g. Raid)** | A line sent with `-tab <name>` at the front also shows in a tab of that name. |  |
| **Glowing dot on a tab** | New lines arrived in that tab while you were looking at another one. Clicking the tab clears it. |  |

## The lines

Each line's colour tells you what kind of line it is (the colours below are the defaults).

| Control | What it does |
|---|---|
| **Line list** | The last 2000 lines. It stays at the bottom as new lines arrive, unless you have scrolled up to read, then it stays where you are.<br>*Right-click to Copy or Select All.* |

## Typing and sending

| Control | What it does |
|---|---|
| **Input line (message, or !c <cmd> ... (Enter to send))** | Press Enter to send the line to every OgreBot session on this PC, including this one. Plain text is chat. A line starting with `!c` is a command that every session runs. `!ci` runs it too but the line is not shown. Anything like `${Me.Name}` is filled in with this character's value before it is sent.<br>*Put `-tab <name>` right after `!c` to also show the line in that tab, or `-cfw <who>` to have only that character (or group of characters) run it.* |

## Settings drawer

Open it with the gear. Settings are saved straight away and are shared by every character on this PC.

| Control | What it does | Default |
|---|---|---|
| **Send typed text to IRC** | When ticked, what you type in the input line goes to IRC instead of only this PC - exactly like typing `irc <text>` in the InnerSpace console. It comes back to your sessions with your IRC name in front. `oc <text>` is not affected.<br>*Needs IRC connected (`ogre irc`). A `!c` line sent this way runs on every session that reads the IRC channel.* | off |
| **Show time stamps** | Shows the time each line arrived at the start of the line.<br>*Display only - changes what you see, not what the bot does.* | on |
| **Hide on load** | When ticked, the console does not pop up when the bot loads. It still collects every line, so opening it later with Ctrl + ~ shows what you missed. | off |
| **Debug: trace verbs to log** | For troubleshooting. Writes one line per command this session receives to the bot's log file, saying whether it ran. Nothing extra shows in the console.<br>*Leave it off in normal play.* | off |
| **Colour square (Command, Chat, System, Error, Event, Timestamp)** | Click a colour square to open R, G and B sliders for it. The colour changes as you drag and is saved when you let go. |  |
| **Reset** | Puts that colour back to its default. |  |
| **Clear text** | Wipes every line from this session's console, removes all tabs except All, and closes the drawer. Only your console is cleared, and the lines cannot be brought back. |  |

## Colours

| Control | What it does |
|---|---|
| **R / G / B sliders** | Red, green and blue for the colour you clicked. Only one colour's sliders are open at a time. |

## What the window shows

- Red line: a command (`!c ...`) sent by any session.
- Green line: chat.
- White line: a message from the bot itself, such as a `[Notify]` alert. Most of these show only on the All tab (a note that a command did nothing here also shows on Commands).
- Bold yellow line on a dark red band: an error, for example a command nobody knows (`Unknown command entered: -pasue`).
- Purple line: a fleet request on the Events tab.
- Orange name at the start of a chat or command line: who said it, for lines that came in over IRC. Only real IRC lines get it - a line you type that starts with `word: ` does not.
- `-cfw <who>` at the end of a command line: that command was meant only for those characters.
- Grey time at the start of each line (when Show time stamps is on).

## Good to know

- `ogre ...` commands are typed in the InnerSpace console, not here. Typed into this box, `ogre smartloot` is just sent to everyone as chat.
- Typing `oc <text>` in the InnerSpace console does exactly the same as typing `<text>` into this box: it goes to every session.
- `!c` commands run on every session, including the one you typed on. Use `-cfw <who>` or a for-who inside the command (such as `igw:${Me.Name}`) to aim it.
- Only the last 2000 lines are kept.
- All console settings live in OgreSave\Common\OgreConsole.json and apply to every character on this PC.

## One tab selected

With **Commands** selected only command lines show. The other tabs glow when something new lands in them.

# Master Control Panel

> **:bulb: In game - the ? button on this window says**
>
> A grid of buttons that send commands to your characters. Pick a page on the left; the static buttons stay the same on every page.
>
> **What you can do here**
>
> - **Click a button** to send its command to the characters picked in **For Who**.
> - **Right-click a button** to build its command, rename it, colour it, copy or paste it, or assign it to a key.
> - **Right-click a page** to rename or colour it; **+ Page** adds one.
> - **Drag** buttons and pages to rearrange them.
> - The **magnifier** finds a button by name or command; the **gear** changes button size and options.
>
> **Good to know**
>
> - Buttons are shared by every character on this PC and saved as you go.
> - **Alt** + the backtick key opens and closes this window.
> - A key assigned to a button follows it when you move the button or its page. Clearing the button removes its keys.
> - A colour is kept however you close the picker; **Reset** takes a custom colour off.
> - A button needs a name - use **Clear button** to remove one.

**Open it:** Press **Alt** and the backtick key together to open or close it, or type `ogre mcp` (close with `ogre end mcp`). `ogre mcp` does nothing if the MCP is already open. Tick **Enable OgreMCP** (OgreBot, Settings tab, On Load) to open it every time a profile loads.

## What it is for

The Master Control Panel (MCP) is a grid of buttons that send commands to your characters: follow, pause, camp, evac, cast an ability, travel, and anything else the bot's command list offers. Buttons are organised into pages (the left column). A block of static buttons stays the same on every page, and the rest of the grid changes with the page you pick. The For Who window decides which characters a button's command goes to. Every change is saved at once and shows up live in the MCP of every other character on the same PC.

## Title bar

The buttons in the title bar. The **?**, the lock and the X are on every window.

| Control | What it does |
|---|---|
| **Magnifier (Find)** | Opens or closes the Find drawer, to search every button on every page by its name or its command. |
| **For Who** | Shows or hides the For Who window, which picks the characters a button's command goes to. The text turns green while For Who is showing. |
| **Gear (Settings)** | Opens or closes the Layout drawer (button size, spacing, font size and the options below). |
| **Title bar close (X)** | Closes the MCP, and with it the For Who, Build command and Assign keys windows.<br>*Key binds still work with the window closed.* |
| **Alt + backtick key (keyboard)** | Opens the MCP if it is closed, closes it if it is open. |

## Pages (left column)

Each page is its own set of buttons for the right-hand block. The static block does not change when you switch pages.

| Control | What it does | Default |
|---|---|---|
| **Click a page** | Switches the right-hand block to that page's buttons.<br>*The page you are on is shared: switching page switches it in every open MCP on this PC.* |  |
| **+ Page** | Adds a new empty page called 'Page N' at the bottom and switches to it. |  |
| **Drag a page** | Moves the page up or down the list. A line shows where it will land. You stay on the same page.<br>*Keys assigned to buttons follow the buttons, so moving pages does not change what a key presses.* | on (needs Allow moving) |
| **Right-click a page > Switch to this page** | Same as clicking the page. |  |
| **Right-click a page > Rename…** | Opens a small box to type the page name (up to 40 letters). An empty name becomes 'Page N'. |  |
| **Right-click a page > Set colour…** | Opens the colour picker for the page selector's background. Reset takes the colour off again. |  |
| **Right-click a page > Set text colour…** | Opens the colour picker for the page name's text. Auto goes back to a colour that reads well on the background. |  |
| **Right-click a page > Delete page…** | Asks you to type the page's exact name, then removes the page, all its buttons and any keys assigned to them. You stay on the page you were on.<br>*Only shown when 'Allow deleting pages' is ticked and there is more than one page.* |  |

## Static buttons

The first block of button columns (3 by default). These buttons are the same whichever page you are on - a good place for Follow, Pause, Resume and Evac.

| Control | What it does | Default |
|---|---|---|
| **Click a button** | Sends the button's command. It goes to the characters picked in For Who, unless the button names its own target in every step (for example 'fighter' or 'Me'), in which case it goes to that target. A button made in Raw mode runs only on the character that clicked it. The button flashes; an empty button does nothing. |  |
| **Drag a button** | Drop it on another slot to swap the two (or move it, if the slot is empty). You can drag between the static block and the page block.<br>*Letting go over empty space cancels the move. A key assigned to the button moves with it.* | on (needs Allow moving) |

## Page buttons

The block to the right of the dashed line. It shows the buttons of the page you picked. Grow the window wider for more columns, taller for more rows.

| Control | What it does |
|---|---|
| **Drag a button onto a page** | Moves the button to that page: into the same spot if it is free, otherwise the first free spot. When it lands on a page other than the one you are on, a message names that page.<br>*A key assigned to the button moves with it.* |

## Right-click a button

Right-click any button slot for this menu. On an empty slot, Assign to key and Copy button are not shown.

| Control | What it does |
|---|---|
| **Build command…** | Opens the Build command window to make or change what this button sends, and its label. |
| **Rename…** | Changes the text on the button (up to 40 letters). Renaming an empty slot makes a button with just a label.<br>*A button needs a name: an empty name is refused and the box says so. To remove a button, use Clear button.* |
| **Set colour…** | Opens the colour picker for the button's background. The text colour adjusts itself to stay readable unless you set one. Reset takes the colour off again. |
| **Set text colour…** | Opens the colour picker for the button's text. Auto goes back to the automatic readable colour. |
| **Assign to key…** | Opens the Assign keys window for this button, to fire it from a keyboard key, a G-key or an extra mouse button. The key belongs to the button: move the button, or move its page, and the key still presses it.<br>*Only shown on a slot that has a button. Clearing the button, or deleting its page, removes its keys.* |
| **Copy button** | Remembers the button (label, command and colours) for pasting, and puts a code for it on your Windows clipboard so you can share it. The code starts with OGREMCP1.<br>*Only shown on a slot that has a button.* |
| **Paste "<name>" [over "<name>"]** | Puts the copied button into this slot. The menu names the button, and the one it would replace.<br>*The copied button is shared by every character on this PC, so you can copy on one and paste on another. Pasting over a button keeps that button's keys, so they now press what you pasted.* |
| **Paste "<name>" from clipboard** | Shown when your Windows clipboard holds a button code (for example one someone sent you). Puts that button into this slot. A code can only make a button; it never runs anything. |
| **Clear button** | Empties the slot: the command, label, colours and any keys assigned to the button are removed. Asks first. |

## Colour picker

Used by every Set colour and Set text colour. The button changes while you drag, and the colour is kept however you close the picker (Done, Escape, or a click on the grid).

| Control | What it does |
|---|---|
| **Colour box (#rrggbb)** | Type a colour as #rrggbb, #rgb or r,g,b (numbers 0-255). A red border means it is not a colour and is ignored. |
| **R / G / B sliders and numbers** | Red, green and blue from 0 to 255. Drag a slider or type a number; the button updates as you go. |
| **Reset / Auto** | For a background it reads Reset and takes the custom colour off, so the button or page goes back to the theme's colour. For text it reads Auto and goes back to the automatic readable colour. |
| **Done** | Closes the picker. The colour is already on the button and is saved. |

## Rename

| Control | What it does |
|---|---|
| **Name box** | The new name. Enter = OK, Escape = Cancel. |
| **OK** | Saves the name. For a button, an empty name is refused with a note in red - use Clear button to remove a button. |
| **Cancel** | Closes without changing anything. |

## Clear and paste-over warning

The same small box asks before Clear button, and before a paste that would replace a button. Pasting into an empty slot never asks.

| Control | What it does | Default |
|---|---|---|
| **Don't ask again for [5] min** | Tick it and set the minutes (1-999) to stop this question for that long. Clears and paste-overs are snoozed separately.<br>*Only for this window: reopening the MCP asks again.* | off, 5 minutes |
| **Clear / Paste** | Goes ahead. |  |
| **Cancel** | Leaves the button as it was. |  |

## Delete page

| Control | What it does |
|---|---|
| **Type the page name** | Delete stays greyed out until this matches the page name exactly (capitals count). |
| **Delete** | Removes the page, every button on it and any keys assigned to those buttons. |
| **Cancel** | Keeps the page. |

## Find

Opened by the magnifier. Searches every button, static ones first, then page by page.

| Control | What it does | Default |
|---|---|---|
| **name or command… (search box)** | Type part of a button's name or of the command it sends. Names that start with the text come first. Up/Down moves through the results, Enter jumps to the highlighted one, Escape closes. | empty |
| **Click a result** | Switches to that button's page and rings the button for a couple of seconds. It does not press it. If the button is outside the window, a message says its page, row and column. |  |
| **▶ Run** | Sends that button's command right away, the same as clicking it, and keeps the Find drawer open. |  |
| **x (close)** | Closes Find. Clicking anywhere outside it also closes it. |  |

## Settings (the gear)

The Layout drawer. Changes show at once and are saved. They change the buttons, not the window size.

| Control | What it does | Default |
|---|---|---|
| **Static columns** | How many columns form the static block (0-99). If the window is too narrow, fewer show. | 3 |
| **Button width** | Width of every button, 24-400 pixels. The - and + step by 2; hold to repeat. | 92 px |
| **Button height** | Height of every button and page selector, 16-200 pixels (steps of 2). | 28 px |
| **Spacing — left/right** | Space between columns, 0-40 pixels. | 6 px |
| **Spacing — above/below** | Space between rows, 0-40 pixels. | 6 px |
| **Font size** | Size of the button text, 8-40 pixels. | 12 px |
| **Show command on hover** | Resting the mouse on a button for a moment shows the command it sends. | on |
| **Outline button text** | Draws a thin outline round button text so it reads on any colour. Display only. | on |
| **Allow moving (drag to rearrange)** | Lets you drag buttons and pages around. Turn it off to stop accidental moves; clicking still works. | on |
| **Allow deleting pages** | Adds Delete page… to a page's right-click menu. | off |
| **Open For Who on load** | Shows the For Who window whenever the MCP opens. | off |
| **x (close)** | Closes the drawer. The gear does the same. |  |

## What the window shows

- Page selectors (left column): the active page has a bright outline. '+ Page' sits under the last page.
- Static block: a slightly tinted border marks static buttons. A dashed line separates them from the page block.
- Empty slots: dashed outlines with no text. Right-click one to build a button there.
- Colours: a button or page with its own colour shows it; otherwise it uses the theme colours.
- A red button showing the first 4 letters of its name and a countdown (for example 'Resc 14.2') is an ability still on cooldown. It goes back to normal when the ability is ready. This only happens for buttons that cast an ability, and only for abilities on the OgreBot Ability Tracker tab with 'Enable Ability Tracker' ticked (Settings). The longest cooldown among your characters is shown.
- A button with a glowing ring is the one Find jumped to, or the one you just pasted.
- A small message at the bottom confirms things like 'Copied "Evac" - the code is on your clipboard' or 'Moved to "Travel"'.
- A menu or box that would not fit in a short window is kept inside it and scrolls.

## Good to know

- Your buttons, pages, the page you are on and your For Who choice are one file shared by every character on this PC: Scripts/OgreSave/EQ2/OgreMCP.json. A change on one character shows up in every open MCP at once.
- Changing button size or spacing does not resize the window. Nudge the window edge and it snaps to fit whole buttons again.
- The page column shows only as many pages as there are rows. With more pages than rows, make the window taller (Find still reaches buttons on hidden pages).

# Reset UI Windows

> **:bulb: In game - the ? button on this window says**
>
> Puts Ogre windows back where they started. Use it when a window is off-screen and you cannot reach its title bar. Open it with `ogre windowreset`.
>
> **What you can do here**
>
> - **Reset** on a row moves that window back to its starting spot and size, at the normal UI scale, unlocked.
> - **Reset All Windows** does that for every window in the list, except help windows and the OgreHUD.
> - **Refresh** re-reads the list after you open or close windows.
>
> **Good to know**
>
> - Reset forgets the window's saved position. Move it where you want and use Save Position again.
> - A hidden window stays hidden; Reset only moves it.

| **Add non-raid** | Adds every resettable zone that does not have 'Raid' in its name. |
| **Add non-locked** | Adds every zone that is not locked: the resettable ones and the ones with no data. |

## Reset queue

The zones you picked. The queue is kept while the bot is loaded, even if you close this window, but is not saved to disk.

| Control | What it does | Default |
|---|---|---|
| **Click a queued zone** | Removes it from the queue. |  |
| **Ctrl-click (or Alt-click) a queued zone** | Selects that zone as the Force reset target (it is highlighted). Ctrl-click it again to unselect. Display only until you press Force reset. |  |
| **Clear list** | Empties the reset queue. |  |
| **Force reset selected / Force reset: <zone> / Click again to SPEND a charge on: <zone>** | Spends one of your limited zone reset charges to reset the selected zone right now, even if it is locked. It takes two clicks: the first click only arms the button (its text changes to 'Click again to SPEND a charge on: <zone>'), and a second click within 5 seconds does the reset. The bot then opens the Zone Reuse window, finds the zone, clicks Force Reset, and only clicks the confirm button if the game's confirm message names exactly that zone. If it does not, nothing is clicked, no charge is spent, and the confirm window is left open for you.<br>*Cannot be undone. If you do not click again within 5 seconds, the button goes back to normal and nothing is spent.* | greyed out until a zone is selected (and while the window is busy) |
| **Reset queue for me** | Resets the lockout timer of every queued zone on this character only, one zone every half second.<br>*Greyed out while the window is busy. With an empty queue it just says the queue is empty.* |  |
| **Reset queue via <oc/irc> for <who>** | Sends a reset for every queued zone to the characters picked in the Master Control Panel's For Who window, over the bot console (or IRC if that is what the For Who window says). Each character that receives it resets its own timer for those zones. The button text shows where it will go.<br>*If the For Who window has never been set, this goes to every character (all).* | oc for all (when the For Who window has never been set) |

## Footer

A reminder of how the lists work, and that Force reset spends a limited charge.

## What the window shows

- Green zone: its lockout can be reset now (the game's tooltip says so).
- Orange zone with [time]: locked; the time in brackets is how long is left.
- Pale yellow zone: no timer data (the game knows the zone but shows no timer for it).
- 'raid' tag: the zone name contains 'Raid'. The Add non-raid button skips these.
- Status text (top right): what the last action did, for example 'reset 3 queued zone(s)', 'the reset queue is empty', 'not in world', or 'ABORTED: ...' when the Force reset safety check refused.
- 'working…': a refresh or reset is running. The reset buttons are greyed out until it finishes.

## Good to know

- Force reset spends a real, limited reset charge and cannot be undone. The first click only arms it; the reset happens on a second click within 5 seconds. The ordinary 'Reset queue' buttons do not spend charges.
- The fleet button uses the For Who window from the Master Control Panel, not your group. If that window was never set, it resets for every character.
- Refresh and Force reset briefly open the game's Zone Reuse window. That can cause a short stutter. A queue reset opens it too, but only on a character whose game has not loaded its zone list yet.
- The queue is forgotten when the bot is unloaded.

# OSA

> **:bulb: In game - the ? button on this window says**
>
> The On Screen Assistant: the NPCs around you with health, your threat, distance and who they are attacking. Named first, then nearest first - up to 35 rows, and every named in range comes before any other NPC.
>
> **What you can do here**
>
> - **Click a row** to target that NPC. The green row is the one you are fighting.
> - **Gear** - choose the columns (HP, Threat, Distance, Target), then **Apply**.
> - Set how far it looks, "targets only" and Clip Y Axis in OgreBot, HUDs tab, OSA section.
>
> **Good to know**
>
> - It opens and closes with **Use On Screen Assistant (OSA)** on OgreBot's Settings tab; `ogre osa` also opens it (and does nothing if it is already open).
> - THR is your threat in percent; at 100 it shows your lead over the next player.
> - Clip Y Axis hides NPCs 8 or more above or below you - the floors over and under you.

**Open it:** Tick **Use On Screen Assistant (OSA)** on OgreBot's Settings tab - it opens at once, opens every time that profile loads, and closes when you untick it. You can also type `ogre osa`.

## What it is for

A compact list of the NPCs around you: name, health, your threat, distance, and who each one is attacking. Named mobs are listed first, then the rest nearest first. Click a row to target that NPC. How far it looks, whether it hides NPCs that are not fighting and whether it hides NPCs on other floors are set in OgreBot, on the HUDs tab (OSA section).

## Title bar

The title shows how many NPCs are listed, for example OSA — 9 NPCs.

| Control | What it does |
|---|---|
| **⚙ (gear)** | Opens and closes the column picker at the top of the window. |
| **Title bar close (X)** | Closes the window. The OgreBot box stays ticked; type `ogre osa` to bring it back.<br>*To turn OSA off for good, untick the box in OgreBot.* |

## The list

| Control | What it does |
|---|---|
| **Click a row** | Targets that NPC. |

## Column picker

Opened with the gear. Name is always shown.

| Control | What it does | Default |
|---|---|---|
| **HP%** | Shows the HP column: the NPC's health in percent. | on |
| **Threat** | Shows the THR column: your threat on that NPC in percent. When you are at the top of its hate list (100), it shows how far ahead of the next player you are instead. | on |
| **Distance** | Shows the DIST column: how far away the NPC is, in metres. | on |
| **Target** | Shows the TARGET column: the name of whoever that NPC is targeting. Empty means it is not targeting anyone. | on |
| **Apply** | Uses the ticked columns, closes the picker, and remembers the choice for next time.<br>*Ticking a box does nothing until you press Apply.* |  |

## What the window shows

- Rows: NPCs and named NPCs only - no players, pets, corpses or objects. Named first, then everyone else, each group nearest first. At most 35 rows - every named in range is listed before any other NPC, so a far-away named is never the one cut.
- Green row with bold green name: the NPC you are fighting - your target, or your target's target if you have a friend targeted.
- HP: health in percent. THR: your threat in percent, or your lead over the next player once you are at 100. DIST: distance in metres. TARGET: who that NPC is targeting.
- 'no NPCs in range' when nothing is inside the scan radius.
- It refreshes 5 times a second.

## Good to know

- Scan Radius, Display NPCs with Targets Only and Clip Y Axis (OgreBot, HUDs tab) only apply while the Use On Screen Assistant box is ticked. If you open OSA with `ogre osa` and the box is not ticked, it looks 50 metres out and lists every NPC on every floor.
- Scan Radius is capped at 200 metres.
- Clip Y Axis (only show mobs on the same floor as you), in the same OgreBot section, hides every NPC whose height differs from yours by 8 or more.
- `ogre osa` when OSA is already open does nothing and prints nothing.
