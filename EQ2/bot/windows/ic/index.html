    Instance Controller¶

    OgreBot is in beta testing. Looking for OgreBot Classic? Click here.

    In game - the ? button on this window says

    Runs zones for your group, one after another: travels in, fights through the zone, and moves on to the next.

    What you can do here

    • Queue zones: pick a zone on the left and double-click it (or Add). Add all queues every zone the list is showing (this folder, after the search and the variant filter), in its order. Drag rows to reorder.
    • Sort (beside the Zones heading): the zones are listed by their number by default (Sort: #); click it for Sort: A-Z, by zone name. It is remembered, and Add all follows it.
    • Remove and Clear sit beside the Queue heading. Remove takes out the highlighted row (click a row first; right-clicking the highlighted row does the same), Clear empties the queue. Each is greyed out until there is something for it to do.
    • Stop after this zone (shown while a list runs): the zone you are in finishes, then the list stops and the end-of-list actions run (call to the guild hall or home, camp). Run clears it.
    • Run starts the list. Pause holds the Instance Controller only (OgreBot keeps running). End stops the run. While the end-of-list actions run (guild hall, home, camp), End cancels them: nothing more starts, and the client is not closed.
    • Options decide what happens in and after each zone: loop the list, reset zones first, call home at the end, and more.
    • Summon merc if solo (on by default): once you are inside the zone with nobody else in your group, it summons your mercenary (merc resume). On a zone-in that happens as you land, so the mercenary gets the rebuff time too.
    • Every option is also a command: ogre ic -skipshinies turns one on, ogre ic -skipshinies=off turns it off, and one command can carry several. ogre ic options lists them all.
    • Zone file: IC File Option 1-3 and IC File Args are for the zone you run. The zone file names the options and reads them.
    • Startup Options are commands sent at the start of every zone, then undone when the run ends.

    Good to know

    • Closing this window stops a running list, the same as End.
    • If a zone fails, the group stays in that zone and the list stops.
    • Every zone file must say how it leaves the zone. Reload skips a file that does not, and the log says what to add.
    • While IC travels the group to a zone, OgreBot is paused, so buffs that drop at each zone line are not recast out in the world. A toon that gets attacked on the way is resumed to fight, then paused again. On arrival everyone is resumed and has a few seconds to rebuff before the zone starts.
    • Settings (including Max wait per zone) and the queue are saved, and shared by every character on this PC.

    Open it: Type ogre ic (or ogre ic panel) in the console. It opens at 775x460. If the window is already open, the command does nothing.

    What it is for¶

    The Instance Controller (IC) runs a list of instanced zones for you, one after another. You browse the zone files, queue the zones you want (each stamped with a variant such as [Heroic]), then press Run. For each row IC travels the group to the zone (resetting it first if asked), applies your Startup Options, walks the zone file's steps (paths, nameds, chests, shinies) and zones out, then moves to the next row. When the list is done it can call the group home, camp out, or loop back to the top.

    Title bar and tabs¶

    Control What it does Default
    ▼ / ▲ Shrinks the window to a one-line strip showing the run status, Pause and Expand. Clicking again restores the previous size. Display only - changes what you see, not what the bot does.
    The strip is 440 pixels wide and only as tall as its content.    		 expanded
    Close (X) Closing the window STOPS a running list, exactly like End (the reason shown is 'panel closed'), and turns IC's pause off.
    Closing is not just hiding the window. It does NOT cancel end-of-list actions that are already running (use End for that), so closing the window on the way out never undoes an armed camp.
    Run / Startup Options / Settings Switches the page you see. Display only. Run

    Shrunk to a strip¶

    Control What it does
    Pause / Resume Same as the Pause button at the bottom. Turns IC's own pause on or off. OgreBot's pause is not touched.
    Only visible when shrunk.
    Expand Restores the full window.

    Run tab - choosing zones¶

    Control What it does Default
    Root dropdown (e.g. "test (4)") Picks which of the three content roots to browse: default, test or custom. Each shows how many files it has. Picking one goes to that root's top folder and clears the selected file. The choice is saved.
    Browse choice only. The roots have no priority order.    		 default; on first ever open it auto-jumps to the first root that has files
    Up Goes up one folder in the browse list and clears the selected file.
    Disabled at a root's top level.
    search Filters the browse list to files whose zone name or path contains the text. Not case-sensitive. It applies about 0.2 seconds after you stop typing.
    Not saved, so it clears when the extension reloads.    		 empty
    any variant / [Solo] / [Heroic] / ... Two jobs. (1) Hides files that do not have this variant. (2) Every zone you queue is tagged with this variant, which decides which instance the zone-in travels to. 'any variant (browse only)' turns the filter off and tags nothing. The choices are every variant found in the loaded zone files. Saved.
    With 'any', queuing a file that has 2+ variants pops up a pick-one menu at the row.    		 any variant
    Reload Re-reads every zone file from the three roots. Prints 'N zone(s) from M file(s) - X skipped, Y warning(s)'. The selected file is cleared if it no longer exists. A zone file that does not say how it leaves the zone is skipped, and the log names the file and the line to add (see Write your own zone files).
    A queued row whose file vanished fails with 'press Reload' when the row starts.

    Run tab - the zone list¶

    Control What it does Default
    Sort: # / Sort: A-Z Flips the order of the Zones list: by the files' number (Sort: #, the default) or by zone name (Sort: A-Z). The button names the order shown. Add all queues in the same order. Saved. Sort: #
    Folder row (name + file count) Single click opens that folder.
    Zone row (click) Selects the file. The add bar then shows its name, and its difficulty menu if it has one.
    Zone files marked as disabled are hidden.
    Zone row (double-click) Adds the zone to the end of the queue, tagged with the chosen variant and the remembered difficulty. With no variant chosen: a file with 0 or 1 variants is added directly; a file with 2 or more opens a pick-one popup at the row. The pick is checked against the zone file; a pick it does not allow is refused, and the error lists the allowed values. The new row becomes the highlighted one.
    The popup pick is one-off. It does not change the variant filter.

    Run tab - the queue¶

    Control What it does
    Queue row (click) Highlights the row. This is the target for Remove and for right-click remove. It does NOT choose where Run starts.
    Drag a row Press a row and drag it up or down to reorder the queue - anywhere on the row; the drag starts once the mouse moves a few pixels, so a click is never taken for a drag. It is a move, not a swap: rows in between shift one place. The moved row becomes highlighted. Saved.
    It works even while a list is running.
    Right-click a row Removes the row, but only if it is already the highlighted one. A right-click on any other row does nothing (it is only noted in the log).
    The highlight is the confirmation step.
    Remove Removes the highlighted queue row (right-clicking the highlighted row does the same). Saved.
    Greyed out until a row is highlighted - click one first. Not blocked while a list runs.
    Clear Empties the whole queue, with no confirmation. Saved.
    Greyed out while the queue is empty. Not blocked while a list runs.

    Run tab - adding to the queue¶

    Control What it does Default
    Difficulty ('choose…' until set) A difficulty that stays chosen while you browse. It is added to rows queued from files that have a difficulty menu, and checked against that file when you add. The bot does NOT use it during a run yet: when the row starts, IC only logs 'the difficulty on this row is recorded but not acted on yet'.
    Only shown when the selected file has a difficulty menu (a list of choices). Saved.    		 empty
    Difficulty number box (e.g. '1-80') Same as the Difficulty dropdown, for files that use a number range. It takes effect when you press Enter or click away. Also recorded only, not used yet.
    Only shown when the selected file uses a range. The range is checked when you add, not while you type.    		 empty
    Add Queues the selected file exactly like a double-click, including the variant popup.
    Disabled until a file is selected.
    Add all Queues every zone the Zones list is showing (this folder, after the search and the variant filter), in the list's order, each tagged with the variant chosen up top and the remembered difficulty.     Control What it does Default
    named # Type which named you are on (1, 2, 3...) and press Enter, or just press Run.     The box empties once it is used. A file with no such named is refused.    		 blank

The zone you are in finishes as always (its steps, then Halt at end of zone or Call to GH after each zone), then the list stops as if that were its last row - no Ogre IM, no loop wait, no next zone, no Stay until a zone is ready - and the end-of-list actions run.     Run clears it, and so does the list stopping. Not saved. A failed zone still stops the list without the end-of-list actions. Also a console switch: ogre ic -stopAfterZone (=off turns it off).    		 off
    Pause / Resume Turns IC's own pause on or off. While paused, IC does nothing: no zone steps advance, the zone-in stops, and the list waits. Actions already started keep going. OgreBot's pause is NOT touched. Also releases a Halt at end of zone hold.
    The window keeps updating while IC is paused (for example when OgreBot is paused or resumed). Run also clears the pause.    		 running
    Resume Only shown when you stand in a queued zone whose last run was stopped mid-zone. That row restarts at the step where it stopped, then Run fires.
    The stop point is not saved to disk.    		 hidden
    Run Starts the list. It starts at the queue row for the zone you are standing in, otherwise row 1, never the highlighted row. It clears IC's pause, checks the row's choices against the zone file again, and runs the safety checks (at least 10 free slots, nobody dead). Each row then runs in turn: zone-in, apply startup options, zone steps, exit.
    Greyed out while running, while the end-of-list actions of the last list are still going (press End to cancel them first), with an empty queue, or if OgreBot is not loaded with a profile.     End Stops the run where it stands and clears IC's pause. The current step is cancelled, exit steps do NOT run, and the list stops. The stop step is remembered for Resume, and the startup options are reverted. During a zone-in, IC's travel route is stopped and the group stays put. End-of-list actions are not triggered. For a zone run by a LavishScript (.iss) file, IC stops following it but the script itself keeps running. A trip to the guild hall or a Call to Home already under way finishes on its own, and the group stays paused - resume OgreBot when you are ready. The console says what was left behind.

    • Root dropdown: the root name plus its file count, e.g. "test (4)".
    • Breadcrumb: or / .
    • Zones list header: "Zones (shown of total loaded)".
    • Zones list folder rows: ▸ name, then the number of files under it.
    • Zones list file rows: the zone name (or path) plus chips - one per variant (e.g. [Solo], [Heroic]) or "no variants"; a difficulty chip (a range "1-80" or choices "normal/expert"); ".iss" when the file hands the run to a LavishScript file. Hover shows the zone name and root/path.
    • Zones list empty messages tell apart: "no zone files loaded", "this root is empty - try test (4)", "nothing in this folder matches", "nothing matches the filter".
    • Queue header: "Queue (n)".
    • Queue rows: label (zone name + variant), and grey sub-text - "diff X" when a difficulty is set; "start at step N (named 3)" when a start point is set; otherwise "stopped at step N (stepId)" when there is a Resume point. While a list runs, a ▶ marks the row it is on.
    • Add-bar text: "Double-click a zone to queue it", or " as [Heroic]", or " — double-click to choose a variant".
    • Status line (the first that applies is shown): 1. orange "HELD inside the zone" - zone - press Resume to zone out; 2. orange "Instance Controller is PAUSED"; 3. while running: bold state (zoning in / launching / running), the zone or zone-in destination and current travel hop, "list r/t (loop)", the phase (enter / steps / wipe / exit) with "(wipe recovery w of max[, given up])", "/ stepId", and a note; 4. orange "END OF LIST - in progress"; 5.     Good to know¶

    • Closing the IC window ends the running list, exactly like pressing End. It does not just hide the window.
    • Run starts at the queue row for the zone you are standing in, otherwise at row 1. The highlighted row does not decide where Run starts.
    • Pausing IC does not pause OgreBot, and pausing OgreBot does not stop IC. A paused OgreBot with IC running is the normal way to move through a zone.
    • The Difficulty setting is saved on the row but a run does not use it yet.
    • When the window is short, the options scroll: scroll them down for At end of list and Zone file.
    • A failed zone stops the list and leaves the group in that zone so it can be looked at. No end-of-list action (guild hall, home, camp) runs.
    • A zone lost to a wipe is different: everyone is revived, the After a lost zone choice runs, and the list moves on.
    • End-of-list actions run only when the list completes or a safety check stops it (fewer than 10 free bag slots, someone left the group, or someone is dead). Never after End.
    • End cancels the end-of-list actions while they run. Anything not yet started never runs and an unfinished camp is stopped (the client is not closed); a trip to the guild hall or a Call to Home already under way finishes on its own. Closing the window does not cancel them.
    • Camp out camps the whole group, not just the IC character.
    • Zoning in always runs the zone file from the top. A named # or Resume point only applies when you are already standing in that zone.
    • Reload profile when the run ends (on by default) reloads the profile of every group member at the end of each zone. It also throws away any change you made by hand during the run.
    • The search text is not saved.
    • All IC settings (including Max wait per zone), the queue and the startup list live in one file, Scripts/OgreSave/EQ2/IC/panel.json, shared by every character on the PC. Each session loads it once and overwrites it on every change.
    • Refresh (Zone lockouts) does not read the lockout table straight away. It is re-read the next time a zone-in needs it.
    • Add defaults appends the shipped rows again, so pressing it twice gives duplicates. Reset to defaults and both Clear buttons ask no confirmation.
