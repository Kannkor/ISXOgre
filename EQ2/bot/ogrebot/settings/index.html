    Settings¶

    OgreBot is in beta testing. Looking for OgreBot Classic? Click here.

    Settings holds the master controls for what the bot is allowed to cast. Column 1 switches whole groups of the Cast Stack off (buffs, heals, cures, combat arts, items, and so on), and holds a few overrides: treating every target as named, the line-of-sight check, and item zone limits. Column 2 sets the area-attack rules (the Smart CAs minimum target counts, plus the "Dynamic Ignore" boxes, which are not saved and which scripts tick and untick during fights) and the per-category bans, such as no stuns or no roots. Column 3 controls Heroic Opportunities (HOs): which HO steps this character does, how it aims them, Heroic Surge, and which HO-icon abilities the normal rotation must leave alone. Column 4 limits threat abilities, but only when the bot picks an ability for a script, a command or an HO. The normal Cast Stack ignores column 4.

    Settings covers cures and combat behaviour. Column 1 controls cures: switching group or single-target cures off, limiting cures to chosen types (arcane, elemental, noxious, trauma), and drinking cure potions automatically. Columns 2 and 3 cover how the bot fights: camp spot, assisting, facing the mob, melee and ranged auto-attack, moving behind, in front or into melee range, turning attack off, sending the pet and mercenary, Bulwark of Order, NPC cast monitoring, raid and heroic encounter setups, the stun checks and the Destiny of Velious (DoV) raid debuff. Column 4 holds the on/off switches for other OgreBot tabs: Chat Events, Spawn and Despawn Events, Announce, Consume Items, Aliases and Ability Tracker. Several boxes here are saved but have no effect yet; each is marked 'Not active yet'.

    Settings covers the bot's everyday conveniences outside combat. 'Pop up windows' decides which game pop-ups it answers for you: loot windows, looting corpses and chests, group invites, rezzes, zone-in lockout prompts, raid ready checks, dungeon finder prompts and quest offers. 'On Load' covers what happens when a profile loads: opening the On Screen Assistant and OgreMCP, and checking ability research. 'On Zone' covers zone-in behaviour, such as the list of available encounter setups and auto-sharing missions. 'Unorganized' holds the rest: native auto-follow, flying with the leader, Quest Compare and the automatic Overseer. About a third of the boxes on this tab are saved but have no effect yet; each is marked 'Not active yet'.

    Cast Stack (1 of 5)¶

    Option What it does Default
    Disable Cast Stack(CS) Nothing on the Cast Stack tab is cast: no buffs, heals, combat arts, items, cures or anything else from your list. Cures that another player asks you for, and requested group cures, still go out.
    The Do HO feature can tick this for the character it picks to run HOs, then put it back afterwards.    		 off
    Disable CS_Buffs Cast Stack entries set as Buff or Non-Combat Buff are skipped, for abilities and items alike. off
    Disable CS_Cure Cast Stack entries set as Cure are skipped, and so is any Cast Stack ability the game marks as a player cure, whatever type it was entered as. The bot also stops choosing cures when a script or command asks for an ability or when it picks an HO ability, and the Other tab's 'cure while stunned' feature is switched off. Cures that someone calls for still go out.
    The Enable/Disable Cures commands tick and untick this box.    		 off
    Disable CS_CureCurse Cast Stack entries set as Cure Curse are skipped.
    Curse cures that someone calls for are handled separately and still go out.    		 off
    Disable CS_Heal Cast Stack entries set as Heal are skipped. off
    Disable CS_PowerHeal Cast Stack entries set as Power Heal are skipped. off
    Disable CS_Res Cast Stack entries set as Res (resurrect another player) are skipped. off
    Disable CS_Combat Cast Stack entries set as Combat are skipped. These are the in-combat-only entries, such as combat buffs and wards. off
    Disable CS_CA Cast Stack entries set as plain CA (combat art) are skipped. Entries set as Named CA or Non-Named CA are not affected. off
    Disable CS_NamedCA Cast Stack entries set as Named CA (named combat art) are skipped. off
    Disable CS_NonNamedCA Cast Stack entries set as Non-Named CA (non-named combat art) are skipped. off
    Disable CS_Debuff Cast Stack entries set as plain Debuff are skipped. Named Debuff entries are not affected. off
    Disable CS_NamedDebuff Cast Stack entries set as Named Debuff are skipped. off
    Disable CS_Items Every item entry on the Cast Stack is skipped (clickies, adornments and so on), whatever its type. Abilities still cast. off
    Ignore Item Zone Restrictions Normally the bot skips an item whose effect only works in certain zones (for example 'only in a Rage of Cthurath raid or Untold zone') when you are somewhere else. Tick this to use such items everywhere.
    The zone list comes from ZoneExpansions.json: the shipped copy plus your own custom copy.    		 off
    Force NamedCA Every target counts as a named mob. Entries that need a named target fire on everything, and entries that need a non-named target stop firing.
    It does not change which Disable CS_ box applies to an entry.    		 off
    Disable Ability Collision Checks The Cast Stack stops checking line of sight to the target, and to your pet, before casting. Abilities go out even through walls, as long as the range is fine.
    Mostly for scripted fights where the game allows casts the line-of-sight check would block.    		 off
    Disable Pre-Cast tab Nothing on the Pre-Cast tab fires (the rules that cast one ability before another).
    Do HO ticks this for the group while it runs and restores it afterwards.    		 off
    Disable Post-Cast tab Nothing on the Post-Cast tab fires (the rules that cast one ability after another).
    Do HO ticks this for the group while it runs and restores it afterwards.    		 off

    Cast Stack (2 of 5)¶

    Option What it does Default
    Encounter Smart CAs An encounter-wide attack is only used when the linked encounter has at least the number of mobs set in 'Targets for Smart Encounters' on the Setup tab (2 if blank). A single mob never qualifies. Untick it to use encounter attacks on anything.
    A Cast Stack entry can override this with its own ignore-encounter setting or a count of 1.    		 off
    Dynamic Ignore Encounter CAs While ticked, the bot casts no encounter-wide attacks: not from the Cast Stack, not from the Pre/Post-Cast tabs, not when it picks an interrupt, and not when a script asks for an ability. Neither Smart CAs nor an entry's own setting can override it.
    Meant for scripts. The Disable AEs (area effects) command and encounter files tick and untick it during a fight.    		 off (not saved; clears on reload)
    AE Smart CAs A point-blank or targeted area attack is only used when at least the number of mobs set in 'Targets for Smart AEs' on the Setup tab are in range (2 if blank). Untick it to use them at any count.
    A Cast Stack entry can override this with its own ignore-area-effect setting or its own count.    		 off
    Dynamic Ignore PBAE CAs While ticked, the bot casts no point-blank or targeted area attacks: not from the Cast Stack, not from the Pre/Post-Cast tabs, not when it picks an interrupt, and not when a script asks for an ability.
    Meant for scripts. The Disable AEs (area effects) command and encounter files tick and untick it during a fight.    		 off (not saved; clears on reload)
    Dynamic Ignore Items While ticked, every item entry on the Cast Stack is skipped. It works like Disable CS_Items, but it does not touch your saved setting.
    Meant for encounter scripts.    		 off (not saved; clears on reload)
    No Invis Casting Not active yet. off
    No Stuns The bot does not cast abilities the game marks as stuns: not from the Cast Stack, not when a script or command asks for an ability, and not when it picks an HO ability.
    The Enable/Disable Stuns commands tick and untick it. Items are never blocked by this.    		 off
    No Dazes The bot does not cast abilities marked as dazes, from the Cast Stack, script/command requests or HO picks. off
    No Stifles The bot does not cast abilities marked as stifles, from the Cast Stack, script/command requests or HO picks. off
    No Interrupts The bot does not cast abilities marked as interrupts, from the Cast Stack, script/command requests or HO picks.
    The Enable/Disable Interrupts commands tick and untick it.    		 off
    No Fears The bot does not cast abilities marked as fears, from the Cast Stack, script/command requests or HO picks. off
    No Dispels The bot does not cast abilities that dispel a mob's buffs, from the Cast Stack, script/command requests or HO picks. For mages it also stops the automatic Mortal Coil dispel.
    The Enable/Disable Dispells commands tick and untick it.    		 off
    No Roots The bot does not cast abilities marked as roots, from the Cast Stack, script/command requests or HO picks. off
    No Snares The bot does not cast abilities marked as snares, from the Cast Stack, script/command requests or HO picks. off
    No AE Blockers The Cast Stack skips abilities the game marks as AE (area effect) blockers. It only affects the Cast Stack. off
    Dynamic Ignore Counter CAs While ticked, the Cast Stack skips 'counter' abilities, mostly reactive stances that deal damage when you are hit.
