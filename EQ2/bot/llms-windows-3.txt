# Radar Types

> **:bulb: In game - the ? button on this window says**
>
> Picks which kinds of things the Radar draws. A lit button is shown; a dim one is hidden.
>
> **What you can do here**
>
> - **The top row**: **[all]**, **quest** (quest only), **qst npc** (quest NPCs) and **no name**. **The grid** under it: one button per type.
> - **Click a type** (npc, named, pc, pet, corpse, chest, door...) to show or hide it.
> - **other** covers anything not in the list.
> - **quest** (quest only) narrows **npc**, **named** and **nokill** to the ones that update one of your quests - a mob to kill or an object to click. Every other type (pc, special, chest...) follows its own button.
> - **qst npc** always shows NPCs with a feather (or a quest update / complete icon) - the ones the quest helper hails - even with **nokill** off or **quest** on.
> - **no name** shows or hides actors with no name - mostly junk, sometimes not.
> - **name** (bottom right) turns name cutting on and off: lit cuts every name on the radar to the number beside it (5 to start). Change the number in the box; it is kept while cutting is off.
> - **[all]** shows everything; when everything is on it reads **[none]** and hides everything.
>
> **Good to know**
>
> - Each click is saved straight away. Only the type choice is saved - other radar changes still wait for **Save**.
> - The dot on each button is that type's colour on the radar (change it under the radar's gear).
> - Open and close it with **types** on the radar.

**Open it:** Press **types** on the Radar's toolbar (open the radar first with `ogre radar`). Press types again, or the X, to close it.

## What it is for

Picks which kinds of things the Radar draws: mobs, named, players, pets, corpses, chests, doors and so on. Each button is one kind; lit means shown. Your choices are saved as soon as you click, so they are still there the next time you open the radar. It changes only what the radar shows, never what the bot does.

## Type buttons

The coloured dot on each button is the colour that kind is drawn in on the radar (change it in the radar's settings, Colours - by type).

| Control | What it does | Default |
|---|---|---|
| **[all] / [none]** | If anything is hidden, [all] shows every kind again. If everything is already shown, the button reads [none] and hides every kind, so you can then turn on just the ones you want. |  |
| **npc** | Mobs you can fight. | shown |
| **named** | Named mobs. | shown |
| **nokill** | NPCs you cannot attack, such as guards and merchants. | shown |
| **special** | Objects the game marks as special, usually things you can click. | shown |
| **pc** | Other players. | shown |
| **pet** | Pets that are not yours (your own pet is mypet). | shown |
| **mypet** | Your own pet. | shown |
| **merc** | Mercenaries. | shown |
| **corpse** | Corpses. | shown |
| **craft** | Crafting stations (forges, sewing tables and the like). | shown |
| **resource** | Harvest nodes. | shown |
| **chest** | Treasure chests. | shown |
| **door** | Doors. | shown |
| **other** | Anything that is none of the kinds above. | shown |
| **quest** | Narrows npc, named and nokill to the ones that update one of your quests - a mob to kill or an object to click. Every other type follows its own button. Saved like a type click. | off |
| **qst npc** | Always shows quest NPCs - a feather, or a quest update / complete icon, over a no-kill NPC (the ones the quest helper hails) - even with nokill off or quest on. The radar looks for them every 2 seconds, only while this is on. | off |
| **no name** | Actors with no name - mostly junk, sometimes not. Lit shows them, dim hides them. Saved like a type click. | shown |
| **name** | The button turns name cutting on and off; while lit, every name on the radar is cut to the number in the box (5 to start). The number is kept while cutting is off. Saved like a type click. | off, 5 |
| **Title bar close (X)** | Closes this window only. The radar keeps running. |  |



## What the window shows

- A lit button means that kind is drawn on the radar; a dim one means it is hidden.
- The top row holds the four switches ([all], quest, qst npc, no name); the grid under it holds one button per type.

## Good to know

- Every click saves your type choice straight away. Only the type choice: any other change you made on the radar and did not save yet (zoom, dim, colours...) still waits for the radar's Save.
- You never appear on the radar as a dot you can hide; you are always the marker in the middle.
- Closing the radar (its X or `ogre end radar`) closes this window too.

# Nav

> **:bulb: In game - the ? button on this window says**
>
> The stop button for navigation. It pops up whenever the bot walks or flies your character somewhere, and closes when the trip ends.
>
> **What you can do here**
>
> - **STOP** - end the trip where you are. Safe to press at any time.
> - **Pause / Resume** - hold the trip and keep the route; Resume carries on from here.
> - The X (or `ogre end nav`) stops the trip and closes the window. To keep it out of the way, move or resize it.
> - Watch the progress bar, waypoint count and distance left. **Waiting for mesh** means the zone's map is still loading; the trip starts by itself when it is ready.
>
> **Good to know**
>
> - Pausing OgreBot does not stop a trip - use STOP (or `ogre nav stop`).
> - While nav is paused nothing else will move your character until you Resume or STOP.
> - `ogre nav -nopanel` stops it popping up; `ogre nav panel` opens it by hand.

**Open it:** It opens by itself whenever your character starts a navigation trip, whoever started it (you, Instance Controller, the travel router...), and closes when the trip ends. To open it by hand type `ogre nav panel`. `ogre nav -nopanel` stops it popping up; `ogre nav -panel` turns that back on and opens it.

## What it is for

The stop button for navigation. While the bot walks or flies your character somewhere along the navigation map, this small window shows how far along it is and gives you a big STOP and a Pause. Navigation keeps going while OgreBot is paused, so this window is how you stop it.

## Status

The top line is the state (Moving in green, Failed in red, Arrived highlighted, Stopped plain) and why. The bar and the line under it show the waypoint you are on out of the whole route, and the distance still to go. The next line names the navigation map loaded for this zone. A red note appears when the trip is paused, nav is switched off, or OgreBot is paused.

## Buttons

| Control | What it does |
|---|---|
| **STOP** | Ends the trip right where you are. The route is thrown away. It is safe to press at any time: if something else has since taken over moving your character, STOP leaves that alone.<br>*Greyed out when no trip is running.* |
| **Pause / Resume** | Pause stops walking but keeps the route, so Resume carries on from where you stopped without planning again. While paused, nav still holds the character: follow or the camp spot will not move it until you Resume or STOP.<br>*Greyed out when no trip is running. Turns yellow and reads Resume while paused.* |
| **Title bar close (X)** | Stops the trip and closes the window, the same as `ogre end nav`. Nothing hides the window while a trip goes on: move it or size it where you want it. |



## What the window shows

- State word: Moving, Planning (the route is being worked out, a little at a time so the game never freezes; the character waits until it is ready), Landing (coming down from flight), Waiting for mesh (the navigation map for this zone is still downloading; the trip starts by itself when it is ready), Arrived, Stopped (something ended the trip on purpose: you pressed STOP, or the bot that started the walk ended it), Failed (navigation could not get there, for example stuck or no route), or Idle.
- Reason, next to the state: why the trip is doing what it does, for example 'navmesh route', 'waiting for the navmesh', 'stuck', or 'OgreBot closed'.
- Bar and 'waypoint X of Y - N u to go': how far along the route you are, and the distance left in game units. 'waiting for the navmesh to land' while the map is still coming; 'no route' when idle.
- 'mesh <zone> - N polys': the navigation map in use. 'no mesh loaded yet (loads on the first trip in a zone)' is normal before your first trip in a zone.
- Red notes: 'Paused here. The route is kept - Resume carries on from this point.' / 'Nav is switched OFF - `ogre nav -on`' / 'OgreBot is paused. This trip keeps going; STOP ends it.'

## Good to know

- Pausing OgreBot does NOT stop a navigation trip. Use STOP here, or type `ogre nav stop`. `ogre end nav` (or the X) stops the trip and closes this window.
- The window closes itself as soon as a trip ends, so you rarely see Arrived, Stopped or Failed in it. The console says how the trip ended.
- While nav is paused it keeps control of your character, so nothing else (follow, camp spot) will move it until you Resume or STOP.

## Points of interest and paths

A point of interest is a name you give a spot in a zone. A path is a saved list of spots to walk in order. Both are kept in the [Points of Interest and Paths window](paths.md): type `ogre paths`.

- A point of interest's name works wherever a location does in that zone: `oc !c -NavTo igw:${Me.Name} bell`, `oc !c -ChangeCampSpot igw:${Me.Name} bell`, and `-TravelMesh` to reach it from another zone.
- `oc !c -Path igw:${Me.Name} <name>` walks a saved path, and `oc !c -PathStop igw:${Me.Name}` stops it. It runs while OgreBot is paused, waits through a fight or a death, and zoning ends it.
- The [Auto-Hunt tab](../ogrebot/auto-hunt.md) picks a path to walk between pulls.

# Travel Helper

> **:bulb: In game - the ? button on this window says**
>
> Lists where a travel map can take you, then sends your group to the one you pick.
>
> **What you can do here**
>
> - **Fast Travel, Wizard Spire, Druid Rings, Bell** - this character opens that map (standing by the spire, ring or bell for those three), reads every destination and lists them. The map closes again.
> - **Open Travel Map** - lists the travel map you already have open, and leaves it open.
> - **Double-click a destination**, or select it and press **Travel** - everyone in the Master Control Panel's For Who window travels there. Each opens their own map and clicks that exact destination.
> - **Filter** - type part of a name to shorten the list.
> - **Keep list open after travelling** - leave this window up after you pick.
>
> **Good to know**
>
> - If the For Who window was never set, everyone travels.
> - Spire, ring and bell travel needs that object within reach of every character you send.
> - With Open Travel Map, everyone you send must have their own map open too.

**Open it:** Type `ogre travel`. Add a method to open it straight on that list: `ogre travel fast`, `ogre travel spire`, `ogre travel druid`, `ogre travel bell` or `ogre travel map`. A Master Control Panel button migrated from the old bot's Travel Helper opens it too. `ogre end travel` (or the window's X) stops a list that is being read, closes the map it opened, and closes the window.

## What it is for

The Travel Helper sends your group somewhere without anyone typing a zone name. Pick how to travel and this character opens that travel map, reads every destination it offers and lists them here. Double-click one and every character in the For Who window travels there: each opens its own map and clicks that exact destination. It is the old bot's Travel Helper window, rebuilt.

## Choosing how to travel

Each button makes this character open that kind of travel map and list it. The map closes again once it has been read, except for Open Travel Map.

| Control | What it does |
|---|---|
| **Fast Travel** | Opens the Fast Travel map and lists its destinations. Works anywhere you can fast travel from. |
| **Wizard Spire** | Clicks the wizard spire next to you and lists where it goes. You must be standing by a spire.<br>*Nothing is cast: it uses the spire in the world, the same as the old bot.* |
| **Druid Rings** | Clicks the druid ring next to you, or in a guild hall the portal druid, and lists where it goes. |
| **Bell** | Clicks the bell or globe next to you and lists where it goes. |
| **Open Travel Map** | Lists the travel map you already have open, and leaves it open.<br>*Everyone you send to must have their own travel map open too - this one opens nothing for them.* |

## Picking a destination

The list shows every destination the map offers, in the map's order. Type in the filter box to narrow it.

| Control | What it does |
|---|---|
| **Filter destinations** | Shows only the destinations whose name contains what you type. |
| **Destination list** | Click a destination to select it. Double-click it to travel there. |
| **Travel** | Sends everyone in the For Who window to the selected destination.<br>*Each character opens its own map and clicks exactly that destination - the whole name, not part of it.* |
| **Keep list open after travelling** | Leaves this window open after you send the group. Off, it closes once you pick. |

## What the window shows

- Sends to: who a pick goes to and how, read from the Master Control Panel's For Who window.
- Opening the map and reading it...: this character is opening the map. The buttons are greyed out until it finishes.
- Could not list: why the map could not be read, for example nothing to click is in reach.
- The line under Sends to: what the last pick sent, and to whom.

## Good to know

- The For Who window decides who travels. If it was never set, everyone travels.
- Wizard Spire, Druid Rings and Bell need the spire, ring or bell within reach of every character you send. Anyone too far away stays where they are.
- Picking a destination with several drop-off points or instances uses the same choice as the travel commands: the last one offered.

# Points of Interest and Paths

> **:bulb: In game - the ? button on this window says**
>
> Names spots in the zone you are in, and saves walks through them. They are kept on this PC, for every toon.
>
> **What you can do here**
>
> - **Add** - save a point of interest at x, y, z. Leave those blank to use where you stand. **My Loc** fills them in for you.
> - **Remove / Rename** - change a point of interest of your own.
> - **New / Delete** - make or drop a path. A zone can hold as many as you like.
> - **Add / Insert / Remove / Clear** under the point list - build the path. Add goes on the end, Insert goes above the selected point. A point is a point of interest or x,y,z.
> - **Drag a point** to move it in the list.
> - **Nav / Camp spot** - how the toon walks that path. **Loop** starts it over after the last point.
> - **Start / Stop** - walk the path on this box.
> - **Import** - bring this zone's old AutoHunt path across from OgreBot Classic.
>
> **Good to know**
>
> - A point of interest's name works wherever a location does in this zone: `-ChangeCampSpot`, `-TravelMesh`.
> - A shipped point of interest cannot be removed or renamed. Adding your own of that name overrides it.
> - Start stops with a line if a point cannot be found, before anything moves. Zoning ends a walk.
> - The first time you enter a zone with an old AutoHunt path, it comes across by itself as a path called Default. Nothing you already have is overwritten, and what you delete does not come back unless you press **Import**.
> - The Auto-Hunt tab picks one of these paths to walk between pulls, and its **Edit** button opens that path here. So does `ogre paths <path>`.
> - A walk under way keeps the points it had when it started. Stop and Start walks the new order.

**Open it:** Type `ogre paths`. To open it on one path, type `ogre paths <path>` or press **Edit** beside the path picker on the Auto-Hunt tab of OgreBot. `ogre end paths` or the window's X closes it. A path being walked goes on.

## What it is for

This window holds the named spots and the saved walks of the zone you are in. A point of interest is a name for a spot: the name then works wherever a location does in this zone, such as `-ChangeCampSpot`, `-NavTo` and `-TravelMesh`. A path is a list of points that a toon walks in order, and a zone can hold as many paths as you like. Both are kept on this PC, for every toon, and everything here also has a command for scripts.

## Zone and Import

The top line names the zone everything below belongs to. While you are zoning, or while the travel data loads, it says why the lists are empty.

| Control | What it does |
|---|---|
| **Import** | Brings this zone's saved Auto-Hunt route across from OgreBot Classic, even if that was done before. A name or path already here is never overwritten.<br>*This also happens by itself, once, the first time you enter a zone that has an old route.* |



## Points of interest

Click a row to fill in the name, the x, y, z boxes and the path's Point box.

| Control | What it does |
|---|---|
| **Name (box)** | The name of the point of interest to add. It cannot be empty, hold a comma or read as a number, because it would then read as a location. |
| **x / y / z (boxes)** | Where the point of interest is. Leave all three blank to use where you stand. |
| **My Loc** | Fills x, y and z from where you stand, so you can change them before you add. |
| **Add** | Saves the point of interest in this zone. A name you already have moves to the new spot. A name the bot ships with is overridden by yours, and it stays yours until you remove it. |
| **Remove** | Removes the selected point of interest of yours. If it was overriding a shipped one, the shipped one is back.<br>*Greyed out for a shipped point of interest.* |
| **New name (box)** | The new name for Rename. |
| **Rename** | Renames the selected point of interest of yours. A name another point of interest here holds is refused, and a path that used the old name does not follow it.<br>*Greyed out for a shipped point of interest.* |



## Paths

Click a path to select it. Its points show in the list under these buttons.

| Control | What it does | Default |
|---|---|---|
| **New path name (box)** | The name of the path to make. |  |
| **New** | Makes an empty path in this zone. It walks by Nav and does not loop until you change it. A name already here is refused, so a slip cannot empty a path. |  |
| **Delete** | Deletes the selected path.<br>*No confirmation.* |  |
| **Walk by Nav / Camp spot** | How the toon walks this path. Nav goes to each point on the navigation map. Camp spot moves the camp spot to each point and lets the leash bring the toon. | Nav |
| **Loop** | Starts the path over at the first point after the last, until something stops it. A path of one point goes there and finishes, and so does a loop whose points are all where you stand. | off |
| **Start** | Walks the selected path on this box, in place of any walk under way. Every point is checked first: one that cannot be found stops it with a line, before anything moves.<br>*It runs while OgreBot is paused, and OgreBot must be open.* |  |
| **Stop** | Stops the walk on this box. The toon stands where it is. |  |



## Points of the path

The selected path's points, in the order they are walked. Drag a row to move that point: a line shows where it lands, the points between shift one place, and a plain click still selects the row.

| Control | What it does |
|---|---|
| **Point: a name, or x,y,z (box)** | The point to add: the name of a point of interest, or x,y,z. A name is looked for when the path starts, so its point of interest can come later. |
| **Add** | Adds the point to the end of the selected path. |
| **Insert** | Puts the point in above the selected point, which moves down one. The new point is then the selected row.<br>*Greyed out until a point is selected.* |
| **Remove** | Removes the selected point. A path that passes the same point twice keeps the other one. |
| **Clear** | Takes every point off the selected path. The path stays, with its Walk by and Loop settings.<br>*No confirmation.* |



## What the window shows

- 'shipped' or 'yours' beside a point of interest: shipped ones come with the bot and cannot be removed or renamed.
- 'at an actor' in place of a location: a shipped point of interest that names an actor, not a spot. It has no location of its own, so a path or a location verb cannot use it.
- Green text: the path being walked and the point it is walking to, with a line under the lists saying the same. After an edit the line still reads the walk, and no row is green if the list no longer holds that point at that place.
- The last line of the window: the last thing the bot said about a point of interest or a path, a refusal included.

## Good to know

- Everything here is for the zone you are in. Another zone has its own points of interest and paths.
- Zoning ends a walk, with a line. So does a point the toon cannot get to, and closing OgreBot.
- A walk waits while something else has the toon and goes on from the same point: a fight, a death until a res or a revive in the same zone, a pull of Auto-Hunt, a movement block, the Pause of the Nav window. The last line of this window says what it is waiting for.
- The first time you enter a zone that has an old OgreBot Classic route, it comes across by itself as a path called Default, and one line says how many points came and which did not. What you delete afterwards does not come back unless you press Import.
- A camp spot walk needs 'Allow Camp Spot' on for that toon. A walk that finishes leaves the camp spot at its last point, and the camp spot you had before does not come back. Stop clears the camp spot, and the toon stands where it is.
- The Auto-Hunt tab picks one of these paths to walk between pulls, and it only walks: it never flies one. Start here walks a path with no hunting, and that walk may fly. Hunting does not end that walk, and the walk waits while Auto-Hunt works a pull. Auto-Hunt pulls nothing in the air, so a walk that flies is never held for one.
- A walk under way keeps the points it had when it started. Change the path as you like: Stop and Start walks the new order, and so does the next pick on the Auto-Hunt tab.
- A move or an insert is refused with a line if another box changed the list since you saw it, so a point never lands in the wrong place.
- A path or a point of interest saved on one box shows on every other box on this PC within a second or so.

### For scripts

The same things have commands: `OgreBotAPI.POI` for points of interest and `OgreBotAPI.Paths` for paths. In OgreConsole, `-POI_Add` saves a point of interest, `-Path` walks a path and `-PathStop` stops it. The verbs that change a path take a for-who first: paths are shared by every box on the PC, so name one box and one line changes the path once. `OgreBotAPI.Paths:InsertPoint` and `MovePoint` take a place counted from 1. `ISXOgreEQ2.Paths:Open` opens this window, on a path if you name one (`ISXOgreEQ2.Paths:Open[North Loop]`): any panel or script that wants a path edited calls that.

# Safe Fall Trainer

> **:bulb: In game - the ? button on this window says**
>
> Trains Safe Fall for you: mount, fly up, dismount, fall, land, remount, repeat. Every landing is a skill-up chance.
>
> **What you can do here**
>
> - **Flight time** - how long each climb lasts, in ticks (10 ticks = 1 second, 5 to 600).
> - **Start** - target yourself, mount up and begin. It is dimmed, and does nothing, while a run is going or you are not in the world.
> - **Stop** - end training where you are.
> - Watch the phase, rounds, falls trained and ramps as it runs. "started at" is the flight time this run began with.
>
> **Good to know**
>
> - Clear your target to stop it; any target (even a mob) keeps it going.
> - Every 100 rounds the flight grows by half a second, up to 25 seconds.
> - Zoning ends the run. Do not mix it with follow, nav or a camp spot.

**Open it:** Type `ogre safefall panel`. `ogre safefall on` (or `ogre safefall on 45` for a 4.5 second flight) starts training without the window, `ogre safefall off` stops it, `ogre end safefall` (or the window's X) stops it and closes the window, and a bare `ogre safefall` prints its status in the console.

## What it is for

Trains your Safe Fall skill for you. It targets you, mounts up, then repeats: fly straight up for the flight time, dismount so you fall, wait until you land, remount, and go again. Every landing is a Safe Fall skill-up chance. Every 100 rounds the flight gets half a second longer so the falls get higher. It runs until you stop it, untarget yourself, or leave the world.

## Start, Stop and flight time

| Control | What it does | Default |
|---|---|---|
| **Start** | Starts training with the flight time in the box: targets you, mounts up, waits 7 seconds, then begins the climb-and-fall loop.<br>*Dimmed, and does nothing, while training runs or while you are not in the world. To change the flight time, press Stop first.* |  |
| **Stop** | Stops training and stops the climb. You stay wherever you are (mounted or not).<br>*Dimmed, and does nothing, when nothing is running.* |  |
| **Flight time (… ticks)** | How long each climb lasts, in ticks: 1 tick is 0.1 second, so 30 is 3 seconds (shown to the right). Allowed 5 to 600.<br>*A number outside 5 to 600 turns the box red and Start refuses. The box follows the running value until you type in it; empty it to hand it back.* | 30 ticks (3.0 s) |



## Status

Read-only. It updates four times a second.

## What the window shows

- Pill next to SAFE FALL: 'running' (green), 'idle', or 'not in world' (red).
- Phase: what it is doing now - starting, flying up, stopping climb, dismounting, falling (1/2), falling (2/2), landed, remounting, idle.
- Round: how many rounds since the last flight-time increase, out of 100.
- Falls trained: completed climb-and-fall rounds since you pressed Start.
- Ramps taken: how many times the flight time has grown this run.
- In world / Target / Flying: yes or no. Target means you have something targeted (training stops when you have nothing targeted). Flying means you are flying on your mount.
- Deadline: the current flight time in milliseconds. It never goes above 25000 (25 seconds), even if the ticks keep growing.
- The long line: flight ticks and seconds, the flight time this run started at ('not started yet' before the first Start), the ramp rule, ramps so far and falls so far.
- The note box: the last thing that happened, for example 'dismounted - falling', 'self-target lost', 'left the world'.

## Good to know

- The quickest way to stop is to clear your target: training ends as soon as you have nothing targeted. Clicking a mob does not stop it - any target keeps it going.
- Zoning, camping or going to character select ends the run; it does not pick up again afterwards.
- It does not check whether something else is moving your character. Do not run it together with other movement (follow, nav, camp spot).

# SmartLoot

> **:bulb: In game - the ? button on this window says**
>
> Decides who gets each drop from a Leader Only loot window. You list the items, a cap for each, and which characters collect them.
>
> **What you can do here**
>
> - **Add items** by name, or from the loot window, your bags, or an examine window.
> - **Set a cap** per item: Never, a Limit (up to N each), or unlimited.
> - **Tick a character** to say they collect an item; the number is how many they already have.
> - **+ Character** adds one column by name; **+ Group** and **+ Raid** add a column for everyone in your group or raid who does not have one yet (mercenaries left out). The number on the button is how many it would add.
> - **Save** writes your changes. **Revert** throws them away. Running `ogre smartloot` again while this is open changes nothing.
>
> **Good to know**
>
> - A drop goes to the lowest group or raid slot that collects it and is still under the cap.
> - It only runs on a Leader Only loot window, and only when the OgreBot Loot tab has both **Enable options below** (Leader Only) and **Smart Loot** ticked.
> - The x on a character column deletes that character's whole entry when you Save.

**Open it:** Type `ogre smartloot` or `ogre sl`. If the window is already open, this does nothing, and your unsaved changes stay. Scripts can use `OgreBotAPI.Loot:Config[all]` to open it and `OgreBotAPI.Loot:Config[all,close]` to close it.

## What it is for

SmartLoot hands out drops from a Leader Only loot window. It decides who gets each item from per-item caps and a per-character list of what each character collects and how many they already have. This window edits that data: the caps and, for each character, a checkbox plus a have-count. When a Leader Only window opens, SmartLoot goes through the raid (or group), lowest slot first. It gives the item to the first character who collects it and is still under the cap, then adds 1 to their have-count.

## Save and Revert

| Control | What it does |
|---|---|
| **Revert** | Throws away every unsaved edit and reloads the caps and the character list from disk. Items added this session and empty character columns disappear.<br>*Greyed out when there are no unsaved changes. Also use it after you fix a damaged file (see the red banner).* |

Your edits are combined with the file as it is now, so have-counts SmartLoot added while the window was open are kept. ## What the window shows

- Title 'SmartLoot — X': X is the character this session is logged into. That column's header is highlighted and is always the first column.
- Dot and 'unsaved changes': orange means some edit is not saved yet. Save and Revert are enabled only then.
- Red banner: appears when a loot file could not be read. It reads '⚠ CharacterLootData.json (ledger) / ItemLootCustomData.json (custom caps) is unreadable — Save is blocked from overwriting it. Fix or remove the file, then Revert.'
- Info text: 'showing X of Y characters' when any column filter is on, plus notes such as 'only Brutus (click the name again to show all)', 'not grouped - showing you', or 'no team named "X"'.
- Rows: items with a custom cap, plus every item any character collects, plus items added this session. It never shows the whole base list. Rows are sorted by name, ignoring case.
- Item column: the item name (hover for the full name), plus the Group and Raid mini buttons.
- Cap column: the segmented control shows the effective cap (custom, else base, else 0). A grey 'default' means the value comes from the base file. An orange 'default N' plus a 'reset' link means a custom value overrides base N (an unlimited base shows as ∞). Nothing extra appears for a custom-only item.
- Character cells: the checkbox means 'this character collects this item'. The number is its have-count.

It goes through the raid (or group), lowest slot first, checking the item and then its adornments. The first member who collects it, whose cap is not 0, and who is under the cap (or the cap is unlimited) gets it. Their have-count goes up by 1. An item with no cap in either file counts as Never.

## Good to know

- The × on a character column deletes that character's whole SmartLoot entry when you Save: every item they collect and every have-count. It is not a hide, and there is no confirmation.
- The × on an item row unmarks every character from collecting that item. If the item is in the shipped base list, its base cap still applies.
- The scope row (That character / Whole group / Whole raid / Everyone in the list) changes who every checkbox and have-count edit hits. It resets to 'That character' each time the window opens. 'Everyone in the list' also changes characters hidden by the column filters.
- A group or raid edit made while you are not grouped or not in a raid changes nothing. The only message is in the console.
- The per-row Group and Raid buttons always act on your group or raid, whatever the scope row says.
- Sync from inventory only updates the character this session is logged into. It also marks you as collecting every capped item you hold, and never lowers a count for an item you no longer have.
- A newly added character column is not saved until at least one item is checked for it.
- An item with no cap anywhere counts as Never, so nobody gets it even if their box is checked.
- Using reset, or typing a Limit equal to the base cap, can make a row disappear if nobody collects the item.
- Messages from Add, From loot window, From inventory, From examine and group/raid edits go to the console, not the window.
- SmartLoot only hands out items when the OgreBot Loot tab has both 'Enable options below' (Leader Only) and 'Smart Loot' ticked. If they were never set they count as off; the Instance Controller ticks them for the group when it runs a zone.

# Potency / Crit Bonus / Fervor

> **:bulb: In game - the ? button on this window says**
>
> Records your Potency, Crit Bonus and Fervor during fights and shows averages, lows, highs and time at cap. It only measures; it changes nothing.
>
> **What you can do here**
>
> - **Stop / Start** - pause and carry on recording. The numbers are kept.
> - **Reset** - throw away every number and start the session over.
> - **Hover** a figure for more detail.
>
> **Good to know**
>
> - **At cap** is when the game says the stat is capped. **At peak** is time at your best value this session.
> - Closing the window stops recording, the same as `ogre end potcb`. **Stop** stops recording and keeps the window open.

**Open it:** Type `ogre potcb` (or `ogre cbpot`). This opens the window and starts recording. `ogre end potcb` (or the window's X) stops recording and closes it; `ogre potcb off` does the same while it is recording.

## What it is for

This window records your Potency, Crit Bonus and Fervor several times a second and shows how they behaved during your fights: the average, lowest and highest value in combat, how much of the time the game said the stat was capped, and how much of the time you were at your best value. It is a measuring tool only; it does not change what the bot does. All the averages are weighted by time, so a slow frame does not count more than a smooth one.

## Start, Stop and Reset

The green text on the left says 'sampling every 200 ms' while recording, or 'stopped'.

| Control | What it does | Default |
|---|---|---|
| **Start / Stop** | Stop pauses the recording. Start carries on from where it stopped; the numbers so far are kept. The time while stopped is not counted. | Stop (recording starts when the window is opened) |
| **Reset** | Throws away every number and starts the session over. Recording keeps going if it was on.<br>*No confirmation.* |  |

## The table

One row per stat. Hover most numbers for more detail.

## What the window shows

- Now: the value right now.
- Combat avg: your average while in combat (hover for how long you have been in combat). Out of combat you are usually unbuffed, so combat is what matters.
- Min / Max: the lowest and highest value seen in combat.
- At cap: the share of combat time the game's own tooltip said the stat had reached its cap.
- At peak: the share of combat time you were at (or within 0.1% of) the highest value seen this session. When a new highest value appears, this starts again from zero, so it is optimistic early on.
- Spread: a small bar chart of your combat time split into ten steps from 0% to 100% of your peak. The right-most (green) bar is time spent near your peak. Hover a bar for its exact share. Like At peak, it starts again when a new peak appears.
- Peak: the highest value seen this session, in or out of combat (hover for how long ago it was set).
- All avg: the average over the whole session, in and out of combat (hover for the overall min and max).
- 'no combat time yet': recording, but you have not been in combat. 'no samples yet': the stat has not been read yet.
- Footer: how long the session has been recording and how much of it was in combat.

## Good to know

- Closing the window with the X stops the recording, the same as `ogre end potcb`. Stop stops it and keeps the window open.
- Opening the window with `ogre potcb` always starts recording.
- Zoning is not counted as time, so a long zone-in does not inflate 'At peak'.
- The numbers are lost when the bot is unloaded; nothing is saved to a file.

# Level Transmuting

> **:bulb: In game - the ? button on this window says**
>
> Levels your Transmuting skill: buys cheap transmuter's stones from Barnaby Blunderbuss in Butcherblock and transmutes them, round after round.
>
> **What you can do here**
>
> - **Buy** sets how many stones to hold after each visit. Leftover stones are used first.
> - **round(s)** is the most visits one run makes. The run also stops when your skill is capped.
> - **Start** begins the run. **Stop** ends it. **Refresh** redraws the window.
> - **Buys** shows the merchant visits and how many stones they really added.
> - **Transmutes** shows how many stones were tried and how many really got used up. If any failed, it says why: the cast was refused, the ability never became ready, or the stone was still there afterwards.
>
> **Good to know**
>
> - Start pauses OgreBot for the run. When the run ends it resumes OgreBot, unless OgreBot was already paused.
> - Start opens the Persona window on Skills > General to read your skill. It closes it again when the run ends, however it ends.
> - Not next to Barnaby? The window tells you, and Start travels to him first, even with OgreBot closed. Stop ends the trip.
> - Each stone costs 1 Gnomish Currency Exchange, not coin. Without any, the buy adds nothing and the run stops and says so.
> - Only items named "Transmuter's Stone" or "Transmutation Stone" are ever transmuted.
> - A round that buys nothing, or transmutes nothing, stops the run, so a problem never repeats for every round.
> - Closing this window stops a run, the same as `ogre end leveltransmuting`. Stop stops it and keeps the window open.

**Open it:** Type `ogre leveltransmuting` (or `ogre lt`). Typing it again while the window is open just refreshes it. `ogre lt status` prints the status to the console instead. `ogre end leveltransmuting` (or the window's X) stops a run and closes the window; Stop stops it and leaves the window open.

## What it is for

A skill-up grinder for the Transmuting tradeskill. The bot buys Minor Lapis Lazuli Transmuter's Stones from Barnaby Blunderbuss in Butcherblock Mountains, transmutes them, and repeats until your Transmuting skill is capped or the round limit is reached. You do not have to stand next to him: if you are not within 10 of Barnaby, Start travels to him first, from another zone too. OgreBot is paused for the run, and the Persona window is opened on Skills > General to read your skill; when the run ends, however it ends, the window is closed again and OgreBot resumes if it was running. It only ever transmutes items whose name contains "Transmuter's Stone" or "Transmutation Stone" - nothing else in your bags is touched.

## Header and the stones-only notice

The dot is green while a run is going. Next to it is what the bot is doing right now.

## The readout

Merchant and Item are fixed - the tool only works with Barnaby and the Minor Lapis Lazuli Transmuter's Stone. Transmuting is your skill as last read from the Persona window (Start reads it, then it is read again at the start of each round, so it shows unavailable until a run has read it). Rounds counts the rounds started out of the most you allowed. Buys shows the visits to Barnaby and how many stones your bags really gained. Transmutes shows how many stones were tried and how many really got used up. Last is the latest thing that happened.

## Quantity and round limit

| Control | What it does | Default |
|---|---|---|
| **Buy** | How many stones you want to be holding when each visit to Barnaby is done. The bot only buys the difference, so stones left over from the last round are used first. 1 to 800.<br>*Locked while a run is going. It is a total to hold, not an amount added every round.* | 60 |
| **per visit, at most ... round(s)** | The hard stop: the most rounds one run will make. Each round is one visit to Barnaby. The run also stops earlier if the Transmuting skill is readable and capped. 1 to 500.<br>*If the skill cannot be read, the run cannot tell when you are capped and goes on until this limit.* | 20 |



## Start, Stop, Refresh

| Control | What it does |
|---|---|
| **Start** | Starts a run with the two numbers above. It pauses OgreBot and opens the Persona window on Skills > General to read your Transmuting skill. The run can also stop by itself - see Good to know below.* |
| **Stop** | Stops the run straight away, even in the middle of buying, travelling or transmuting. It closes the Persona window and resumes OgreBot if it was running before you pressed Start.<br>*Only active while a run is going.* |
| **Refresh** | Redraws the window with the latest numbers. It does not change anything, and it does not read the skill. |

## When the skill cannot be read

The bot reads your Transmuting skill from the Persona window, Skills > General, which Start opens itself. It reads it once when the window opens and again at the start of every round. If the window is closed during a run, the next round opens it again. ## What the window shows

- Dot and phase text (top right): green dot = running. Phase is one of idle, waiting for the world, opening the Persona window, travelling to the merchant, reading the Transmuting skill, looking for the merchant, buying, transmuting stones, BLOCKED - cannot transmute, stopped.

- Note about Barnaby (only while stopped): shown when you are not within 10 of him. It says you are not in Butcherblock Mountains, how far you are from him, or that he is not in view - and that Start will travel or walk to him first.

- Last: the latest step or the reason the run stopped, for example 'transmuting 60 stone(s)' or 'Transmuting is at its cap for this level'.
- Footer: a reminder that Start pauses OgreBot, opens the Persona window (Skills > General) and travels to Barnaby when you are not within 10, and that Stop, or the run ending any other way, closes the Persona window and resumes OgreBot if it was running.

- Closing the window stops a run, the same as `ogre end leveltransmuting`. Stop stops it and keeps the window open.

# Quest Compare

> **:bulb: In game - the ? button on this window says**
>
> Shows whether each member of your group is on the same step of a quest as you.
>
> **What you can do here**
>
> - **Auto compare**: every time one of your quests updates, the group is asked to compare it. Turn it on for one character per group.
> - **Compare again** asks about the last quest again, right now.
> - **Legend** (title bar) shows what each icon means.
>
> **Good to know**
>
> - Green tick = same step. Red cross = different step (their line is shown). Orange ! = does not have the quest. Grey ? = did not answer.
> - Ticking Auto compare here unticks it on the rest of your group.
> - The window pops up by itself when an automatic compare finds someone out of step.

**Open it:** Type `ogre questcompare` (or `ogre qc`). It also opens by itself when you tick Auto compare / Enable Quest Compare, and when an automatic compare finds someone out of step. `ogre end questcompare` closes it.

## What it is for

Checks whether everyone in your group is on the same step of a quest as you. One character is the reference. When its quest updates, it asks the rest of the group to compare their step with its own, and this window shows the answer: one row per group member with an icon. The comparison happens on each member's own session, so the character that is out of step also says so in its own console.

## Quest and summary line

# Craft Grandmasters

> **:bulb: In game - the ? button on this window says**
>
> Turns the (Master) spell scrolls in your bags into (Grandmaster) crafts, one craft per scroll.
>
> **What you can do here**
>
> - **All levels**, or untick it and set a recipe **Level** range.
> - **Also pull from Scroll Depot** withdraws matching scrolls from the depot first, in batches that fit your bags.
> - **Scan** shows what would be crafted. **Start** queues it and crafts it. **Stop** ends the run.
> - **Queue only** puts the recipes in Ogre Craft's queue and stops, so you can save the queue, check the materials or change it. It never uses the Scroll Depot, and the Craft window opens on the queue.
>
> **Good to know**
>
> - Each batch, and Queue only, empties Ogre Craft's setup queue before it adds its recipes, so anything already there is cleared, not crafted.
> - With the depot box ticked, Scan only looks in the depot; Start withdraws. Withdrawn scrolls are never put back.
> - It never walks - stand at the Scroll Depot for a depot run.
> - Closing the window (the X) or `ogre end craftgm` stops a run, then closes.

**Open it:** Type `ogre craftgm`. `ogre craftgm 131-135` opens it with that level range already filled in (it does not scan). `ogre end craftgm` stops a run and closes the window.

## What it is for

Turns (Master) spell scrolls into (Grandmaster) crafts. It looks through your bags for every spell scroll named '... (Master)', works out the matching '... (Grandmaster)' recipe, and queues one craft per scroll you hold. Then it starts the Ogre Craft queue and watches until it is done. You can limit it to a range of recipe levels, and it can first pull (Master) scrolls out of your Scroll Depot.

## Status readout

State is what it is doing (idle, reading your recipe book, opening / withdrawing from the Scroll Depot, scanning your bags, crafting). Level filter is the range in use. Admits shows how many found recipes the range lets through, e.g. '3 of 6 recipe(s) (4 of 9 craft(s)) [2 outside] [1 no level]' - orange when some levels could not be read. Queued, Crafted and Recipe book are the run's progress; Last is the latest message.

## Level range

| Control | What it does | Default |
|---|---|---|
| **All levels** | Ticked = craft every Grandmaster found, whatever its level. Untick to use the two level boxes.<br>*Nothing is sent when you tick it; the range is used the next time you press Scan or Start.* | on |
| **Level** | The lowest RECIPE level to craft (inclusive). 1 to 999.<br>*Only used when All levels is unticked. Locked while a run is going.* | 131 |
| **to** | The highest recipe level to craft (inclusive). 1 to 999.<br>*A range typed backwards (e.g. 135 to 131) is refused, not swapped.* | 135 |



## Scroll Depot

Once a Scan or Start has run with the box ticked (ticking it alone does not show it), a grey box shows the depot progress: which batch, how many (Master) scrolls the depot holds and how many your range admits, how many fit in your bags this batch, and how many were withdrawn.

| Control | What it does | Default |
|---|---|---|
| **Also pull from Scroll Depot** | Before looking in your bags, withdraw (Master) scrolls that your range admits from the Scroll Depot, as many as fit in your free bag slots. After crafting those it goes back for the next batch, until the depot has none left or nothing more fits.<br>*Stand next to the Scroll Depot - it never walks. Scrolls withdrawn and not crafted stay in your bags; it never puts them back. The setting stays as you left it for the next run.* | off |



## Scan, Start, Queue only, Stop, Refresh

| Control | What it does |
|---|---|
| **Scan** | Looks through your bags and fills the table with what the range would craft. It queues and crafts nothing.<br>*With Also pull from Scroll Depot ticked, Scan also opens the Scroll Depot and shows what a Start would withdraw - it withdraws nothing.* |
| **Start** | Scans, adds every admitted Grandmaster recipe to the Ogre Craft setup queue (one craft per scroll held), starts the craft queue and watches it to the end.<br>*Refused if an Ogre Craft run is already going. Each batch empties the setup queue just before it adds its recipes, so anything you queued yourself is not crafted with it. Recipes you have not learned are skipped and marked 'not in your recipe book'.* |
| **Queue only** | Scans, then replaces the Ogre Craft setup queue with every admitted Grandmaster recipe (one craft per scroll held) and stops. Nothing is crafted, and the Craft window opens on the queue so you can save it, check the materials or change it.<br>*Never uses the Scroll Depot, whatever the depot box says - it builds the list from your bags. Refused if an Ogre Craft run is already going. Recipes you have not learned are skipped and marked 'not in your recipe book'.* |
| **Stop** | Stops the run. If this window started the craft queue, that is stopped too; a craft run somebody else started is left alone.<br>*Only active while a run is going. The window stays open.* |
| **Refresh** | Redraws the window. It changes nothing. |
| **Title bar close (X)** | Stops a run and closes the window, the same as `ogre end craftgm`. |



## The scan table

One row per (Master) scroll found: the scroll, the Grandmaster recipe it becomes, how many you hold (= how many crafts), the recipe's level ('?' if it could not be read from your recipe book), and what happened to it: queued, not in your recipe book, outside the level range, or level could not be read.

## What the window shows

- Dot and phase (top right): green dot = running.
- Orange 'Recipe levels unavailable' note: shown when no level could be read for any scroll found; with a level range set, none of them will be queued.
- Rows marked 'outside the level range' or 'level could not be read' are not queued. With All levels ticked every row is admitted, even one with an unknown level.
- 'Nothing scanned yet - press Scan.' before the first scan; 'No (Master) spell scrolls found in your bags (N carried item(s) scanned).' when there are none.

## Good to know

- Each batch Start crafts empties Ogre Craft's setup queue first, so anything you had waiting there is cleared, not crafted. Stop never empties it.
- With the Scroll Depot box ticked, Scan only looks in the depot; Start withdraws. Withdrawn scrolls are never put back.
- Withdrawn scrolls that are not crafted (not learned, out of range) stay in your bags.
- It never walks: stand at the Scroll Depot for a depot run. If it is not nearby the run stops and does nothing (it does not quietly fall back to bags only).
- A range typed backwards (e.g. 135 to 131) is refused - the run does not start. A blank or 0 box is filled in for you instead (Level becomes 1, to becomes the Level value).
- The run has no time limit while crafting; use Stop if it is stuck.

# Crafting Mats

> **:bulb: In game - the ? button on this window says**
>
> Edits the shopping lists `ogre craftingmats` uses: the mats it pulls from the Harvesting Supply Depot and the fuel it buys.
>
> **What you can do here**
>
> - **Pick a list** (one per expansion) and a **category**.
> - **Change an amount** in its box, or remove a row with the x.
> - **Add an item**: type the name (or use **Item name via examine window**), set how many, then **Add to mats** or **Add to fuel**.
> - **+ new list** and **+ category** use the name in the item name box.
> - **Save** writes your changes; **Revert** throws them away (on a new list you never saved, it discards the list).
>
> **Good to know**
>
> - Amounts are how many to be holding, not how many to add.
> - Your changes go in your own folder; the shipped lists are never changed.
> - Removing a row from a shipped list stops that list getting future updates.
> - Closing the window keeps unsaved changes; switching to another list throws them away.
> - Closing the window also stops a depot pull that `ogre craftingmats` started, the same as `ogre end craftingmats`.

**Open it:** Type `ogre craftingmats` (or `ogre cmats`) with nothing after it. With options (e.g. `ogre craftingmats -sig -vov`) it RUNS instead: pulls those mats out of the Harvesting Supply Depot and buys the fuel. `ogre end craftingmats` (or the window's X) stops a depot pull that `ogre craftingmats` started and closes the window. From a script: `ISXOgreEQ2.CraftingMats:Open` / `:End`.

## What it is for

Edits the shopping lists that `ogre craftingmats` uses. Each list (one per expansion, e.g. vov = Visions of Vetrovia) has categories such as signature, daily or weekly, and each category has Mats (withdrawn from the Harvesting Supply Depot) and Fuel (bought from the Guild Fuel Merchant), each with the amount you want to be holding. Your edits are saved to your own folder; the shipped lists are never changed, and a Save is used by the very next run.

## Choosing a list

One button per list. A small badge says where it comes from: no badge = the shipped list, 'merged' = the shipped list with your changes on top, 'custom' = a list only you have.

| Control | What it does |
|---|---|
| **List buttons (cd, ka, mm, pop, vov, ...)** | Opens that list for editing. Unsaved changes to the list you were on are thrown away. |
| **+ new list** | Starts a new list of your own. Type its short name in the item name box first - that name is what you will type after `ogre craftingmats` to use it. The new list gets one category, 'all'.<br>*With the name box empty it only shows a message.* |



## Choosing a category

| Control | What it does |
|---|---|
| **Category buttons (signature, daily, weekly, all ...)** | Shows that category's Mats and Fuel below. An 'all' category is always used, whatever categories a run asks for. |
| **+ category** | Adds a category named whatever is in the item name box to this list.<br>*A run can only ask for signature, daily or weekly (and always uses 'all'), so a category with any other name is never used by `ogre craftingmats`. With the name box empty a message says where to type the name; a name the list already has just selects that category.* |



## Mats and Fuel

Left: materials withdrawn from the Harvesting Supply Depot. Right: fuel bought from the Guild Fuel Merchant. The number is how many you want to be HOLDING - a total, not an amount added each time.

| Control | What it does |
|---|---|
| **Quantity box on a row** | Changes that item's amount. It is applied when you press Enter or click away.<br>*0, blank or text is ignored and the old number comes back.* |
| **× (remove this row)** | Removes the item from this category.<br>*Removing something from a shipped list turns your saved copy into a full replacement (see below).* |



## Adding an item

| Control | What it does | Default |
|---|---|---|
| **item name** | The item's name, exactly as the game spells it (capitals do not matter). Also used as the name for + new list and + category. | empty |
| **Item name via examine window** | Copies the item name from the examine window you have open into the name box.<br>*Examine the item in game first; otherwise a red message says no examine window is open.* |  |
| **Quantity (next to the name)** | How many of the item to hold. | 1 |
| **Add to mats** | Adds the item to the Mats side of the selected category. If it is already there, its amount is replaced with the new one. |  |
| **Add to fuel** | Same, on the Fuel side. |  |



## Save and Revert

The grey text shows the folder your edits are written to.

| Control | What it does |
|---|---|
| **Revert** | Throws away unsaved changes and shows the list as it is on disk. On a brand-new list you have not saved yet, there is nothing on disk to go back to: Revert discards the new list and says so.<br>*Only active when there are unsaved changes.* |
| **Save** | Writes your changes to your own folder (OgreSave/EQ2/CraftingMats/custom) and reloads the lists, so the next `ogre craftingmats` run uses them. Only what you changed is written, so later updates to the shipped list still reach the rest. If your changes match the shipped list exactly, your file is deleted.<br>*Only active when there are unsaved changes.* |
| **Title bar close (X)** | Closes the window, and stops a depot pull that `ogre craftingmats` started (the same as `ogre end craftingmats`). Unsaved changes are kept: the next time it opens they are still there, with a reminder to Save or Revert. Without unsaved changes the list is read fresh from disk.<br>*`ogre craftingmats` while the window is already open does nothing.* |



## Removing a row from a shipped list

Your saved file can only ADD to or CHANGE a shipped list. The moment you remove a row (or category) that came with the shipped list, this orange warning appears: Save will then write the whole list as a full replacement ('noMerge'), and that list will no longer pick up future shipped updates.

## What the window shows

- Badges on list buttons: none = shipped, 'merged' = shipped plus your changes, 'custom' = your own list.
- Green line after Save: 'saved - only your changes were written, so shipped updates still reach the rest.' Red when something went wrong or after a replacement save.
- Orange warning: you removed a row, so Save will write a full replacement.

## Good to know

- Plain `ogre craftingmats` opens this window. Add options (like `-sig -vov`) to actually pull mats; `ogre craftingmats help` lists them. Each list or category is typed with its dash (`-cd -sig`, not `cd sig`).
- A list typed without a category pulls its signature line. A list with no signature line pulls its daily and weekly: `ogre craftingmats -ka` is Kunark's Ascending daily + weekly.
- A word that is not an option is ignored with a warning. A command with nothing but such words (a typo like `-sgi`) pulls nothing, and the warning lists the options.
- Amounts are totals to hold, not top-ups.
- Removing any row from a shipped list stops that list getting future shipped updates.
- Switching to another list throws away unsaved changes without asking. Closing and reopening the window keeps them.
- + new list and + category take their name from the item name box. A run only ever uses the signature, daily, weekly and all categories, so a category with another name does nothing.
- A new list is not in the list buttons until you Save it.
