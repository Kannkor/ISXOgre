== OgreBotAPI.IM ==

${OgreBotAPI.IM.EndWhenFinished}
  kind: member of OgreBotAPI.IM
  what: Whether -end is armed, so the Inventory Manager window closes itself once the work has been idle for about 1.5 seconds. Only the console arms it (the -end flag of an `ogre im` line); there is no method for it, and closing the window clears it.
  returns: bool: TRUE while -end is armed; FALSE otherwise.
  example: echo ${OgreBotAPI.IM.EndWhenFinished}

${OgreBotAPI.IM.IsOpen}
  kind: member of OgreBotAPI.IM
  what: Whether the Inventory Manager window is up on this session - the window is the session, so this is what a script waits on after starting it with -end. It reads FALSE when the UI host is not available, even while modes run from the console.
  returns: bool: TRUE while the Inventory Manager window really exists; FALSE when it is closed or could not open.
  example: echo ${OgreBotAPI.IM.IsOpen}

${OgreBotAPI.IM.IsRunning}
  kind: member of OgreBotAPI.IM
  what: Whether the Inventory Manager is doing work right now - a mode (depot, sell, destroy, tse, restock, trade, quiver), a chain of them, or a depot withdraw started anywhere. It is FALSE while the window sits open and idle and can be FALSE just before a mode starts, so to wait for work to finish poll IsOpen with -end instead.
  returns: bool: TRUE while any Inventory Manager mode or chain is working; FALSE when idle.
  example: echo ${OgreBotAPI.IM.IsRunning}

${OgreBotAPI.IM.Mode}
  kind: member of OgreBotAPI.IM
  what: The Inventory Manager mode working right now: depot, sell, destroy, tse, restock, trade, quiver or withdraw (a depot withdraw from anywhere). It reads chain when only a chain is busy between modes, and empty when idle.
  returns: string: the busy mode's name, "chain", or "" when nothing is running.
  example: echo ${OgreBotAPI.IM.Mode}

${OgreBotAPI.IM.Status}
  kind: member of OgreBotAPI.IM
  what: One line saying what the Inventory Manager is doing, the same line `echo ${OgreBotAPI.IM}` prints. It reads "closed", "open, idle", "open, running sell", "open, running withdraw" or "closed (running headless), running restock", with "; will close when finished (-end)" added while -end is armed.
  returns: string: the status line, such as "open, idle" or "closed".
  example: echo ${OgreBotAPI.IM.Status}

OgreBotAPI.IM:Chain[fw, words...]
  kind: method of OgreBotAPI.IM
  what: Prints what each -<mode> flag expands to. `reload` reads the chain defaults from disk again.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): reload. Optional.
  example: OgreBotAPI.IM:Chain[all,reload]

OgreBotAPI.IM:Close[fw]
  kind: method of OgreBotAPI.IM
  what: Closes the Inventory Manager window, clears a pending -end, and closes the merchant window unless a sell run is using it. It does not stop work that is running - use Stop for that.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:Close[${Me.Name}]

OgreBotAPI.IM:Console[fw, word]
  kind: method of OgreBotAPI.IM
  what: The window's activity log: always, running or never sets when the strip shows, and clear empties it. With no word it prints the setting and how many lines it holds.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg word (string): always, running, never or clear. Optional.
  example: OgreBotAPI.IM:Console[all,running]

OgreBotAPI.IM:Depot[fw, words...]
  kind: method of OgreBotAPI.IM
  what: Runs the depot mode, deposits into the nearest house or guild hall depots, and brings the window up; with no flags it runs the line saved on the Depot tab, or warns if nothing is saved. The words after it are read as one `ogre im` line, so `ogre im depot status` is `ogre im status`.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): The depot flags, one argument each, such as -harvest all -nearestdepot. `ogre im help` lists them. Optional.
  example: OgreBotAPI.IM:Depot[all,-harvest,all,-nearestdepot]

OgreBotAPI.IM:Destroy[fw, words...]
  kind: method of OgreBotAPI.IM
  what: The destroy mode: with no words, or flags first, it brings the window up and destroys what is on the destroy list; a name or an item id destroys that one item. The other first words are in the param.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): stop, status, reload, preview (or plan), list [all], add <name> or remove <name>; or flags; or an item. One argument each. Optional.
  example: OgreBotAPI.IM:Destroy[all,preview]

OgreBotAPI.IM:End[fw]
  kind: method of OgreBotAPI.IM
  what: Stops whatever the Inventory Manager is running and closes the window, the same as `ogre end im` and the window's X. It stops first, so a script polling IsOpen never reads FALSE while work is still going.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:End[all]

OgreBotAPI.IM:Examine[fw, box]
  kind: method of OgreBotAPI.IM
  what: Fills the named box of the window with the item in the open item examine window; you still pick the quantity and add it. It warns when no item examine window is open.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg box (string): restock or trade: the tab whose box it fills.
  example: OgreBotAPI.IM:Examine[all,restock]

OgreBotAPI.IM:Flags[fw, words...]
  kind: method of OgreBotAPI.IM
  what: Takes the words no other method spells: a line wholly of mode flags is a chain, run in that order, with -end to close the window when it finishes. Any other line goes to the depot parser, which says what it cannot read.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): The line, one argument each.
  example: OgreBotAPI.IM:Flags[all,-destroy,-tse,-end]

OgreBotAPI.IM:Help[fw]
  kind: method of OgreBotAPI.IM
  what: Prints the `ogre im` usage to the console: the depot flags, every other mode, chains, the queue and the settings.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:Help[all]

OgreBotAPI.IM:Open[fw]
  kind: method of OgreBotAPI.IM
  what: Opens the Inventory Manager window on the characters named; calling it while the window is up just refreshes it. If the UI host is not available it prints a warning and IsOpen stays FALSE.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:Open[${Me.Name}]

OgreBotAPI.IM:Pane[fw, words...]
  kind: method of OgreBotAPI.IM
  what: Builds the editor list for a tab and prints how many rows it holds: sell or destroy, destroy when no name is given. `sell reopen` opens the merchant again first if its window is shut, as the Sell list tab's Refresh button does.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): The tab name, then reopen for sell. Optional.
  example: OgreBotAPI.IM:Pane[all,destroy]

OgreBotAPI.IM:Probe[fw]
  kind: method of OgreBotAPI.IM
  what: Prints what the open depot's tier dropdown holds, for checking a depot window against the depot tables. It changes nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:Probe[all]

OgreBotAPI.IM:Queue[fw, mode]
  kind: method of OgreBotAPI.IM
  what: Adds a mode to the run queue and brings the window up: it runs when the current work finishes. With no mode it prints what is waiting, and a word that is not a mode is refused.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg mode (string): depot, sell, destroy, tse, restock, trade or quiver. Optional.
  example: OgreBotAPI.IM:Queue[all,sell]

OgreBotAPI.IM:Reload[fw]
  kind: method of OgreBotAPI.IM
  what: Reloads the depot tables from disk: the depot kinds, the ammo rows and the shared resource table.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:Reload[all]

OgreBotAPI.IM:Restock[fw, words...]
  kind: method of OgreBotAPI.IM
  what: The restock mode: with no words, or a profile name, it brings the window up and tops up from the depots, and -forwho <expr> runs it only on the characters named. A word short of its arguments is read as a profile name.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): A profile, or one of stop, status, reload, list (or profiles), show <profile>, preview (or plan) [profile], set <profile> <qty> <item>, forwho <profile> <who> <item>, drop <profile> <item>. Optional.
  example: OgreBotAPI.IM:Restock[all,"Raid night",-forwho,${Me.Name}]

OgreBotAPI.IM:Sell[fw, words...]
  kind: method of OgreBotAPI.IM
  what: The sell mode: with no words it brings the window up and sells what is on the sell list, opening a nearby merchant if none is open. The other first words are in the param; any other words go to the run.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): stop, status, reload, preview (or plan), list [all], add <name> or remove <name>, then its arguments. Optional.
  example: OgreBotAPI.IM:Sell[all,preview]

OgreBotAPI.IM:Settings[fw, words...]
  kind: method of OgreBotAPI.IM
  what: With no words, prints the saved settings; too few words prints the usage and changes nothing. Otherwise it changes one setting, as the param says.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): One of: bag <tse|destroy> <1-6|overseer|harvest|sharedtradeskill> <on|off>; tse <option> <on|off|number>; quiver <arrow|bolt|throwing> <name|clear|examine>; depot <flags>; reload. One argument each. Optional.
  example: OgreBotAPI.IM:Settings[all,tse,minlevel,120]

OgreBotAPI.IM:Status[fw]
  kind: method of OgreBotAPI.IM
  what: Prints the session line to the console, then the chain if one runs and one summary line each for depot, sell, destroy, restock and trade. For one line a script can read, use ${OgreBotAPI.IM.Status}.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:Status[all]

OgreBotAPI.IM:Stop[fw]
  kind: method of OgreBotAPI.IM
  what: Stops whatever the Inventory Manager is running (the chain, every busy mode, or a depot withdraw still in flight) and leaves the window open. When nothing is running it prints "im: nothing is running." to the console.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.IM:Stop[igw:${Me.Name}]

OgreBotAPI.IM:Trade[fw, words...]
  kind: method of OgreBotAPI.IM
  what: The trade mode: with no words it brings the window up and runs the queue. The other first words are in the param.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): add <player> <qty|all> <item>, remove <n> (or delete), list, clear, preview (or plan), status or stop, then its arguments. Optional.
  example: OgreBotAPI.IM:Trade[all,add,Tobbin,5,"Rare Ore"]

OgreBotAPI.IM:Transmute[fw, words...]
  kind: method of OgreBotAPI.IM
  what: Brings the window up and transmutes one named item, or an item by id.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): The item name or id. A name may be several arguments; they are joined with spaces.
  example: OgreBotAPI.IM:Transmute[all,"Rusted Greatsword"]

OgreBotAPI.IM:Tse[fw, words...]
  kind: method of OgreBotAPI.IM
  what: The transmute, salvage and extract mode: `stop` stops it, and anything else brings the window up and runs. It starts from the options saved on the TSE tab, and flags such as -salvage or -stopafter 5 change that run.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg words... (string): stop, or the run's flags, one argument each. Optional.
  example: OgreBotAPI.IM:Tse[all,-stopafter,5]


== OgreBotAPI.Inventory ==

${OgreBotAPI.Inventory.AdornmentColour[iconId]}
  kind: member of OgreBotAPI.Inventory
  what: Looks up the colour of an adornment from its icon id, using the bot's built-in table of known adornment icons.
  arg iconId (number): the adornment's icon id
  returns: string - White, Red, Blue, Cyan, Green, Purple or Black. Empty when the icon id is not in the table.
  example: echo ${OgreBotAPI.Inventory.AdornmentColour[3877]}
  oldbot: OgreBotAPI.AdornmentIconIDColour, OgreBotAPI.Get_AdornmentColour

${OgreBotAPI.Inventory.AdornToRemoveSlot[adorn]}
  kind: member of OgreBotAPI.Inventory
  what: The reverse of AdornToSlot: takes the slot number out of an adornment entry name, so _ADORN_<slot>_<name> becomes _ADORN_<name>. Text that is not in that form comes back unchanged.
  arg adorn (text): the adornment entry name, _ADORN_<slot>_<name>
  returns: string - the entry name without the slot, or the input unchanged when it is not in the _ADORN_<slot>_<name> form.
  example: echo ${OgreBotAPI.Inventory.AdornToRemoveSlot["_ADORN_21_Raid Rune: Void Flow III"]}
  oldbot: OgreBotAPI.ConvertAdornToRemoveSlot

${OgreBotAPI.Inventory.AdornToSlot[adorn, slot=21]}
  kind: member of OgreBotAPI.Inventory
  what: Puts a slot number into an adornment entry name: _ADORN_<name> becomes _ADORN_<slot>_<name>. Text that is not in the _ADORN_<name> form (with no other underscores) comes back unchanged.
  arg adorn (text): the adornment entry name, _ADORN_<name>
  arg slot (number, default: 21): the slot number to insert
  returns: string - the entry name with the slot inserted, or the input unchanged when it is not in the _ADORN_<name> form.
  example: echo ${OgreBotAPI.Inventory.AdornToSlot["_ADORN_Raid Rune: Void Flow III",21]}
  oldbot: OgreBotAPI.ConvertAdornToSlot

${OgreBotAPI.Inventory.Count[itemName, exact|contains]}
  kind: member of OgreBotAPI.Inventory
  what: Counts how many of an item you are carrying, adding up every stack in your bags and your Harvest Bag. The name match ignores case; it is exact unless you pass contains.
  arg itemName (item name): the item to count
  arg exact|contains (text, default: exact): exact = the whole name must match, contains = any item whose name contains the text
  returns: int - the total quantity on hand. 0 when nothing matches, the name is empty, you are not in the world, or the match word is not exact or contains (that last case also prints a line).
  example: echo ${OgreBotAPI.Inventory.Count[Ingot,contains]}
  oldbot: Obj_OgreUtilities.ItemCount, OgreBotAPI.ItemCount

${OgreBotAPI.Inventory.CurrentImmunityRune}
  kind: member of OgreBotAPI.Inventory
  what: Names the immunity rune on the belt you are wearing; it only reads your own character. It needs the belt's item details: an empty answer means they are still loading (the read asks the game for them), so ask again shortly - never treat empty as no rune.
  returns: string - Stun, Stifle, Mez, Fear or Medic for the rune worn. Unknown when the details are loaded and no known rune is on the belt. Empty when the details are not loaded yet or you are not in the world.
  example: echo ${OgreBotAPI.Inventory.CurrentImmunityRune}
  oldbot: OgreBotAPI.Get_CurrentImmunityRune

${OgreBotAPI.Inventory.IsAdornmentColour[iconId, colour]}
  kind: member of OgreBotAPI.Inventory
  what: TRUE when an adornment icon id is a known icon of the given colour. The colour match ignores case, and a blank colour means White.
  arg iconId (number): the adornment's icon id
  arg colour (text, default: White): White, Red, Blue, Cyan, Green, Purple or Black
  returns: bool - TRUE when the icon is in the table with that colour. FALSE when the colour differs or the icon id is not in the table.
  example: echo ${OgreBotAPI.Inventory.IsAdornmentColour[3877,White]}
  oldbot: OgreBotAPI.IsAdornmentColour

${OgreBotAPI.Inventory.PackPonyRunning}
  kind: member of OgreBotAPI.Inventory
  what: TRUE while a pack pony run is in progress, whether CheckPackPony or the bot's own pack pony chore started it.
  returns: bool: TRUE while a pack pony run is in progress; FALSE otherwise.
  example: echo ${OgreBotAPI.Inventory.PackPonyRunning}
  oldbot: OgreBotAPI.Get_APIPackPonyRunning, OgreBotAPI.Get_PackPonyRunning, OgreBotAPI.bAPIPackPonyRunning

${OgreBotAPI.Inventory.SlotAvailable[slot name]}
  kind: member of OgreBotAPI.Inventory
  what: TRUE when the item worn in the named equipment slot can be used (activated) right now - for example, a clicky cloak on cooldown reads FALSE. It does not tell you whether the slot is empty or can hold an item.
  arg slot name (text): one of: primary, secondary, head, cloak, chest, shoulders, forearms, hands, legs, feet, left_ring, right_ring, ears, ears2, neck, left_wrist, right_wrist, ranged, ammo, waist, activate1, activate2, event_slot, food, drink (any case)
  returns: bool - TRUE when the item in that slot is usable now. FALSE when it is not, when the name is not one of the slot names (a warning is printed), or when the slot could not be read.
  example: echo ${OgreBotAPI.Inventory.SlotAvailable[cloak]}
  oldbot: OgreBotAPI.EquipmentSlotAvailable

${OgreBotAPI.Inventory.SlotModifier[slot, modifier]}
  kind: member of OgreBotAPI.Inventory
  what: Reads one stat modifier from the item equipped in a slot, matching the modifier name without regard to case. It reads the item's detail record, which the game may have to fetch first, so it can return empty until that has loaded.
  arg slot (slot name or number): the equipment slot, as the game's equipment list accepts it
  arg modifier (text): the modifier name, e.g. Potency
  returns: string - the modifier's value. Empty when the item has no such modifier, its details are not loaded yet, or you are not in the world.
  example: echo ${OgreBotAPI.Inventory.SlotModifier[primary,Potency]}
  oldbot: OgreBotAPI.Get_EquipmentModifierValue

${OgreBotAPI.Inventory.SlotName[n=1]}
  kind: member of OgreBotAPI.Inventory
  what: Turns one of the bot's slot numbers (1 to 22) into the bot's short slot name: primary, secondary, head, chest, shoulders, Forearms, Hands, legs, feet, LRing, RRing, ear, ear2, neck, lwrist, rwrist, ranged, ammo, waist, cloak, Activate1, Activate2.
  arg n (number, default: 1): the slot number, 1 to 22
  returns: string - the slot name. Empty when n is outside 1 to 22.
  example: echo ${OgreBotAPI.Inventory.SlotName[20]}
  oldbot: OgreBotAPI.Get_SlotNum_To_SlotNames, OgreBotAPI.SlotNum_SlotNames, OgreBotAPI.Slot_SlotNames

${OgreBotAPI.Inventory.SlotNumAvailable[slot number 1-22]}
  kind: member of OgreBotAPI.Inventory
  what: The same check as SlotAvailable, with the slot given as a number from 1 to 22 in the bot's own numbering (not the game's equipment index): 1 primary, 2 secondary, 3 head, 4 chest, 5 shoulders, 6 forearms, 7 hands, 8 legs, 9 feet, 10 left_ring, 11 right_ring, 12 ears, 13 ears2, 14 neck, 15 left_wrist, 16 right_wrist, 17 ranged, 18 ammo, 19 waist, 20 cloak, 21 activate1, 22 activate2.
  arg slot number 1-22 (number): the slot, in the bot's numbering (whole digits only)
  returns: bool - TRUE when the item in that slot is usable now. FALSE when it is not, when the number is not 1 to 22 (a warning is printed), or when the slot could not be read. event_slot, food and drink have no number; use SlotAvailable for them.
  example: echo ${OgreBotAPI.Inventory.SlotNumAvailable[20]}
  oldbot: OgreBotAPI.EquipmentSlotNumAvailable

${OgreBotAPI.Inventory.SlotUIName[n=1]}
  kind: member of OgreBotAPI.Inventory
  what: Turns one of the bot's slot numbers (1 to 22) into the slot's name as the game's character window spells it: primary, secondary, head, chest, shoulders, Forearms, Hands, legs, feet, left_ring, right_ring, ears, ears2, neck, left_wrist, right_wrist, ranged, ammo, waist, cloak, Activate1, Activate2.
  arg n (number, default: 1): the slot number, 1 to 22
  returns: string - the window's slot name. Empty when n is outside 1 to 22.
  example: echo ${OgreBotAPI.Inventory.SlotUIName[10]}
  oldbot: OgreBotAPI.Get_SlotNum_EQ2UIPageSlotNames, OgreBotAPI.SlotNum_EQ2UIPageSlotNames

OgreBotAPI.Inventory:AddEmbargo[fw, linkId, durationSec]
  kind: method of OgreBotAPI.Inventory
  what: Stops the bot's casting from using an item, given by its LinkID, for a number of seconds (while item embargo is enabled in the bot's settings). Both arguments are required; a new embargo on the same item only ever extends it, and the signed and unsigned forms of a LinkID both work.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg linkId (number): the item's LinkID, a whole number from -2147483648 to 4294967295
  arg durationSec (number): how long, in seconds; 0 expires at once
  example: OgreBotAPI.Inventory:AddEmbargo["all",-1112810742,30]
  oldbot: OgreBotAPI:ItemEmbargo_AddRotateTimer

OgreBotAPI.Inventory:AutoConsumeFamiliarXP[fw]

  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Inventory:AutoConsumeFamiliarXP[${Me.Name}]
  oldbot: OgreBotAPI:AutoConsumeTemporaryFamiliarExperience

  arg value (true/false or word, default: TRUE): TRUE = on, FALSE = off, toggle = flip, report = change nothing; any other word means TRUE

  arg fw (for-who): for-who: this runs only when this character is one it names

  arg fw (for-who): for-who: this runs only when this character is one it names

  kind: method of OgreBotAPI.Inventory

  arg fw (for-who): for-who: this runs only when this character is one it names

OgreBotAPI.Inventory:ChangeBeltAdorn[fw, adornType, unequip=TRUE]
  kind: method of OgreBotAPI.Inventory
  what: Applies an immunity rune from your bags to your belt; it is queued and refuses while you are moving or in combat. A rune it replaces is accepted back and moved next to where the new rune was.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg adornType (text): Stun, Stifle, Mez, Fear or Medic
  arg unequip (true/false, default: TRUE): TRUE takes the belt off, applies the rune and puts the belt back on; FALSE applies the rune to the worn belt
  example: OgreBotAPI.Inventory:ChangeBeltAdorn[${Me.Name},Stun,TRUE]
  oldbot: OgreBotAPI:ChangeBeltAdorn

OgreBotAPI.Inventory:CheckGear[fw, threshold=100]
  kind: method of OgreBotAPI.Inventory
  what: Checks the condition of the item in your primary slot and prints "<name> gear N%" when it is at or below the threshold (and always at 30, 20, 10 and 0). It is queued, waits up to 5 seconds for the item's details to load, and fires the gear-condition event on every check.
  arg fw (for-who): for-who: this runs only when this character is one it names

  what: Loads the named OgreBot profile for this character, opening OgreBot first if it is not open; Use_UI reloads the current profile. A missing name gets one line and loads nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): Profile name, or Use_UI for the current profile. Required.
  example: OgreBotAPI.Options:LoadProfile[${Me.Name},Raid]
  oldbot: ProfileConfig:LoadProfileForWho, OgreBotAPI:LoadProfile, ProfileConfig:LoadProfile

OgreBotAPI.Options:Revert[fw, source]
  kind: method of OgreBotAPI.Options
  what: Puts back every option that scripts, commands or encounters changed since the last revert, then forgets those changes; changes you made yourself in the OgreBot window are never reverted. Prints "options: reverted N" with the source in the console.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg source (string): Which writer's changes to put back: an encounter's key, command for typed and script changes, or all / empty for every source
  example: OgreBotAPI.Options:Revert[${Me.Name},all]
  oldbot: OgreBotAPI:RevertOptions, Obj_LICH:HODefaultSettings

OgreBotAPI.Options:Set[fw, silent|loud|verbose="", (id,value)..., silent=FALSE]
  kind: method of OgreBotAPI.Options
  what: Writes one or more OgreBot options by control id in the loaded profile, prints each real change in OgreConsole unless silenced, and remembers the old value so Revert can put it back. The write is unsaved until Save, and does nothing when no profile is loaded.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg silent|loud|verbose (string, default: ""): Optional, before an id: silent turns the change lines off, loud or verbose turns them on
  arg (id,value)... (string): Pairs of control id and new value; a TRUE or FALSE after a value, with more pairs after it, sets silent too
  arg silent (bool, default: FALSE): A TRUE or FALSE at the very end: TRUE makes the whole call silent
  example: OgreBotAPI.Options:Set[all,checkbox_settings_enable_chatevents,TRUE]
  oldbot: OgreBotAPI:ChangeOgreBotUIOption, OgreBotAPI:UplinkOptionChange, Obj_OgreUtilities:Set_EQ2_onQuestOffered

OgreBotAPI.Paths:InsertPoint[fw, name, at, point]
  kind: method of OgreBotAPI.Paths
  what: Puts a point into a saved path of the zone you are in at a place in the list, and the point at that place and the ones after it move down one. An unknown path, a place outside the list or a point that cannot be one prints one line and changes nothing, and a walk under way keeps the points it had at its Start.
  arg fw (for-who): for-who: this runs only when this character is one it names. Paths are shared by every box on the PC, so a line that reaches several boxes names one, or each box it lands on does it.
  arg name (string): The path's name, in any case. It must exist: a place is a place in a list, so this never makes a path.
  arg at (number): The place the point takes, counted from 1. One past the last point puts it on the end.
  arg point (string): A POI name, or x,y,z. A script that writes x,y,z without quotes gets the same point.

  kind: method of OgreBotAPI.Paths
  what: Moves a point of a saved path of the zone you are in to another place in the list, and the points between shift one place. An unknown path or a place outside the list prints one line and changes nothing, and a walk under way keeps the points it had at its Start.
  arg fw (for-who): for-who: this runs only when this character is one it names. Paths are shared by every box on the PC, so a line that reaches several boxes names one, or each box it lands on does it.
  arg name (string): The path's name, in any case.
  arg from (number): The place of the point to move, counted from 1.
  arg to (number): The place it ends at, counted from 1. Moving a point to the place it holds changes nothing.
  example: OgreBotAPI.Paths:MovePoint[${Me.Name},autohuntpath1,5,2]

  kind: method of OgreBotAPI.Paths
  what: Takes the first point of that text off a saved path of the zone you are in, so a path that passes a point twice keeps the later one. An unknown path or point prints one line and changes nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names. Paths are shared by every box on the PC, so a line that reaches several boxes names one, or each box it lands on does it.

  oldbot: OgreBotAPI:AutoHunt_RemovePoint

OgreBotAPI.Paths:Start[fw, name]
  kind: method of OgreBotAPI.Paths
  what: Walks a saved path of the zone you are in, point by point, by the path's own mover, in place of any walk under way and through a pause of OgreBot; a point that does not resolve stops it before anything moves, and OgreBot must be open. It waits while something else has the character (a fight, a death, an AutoHunt pull, a movement block) and goes on from the same point, and one line says when it finishes, cannot reach a point, or ends at a zone or OgreBot closing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): The path's name, in any case. A path of one point goes there and finishes, looping or not. A path walked by camp spot leaves the camp spot at its last point when it finishes, and no earlier camp spot comes back.

  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Paths:Stop[${Me.Name}]
