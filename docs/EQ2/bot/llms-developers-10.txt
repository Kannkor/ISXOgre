# ISXOgreEQ2.OgreBot

## Members

### `Character`

`${ISXOgreEQ2.OgreBot.Character}`

The character whose OgreBot profile is loaded.

**Returns:** string: the character name; empty when nothing is loaded.

```text
echo ${ISXOgreEQ2.OgreBot.Character}
```

### `Count`

`${ISXOgreEQ2.OgreBot.Count}`

How many single control values the loaded profile holds (checkboxes, text boxes, combo boxes). List sections such as the Cast Stack are not counted.

**Returns:** int: the number of stored control values; 0 when nothing is loaded.

```text
echo ${ISXOgreEQ2.OgreBot.Count}
```

### `Dirty`

`${ISXOgreEQ2.OgreBot.Dirty}`

TRUE when the loaded profile has changes that are not saved to disk yet. Only Save writes them; closing OgreBot, Reload, or loading another profile drops them.

**Returns:** bool: TRUE when there are unsaved changes; FALSE when there are none or nothing is loaded.

```text
echo ${ISXOgreEQ2.OgreBot.Dirty}
```

### `IsReady`

`${ISXOgreEQ2.OgreBot.IsReady}`

TRUE when OgreBot is up: its main window or mini toolbar is open AND a profile is loaded. This is the check the bot's own features use before they act.

**Returns:** bool: TRUE when a window is open and a profile is loaded; FALSE otherwise.

```text
echo ${ISXOgreEQ2.OgreBot.IsReady}
```

### `Loaded`

`${ISXOgreEQ2.OgreBot.Loaded}`

TRUE while an OgreBot profile is loaded for this session. Closing OgreBot unloads the profile, so this goes FALSE on close.

**Returns:** bool: TRUE when a profile is loaded; FALSE when none is.

```text
echo ${ISXOgreEQ2.OgreBot.Loaded}
```

### `PanelVisible`

`${ISXOgreEQ2.OgreBot.PanelVisible}`

TRUE when the OgreBot main window or the mini toolbar is open, whether or not a profile is loaded. Use IsReady to ask whether the bot can run.

**Returns:** bool: TRUE when either window is open; FALSE when both are closed.

```text
echo ${ISXOgreEQ2.OgreBot.PanelVisible}
```

### `Profile`

`${ISXOgreEQ2.OgreBot.Profile}`

The name of the loaded OgreBot profile, in the spelling stored in the profile file.

**Returns:** string: the profile name; empty when nothing is loaded.

```text
echo ${ISXOgreEQ2.OgreBot.Profile}
```

### `Value`

`${ISXOgreEQ2.OgreBot.Value[id]}`

The stored value of one OgreBot window control, read from the loaded profile in memory (unsaved changes included). The id must match exactly; OgreBotAPI.Options.Value is the case-insensitive version.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `id` | string |  | the control id (the same id the profile saves it under), for example checkbox_settings_enablealiases |

**Returns:** string: the control's value as text; empty when the id is not stored, no id is given, or nothing is loaded.

```text
echo ${ISXOgreEQ2.OgreBot.Value[checkbox_settings_enablealiases]}
```

## Methods

### `Alias`

`ISXOgreEQ2.OgreBot:Alias[verb,arg1,arg2,arg3,arg4]`

Edits the loaded profile's custom aliases in memory (Save keeps them) and refreshes the Aliases tab and Target list; names get a leading * if they lack one, and add refuses only the same name with the same For. Verbs are display (print what each alias resolves to now), add or edit (name,For,NoRaid), del (name), delat or toggle (index), editat (index,name,For,NoRaid) and move (from,to) with 0-based indexes, it does nothing with no profile loaded, and OgreBotAPI.ForWho:AddAlias and RemoveAlias use this same editor.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `verb` | string |  | display, add, edit, del, delat, editat, toggle or move |
| `arg1` | string |  | the alias name (add, edit, del) or a 0-based row index (delat, editat, toggle, move) |
| `arg2` | string |  | the For value (add, edit; an empty one on edit clears it), the new name (editat) or the target index (move) |
| `arg3` | string |  | No-Raid as a yes/no word (add, edit) or the For value (editat) |
| `arg4` | bool |  | editat only: No-Raid |

```text
ISXOgreEQ2.OgreBot:Alias[add,Healer,${Group[1].Name},FALSE]
```

### `Close`

`ISXOgreEQ2.OgreBot:Close`

Closes OgreBot entirely: both windows close, the profile is unloaded (unsaved changes are dropped with a warning in the console), travel routes stop, and follow and camp spots are cleared unless OgreBotAPI.Movement:UseWithoutOgreBot is on. It is the same close as the X on either window, `ogre end bot` and OgreBotAPI.Bot:End.

```text
ISXOgreEQ2.OgreBot:Close
```

### `CreateProfile`

`ISXOgreEQ2.OgreBot:CreateProfile[name]`

Makes a new profile from the current settings, unsaved changes included, writes it to disk and switches to it. It fails with a console line when the name is already used (case does not matter).

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | the new profile's name; a b64: prefix marks a base64 name |

```text
ISXOgreEQ2.OgreBot:CreateProfile[Solo]
```

### `DeleteProfile`

`ISXOgreEQ2.OgreBot:DeleteProfile[name]`

Deletes a named profile from the character's profile file on disk. It refuses, with a console line, the loaded profile, the default profile, the last remaining profile and a name that does not exist.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | the profile name (case does not matter); a b64: prefix marks a base64 name |

```text
ISXOgreEQ2.OgreBot:DeleteProfile[Solo]
```

### `Dump`

`ISXOgreEQ2.OgreBot:Dump[path]`

Writes every stored control value of the loaded profile (unsaved changes included) to a JSON file and prints the count and path. List sections such as the Cast Stack are not included, and the file is overwritten each time.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `path` | string |  | the file to write |

```text
ISXOgreEQ2.OgreBot:Dump["${LavishScript.HomeDirectory}/ogrebot_values.json"]
```

### `List`

`ISXOgreEQ2.OgreBot:List[section,op,arg1,arg2]`

Edits one list section of the loaded profile (the Cast Stack or any other ordered list tab) in memory; Save keeps it, and a Cast Stack edit reaches the running cast stack at once. Ops are add (entry), insert or update (index,entry), del or toggle (index) and move (from,to), with 0-based indexes and each entry as base64-encoded JSON; it does not refresh the open window and does nothing with no profile loaded.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `section` | string |  | the profile section name, for example CastStack |
| `op` | string |  | add, insert, update, del, move or toggle |
| `arg1` | string |  | the base64 JSON entry (add) or a 0-based row index (every other op) |
| `arg2` | string |  | the base64 JSON entry (insert, update) or the target index (move) |

```text
ISXOgreEQ2.OgreBot:List[CastStack,toggle,0]
```

### `LoadProfile`

`ISXOgreEQ2.OgreBot:LoadProfile[name]`

Switches to another named profile of the loaded character and refreshes the cast stack and window; if OgreBot is not open it opens it with that profile. Unsaved changes to the current profile are dropped, with one warning line unless you named the profile already loaded, a name that is not found prints a line and keeps the current profile, and OgreBotAPI.Options:LoadProfile calls this.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | the profile name (case does not matter); a b64: prefix marks a base64 name |

```text
ISXOgreEQ2.OgreBot:LoadProfile[Raid]
```

### `Open`

`ISXOgreEQ2.OgreBot:Open[character,profile]`

Loads the character's profile from disk and opens the OgreBot main window and mini toolbar with it, then scans gear and inventory for the Items tab. Calling it while OgreBot is open loads the profile again and drops unsaved changes with one warning line; unlike the `ogre` command it leaves the pause state as it was, and a failed load (no character, profile not found) prints a line and changes nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `character` | string | `${Me.Name}` | the character whose profile to load |
| `profile` | string | `the character's default profile` | the profile name to load |

```text
ISXOgreEQ2.OgreBot:Open[${Me.Name},Group]
```

### `OpenMini`

`ISXOgreEQ2.OgreBot:OpenMini`

Opens the OgreBot mini toolbar on its own, without loading a profile, and prints a line. If the mini toolbar is already open it does nothing.

```text
ISXOgreEQ2.OgreBot:OpenMini
```

### `RefreshTargets`

`ISXOgreEQ2.OgreBot:RefreshTargets`

Re-reads which aliases and targets resolve right now and sends them to the OgreBot window's Target dropdown. It does nothing when the main window is closed.

```text
ISXOgreEQ2.OgreBot:RefreshTargets
```

### `Reload`

`ISXOgreEQ2.OgreBot:Reload`

Reads the loaded profile again from disk, dropping unsaved changes with one warning line, and refreshes the cast stack and the open window. It does nothing when no profile is loaded; OgreBotAPI.Bot:Reload is a different call that restarts the whole bot.

```text
ISXOgreEQ2.OgreBot:Reload
```

### `ReloadKeyBinds`

`ISXOgreEQ2.OgreBot:ReloadKeyBinds`

Reads the shared key binds file again (forward, backward and the other movement keys) and prints the new forward and backward keys. Another EQ2 session on this PC sends it after a key is changed.

```text
ISXOgreEQ2.OgreBot:ReloadKeyBinds
```

### `ReloadUi`

`ISXOgreEQ2.OgreBot:ReloadUi`

Reloads the in-game window pages from disk, then reopens the OgreBot main window and mini toolbar if they were open, with the same profile and settings. Nothing in the bot is reloaded or reset; this is what `ogre ui reload` runs.

```text
ISXOgreEQ2.OgreBot:ReloadUi
```

### `Research`

`ISXOgreEQ2.OgreBot:Research[mode]`

Runs the Ability Research check: it opens the Knowledge window and, with go or run, claims finished research and starts the next ability from the saved priority list, then closes the window. With no mode or any other word it only reads the window and says what it would do (trace also logs each window read), and a call while a check is running is ignored.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `mode` | string | `preview` | go or run for the real run, trace for a logged preview; anything else is a preview |

```text
ISXOgreEQ2.OgreBot:Research[go]
```

### `Save`

`ISXOgreEQ2.OgreBot:Save`

Writes the loaded profile's changes to disk and prints each file it wrote. With nothing loaded or nothing changed it prints that and writes nothing.

```text
ISXOgreEQ2.OgreBot:Save
```

### `SaveProfileAs`

`ISXOgreEQ2.OgreBot:SaveProfileAs[name]`

Overwrites another profile with the current settings, unsaved changes included, and switches to it. It fails with a console line when that profile does not exist or is the loaded one.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | the profile to overwrite; a b64: prefix marks a base64 name |

```text
ISXOgreEQ2.OgreBot:SaveProfileAs[Solo]
```

### `ScanItems`

`ISXOgreEQ2.OgreBot:ScanItems`

Asks for a scan of equipped gear, inventory and adornments on the next pulse, to fill the Items tab's source list. The request is dropped when no profile is loaded or the in-game UI is not ready, and opening OgreBot already runs one.

```text
ISXOgreEQ2.OgreBot:ScanItems
```

### `SetDefault`

`ISXOgreEQ2.OgreBot:SetDefault[name]`

Makes a named profile the one this character loads by default, and writes that to the profile file at once. It fails with a console line when nothing is loaded or the profile does not exist.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | the profile name (case does not matter); a b64: prefix marks a base64 name |

```text
ISXOgreEQ2.OgreBot:SetDefault[Group]
```

### `UplinkConnect`

`ISXOgreEQ2.OgreBot:UplinkConnect`

Connects this PC's uplink to every PC on the Uplink Info list except this one, spaced out, and prints how many it did (or that there is nothing to do). A second connect or disconnect from the same session within 3 seconds is ignored and only written to the log.

```text
ISXOgreEQ2.OgreBot:UplinkConnect
```

### `UplinkDisconnect`

`ISXOgreEQ2.OgreBot:UplinkDisconnect`

Disconnects this PC's uplink from every PC on the Uplink Info list except this one, and prints how many it did (or that there is nothing to do). A second connect or disconnect from the same session within 3 seconds is ignored and only written to the log.

```text
ISXOgreEQ2.OgreBot:UplinkDisconnect
```

# ISXOgreEQ2.OSA

## Methods

### `Close`

`ISXOgreEQ2.OSA:Close`

Closes the On-Screen Assistant window and stops its NPC scan, including an open that is still being retried. It does not untick the Enable On-Screen Assistant setting, so the window opens again only when that setting is next switched on (or at the next load while it is ticked).

```text
ISXOgreEQ2.OSA:Close
```

### `Open`

`ISXOgreEQ2.OSA:Open`

Opens the On-Screen Assistant (OSA) window, the same as `ogre osa`: a live list of the NPCs around you, named NPCs first and then by distance, up to 35 rows, refreshed about 5 times a second within the Settings scan radius (50 until a value is set, at most 200). It does nothing while the window is already up, and it does not tick the Enable On-Screen Assistant setting, which opens and closes the window by itself whenever it changes.

```text
ISXOgreEQ2.OSA:Open
```

### `Target`

`ISXOgreEQ2.OSA:Target[id]`

Targets the actor with the given ID at once by sending the `target <id>` command, which is what clicking a row in the OSA window does. A call with no ID prints a line and targets nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `id` | int |  | ID of the actor to target |

```text
ISXOgreEQ2.OSA:Target[${Target.Target.ID}]
```

# ISXOgreEQ2.Overseer

## Methods

### `BuyMissions`

`ISXOgreEQ2.Overseer:BuyMissions[flag...]`

Starts a run that buys Overseer missions at the merchant on this session, using this character's Overseer Buy tab with any flags overriding it: -season N, -colour C, -num N, -amount N (at most 20), -replenishonly, -scribe or -noscribe, -destroy or -nodestroy, -gettogh or -nogettogh (go to the guild hall when done); unknown words are skipped. Refused with a console line when OgreBot is not open with a profile, a buy run is already going, or the first argument is not a -flag - the same run OgreBotAPI.Overseer:BuyMissions queues with a for-who.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `flag...` | string |  | Optional flags, one per argument, each value as its own argument after its flag; none uses the Overseer Buy tab as saved |

```text
ISXOgreEQ2.Overseer:BuyMissions[-season,2,-amount,5]
```

### `BuyMissionsStatus`

`ISXOgreEQ2.Overseer:BuyMissionsStatus`

Prints whether the Overseer mission buy run is idle or, if running, the phase it is in.

```text
ISXOgreEQ2.Overseer:BuyMissionsStatus
```

### `BuyMissionsStop`

`ISXOgreEQ2.Overseer:BuyMissionsStop`

Aborts the Overseer mission buy run in progress and prints the reason. Prints "nothing running." when idle; same as `ogre end buyoverseermissions`.

```text
ISXOgreEQ2.Overseer:BuyMissionsStop
```

### `Run`

`ISXOgreEQ2.Overseer:Run`

Starts a manual Overseer run on this session now, skipping the 60-minute throttle; it uses OgreBot's Overseer tab when OgreBot is open, and the defaults (complete finished quests, add bag missions, start mishaps and new quests, take rewards) when it is not. Refused with a console line when any argument is passed, a run is already going, a bag-mission add is busy, or 'Do not touch overseer at all no matter what' is ticked - the same run as OgreBotAPI.Overseer:CheckQuests and `ogre overseer`.

```text
ISXOgreEQ2.Overseer:Run
```

### `Status`

`ISXOgreEQ2.Overseer:Status`

Prints the Overseer run's current phase, whether it is running, and how many quests it has started and completed. When idle after a run it also prints roughly how many seconds until the next automatic run is allowed.

```text
ISXOgreEQ2.Overseer:Status
```

### `Stop`

`ISXOgreEQ2.Overseer:Stop`

Ends the Overseer run in progress on this session and prints "run aborted", or prints "nothing to stop" when idle. Same as `ogre end overseer`.

```text
ISXOgreEQ2.Overseer:Stop
```

# ISXOgreEQ2.Paths

## Methods

### `End`

`ISXOgreEQ2.Paths:End`

Closes the Points of Interest and Paths window, which is what `ogre end paths` and the window's X do. A path being walked goes on.

```text
ISXOgreEQ2.Paths:End
```

### `Open`

`ISXOgreEQ2.Paths:Open[path]`

Opens the Points of Interest and Paths window (the same as `ogre paths`), on a saved path of the zone you are in when you name one: this is the one way to open it, from a panel, a button or a script. A window already open comes to the front on that path, a path this zone does not have prints one line and the window opens with nothing picked, and without the Ogre UI desktop it prints a warning.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `path` | string | `none (nothing picked)` | The path to open on, in any case. A name with spaces may be quoted or written as several words. Leave it out to open the window with nothing picked. |

```text
ISXOgreEQ2.Paths:Open["North Loop"]
```

# ISXOgreEQ2.Perf

## Methods

### `Measure`

`ISXOgreEQ2.Perf:Measure[seconds,nothreads]`

Measures the frame rate and what uses each frame for a number of seconds, then prints a report to the console and the log file - the same as ogre perf. The capture starts on the next frame; if one is already running, or a word other than a number or nothreads is given, it prints a line and measures nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `seconds` | int | `10` | how long to measure, 3 to 120 (values outside are clamped) |
| `nothreads` | string | `""` | the word nothreads turns off the per-thread breakdown; it may come before or after the seconds |

```text
ISXOgreEQ2.Perf:Measure[30]
```

### `Status`

`ISXOgreEQ2.Perf:Status`

Prints one console line saying whether a measurement is idle, about to start, or running with the seconds done and left - the same as ogre perf status.

```text
ISXOgreEQ2.Perf:Status
```

### `Stop`

`ISXOgreEQ2.Perf:Stop`

Ends a running measurement early and prints the report for what was measured, or cancels one that has not started yet - the same as ogre perf stop. With nothing running it prints that nothing is being measured.

```text
ISXOgreEQ2.Perf:Stop
```

# ISXOgreEQ2.PotCb

## Methods

### `End`

`ISXOgreEQ2.PotCb:End`

Stops the Potency / Crit Bonus / Fervor sampler if it runs and always closes its panel, keeping the history. This is what `ogre end potcb` and the panel's X do.

```text
ISXOgreEQ2.PotCb:End
```

### `Help`

`ISXOgreEQ2.PotCb:Help`

Prints the `ogre potcb` usage to the console: open, on / off, status, reset and interval.

```text
ISXOgreEQ2.PotCb:Help
```

### `Interval`

`ISXOgreEQ2.PotCb:Interval[ms]`

Sets how often the sampler reads Potency, Crit Bonus and Fervor, held between 50 and 10000 ms (a negative is 50), and prints the new value. With no value it prints the current interval; a value that is not a number keeps the interval in force and says so.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `ms` | int |  | Sampling interval in milliseconds, 50 to 10000 (the sampler starts at 200). Optional: leave it out to print the current interval. |

```text
ISXOgreEQ2.PotCb:Interval[500]
```

### `Off`

`ISXOgreEQ2.PotCb:Off`

Stops the Potency / Crit Bonus / Fervor sampler and closes its panel, keeping the recorded history. If it was not sampling it prints "potcb: not running." and leaves the panel open.

```text
ISXOgreEQ2.PotCb:Off
```

### `On`

`ISXOgreEQ2.PotCb:On`

Starts the Potency / Crit Bonus / Fervor sampler, which reads the three stats every interval (default 200 ms) while you are in world, and prints one line saying so. Does nothing if it is already sampling, and does not open the panel.

```text
ISXOgreEQ2.PotCb:On
```

### `Open`

`ISXOgreEQ2.PotCb:Open`

Opens the Potency / Crit Bonus / Fervor tracker panel, starting the sampler first if it was stopped (the same as bare `ogre potcb`). If the panel is already up it stays as it is, and without the Ogre UI desktop it prints a warning while sampling still starts.

```text
ISXOgreEQ2.PotCb:Open
```

### `Reset`

`ISXOgreEQ2.PotCb:Reset`

Clears every recorded Potency / Crit Bonus / Fervor figure and the sampled time, then prints "potcb: history cleared". The sampler stays on or off as it was.

```text
ISXOgreEQ2.PotCb:Reset
```

### `Status`

`ISXOgreEQ2.PotCb:Status`

Prints every Potency / Crit Bonus / Fervor figure to the console: running or stopped and time sampled, then per stat the current value and peak, the in-combat min / avg / max, time at cap, time at peak and combat time by tenth of the peak, and the overall min / avg / max. It also warns when readings were skipped because a stat showed no number.

```text
ISXOgreEQ2.PotCb:Status
```

# ISXOgreEQ2.PulseBudget

## Methods

### `Ceiling`

`ISXOgreEQ2.PulseBudget:Ceiling[us]`

Sets the shared frame ceiling and saves it; below 0 reads as 0. With no value it prints one warning and changes nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `us` | float |  | The ceiling in microseconds; 0 means none. |

```text
ISXOgreEQ2.PulseBudget:Ceiling[4000]
```

### `Close`

`ISXOgreEQ2.PulseBudget:Close`

Closes the Pulse Budget window, the same as `ogre end pulse`. The budget keeps running.

```text
ISXOgreEQ2.PulseBudget:Close
```

### `JobTest`

`ISXOgreEQ2.PulseBudget:JobTest[state]`

A test mode for this session only: every pulse job pauses at every checkpoint, so state that does not survive a frame shows up at once. It is never saved.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `state` | string |  | on or 1 turns it on; any other word turns it off. Required. |

```text
ISXOgreEQ2.PulseBudget:JobTest[on]
```

# ISXOgreEQ2.Queue

## Members

### `Blocking`

`${ISXOgreEQ2.Queue.Blocking}`

Why the most urgent waiting entry cannot start yet, as a line like seq=5 CastAbility prio=100 age=900ms: resource busy: CastBar, or starved by a higher-priority haltQueue entry. Empty when nothing is waiting or the next entry is free to start.

**Returns:** string: the reason line; empty when nothing is held up

```text
echo ${ISXOgreEQ2.Queue.Blocking}
```

### `Count`

`${ISXOgreEQ2.Queue.Count}`

Number of entries in the action queue, running plus waiting.

**Returns:** int: entries running plus waiting; 0 when the queue is empty

```text
echo ${ISXOgreEQ2.Queue.Count}
```

### `Enqueue`

`${ISXOgreEQ2.Queue.Enqueue[priority,kind,arg0,arg1,ttlstart,ttlmax]}`

Adds an entry exactly like ISXOgreEQ2.Queue:Add and returns its seq, the id you pass to Status, IsDone and Remove. Reading the member is what adds the entry, so every read queues another one, and an unknown kind (ApplyVerbCastBar and DialogChoices included) or a flow name that is not registered adds nothing and returns 0.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `priority` | int | `100` | Higher runs first; 0 means the default 100 |
| `kind` | string |  | What to do, any case: CastAbility, CastItem, ClickCastBar, RawCommand, Movement or Flow. ApplyVerbCastBar and DialogChoices are not kinds here; OgreBotAPI.Actors:ApplyVerbIDQueued queues an apply-verb |
| `arg0` | string |  | Depends on kind: RawCommand the console command, CastAbility the ability id or name, CastItem the item name, ClickCastBar the actor id, Movement x,y,z with an optional precision, Flow the flow name |
| `arg1` | string |  | Depends on kind: CastAbility the target name (empty = current target), CastItem the equip slot (empty = the bag item by name), ClickCastBar the wait in tenths of a second (empty = 4 seconds), Flow its arguments |
| `ttlstart` | int | `0` | Milliseconds the entry may wait to start before it is dropped with status Expired; 0 = no limit |
| `ttlmax` | int | `0` | Milliseconds the entry may run before it is stopped with status Aborted; 0 = no limit |

**Returns:** int64: the new entry's seq (1 and up); 0 when the kind is unknown

```text
echo ${ISXOgreEQ2.Queue.Enqueue[100,RawCommand,"echo queued"]}
```

### `Entry`

`${ISXOgreEQ2.Queue.Entry[index]}`

One queue entry as a readable line, such as seq=12 prio=100 RawCommand waiting age=40ms arg0=echo hi, where seq is the entry's id. The index counts from 1, running entries first and then waiting ones, each sorted by priority then by the order they were added.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `index` | int |  | Position in the queue counting from 1: running entries first, then waiting ones, highest priority first |

**Returns:** string: the entry line; empty when the index is 0, past the end or missing

```text
echo ${ISXOgreEQ2.Queue.Entry[1]}
```

### `EntryJSON`

`${ISXOgreEQ2.Queue.EntryJSON[index]}`

One queue entry as a JSON object with seq, priority, kind, status (running or waiting), holds, haltQueue, haltCastStack, ageMs, blocked, arg0, arg1 and label. Same index as Entry, counting from 1, so a loop from 1 to Count reads the whole queue.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `index` | int |  | Position in the queue counting from 1: running entries first, then waiting ones, highest priority first |

**Returns:** string: the entry as a JSON object; {} when the index is 0, past the end or missing

```text
echo ${ISXOgreEQ2.Queue.EntryJSON[1]}
```

### `InFlight`

`${ISXOgreEQ2.Queue.InFlight}`

Whether any queue entry is running right now.

**Returns:** bool: TRUE when at least one entry is running; FALSE when none is

```text
echo ${ISXOgreEQ2.Queue.InFlight}
```

### `IsDone`

`${ISXOgreEQ2.Queue.IsDone[seq]}`

Whether the queue entry with that seq has finished in any way (Done, Failed, Expired, Aborted or Removed), so a wait loop never hangs on a failed entry; read Status for how it ended. A seq that finished and has since been forgotten also reads TRUE, while a seq never issued reads FALSE.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `seq` | int64 |  | The entry's id, from Enqueue or the seq= field of Entry and Spew |

**Returns:** bool: TRUE when the entry has finished, however it ended; FALSE while it is waiting or running, or when the seq was never issued

```text
echo ${ISXOgreEQ2.Queue.IsDone[1]}
```

### `Status`

`${ISXOgreEQ2.Queue.Status[seq]}`

The state of the queue entry with that seq. Unknown means the seq was never issued or finished too long ago to remember (only the most recent 256 are kept).

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `seq` | int64 |  | The entry's id, from Enqueue or the seq= field of Entry and Spew |

**Returns:** string: Pending, InFlight, Done, Failed, Expired, Aborted, Removed or Unknown

```text
echo ${ISXOgreEQ2.Queue.Status[1]}
```

# ISXOgreEQ2.TravelMesh

## Members

### `TMActive`

`${ISXOgreEQ2.TravelMesh.TMActive}`

TRUE while a travel route is running on this character. It reads FALSE while idle, after arriving or giving up, and while a Go is still waiting for a zone to finish loading.

**Returns:** bool: TRUE when a route is running; FALSE otherwise

```text
echo ${ISXOgreEQ2.TravelMesh.TMActive}
```

### `TMBias`

`${ISXOgreEQ2.TravelMesh.TMBias[kind]}`

The cost multiplier the planner uses for one kind of hop (door, bell, spire, druid, map, amenity or item): 1 is neutral, below 1 prefers it, above 1 avoids it, 0 or less forbids it. Every kind starts at 1.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `kind` | string |  | the hop kind: door, bell, spire, druid, map, amenity or item |

**Returns:** float: the multiplier for that kind; -1 when the kind is unknown or missing

```text
echo ${ISXOgreEQ2.TravelMesh.TMBias[bell]}
```

### `TMCurrentHop`

`${ISXOgreEQ2.TravelMesh.TMCurrentHop}`

A one-line description of the hop in progress: the kind (door, bell, spire, druid, map, amenity or item), the from and to zone short names, and the travel action and destination label when there is one. Empty when no hop is in progress, including after arrival.

**Returns:** string: the current hop's description; empty when there is none

```text
echo ${ISXOgreEQ2.TravelMesh.TMCurrentHop}
```

### `TMDataErrors`

`${ISXOgreEQ2.TravelMesh.TMDataErrors}`

How many travel data files had a problem at the last load, counting files that were skipped and files that loaded with a warning. It reads 0 until the travel data has loaded.

**Returns:** int: the number of problem files; 0 when the data loaded cleanly

```text
echo ${ISXOgreEQ2.TravelMesh.TMDataErrors}
```

### `TMDataErrorText`

`${ISXOgreEQ2.TravelMesh.TMDataErrorText}`

The problem report from the last load, one line per file: its path, which layer it came from (default or custom) and the message. Empty when every file loaded cleanly, or until the travel data has loaded.

**Returns:** string: the problem report, one file per line; empty when clean

```text
echo ${ISXOgreEQ2.TravelMesh.TMDataErrorText}
```

### `TMEdges`

`${ISXOgreEQ2.TravelMesh.TMEdges}`

How many zone-to-zone connections (doors, zone lines, guild hall amenities, travel items and so on) the loaded travel data holds. It reads 0 until the travel data has loaded.

**Returns:** int: the number of connections in the travel data

```text
echo ${ISXOgreEQ2.TravelMesh.TMEdges}
```

### `TMFeatures`

`${ISXOgreEQ2.TravelMesh.TMFeatures}`

One line per account feature the travel data can require (the expansion Friends and Family features), with this character's answer: YES or no, and whether it was scanned or set by you, or unanswered. A no from a scan is checked again after a week, a YES or your own answer is kept, and the lines are read by the travel engine about once a second while you are in the world.

**Returns:** string: one line per account feature

```text
echo ${ISXOgreEQ2.TravelMesh.TMFeatures}
```

### `TMGoal`

`${ISXOgreEQ2.TravelMesh.TMGoal}`

The short zone name of the destination of the current or last route, such as antonica. Empty before any route has started.

**Returns:** string: the destination zone short name; empty before the first route

```text
echo ${ISXOgreEQ2.TravelMesh.TMGoal}
```

### `TMHop`

`${ISXOgreEQ2.TravelMesh.TMHop}`

The number of the hop the route is on, counting from 1. It reads 1 before any route has run and one more than TMHops once the route has arrived.

**Returns:** int: the current hop number, 1-based

```text
echo ${ISXOgreEQ2.TravelMesh.TMHop}
```

### `TMHops`

`${ISXOgreEQ2.TravelMesh.TMHops}`

How many hops the current plan has. After a re-plan this is the hop count of the new plan for the rest of the trip, not the original total.

**Returns:** int: the hop count of the current plan; 0 before any route

```text
echo ${ISXOgreEQ2.TravelMesh.TMHops}
```

### `TMParty`

`${ISXOgreEQ2.TravelMesh.TMParty}`

For the current or last route: the route id, how many group members it counted, and either "everyone is here" or the names of members not yet in this zone and settled. It is empty before any route has started, and read by the travel engine about once a second while you are in the world.

**Returns:** string: the group status line; empty before the first route

```text
echo ${ISXOgreEQ2.TravelMesh.TMParty}
```

### `TMReason`

`${ISXOgreEQ2.TravelMesh.TMReason}`

Why the last route stopped, or what its last step reported, such as "stopped by request" or "replaced by a new route". Empty while a route runs normally.

echo ${ISXOgreEQ2.TravelMesh.TMReason}

### `TMReplans`

## Methods

### `Go`

`ISXOgreEQ2.TravelMesh:Go[destination,poi]`

Starts a route like OgreBotAPI.Travel:Mesh, from your current zone to the destination, walking and using doors, zone lines, bells, spires, druid rings, the fast-travel map, guild hall amenities and travel items in your bags as needed; it replaces a running route, whoever started it, only when the new one can be planned. Problems (no destination, unknown destination with suggestions, current zone not in the travel data, no route) are echoed to the console, a Go made while zoning waits for the zone to settle, and the route moves with OgreBot closed too - TravelMesh:Stop ends it.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `destination` | string |  | the zone to travel to - its display name, an alias or its short name, any case |
| `poi` | string | `none` | optional point of interest in the destination zone to finish at; one the zone data does not list is reported and the trip still goes to the zone |

```text
ISXOgreEQ2.TravelMesh:Go[Antonica,"Druid Rings"]
```

### `GoGroup`

`ISXOgreEQ2.TravelMesh:GoGroup[destination,poi]`

Like OgreBotAPI.Travel:MeshGroup: starts your own route as Go does, then sends -TravelMesh for the same destination to the rest of your group through OgreConsole, so each member plans its own route from where it stands, with starts staggered by TMStagger. If your own route cannot be planned the error is echoed and nothing is sent; the other members' copies run as OgreBot routes, so they are stopped with -TravelMeshStop.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `destination` | string |  | the zone to travel to - its display name, an alias or its short name, any case |
| `poi` | string | `none` | optional point of interest in the destination zone to finish at; one the zone data does not list is reported and the trip still goes to the zone |

```text
ISXOgreEQ2.TravelMesh:GoGroup[Antonica]
```

### `Preview`

`ISXOgreEQ2.TravelMesh:Preview[destination]`

Plans a route from your current zone to the destination and prints it to the console without moving: a summary line with the hop count and rough time in seconds, then one numbered hop per line. An unknown destination prints an "unknown destination" line with suggestions, and no destination prints an error.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `destination` | string |  | the zone to plan to - its display name, an alias or its short name, any case |

```text
ISXOgreEQ2.TravelMesh:Preview[Antonica]
```

### `Reload`

`ISXOgreEQ2.TravelMesh:Reload`

Re-reads the travel data from Ogre/EQ2/Travel/default and your own OgreSave/EQ2/Travel/custom files and echoes a summary of zones, connections, files and errors. Any running route is stopped first, whoever started it; if the first load has not finished within 5 seconds it says so and changes nothing.

```text
ISXOgreEQ2.TravelMesh:Reload
```

### `ScanFeatures`

`ISXOgreEQ2.TravelMesh:ScanFeatures`

Runs the game's show_account_features command to answer this character's unanswered or expired account features, and echoes a status line. Each feature is scanned at most once per session, a scan also starts by itself when a route is planned, and when nothing is scanned (out of the world included) the line says every feature is already answered.

```text
ISXOgreEQ2.TravelMesh:ScanFeatures
```

### `SetBias`

`ISXOgreEQ2.TravelMesh:SetBias[kind,multiplier]`

Sets how much the planner likes one kind of hop: 1 is neutral, below 1 prefers it, above 1 avoids it, 0 or less forbids it, and the new value is echoed. It applies to the next plan and is not saved; a multiplier that is not a number sets the normal bias of 1 and says so.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `kind` | string |  | the hop kind: door, bell, spire, druid, map, amenity or item; anything else is refused with a console error |
| `multiplier` | float |  | the cost multiplier: 1 neutral, below 1 prefer, above 1 avoid, 0 or less forbid; a word is 1 |

```text
ISXOgreEQ2.TravelMesh:SetBias[druid,0.5]
```

### `SetFeature`

`ISXOgreEQ2.TravelMesh:SetFeature[flag,value]`

Saves your own answer for one account feature for this character in OgreSave/EQ2/Travel/account-features.json; it is permanent and never scanned over, and the answer is echoed. A feature name the travel data does not use is refused with a line naming the ones it does, a blank value prints an error, and a word that is not yes or no leaves the feature as it is and says so.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `flag` | string |  | the account feature name as TMFeatures shows it, such as roc_friends_and_family, in any case |
| `value` | bool |  | TRUE, 1, yes or on means this character has the feature; FALSE, 0, no or off means it does not |

```text
ISXOgreEQ2.TravelMesh:SetFeature[roc_friends_and_family,TRUE]
```

### `SetStagger`

`ISXOgreEQ2.TravelMesh:SetStagger[ms]`

Sets the start delay in milliseconds per group member for group travel (0 = everybody at once) and echoes it. A negative number is stored as 0, a value that is not a number counts as 0, and the setting is not saved.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `ms` | int |  | milliseconds of start delay per group member; 0 starts everybody at once |

```text
ISXOgreEQ2.TravelMesh:SetStagger[5000]
```

### `Stop`

`ISXOgreEQ2.TravelMesh:Stop[-force]`

Cancels a route started with this object's Go or GoGroup, including one still waiting for a zone to settle. A route someone else started is refused with one line naming the owner and how to stop it, and -force stops it anyway.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `-force` | switch |  | stop the route whoever started it |

```text
ISXOgreEQ2.TravelMesh:Stop
```

# ISXOgreEQ2.Watcher

## Methods

### `End`

`ISXOgreEQ2.Watcher:End`

Turns off both the name watch (Find) and the shiny watch (TrackShiny), closes the Watcher window and prints which of them were on; the off state is saved, so they stay off on the next load. This is what `ogre end watcher` and the window's close button do.

```text
ISXOgreEQ2.Watcher:End
```

### `Find`

`ISXOgreEQ2.Watcher:Find[word...]`

Watches for actors by exact name, case not mattering (`ogre find`): given names it replaces the watch list, arms and checks the zone once, then each time a watched name spawns it prints where, broadcasts '&lt;you>: APPEARED: &lt;name>' to your bot sessions and sets an in-game waypoint on it, and it prints when one despawns (these alerts are skipped in a guild hall). A first word that is an option does that instead (-add or -remove &lt;name>, -clear, -list, -on, -off, -scan, -status, -panel opens the Watcher window, -rorr adds the four Renewal of Ro researchers to the names), no words prints the usage, and the list and armed state are saved and restored on the next load.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `word...` | string | `none (prints the usage)` | the names to watch (quote a name that has spaces), or one option first followed by its value |

```text
ISXOgreEQ2.Watcher:Find[${Target.Name}]
```

### `TrackShiny`

`ISXOgreEQ2.Watcher:TrackShiny[word...]`

Watches for shiny harvest nodes of one colour within 100 units, every 500 ms by default (`ogre trackshiny`): when it finds one it did not just announce, it prints '&lt;colour> shiny!', broadcasts it to your bot sessions and sets an in-game waypoint on it. No word arms it on Purple, a colour name (White, Green, Purple, Red, BlueShimmer, Blue) arms that colour and an unknown one is refused with the list, the options are -off, -status, -colours (or -colors), -interval &lt;ms> (held to 250..30000) and -panel, and the settings are saved and restored on the next load.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `word...` | string | `Purple` | a colour to watch for, or one option first followed by its value |

```text
ISXOgreEQ2.Watcher:TrackShiny[Red]
```
