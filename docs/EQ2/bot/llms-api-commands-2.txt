== ISXOgreEQ2 console commands (-AbilityEmbargo to -LoadProfile) ==

Sent as `oc !c <command> <who> ...` to the sessions on this PC, this one included; the for-who in <who> picks which act. `oc !ci` does the same without showing the line.

oc !c -AbilityEmbargo <who> <abilityid> <duration> <args>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  also: -AbilityRotate
  what: Embargo an ability (its name or id) for N seconds on the toons the for-who names (an ability rotation: the caster tells the others not to cast it).
  arg who (forwho, default: auto): Who embargoes - leave blank to use the For Who window; `all` = every session that hears it.
  arg abilityid (string)
  arg duration (string)
  arg args (rest)
  runs: OgreBotAPI.Abilities:AddEmbargo
  example: oc !c -AbilityEmbargo all 1234567890 15

oc !c -AbilityEmbargo_ResetAbilityEmbargo <who> <value>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Clears the embargo on one ability, given by name or id, on the matching characters. A name that cannot be found (including the default Unknown) does nothing.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg value (string, default: Unknown)
  runs: OgreBotAPI.Abilities:ClearEmbargo
  example: oc !c -AbilityEmbargo_ResetAbilityEmbargo all 1234567890

oc !c -AbilityEmbargo_ResetAllAbilityEmbargos <who>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Clears every ability embargo on the matching characters, so their cast stacks may cast those abilities again. Item embargos are not touched.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  runs: OgreBotAPI.Abilities:ClearAllEmbargos
  example: oc !c -AbilityEmbargo_ResetAllAbilityEmbargos all

oc !c -AbilityTagEmbargo <who> <tagname> <duration> <type> <args>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  also: -AbilityTagRotate, -AbilityTag
  what: Holds a cast stack tag on the matching characters for duration seconds: type Embargo (the default) stops entries carrying that embargo tag from casting, and type Allow lets entries that need that allow tag cast. It only takes effect while the Settings tab's Enable Tag Embargo or Enable Tag Allow box is ticked; -m <buff> in the extra arguments ties the tag to a maintained buff, and a missing or 0 duration ends it at once.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg tagname (string)
  arg duration (string)
  arg type (string, default: Embargo)
  arg args (rest)
  runs: OgreBotAPI.CastStack:HoldTag
  example: oc !c -AbilityTagEmbargo all Stifle 20 Embargo

oc !c -AbilityTracker_Add <who> <abilityname>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Adds the named ability to the Ability Tracker watch list (an id is stored as the ability's name) and echoes the result. The name is not checked against the export, one already on the list is not added again, and the change is lost unless you save the profile.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg abilityname (string)
  runs: OgreBotAPI.Abilities:TrackerAdd
  example: oc !c -AbilityTracker_Add ${Me.Name} "Bulwark of Order"

oc !c -Actor_Click <who> <actorname> <exactname>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Double-clicks an actor right away: a number is taken as an actor id, otherwise it picks the nearest interactable actor whose name contains the text (or matches it exactly when exactname is TRUE). Nothing happens when no such actor is found.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg actorname (string, default: asdf1323)
  arg exactname (string, default: FALSE)
  runs: OgreBotAPI.Actors:Click
  example: oc !c -Actor_Click ${Me.Name} "Strange Lever" FALSE

oc !c -Actor_ClickQueued <who> <actorname> <exactname>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Picks the actor the same way as -Actor_Click, but puts the click in the action queue: at its turn it double-clicks the actor and waits for the cast bar (4 seconds by default) before the next queued action. If the actor is gone by then, the click is dropped.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg actorname (string, default: asdf1323)
  arg exactname (string, default: FALSE)
  runs: OgreBotAPI.Actors:ClickQueued
  example: oc !c -Actor_ClickQueued igw:${Me.Name} "Strange Lever" FALSE

oc !c -AddNoOffensiveOn <who> <mobname> <exactmatchonly>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Adds a mob name to the no-offensive list: while your target matches it, the bot casts no offensive abilities and does not auto-attack. exactmatchonly TRUE (default) needs the exact name, and FALSE matches any name that contains it.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg mobname (string, default: DoesNotExist)
  arg exactmatchonly (bool, default: TRUE): TRUE: only a target with exactly this name. FALSE: any target whose name contains it.
  runs: OgreBotAPI.Combat:AddNoOffensive
  example: oc !c -AddNoOffensiveOn igw:${Me.Name} "${Target.Name}" TRUE

oc !c -AutoCure <who> <toonname> <args>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: Ask the curers to cure a toon. No kinds = arcane, elemental, noxious and trauma; name kinds (arcane/a, elemental/e, noxious/n, trauma/t, curse, confrontfear) to cure only those. Options: -AutoRemove <seconds> (give up after this long, default 8), -tag <name> (a name -AutoCureRemove can cancel it by). Any other word refuses the request.
  arg who (forwho, default: auto): Who to target - leave blank to use the For Who window.
  arg toonname (string)
  arg args (rest): Kinds, then options: -AutoRemove <seconds>, -tag <name>
  runs: OgreBotAPI.Cures:Request
  example: oc !c -AutoCure igw:${Me.Name} ${Group[1].Name} trauma
