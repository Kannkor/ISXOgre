== ISXOgreEQ2.OgreBot ==

${ISXOgreEQ2.OgreBot.Character}
  kind: member of ISXOgreEQ2.OgreBot
  what: The character whose OgreBot profile is loaded.
  returns: string: the character name; empty when nothing is loaded.
  example: echo ${ISXOgreEQ2.OgreBot.Character}

${ISXOgreEQ2.OgreBot.Count}
  kind: member of ISXOgreEQ2.OgreBot
  what: How many single control values the loaded profile holds (checkboxes, text boxes, combo boxes). List sections such as the Cast Stack are not counted.
  returns: int: the number of stored control values; 0 when nothing is loaded.
  example: echo ${ISXOgreEQ2.OgreBot.Count}

${ISXOgreEQ2.OgreBot.Dirty}
  kind: member of ISXOgreEQ2.OgreBot
  what: TRUE when the loaded profile has changes that are not saved to disk yet. Only Save writes them; closing OgreBot, Reload, or loading another profile drops them.
  returns: bool: TRUE when there are unsaved changes; FALSE when there are none or nothing is loaded.
  example: echo ${ISXOgreEQ2.OgreBot.Dirty}

${ISXOgreEQ2.OgreBot.IsReady}
  kind: member of ISXOgreEQ2.OgreBot
  what: TRUE when OgreBot is up: its main window or mini toolbar is open AND a profile is loaded - the check the bot's own features use before they act, and what ${OgreBotAPI.Combat.IsReady} reads too.
  returns: bool: TRUE when a window is open and a profile is loaded; FALSE otherwise.
  example: echo ${ISXOgreEQ2.OgreBot.IsReady}

${ISXOgreEQ2.OgreBot.Loaded}
  kind: member of ISXOgreEQ2.OgreBot
  what: TRUE while an OgreBot profile is loaded for this session. Closing OgreBot unloads the profile, so this goes FALSE on close.
  returns: bool: TRUE when a profile is loaded; FALSE when none is.
  example: echo ${ISXOgreEQ2.OgreBot.Loaded}

${ISXOgreEQ2.OgreBot.PanelVisible}
  kind: member of ISXOgreEQ2.OgreBot
  what: TRUE when the OgreBot main window or the mini toolbar is open, whether or not a profile is loaded. Use IsReady to ask whether the bot can run.
  returns: bool: TRUE when either window is open; FALSE when both are closed.
  example: echo ${ISXOgreEQ2.OgreBot.PanelVisible}

${ISXOgreEQ2.OgreBot.Profile}
  kind: member of ISXOgreEQ2.OgreBot
  what: The name of the loaded OgreBot profile, in the spelling stored in the profile file.
  returns: string: the profile name; empty when nothing is loaded.
  example: echo ${ISXOgreEQ2.OgreBot.Profile}

${ISXOgreEQ2.OgreBot.Value[id]}
  kind: member of ISXOgreEQ2.OgreBot
  what: The stored value of one OgreBot window control, read from the loaded profile in memory (unsaved changes included). The id must match exactly; OgreBotAPI.Options.Value is the case-insensitive version.
  arg id (string): the control id (the same id the profile saves it under), for example checkbox_settings_enablealiases
  returns: string: the control's value as text; empty when the id is not stored, no id is given, or nothing is loaded.
  example: echo ${ISXOgreEQ2.OgreBot.Value[checkbox_settings_enablealiases]}

ISXOgreEQ2.OgreBot:Alias[verb,arg1,arg2,arg3,arg4]
  kind: method of ISXOgreEQ2.OgreBot
  what: Edits the loaded profile's custom aliases in memory (Save keeps them) and refreshes the Aliases tab and Target list; names get a leading * if they lack one, and add refuses only the same name with the same For. Verbs are display (print what each alias resolves to now), add or edit (name,For,NoRaid), del (name), delat or toggle (index), editat (index,name,For,NoRaid) and move (from,to) with 0-based indexes, it does nothing with no profile loaded, and OgreBotAPI.ForWho:AddAlias and RemoveAlias use this same editor.
  arg verb (string): display, add, edit, del, delat, editat, toggle or move
  arg arg1 (string): the alias name (add, edit, del) or a 0-based row index (delat, editat, toggle, move)
  arg arg2 (string): the For value (add, edit; an empty one on edit clears it), the new name (editat) or the target index (move)
  arg arg3 (string): No-Raid as a yes/no word (add, edit) or the For value (editat)
  arg arg4 (bool): editat only: No-Raid
  example: ISXOgreEQ2.OgreBot:Alias[add,Healer,${Group[1].Name},FALSE]

ISXOgreEQ2.OgreBot:Close
  kind: method of ISXOgreEQ2.OgreBot
  what: Closes OgreBot entirely: both windows close, the profile is unloaded (unsaved changes are dropped with a warning in the console), travel routes stop, and follow and camp spots are cleared unless OgreBotAPI.Movement:UseWithoutOgreBot is on. It is the same close as the X on either window, `ogre end bot` and OgreBotAPI.Bot:End.
  example: ISXOgreEQ2.OgreBot:Close

ISXOgreEQ2.OgreBot:CreateProfile[name]
  kind: method of ISXOgreEQ2.OgreBot
  what: Makes a new profile from the current settings, unsaved changes included, writes it to disk and switches to it. It fails with a console line when the name is already used (case does not matter).
  arg name (string): the new profile's name; a b64: prefix marks a base64 name
  example: ISXOgreEQ2.OgreBot:CreateProfile[Solo]

ISXOgreEQ2.OgreBot:DeleteProfile[name]
  kind: method of ISXOgreEQ2.OgreBot
  what: Deletes a named profile from the character's profile file on disk. It refuses, with a console line, the loaded profile, the default profile, the last remaining profile and a name that does not exist.
  arg name (string): the profile name (case does not matter); a b64: prefix marks a base64 name
  example: ISXOgreEQ2.OgreBot:DeleteProfile[Solo]

ISXOgreEQ2.OgreBot:Dump[path]
  kind: method of ISXOgreEQ2.OgreBot
  what: Writes every stored control value of the loaded profile (unsaved changes included) to a JSON file and prints the count and path. List sections such as the Cast Stack are not included, and the file is overwritten each time.
  arg path (string): the file to write
  example: ISXOgreEQ2.OgreBot:Dump["${LavishScript.HomeDirectory}/ogrebot_values.json"]

ISXOgreEQ2.OgreBot:List[section,op,arg1,arg2]
  kind: method of ISXOgreEQ2.OgreBot
  what: Edits one list section of the loaded profile (the Cast Stack or any other ordered list tab) in memory; Save keeps it, and a Cast Stack edit reaches the running cast stack at once. Ops are add (entry), insert or update (index,entry), del or toggle (index) and move (from,to), with 0-based indexes and each entry as base64-encoded JSON; it does not refresh the open window and does nothing with no profile loaded.
  arg section (string): the profile section name, for example CastStack
  arg op (string): add, insert, update, del, move or toggle
  arg arg1 (string): the base64 JSON entry (add) or a 0-based row index (every other op)
  arg arg2 (string): the base64 JSON entry (insert, update) or the target index (move)
  example: ISXOgreEQ2.OgreBot:List[CastStack,toggle,0]

ISXOgreEQ2.OgreBot:LoadProfile[name]
  kind: method of ISXOgreEQ2.OgreBot
  what: Switches to another named profile of the loaded character and refreshes the cast stack and window; if OgreBot is not open it opens it with that profile. Unsaved changes to the current profile are dropped, with one warning line unless you named the profile already loaded, a name that is not found prints a line and keeps the current profile, and OgreBotAPI.Options:LoadProfile calls this.
  arg name (string): the profile name (case does not matter); a b64: prefix marks a base64 name
  example: ISXOgreEQ2.OgreBot:LoadProfile[Raid]

ISXOgreEQ2.OgreBot:Open[character,profile]
  kind: method of ISXOgreEQ2.OgreBot
  what: Loads the character's profile from disk and opens the OgreBot main window and mini toolbar with it, then scans gear and inventory for the Items tab. Calling it while OgreBot is open loads the profile again and drops unsaved changes with one warning line; unlike the `ogre` command it leaves the pause state as it was, and a failed load (no character, profile not found) prints a line and changes nothing.
  arg character (string, default: ${Me.Name}): the character whose profile to load
  arg profile (string, default: the character's default profile): the profile name to load
  example: ISXOgreEQ2.OgreBot:Open[${Me.Name},Group]

ISXOgreEQ2.OgreBot:OpenMini
  kind: method of ISXOgreEQ2.OgreBot
  what: Opens the OgreBot mini toolbar on its own, without loading a profile, and prints a line. If the mini toolbar is already open it does nothing.
  example: ISXOgreEQ2.OgreBot:OpenMini

ISXOgreEQ2.OgreBot:RefreshTargets
  kind: method of ISXOgreEQ2.OgreBot
  what: Re-reads which aliases and targets resolve right now and sends them to the OgreBot window's Target dropdown. It does nothing when the main window is closed.
  example: ISXOgreEQ2.OgreBot:RefreshTargets

ISXOgreEQ2.OgreBot:Reload
  kind: method of ISXOgreEQ2.OgreBot
  what: Reads the loaded profile again from disk, dropping unsaved changes with one warning line, and refreshes the cast stack and the open window. It does nothing when no profile is loaded; OgreBotAPI.Bot:Reload is a different call that restarts the whole bot.
  example: ISXOgreEQ2.OgreBot:Reload

ISXOgreEQ2.OgreBot:ReloadKeyBinds
  kind: method of ISXOgreEQ2.OgreBot
  what: Reads the shared key binds file again (forward, backward and the other movement keys) and prints the new forward and backward keys. Another EQ2 session on this PC sends it after a key is changed.
  example: ISXOgreEQ2.OgreBot:ReloadKeyBinds

ISXOgreEQ2.OgreBot:ReloadUi
  kind: method of ISXOgreEQ2.OgreBot
  what: Reloads the in-game window pages from disk, then reopens the OgreBot main window and mini toolbar if they were open, with the same profile and settings. Nothing in the bot is reloaded or reset; this is what `ogre ui reload` runs.
  example: ISXOgreEQ2.OgreBot:ReloadUi

ISXOgreEQ2.OgreBot:Research[mode]
  kind: method of ISXOgreEQ2.OgreBot
  what: Runs the Ability Research check: it opens the Knowledge window and, with go or run, claims finished research and starts the next ability from the saved priority list, then closes the window. With no mode or any other word it only reads the window and says what it would do (trace also logs each window read), and a call while a check is running is ignored.
  arg mode (string, default: preview): go or run for the real run, trace for a logged preview; anything else is a preview
  example: ISXOgreEQ2.OgreBot:Research[go]

ISXOgreEQ2.OgreBot:Save
  kind: method of ISXOgreEQ2.OgreBot
  what: Writes the loaded profile's changes to disk and prints each file it wrote. With nothing loaded or nothing changed it prints that and writes nothing.
  example: ISXOgreEQ2.OgreBot:Save

ISXOgreEQ2.OgreBot:SaveProfileAs[name]
  kind: method of ISXOgreEQ2.OgreBot
  what: Overwrites another profile with the current settings, unsaved changes included, and switches to it. It fails with a console line when that profile does not exist or is the loaded one.
  arg name (string): the profile to overwrite; a b64: prefix marks a base64 name
  example: ISXOgreEQ2.OgreBot:SaveProfileAs[Solo]

ISXOgreEQ2.OgreBot:ScanItems
  kind: method of ISXOgreEQ2.OgreBot
  what: Asks for a scan of equipped gear, inventory and adornments on the next pulse, to fill the Items tab's source list. The request is dropped when no profile is loaded or the in-game UI is not ready, and opening OgreBot already runs one.
  example: ISXOgreEQ2.OgreBot:ScanItems

ISXOgreEQ2.OgreBot:SetDefault[name]
  kind: method of ISXOgreEQ2.OgreBot
  what: Makes a named profile the one this character loads by default, and writes that to the profile file at once. It fails with a console line when nothing is loaded or the profile does not exist.
  arg name (string): the profile name (case does not matter); a b64: prefix marks a base64 name
  example: ISXOgreEQ2.OgreBot:SetDefault[Group]

ISXOgreEQ2.OgreBot:UplinkConnect
  kind: method of ISXOgreEQ2.OgreBot
  what: Connects this PC's uplink to every PC on the Uplink Info list except this one, spaced out, and prints how many it did (or that there is nothing to do). A second connect or disconnect from the same session within 3 seconds is ignored and only written to the log.
  example: ISXOgreEQ2.OgreBot:UplinkConnect

ISXOgreEQ2.OgreBot:UplinkDisconnect
  kind: method of ISXOgreEQ2.OgreBot
  what: Disconnects this PC's uplink from every PC on the Uplink Info list except this one, and prints how many it did (or that there is nothing to do). A second connect or disconnect from the same session within 3 seconds is ignored and only written to the log.
  example: ISXOgreEQ2.OgreBot:UplinkDisconnect


== ISXOgreEQ2.OSA ==

ISXOgreEQ2.OSA:Close
  kind: method of ISXOgreEQ2.OSA
  what: Closes the On-Screen Assistant window and stops its NPC scan, including an open that is still being retried. It does not untick the Enable On-Screen Assistant setting, so the window opens again only when that setting is next switched on (or at the next load while it is ticked).
  example: ISXOgreEQ2.OSA:Close

ISXOgreEQ2.OSA:Open
  kind: method of ISXOgreEQ2.OSA
  what: Opens the On-Screen Assistant (OSA) window, the same as `ogre osa`: a live list of the NPCs around you, named NPCs first and then by distance, up to 35 rows, refreshed about 5 times a second within the Settings scan radius (50 until a value is set, at most 200). It does nothing while the window is already up, and it does not tick the Enable On-Screen Assistant setting, which opens and closes the window by itself whenever it changes.
  example: ISXOgreEQ2.OSA:Open

ISXOgreEQ2.OSA:Target[id]
  kind: method of ISXOgreEQ2.OSA
  what: Targets the actor with the given ID at once by sending the `target <id>` command, which is what clicking a row in the OSA window does. A call with no ID prints a line and targets nothing.
  arg id (int): ID of the actor to target
  example: ISXOgreEQ2.OSA:Target[${Target.Target.ID}]


== ISXOgreEQ2.Overseer ==

ISXOgreEQ2.Overseer:BuyMissions[flag...]
  kind: method of ISXOgreEQ2.Overseer
  what: Starts a run that buys Overseer missions at the merchant on this session, using this character's Overseer Buy tab with any flags overriding it: -season N, -colour C, -num N, -amount N (at most 20), -replenishonly, -scribe or -noscribe, -destroy or -nodestroy, -gettogh or -nogettogh (go to the guild hall when done); unknown words are skipped. Refused with a console line when OgreBot is not open with a profile, a buy run is already going, or the first argument is not a -flag - the same run OgreBotAPI.Overseer:BuyMissions queues with a for-who.
  arg flag... (string): Optional flags, one per argument, each value as its own argument after its flag; none uses the Overseer Buy tab as saved
  example: ISXOgreEQ2.Overseer:BuyMissions[-season,2,-amount,5]

ISXOgreEQ2.Overseer:BuyMissionsStatus
  kind: method of ISXOgreEQ2.Overseer
  what: Prints whether the Overseer mission buy run is idle or, if running, the phase it is in.
  example: ISXOgreEQ2.Overseer:BuyMissionsStatus

ISXOgreEQ2.Overseer:BuyMissionsStop
  kind: method of ISXOgreEQ2.Overseer
  what: Aborts the Overseer mission buy run in progress and prints the reason. Prints "nothing running." when idle; same as `ogre end buyoverseermissions`.
  example: ISXOgreEQ2.Overseer:BuyMissionsStop

ISXOgreEQ2.Overseer:Run
  kind: method of ISXOgreEQ2.Overseer
  what: Starts a manual Overseer run on this session now, skipping the 60-minute throttle; it uses OgreBot's Overseer tab when OgreBot is open, and the defaults (complete finished quests, add bag missions, start mishaps and new quests, take rewards) when it is not. Refused with a console line when any argument is passed, a run is already going, a bag-mission add is busy, or 'Do not touch overseer at all no matter what' is ticked - the same run as OgreBotAPI.Overseer:CheckQuests and `ogre overseer`.
  example: ISXOgreEQ2.Overseer:Run

ISXOgreEQ2.Overseer:Status
  kind: method of ISXOgreEQ2.Overseer
  what: Prints the Overseer run's current phase, whether it is running, and how many quests it has started and completed. When idle after a run it also prints roughly how many seconds until the next automatic run is allowed.
  example: ISXOgreEQ2.Overseer:Status

ISXOgreEQ2.Overseer:Stop
  kind: method of ISXOgreEQ2.Overseer
  what: Ends the Overseer run in progress on this session and prints "run aborted", or prints "nothing to stop" when idle. Same as `ogre end overseer`.
  example: ISXOgreEQ2.Overseer:Stop

== ISXOgreEQ2.Paths ==

ISXOgreEQ2.Paths:End
  kind: method of ISXOgreEQ2.Paths
  what: Closes the Points of Interest and Paths window, which is what `ogre end paths` and the window's X do. A path being walked goes on.
  example: ISXOgreEQ2.Paths:End

ISXOgreEQ2.Paths:Open[path]
  kind: method of ISXOgreEQ2.Paths
  what: Opens the Points of Interest and Paths window (the same as `ogre paths`), on a saved path of the zone you are in when you name one: this is the one way to open it, from a panel, a button or a script. A window already open comes to the front on that path, a path this zone does not have prints one line and the window opens with nothing picked, and without the Ogre UI desktop it prints a warning.
  arg path (string, default: none (nothing picked)): The path to open on, in any case. A name with spaces may be quoted or written as several words. Leave it out to open the window with nothing picked.
  example: ISXOgreEQ2.Paths:Open["North Loop"]


== ISXOgreEQ2.Perf ==

ISXOgreEQ2.Perf:Measure[seconds,nothreads]
  kind: method of ISXOgreEQ2.Perf
  what: Measures the frame rate and what uses each frame for a number of seconds, then prints a report to the console and the log file - the same as ogre perf. The capture starts on the next frame; if one is already running, or a word other than a number or nothreads is given, it prints a line and measures nothing.
  arg seconds (int, default: 10): how long to measure, 3 to 120 (values outside are clamped)
  arg nothreads (string, default: ""): the word nothreads turns off the per-thread breakdown; it may come before or after the seconds
  example: ISXOgreEQ2.Perf:Measure[30]

ISXOgreEQ2.Perf:Status
  kind: method of ISXOgreEQ2.Perf
  what: Prints one console line saying whether a measurement is idle, about to start, or running with the seconds done and left - the same as ogre perf status.
  example: ISXOgreEQ2.Perf:Status

ISXOgreEQ2.Perf:Stop
  kind: method of ISXOgreEQ2.Perf
  what: Ends a running measurement early and prints the report for what was measured, or cancels one that has not started yet - the same as ogre perf stop. With nothing running it prints that nothing is being measured.
  example: ISXOgreEQ2.Perf:Stop

== ISXOgreEQ2.PotCb ==

ISXOgreEQ2.PotCb:End
  kind: method of ISXOgreEQ2.PotCb
  what: Stops the Potency / Crit Bonus / Fervor sampler if it runs and always closes its panel, keeping the history. This is what `ogre end potcb` and the panel's X do.
  example: ISXOgreEQ2.PotCb:End

ISXOgreEQ2.PotCb:Help
  kind: method of ISXOgreEQ2.PotCb
  what: Prints the `ogre potcb` usage to the console: open, on / off, status, reset and interval.
  example: ISXOgreEQ2.PotCb:Help

ISXOgreEQ2.PotCb:Interval[ms]
  kind: method of ISXOgreEQ2.PotCb
  what: Sets how often the sampler reads Potency, Crit Bonus and Fervor, held between 50 and 10000 ms (a negative is 50), and prints the new value. With no value it prints the current interval; a value that is not a number keeps the interval in force and says so.
  arg ms (int): Sampling interval in milliseconds, 50 to 10000 (the sampler starts at 200). Optional: leave it out to print the current interval.
  example: ISXOgreEQ2.PotCb:Interval[500]

ISXOgreEQ2.PotCb:Off
  kind: method of ISXOgreEQ2.PotCb
  what: Stops the Potency / Crit Bonus / Fervor sampler and closes its panel, keeping the recorded history. If it was not sampling it prints "potcb: not running." and leaves the panel open.
  example: ISXOgreEQ2.PotCb:Off

ISXOgreEQ2.PotCb:On
  kind: method of ISXOgreEQ2.PotCb
  what: Starts the Potency / Crit Bonus / Fervor sampler, which reads the three stats every interval (default 200 ms) while you are in world, and prints one line saying so. Does nothing if it is already sampling, and does not open the panel.
  example: ISXOgreEQ2.PotCb:On

ISXOgreEQ2.PotCb:Open
  kind: method of ISXOgreEQ2.PotCb
  what: Opens the Potency / Crit Bonus / Fervor tracker panel, starting the sampler first if it was stopped (the same as bare `ogre potcb`). If the panel is already up it stays as it is, and without the Ogre UI desktop it prints a warning while sampling still starts.
  example: ISXOgreEQ2.PotCb:Open

ISXOgreEQ2.PotCb:Reset
  kind: method of ISXOgreEQ2.PotCb
  what: Clears every recorded Potency / Crit Bonus / Fervor figure and the sampled time, then prints "potcb: history cleared". The sampler stays on or off as it was.
  example: ISXOgreEQ2.PotCb:Reset

ISXOgreEQ2.PotCb:Status
  kind: method of ISXOgreEQ2.PotCb
  what: Prints every Potency / Crit Bonus / Fervor figure to the console: running or stopped and time sampled, then per stat the current value and peak, the in-combat min / avg / max, time at cap, time at peak and combat time by tenth of the peak, and the overall min / avg / max. It also warns when readings were skipped because a stat showed no number.
  example: ISXOgreEQ2.PotCb:Status


== ISXOgreEQ2.PulseBudget ==

ISXOgreEQ2.PulseBudget:Ceiling[us]
  kind: method of ISXOgreEQ2.PulseBudget
  what: Sets the shared frame ceiling and saves it; below 0 reads as 0. With no value it prints one warning and changes nothing.
  arg us (float): The ceiling in microseconds; 0 means none.
  example: ISXOgreEQ2.PulseBudget:Ceiling[4000]

ISXOgreEQ2.PulseBudget:Close
  kind: method of ISXOgreEQ2.PulseBudget
  what: Closes the Pulse Budget window, the same as `ogre end pulse`. The budget keeps running.
  example: ISXOgreEQ2.PulseBudget:Close

ISXOgreEQ2.PulseBudget:JobTest[state]
  kind: method of ISXOgreEQ2.PulseBudget
  what: A test mode for this session only: every pulse job pauses at every checkpoint, so state that does not survive a frame shows up at once. It is never saved.
  arg state (string): on or 1 turns it on; any other word turns it off. Required.
  example: ISXOgreEQ2.PulseBudget:JobTest[on]

ISXOgreEQ2.PulseBudget:Off
  kind: method of ISXOgreEQ2.PulseBudget
  what: Turns the shared frame ceiling off and saves it. Each section still keeps its own slice.
  example: ISXOgreEQ2.PulseBudget:Off

ISXOgreEQ2.PulseBudget:On
  kind: method of ISXOgreEQ2.PulseBudget
  what: Turns the shared frame ceiling on, resets the counters and saves it.
  example: ISXOgreEQ2.PulseBudget:On

ISXOgreEQ2.PulseBudget:Open
  kind: method of ISXOgreEQ2.PulseBudget
  what: Opens the Pulse Budget window, the same as bare `ogre pulse`.
  example: ISXOgreEQ2.PulseBudget:Open

== ISXOgreEQ2.Queue ==

${ISXOgreEQ2.Queue.Blocking}
  kind: member of ISXOgreEQ2.Queue
  what: Why the most urgent waiting entry cannot start yet, as a line like seq=5 CastAbility prio=100 age=900ms: resource busy: CastBar, or starved by a higher-priority haltQueue entry. Empty when nothing is waiting or the next entry is free to start.
  returns: string: the reason line; empty when nothing is held up
  example: echo ${ISXOgreEQ2.Queue.Blocking}

${ISXOgreEQ2.Queue.Count}
  kind: member of ISXOgreEQ2.Queue
  what: Number of entries in the action queue, running plus waiting.
  returns: int: entries running plus waiting; 0 when the queue is empty
  example: echo ${ISXOgreEQ2.Queue.Count}

${ISXOgreEQ2.Queue.Enqueue[priority,kind,arg0,arg1,ttlstart,ttlmax]}
  kind: member of ISXOgreEQ2.Queue
  what: Adds an entry exactly like ISXOgreEQ2.Queue:Add and returns its seq, the id you pass to Status, IsDone and Remove. Reading the member is what adds the entry, so every read queues another one, and an unknown kind (ApplyVerbCastBar and DialogChoices included) or a flow name that is not registered adds nothing and returns 0.
  arg priority (int, default: 100): Higher runs first; 0 means the default 100
  arg kind (string): What to do, any case: CastAbility, CastItem, ClickCastBar, RawCommand, Movement or Flow. ApplyVerbCastBar and DialogChoices are not kinds here; OgreBotAPI.Actors:ApplyVerbIDQueued queues an apply-verb
  arg arg0 (string): Depends on kind: RawCommand the console command, CastAbility the ability id or name, CastItem the item name, ClickCastBar the actor id, Movement x,y,z with an optional precision, Flow the flow name
  arg arg1 (string): Depends on kind: CastAbility the target name (empty = current target), CastItem the equip slot (empty = the bag item by name), ClickCastBar the wait in tenths of a second (empty = 4 seconds), Flow its arguments
  arg ttlstart (int, default: 0): Milliseconds the entry may wait to start before it is dropped with status Expired; 0 = no limit
  arg ttlmax (int, default: 0): Milliseconds the entry may run before it is stopped with status Aborted; 0 = no limit
  returns: int64: the new entry's seq (1 and up); 0 when the kind is unknown
  example: echo ${ISXOgreEQ2.Queue.Enqueue[100,RawCommand,"echo queued"]}

${ISXOgreEQ2.Queue.Entry[index]}
  kind: member of ISXOgreEQ2.Queue
  what: One queue entry as a readable line, such as seq=12 prio=100 RawCommand waiting age=40ms arg0=echo hi, where seq is the entry's id. The index counts from 1, running entries first and then waiting ones, each sorted by priority then by the order they were added.
  arg index (int): Position in the queue counting from 1: running entries first, then waiting ones, highest priority first
  returns: string: the entry line; empty when the index is 0, past the end or missing
  example: echo ${ISXOgreEQ2.Queue.Entry[1]}

${ISXOgreEQ2.Queue.EntryJSON[index]}
  kind: member of ISXOgreEQ2.Queue
  what: One queue entry as a JSON object with seq, priority, kind, status (running or waiting), holds, haltQueue, haltCastStack, ageMs, blocked, arg0, arg1 and label. Same index as Entry, counting from 1, so a loop from 1 to Count reads the whole queue.
  arg index (int): Position in the queue counting from 1: running entries first, then waiting ones, highest priority first
  returns: string: the entry as a JSON object; {} when the index is 0, past the end or missing
  example: echo ${ISXOgreEQ2.Queue.EntryJSON[1]}

${ISXOgreEQ2.Queue.InFlight}
  kind: member of ISXOgreEQ2.Queue
  what: Whether any queue entry is running right now.
  returns: bool: TRUE when at least one entry is running; FALSE when none is
  example: echo ${ISXOgreEQ2.Queue.InFlight}

${ISXOgreEQ2.Queue.IsDone[seq]}
  kind: member of ISXOgreEQ2.Queue
  what: Whether the queue entry with that seq has finished in any way (Done, Failed, Expired, Aborted or Removed), so a wait loop never hangs on a failed entry; read Status for how it ended. A seq that finished and has since been forgotten also reads TRUE, while a seq never issued reads FALSE.
  arg seq (int64): The entry's id, from Enqueue or the seq= field of Entry and Spew
  returns: bool: TRUE when the entry has finished, however it ended; FALSE while it is waiting or running, or when the seq was never issued
  example: echo ${ISXOgreEQ2.Queue.IsDone[1]}

${ISXOgreEQ2.Queue.Status[seq]}
  kind: member of ISXOgreEQ2.Queue
  what: The state of the queue entry with that seq. Unknown means the seq was never issued or finished too long ago to remember (only the most recent 256 are kept).
  arg seq (int64): The entry's id, from Enqueue or the seq= field of Entry and Spew
  returns: string: Pending, InFlight, Done, Failed, Expired, Aborted, Removed or Unknown
  example: echo ${ISXOgreEQ2.Queue.Status[1]}

ISXOgreEQ2.Queue:Add[priority,kind,arg0,arg1,ttlstart,ttlmax]
  kind: method of ISXOgreEQ2.Queue
  what: Adds an action to the priority queue, which runs it on its turn once the cast bar or movement it needs is free (highest priority first, even while OgreBot is paused), and prints an Add seq=N line to the console. Waiting and running entries are dropped on a zone change or when OgreBot ends, a Flow lives as its registered flow does, with that flow's holds and halts, and a flow name that is not registered gets one line; use the Enqueue member instead when you need the seq back.
  arg priority (int, default: 100): Higher runs first; 0 means the default 100
  arg kind (string): What to do, any case: CastAbility, CastItem, ClickCastBar, RawCommand, Movement or Flow. ApplyVerbCastBar and DialogChoices are not kinds here; OgreBotAPI.Actors:ApplyVerbIDQueued queues an apply-verb
  arg arg0 (string): Depends on kind: RawCommand the console command, CastAbility the ability id or name, CastItem the item name, ClickCastBar the actor id, Movement x,y,z with an optional precision, Flow the flow name
  arg arg1 (string): Depends on kind: CastAbility the target name (empty = current target), CastItem the equip slot (empty = the bag item by name), ClickCastBar the wait in tenths of a second (empty = 4 seconds), Flow its arguments
  arg ttlstart (int, default: 0): Milliseconds the entry may wait to start before it is dropped with status Expired; 0 = no limit
  arg ttlmax (int, default: 0): Milliseconds the entry may run before it is stopped with status Aborted; 0 = no limit. For a Flow it can only shorten the flow's own limit
  example: ISXOgreEQ2.Queue:Add[100,RawCommand,"echo queued"]

ISXOgreEQ2.Queue:Remove[seq]
  kind: method of ISXOgreEQ2.Queue
  what: Removes the waiting queue entry with that seq (its Status becomes Removed) and prints the result to the console. A running entry is not removed, and an unknown or missing seq only prints that there is no such entry.
  arg seq (int64): The entry's id, from Enqueue or the seq= field of Entry and Spew
  example: ISXOgreEQ2.Queue:Remove[1]

ISXOgreEQ2.Queue:Spew
  kind: method of ISXOgreEQ2.Queue
  what: Prints every queue entry to the console, running entries then waiting ones, one line each starting with its seq, then a line on how to remove one. Prints empty - 0 entries when the queue is empty.
  example: ISXOgreEQ2.Queue:Spew

== ISXOgreEQ2.Scheduler ==

${ISXOgreEQ2.Scheduler.Active[key]}
  kind: member of ISXOgreEQ2.Scheduler
  what: Whether a timer with this key still has a fire pending. Keys ignore case; a one-shot timer reads FALSE once it has fired.
  arg key (string): the timer's key (its event name unless it was armed with -key)
  returns: bool: TRUE when a fire is still pending for this key; FALSE when there is no such timer.
  example: echo ${ISXOgreEQ2.Scheduler.Active[MyTimerEvent]}

${ISXOgreEQ2.Scheduler.Count}
  kind: member of ISXOgreEQ2.Scheduler
  what: How many keyed timers are pending in the scheduler. The encounter engine's timers live in the same table, so they count too.
  returns: int: number of pending keyed timers.
  example: echo ${ISXOgreEQ2.Scheduler.Count}

${ISXOgreEQ2.Scheduler.Remaining[key]}
  kind: member of ISXOgreEQ2.Scheduler
  what: Milliseconds until the next fire of the timer with this key. Reads 0 when there is no such timer or it is due now.
  arg key (string): the timer's key (its event name unless it was armed with -key)
  returns: int64: milliseconds to the next fire; 0 when there is no such timer or it is due.
  example: echo ${ISXOgreEQ2.Scheduler.Remaining[MyTimerEvent]}

ISXOgreEQ2.Scheduler:Cancel[key]
  kind: method of ISXOgreEQ2.Scheduler
  what: Stops the timer with this key before it fires again. Keys ignore case, and a key with no timer does nothing.
  arg key (string): the timer's key (its event name unless it was armed with -key)
  example: ISXOgreEQ2.Scheduler:Cancel[MyTimerEvent]

ISXOgreEQ2.Scheduler:ClearNonPersistent
  kind: method of ISXOgreEQ2.Scheduler
  what: Cancels every script and encounter timer that was not armed with -persistent, and leaves the bot's own pending delayed casts and actions. Finishing a zone clears every non-persistent timer, the bot's included.
  example: ISXOgreEQ2.Scheduler:ClearNonPersistent

ISXOgreEQ2.Scheduler:FireEvent[delay,eventName,payload,-persistent,-key]
  kind: method of ISXOgreEQ2.Scheduler
  what: Fires the LavishScript event eventName once after the delay, always with exactly one argument (the payload, or an empty string). Arming a key that is already pending replaces that timer, and unless -persistent is given the timer is dropped when you finish zoning; a bad delay such as 30x fires nothing and warns on the console.
  arg delay (string): how long to wait: a whole number of milliseconds, or a number with ms, s, m or h (30s, 1.5s, 2m)
  arg eventName (string): the LavishScript event to fire
  arg payload (string, default: ""): the one argument passed to the event; the first extra word not starting with a dash
  arg -persistent (switch, default: off): keep the timer across zoning
  arg -key (switch, default: the event name): -key <k>: the timer's key, case-insensitive
  example: ISXOgreEQ2.Scheduler:FireEvent[5s,MyTimerEvent,hello]

ISXOgreEQ2.Scheduler:FireEventEvery[interval,eventName,repeats,payload,-persistent,-key]
  kind: method of ISXOgreEQ2.Scheduler
  what: Fires the LavishScript event eventName every interval, repeats times, always with exactly one argument (the payload, or an empty string); a missing, 0 or negative repeats means forever. Re-arming a pending key replaces it, and unless -persistent is given the timer is dropped when you finish zoning; a bad interval fires nothing and warns on the console.
  arg interval (string): time between fires: a whole number of milliseconds, or a number with ms, s, m or h; the first fire comes one interval after the call
  arg eventName (string): the LavishScript event to fire
  arg repeats (int, default: forever): how many times to fire; 0 or less fires until cancelled
  arg payload (string, default: ""): the one argument passed to the event; the first extra word not starting with a dash
  arg -persistent (switch, default: off): keep the timer across zoning
  arg -key (switch, default: the event name): -key <k>: the timer's key, case-insensitive
  example: ISXOgreEQ2.Scheduler:FireEventEvery[10s,MyTimerEvent,6,tick]

ISXOgreEQ2.Scheduler:Spew
  kind: method of ISXOgreEQ2.Scheduler
  what: Prints every pending keyed timer to the console, the encounter engine's included: a count line, then one line per timer with its key, event, milliseconds to the next fire, how many times it has fired, and whether it is persistent.
  example: ISXOgreEQ2.Scheduler:Spew

  example: ISXOgreEQ2.Tour:Skip

== ISXOgreEQ2.TravelMesh ==

${ISXOgreEQ2.TravelMesh.TMActive}
  kind: member of ISXOgreEQ2.TravelMesh
  what: TRUE while a travel route is running on this character. It reads FALSE while idle, after arriving or giving up, and while a Go is still waiting for a zone to finish loading.
  returns: bool: TRUE when a route is running; FALSE otherwise
  example: echo ${ISXOgreEQ2.TravelMesh.TMActive}

${ISXOgreEQ2.TravelMesh.TMBias[kind]}
  kind: member of ISXOgreEQ2.TravelMesh
  what: The cost multiplier the planner uses for one kind of hop (door, bell, spire, druid, map, amenity or item): 1 is neutral, below 1 prefers it, above 1 avoids it, 0 or less forbids it. Every kind starts at 1.
  arg kind (string): the hop kind: door, bell, spire, druid, map, amenity or item
  returns: float: the multiplier for that kind; -1 when the kind is unknown or missing
  example: echo ${ISXOgreEQ2.TravelMesh.TMBias[bell]}

${ISXOgreEQ2.TravelMesh.TMCurrentHop}
  kind: member of ISXOgreEQ2.TravelMesh
  what: A one-line description of the hop in progress: the kind (door, bell, spire, druid, map, amenity or item), the from and to zone short names, and the travel action and destination label when there is one. Empty when no hop is in progress, including after arrival.
  returns: string: the current hop's description; empty when there is none
  example: echo ${ISXOgreEQ2.TravelMesh.TMCurrentHop}

${ISXOgreEQ2.TravelMesh.TMDataErrors}
  kind: member of ISXOgreEQ2.TravelMesh
  what: How many travel data files had a problem at the last load, counting files that were skipped and files that loaded with a warning. It reads 0 until the travel data has loaded.
  returns: int: the number of problem files; 0 when the data loaded cleanly
  example: echo ${ISXOgreEQ2.TravelMesh.TMDataErrors}

${ISXOgreEQ2.TravelMesh.TMDataErrorText}
  kind: member of ISXOgreEQ2.TravelMesh
  what: The problem report from the last load, one line per file: its path, which layer it came from (default or custom) and the message. Empty when every file loaded cleanly, or until the travel data has loaded.
  returns: string: the problem report, one file per line; empty when clean
  example: echo ${ISXOgreEQ2.TravelMesh.TMDataErrorText}

${ISXOgreEQ2.TravelMesh.TMEdges}
  kind: member of ISXOgreEQ2.TravelMesh
  what: How many zone-to-zone connections (doors, zone lines, guild hall amenities, travel items and so on) the loaded travel data holds. It reads 0 until the travel data has loaded.
  returns: int: the number of connections in the travel data
  example: echo ${ISXOgreEQ2.TravelMesh.TMEdges}

${ISXOgreEQ2.TravelMesh.TMFeatures}
  kind: member of ISXOgreEQ2.TravelMesh
  what: One line per account feature the travel data can require (the expansion Friends and Family features), with this character's answer: YES or no, and whether it was scanned or set by you, or unanswered. A no from a scan is checked again after a week, a YES or your own answer is kept, and the lines are read by the travel engine about once a second while you are in the world.
  returns: string: one line per account feature
  example: echo ${ISXOgreEQ2.TravelMesh.TMFeatures}

${ISXOgreEQ2.TravelMesh.TMGoal}
  kind: member of ISXOgreEQ2.TravelMesh
  what: The short zone name of the destination of the current or last route, such as antonica. Empty before any route has started.
  returns: string: the destination zone short name; empty before the first route
  example: echo ${ISXOgreEQ2.TravelMesh.TMGoal}

${ISXOgreEQ2.TravelMesh.TMHop}
  kind: member of ISXOgreEQ2.TravelMesh
  what: The number of the hop the route is on, counting from 1. It reads 1 before any route has run and one more than TMHops once the route has arrived.
  returns: int: the current hop number, 1-based
  example: echo ${ISXOgreEQ2.TravelMesh.TMHop}

${ISXOgreEQ2.TravelMesh.TMHops}
  kind: member of ISXOgreEQ2.TravelMesh
  what: How many hops the current plan has. After a re-plan this is the hop count of the new plan for the rest of the trip, not the original total.
  returns: int: the hop count of the current plan; 0 before any route
  example: echo ${ISXOgreEQ2.TravelMesh.TMHops}

${ISXOgreEQ2.TravelMesh.TMParty}
  kind: member of ISXOgreEQ2.TravelMesh
  what: For the current or last route: the route id, how many group members it counted, and either "everyone is here" or the names of members not yet in this zone and settled. It is empty before any route has started, and read by the travel engine about once a second while you are in the world.
  returns: string: the group status line; empty before the first route
  example: echo ${ISXOgreEQ2.TravelMesh.TMParty}

${ISXOgreEQ2.TravelMesh.TMReason}
  kind: member of ISXOgreEQ2.TravelMesh
  what: Why the last route stopped, or what its last step reported, such as "stopped by request" or "replaced by a new route". Empty while a route runs normally.
  returns: string: the stop reason or last step message; empty when there is none
  example: echo ${ISXOgreEQ2.TravelMesh.TMReason}

${ISXOgreEQ2.TravelMesh.TMReplans}
  kind: member of ISXOgreEQ2.TravelMesh
  what: How many times the current route has re-planned around a hop that failed. A route gives up after 3 re-plans.
  returns: int: the re-plan count for the current or last route
  example: echo ${ISXOgreEQ2.TravelMesh.TMReplans}

${ISXOgreEQ2.TravelMesh.TMRoute}
  kind: member of ISXOgreEQ2.TravelMesh
  what: The whole current plan as text, one numbered hop per line in the same form as TMCurrentHop. It still holds the last plan after the route ends.
  returns: string: the plan, one hop per line; empty before any route
  example: echo ${ISXOgreEQ2.TravelMesh.TMRoute}

${ISXOgreEQ2.TravelMesh.TMStagger}
  kind: member of ISXOgreEQ2.TravelMesh
  what: The start delay in milliseconds per group member for group travel, so members do not all set off at once. The default is 10000, and 0 means everybody starts at once.
  returns: int: milliseconds of start delay per group member
  example: echo ${ISXOgreEQ2.TravelMesh.TMStagger}

${ISXOgreEQ2.TravelMesh.TMState}
  kind: member of ISXOgreEQ2.TravelMesh
  what: The step the route is on: idle, hop-start, walk, wait-for-group, ride, act, verify, done or failed. It keeps done or failed after a route ends until the next route starts.
  returns: string: the current route step name
  example: echo ${ISXOgreEQ2.TravelMesh.TMState}

${ISXOgreEQ2.TravelMesh.TMValidate}
  kind: member of ISXOgreEQ2.TravelMesh
  what: A health check of the loaded travel data, one issue per line. Empty when no issues are found, or until the travel data has loaded.
  returns: string: the issues, one per line; empty when there are none
  example: echo ${ISXOgreEQ2.TravelMesh.TMValidate}

${ISXOgreEQ2.TravelMesh.TMZones}
  kind: member of ISXOgreEQ2.TravelMesh
  what: How many zones the loaded travel data knows. It reads 0 until the travel data has loaded.
  returns: int: the number of zones in the travel data
  example: echo ${ISXOgreEQ2.TravelMesh.TMZones}

ISXOgreEQ2.TravelMesh:Go[destination,poi]
  kind: method of ISXOgreEQ2.TravelMesh
  what: Starts a route like OgreBotAPI.Travel:Mesh, from your current zone to the destination, walking and using doors, zone lines, bells, spires, druid rings, the fast-travel map, guild hall amenities and travel items in your bags as needed; it replaces a running route, whoever started it, only when the new one can be planned. Problems (no destination, unknown destination with suggestions, current zone not in the travel data, no route) are echoed to the console, a Go made while zoning waits for the zone to settle, and the route moves with OgreBot closed too - TravelMesh:Stop ends it.
  arg destination (string): the zone to travel to - its display name, an alias or its short name, any case
  arg poi (string, default: none): optional point of interest in the destination zone to finish at; one the zone data does not list is reported and the trip still goes to the zone
  example: ISXOgreEQ2.TravelMesh:Go[Antonica,"Druid Rings"]

ISXOgreEQ2.TravelMesh:GoGroup[destination,poi]
  kind: method of ISXOgreEQ2.TravelMesh
  what: Like OgreBotAPI.Travel:MeshGroup: starts your own route as Go does, then sends -TravelMesh for the same destination to the rest of your group through OgreConsole, so each member plans its own route from where it stands, with starts staggered by TMStagger. If your own route cannot be planned the error is echoed and nothing is sent; the other members' copies run as OgreBot routes, so they are stopped with -TravelMeshStop.
  arg destination (string): the zone to travel to - its display name, an alias or its short name, any case
  arg poi (string, default: none): optional point of interest in the destination zone to finish at; one the zone data does not list is reported and the trip still goes to the zone
  example: ISXOgreEQ2.TravelMesh:GoGroup[Antonica]

ISXOgreEQ2.TravelMesh:Preview[destination]
  kind: method of ISXOgreEQ2.TravelMesh
  what: Plans a route from your current zone to the destination and prints it to the console without moving: a summary line with the hop count and rough time in seconds, then one numbered hop per line. An unknown destination prints an "unknown destination" line with suggestions, and no destination prints an error.
  arg destination (string): the zone to plan to - its display name, an alias or its short name, any case
  example: ISXOgreEQ2.TravelMesh:Preview[Antonica]

ISXOgreEQ2.TravelMesh:Reload
  kind: method of ISXOgreEQ2.TravelMesh
  what: Re-reads the travel data from Ogre/EQ2/Travel/default and your own OgreSave/EQ2/Travel/custom files and echoes a summary of zones, connections, files and errors. Any running route is stopped first, whoever started it; if the first load has not finished within 5 seconds it says so and changes nothing.
  example: ISXOgreEQ2.TravelMesh:Reload

ISXOgreEQ2.TravelMesh:ScanFeatures
  kind: method of ISXOgreEQ2.TravelMesh
  what: Runs the game's show_account_features command to answer this character's unanswered or expired account features, and echoes a status line. Each feature is scanned at most once per session, a scan also starts by itself when a route is planned, and when nothing is scanned (out of the world included) the line says every feature is already answered.
  example: ISXOgreEQ2.TravelMesh:ScanFeatures

ISXOgreEQ2.TravelMesh:SetBias[kind,multiplier]
  kind: method of ISXOgreEQ2.TravelMesh
  what: Sets how much the planner likes one kind of hop: 1 is neutral, below 1 prefers it, above 1 avoids it, 0 or less forbids it, and the new value is echoed. It applies to the next plan and is not saved; a multiplier that is not a number sets the normal bias of 1 and says so.
  arg kind (string): the hop kind: door, bell, spire, druid, map, amenity or item; anything else is refused with a console error
  arg multiplier (float): the cost multiplier: 1 neutral, below 1 prefer, above 1 avoid, 0 or less forbid; a word is 1
  example: ISXOgreEQ2.TravelMesh:SetBias[druid,0.5]

ISXOgreEQ2.TravelMesh:SetFeature[flag,value]
  kind: method of ISXOgreEQ2.TravelMesh
  what: Saves your own answer for one account feature for this character in OgreSave/EQ2/Travel/account-features.json; it is permanent and never scanned over, and the answer is echoed. A feature name the travel data does not use is refused with a line naming the ones it does, a blank value prints an error, and a word that is not yes or no leaves the feature as it is and says so.
  arg flag (string): the account feature name as TMFeatures shows it, such as roc_friends_and_family, in any case
  arg value (bool): TRUE, 1, yes or on means this character has the feature; FALSE, 0, no or off means it does not
  example: ISXOgreEQ2.TravelMesh:SetFeature[roc_friends_and_family,TRUE]

ISXOgreEQ2.TravelMesh:SetStagger[ms]
  kind: method of ISXOgreEQ2.TravelMesh
  what: Sets the start delay in milliseconds per group member for group travel (0 = everybody at once) and echoes it. A negative number is stored as 0, a value that is not a number counts as 0, and the setting is not saved.
  arg ms (int): milliseconds of start delay per group member; 0 starts everybody at once
  example: ISXOgreEQ2.TravelMesh:SetStagger[5000]

ISXOgreEQ2.TravelMesh:Stop[-force]
  kind: method of ISXOgreEQ2.TravelMesh
  what: Cancels a route started with this object's Go or GoGroup, including one still waiting for a zone to settle. A route someone else started is refused with one line naming the owner and how to stop it, and -force stops it anyway.
  arg -force (switch): stop the route whoever started it
  example: ISXOgreEQ2.TravelMesh:Stop


== ISXOgreEQ2.Watcher ==

ISXOgreEQ2.Watcher:End
  kind: method of ISXOgreEQ2.Watcher
  what: Turns off both the name watch (Find) and the shiny watch (TrackShiny), closes the Watcher window and prints which of them were on; the off state is saved, so they stay off on the next load. This is what `ogre end watcher` and the window's close button do.
  example: ISXOgreEQ2.Watcher:End

ISXOgreEQ2.Watcher:Find[word...]
  kind: method of ISXOgreEQ2.Watcher
  what: Watches for actors by exact name, case not mattering (`ogre find`): given names it replaces the watch list, arms and checks the zone once, then each time a watched name spawns it prints where, broadcasts '<you>: APPEARED: <name>' to your bot sessions and sets an in-game waypoint on it, and it prints when one despawns (these alerts are skipped in a guild hall). A first word that is an option does that instead (-add or -remove <name>, -clear, -list, -on, -off, -scan, -status, -panel opens the Watcher window, -rorr adds the four Renewal of Ro researchers to the names), no words prints the usage, and the list and armed state are saved and restored on the next load.
  arg word... (string, default: none (prints the usage)): the names to watch (quote a name that has spaces), or one option first followed by its value
  example: ISXOgreEQ2.Watcher:Find[${Target.Name}]

ISXOgreEQ2.Watcher:TrackShiny[word...]
  kind: method of ISXOgreEQ2.Watcher
  what: Watches for shiny harvest nodes of one colour within 100 units, every 500 ms by default (`ogre trackshiny`): when it finds one it did not just announce, it prints '<colour> shiny!', broadcasts it to your bot sessions and sets an in-game waypoint on it. No word arms it on Purple, a colour name (White, Green, Purple, Red, BlueShimmer, Blue) arms that colour and an unknown one is refused with the list, the options are -off, -status, -colours (or -colors), -interval <ms> (held to 250..30000) and -panel, and the settings are saved and restored on the next load.
  arg word... (string, default: Purple): a colour to watch for, or one option first followed by its value
  example: ISXOgreEQ2.Watcher:TrackShiny[Red]
