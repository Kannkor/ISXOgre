# ISXOgreEQ2.Targeting

## Members

### `ActiveList`

`${ISXOgreEQ2.Targeting.ActiveList}`

The name of the saved auto-target list last loaded or saved into the working list, like OgreBotAPI.AutoTarget.ListName. Reading it also refreshes the saved-list catalogue for the current zone.

**Returns:** string: the saved-list name; "" when none is loaded or when not in the world.

```text
echo ${ISXOgreEQ2.Targeting.ActiveList}
```

### `AssistId`

`${ISXOgreEQ2.Targeting.AssistId}`

The assist decision as one number, read fresh on each call - the same call as OgreBotAPI.Assist.TargetID. It answers even when the Auto Assist box is off.

**Returns:** int64: greater than 0 is the ID this character would target; 0 when it picks its own target; -1 when its current target should be left alone; NULL when not in the world.

```text
echo ${ISXOgreEQ2.Targeting.AssistId}
```

### `Enabled`

`${ISXOgreEQ2.Targeting.Enabled}`

Whether either targeting engine is switched on: the Auto Assist box or the auto-target box. This is not OgreBotAPI.AutoTarget.Enabled, which reads only the auto-target box.

**Returns:** bool: TRUE when the Auto Assist box or the auto-target box is ticked; FALSE when both are off.

```text
echo ${ISXOgreEQ2.Targeting.Enabled}
```

### `InControl`

`${ISXOgreEQ2.Targeting.InControl}`

Whether this character picks its own target instead of following someone else's - the same call as OgreBotAPI.Assist.InControl. With the Auto Assist box off it reads TRUE.

**Returns:** bool: TRUE when this character picks its own target; FALSE when it follows another player, and FALSE when not in the world.

```text
echo ${ISXOgreEQ2.Targeting.InControl}
```

### `SavedList`

`${ISXOgreEQ2.Targeting.SavedList[index]}`

The name of one saved auto-target list for the current zone, counting from 1 in file order, the same as OgreBotAPI.AutoTarget.SavedName.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `index` | int |  | Which saved list, counting from 1. 0, or text that is not a number, reads empty. |

**Returns:** string: the saved list's name; "" when index is 0 or past the count, when no index is given, or when not in the world.

```text
echo ${ISXOgreEQ2.Targeting.SavedList[1]}
```

### `SavedListCount`

`${ISXOgreEQ2.Targeting.SavedListCount}`

The number of saved auto-target lists for the current zone, like OgreBotAPI.AutoTarget.SavedCount. Unlike that member it reloads the zone's catalogue first when the zone has changed, so it never shows the previous zone.

**Returns:** int: the number of saved lists; 0 when the zone has none or when not in the world.

```text
echo ${ISXOgreEQ2.Targeting.SavedListCount}
```

## Methods

### `ClearList`

`ISXOgreEQ2.Targeting:ClearList`

Empties the working auto-target list and blanks ActiveList - OgreBotAPI.AutoTarget:Clear without the for-who. Auto-target then falls back to the profile's own AutoTarget entries (nothing to pick if it has none) until a list is loaded or entries are added, and saved lists on disk are not touched.

```text
ISXOgreEQ2.Targeting:ClearList
```

### `LoadList`

`ISXOgreEQ2.Targeting:LoadList[<name>]`

Replaces the working auto-target list with the saved list of that name for the current zone (the name is matched ignoring case) - OgreBotAPI.AutoTarget:LoadSaved without the for-who. If the zone has no list by that name, or you are not in the world, nothing changes and nothing is printed.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `<name>` | string |  | The saved list's name. |

```text
ISXOgreEQ2.Targeting:LoadList[Trash]
```

### `Status`

`ISXOgreEQ2.Targeting:Status`

Prints the assist state to this character's console, the same as `ogre assist`: the Auto Assist, auto-target and direct targeting boxes, the decision and why, the assist anchor, each assist-list entry with their target, and your own target. Prints nothing when not in the world.

```text
ISXOgreEQ2.Targeting:Status
```

### `Target`

`ISXOgreEQ2.Targeting:Target[id]`

Queues a one-time retarget to the actor ID, issued on the next pulse even while OgreBot is paused; it beats auto-target and assist but yields to a target lock or a manual target. It is skipped when that is already your target or is you, and does nothing without an ID.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `id` | int64 |  | The actor ID to target. |

```text
ISXOgreEQ2.Targeting:Target[${Target.ID}]
```

### `Tick`

`ISXOgreEQ2.Targeting:Tick`

Runs the assist and auto-target decision now and queues any retarget for the next pulse; it never targets during the call. The bot already does this on its own every 250 ms, and with auto-target on and entries to pick from each call can run a nearby-actor scan, so a script rarely needs it.

```text
ISXOgreEQ2.Targeting:Tick
```

# ISXOgreEQ2.TaskRunner

## Methods

### `Clear`

`ISXOgreEQ2.TaskRunner:Clear[toon,task]`

Clears error and backoff records and saves them. Last-completed stamps are left alone.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `toon` | string |  | Only this character. Optional: with none, every character. |
| `task` | string |  | Only this task. Optional. |

```text
ISXOgreEQ2.TaskRunner:Clear[Bob,packpony]
```

### `Close`

`ISXOgreEQ2.TaskRunner:Close`

Closes the Lists window and leaves a run going. :End stops it too.

```text
ISXOgreEQ2.TaskRunner:Close
```

### `End`

`ISXOgreEQ2.TaskRunner:End`

Stops a run and closes the Lists window, the same as `ogre end taskrunner` and the window's X.

```text
ISXOgreEQ2.TaskRunner:End
```

### `Lists`

`ISXOgreEQ2.TaskRunner:Lists`

Prints the configured lists and their characters to the console.

```text
ISXOgreEQ2.TaskRunner:Lists
```

### `Now`

`ISXOgreEQ2.TaskRunner:Now`

Scans for due work now rather than at the next interval. Only while the runner is idle.

```text
ISXOgreEQ2.TaskRunner:Now
```

### `Open`

`ISXOgreEQ2.TaskRunner:Open`

Opens the TaskRunner Lists window, the same as bare `ogre taskrunner`.

```text
ISXOgreEQ2.TaskRunner:Open
```

### `Plan`

`ISXOgreEQ2.TaskRunner:Plan[list]`

Prints what is due to the console.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `list` | string |  | Only this list. Optional: with none, the list this session runs. |

```text
ISXOgreEQ2.TaskRunner:Plan[daily]
```

### `Reload`

`ISXOgreEQ2.TaskRunner:Reload`

Reads the config again. Refused while a batch is in flight; if the list you are on is gone, the run stops.

```text
ISXOgreEQ2.TaskRunner:Reload
```

### `Run`

`ISXOgreEQ2.TaskRunner:Run[list,options]`

Starts this session on one list, the same as `ogre taskrunner run <list>` and `ogre taskrunner -list <list>`. An unknown option, or no list, prints one warning and nothing starts.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `list` | string |  | The list's name, after an optional -list or -l; required. |
| `options` | string |  | once or loop, stagger or nostagger, with or without a leading dash, one argument each. Optional. |

```text
ISXOgreEQ2.TaskRunner:Run[daily,once]
```

### `Start`

`ISXOgreEQ2.TaskRunner:Start`

Starts cycling all configured characters. Refused while a batch is in flight, when the config is off, with no characters, or when lists exist and none was named: use :Run then.

```text
ISXOgreEQ2.TaskRunner:Start
```

### `Status`

`ISXOgreEQ2.TaskRunner:Status`

Prints what the runner is doing to the console.

```text
ISXOgreEQ2.TaskRunner:Status
```

### `Stop`

`ISXOgreEQ2.TaskRunner:Stop`

Stops a run and leaves the window up.

```text
ISXOgreEQ2.TaskRunner:Stop
```

# ISXOgreEQ2.Tour

## Methods

### `Close`

`ISXOgreEQ2.Tour:Close`

Closes the New User Tour window, and its intro if that is still playing. The tour is not marked as seen, so it opens by itself again on the next load.

```text
ISXOgreEQ2.Tour:Close
```

### `Done`

`ISXOgreEQ2.Tour:Done`

Marks the New User Tour finished: prints 'tour: completed', saves it as seen so it no longer opens on load, and closes the window, then starts the Migration Assistant's automatic run, which copies any OldBot settings files that have no new copy yet and shows a progress window only when something is copied. A call when the tour is not open does nothing.

```text
ISXOgreEQ2.Tour:Done
```

### `Open`

`ISXOgreEQ2.Tour:Open`

Opens the New User Tour, the same as `ogre tour`: a short walkthrough of three window controls (drag to resize, right-click the title bar, Save Position), which also opens by itself on first load until it has been finished or skipped. It hides the InnerSpace console if that is showing and prints 'tour opened', and it does nothing while the tour is already up.

```text
ISXOgreEQ2.Tour:Open
```

### `Skip`

`ISXOgreEQ2.Tour:Skip`

Skips the New User Tour: prints 'tour: skipped', saves it as seen so it no longer opens on load, closes the window and, like Tour:Done, starts the Migration Assistant's automatic run of any OldBot settings not yet copied. A call when the tour is not open does nothing.

```text
ISXOgreEQ2.Tour:Skip
```

### `Step`

`ISXOgreEQ2.Tour:Step[step]`

Called by the tour window when it moves to a new step, and all it does is print 'tour: advanced to step N' to the console. Nothing is saved and the tour window does not change, so a script has no reason to call it.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `step` | int | `0` | the step number to print (the tour has steps 1 to 3); text that is not a number prints 0 |

```text
ISXOgreEQ2.Tour:Step[2]
```

## Methods

ISXOgreEQ2.Travel:End

```text
ISXOgreEQ2.Travel:Help
```

### `Open`

`ISXOgreEQ2.Travel:Open[method]`

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `method` | string |  | fast, spire, druid, bell or map. Optional: leave it out to only open the window. |

```text
ISXOgreEQ2.Travel:Open[spire]
```

# ISXOgreEQ2.TravelMesh

## Members

### `TMActive`

`${ISXOgreEQ2.TravelMesh.TMActive}`

TRUE while a travel route is running on this character. It reads FALSE while idle, after arriving or giving up, and while a Go is still waiting for a zone to finish loading.

**Returns:** bool: TRUE when a route is running; FALSE otherwise

```text
echo ${ISXOgreEQ2.TravelMesh.TMActive}
```

### `TMBias`

`${ISXOgreEQ2.TravelMesh.TMBias[kind]}`

The cost multiplier the planner uses for one kind of hop (door, bell, spire, druid, map, amenity or item): 1 is neutral, below 1 prefers it, above 1 avoids it, 0 or less forbids it. Every kind starts at 1.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `kind` | string |  | the hop kind: door, bell, spire, druid, map, amenity or item |

**Returns:** float: the multiplier for that kind; -1 when the kind is unknown or missing

```text
echo ${ISXOgreEQ2.TravelMesh.TMBias[bell]}
```

### `TMCurrentHop`

`${ISXOgreEQ2.TravelMesh.TMCurrentHop}`

A one-line description of the hop in progress: the kind (door, bell, spire, druid, map, amenity or item), the from and to zone short names, and the travel action and destination label when there is one. Empty when no hop is in progress, including after arrival.

**Returns:** string: the current hop's description; empty when there is none

```text
echo ${ISXOgreEQ2.TravelMesh.TMCurrentHop}
```

### `TMDataErrors`

`${ISXOgreEQ2.TravelMesh.TMDataErrors}`

How many travel data files had a problem at the last load, counting files that were skipped and files that loaded with a warning. It reads 0 until the travel data has loaded.

**Returns:** int: the number of problem files; 0 when the data loaded cleanly

```text
echo ${ISXOgreEQ2.TravelMesh.TMDataErrors}
```

### `TMDataErrorText`

`${ISXOgreEQ2.TravelMesh.TMDataErrorText}`

The problem report from the last load, one line per file: its path, which layer it came from (default or custom) and the message. Empty when every file loaded cleanly, or until the travel data has loaded.

**Returns:** string: the problem report, one file per line; empty when clean

```text
echo ${ISXOgreEQ2.TravelMesh.TMDataErrorText}
```

### `TMEdges`

`${ISXOgreEQ2.TravelMesh.TMEdges}`

How many zone-to-zone connections (doors, zone lines, guild hall amenities, travel items and so on) the loaded travel data holds. It reads 0 until the travel data has loaded.

**Returns:** int: the number of connections in the travel data

```text
echo ${ISXOgreEQ2.TravelMesh.TMEdges}
```

### `TMFeatures`

`${ISXOgreEQ2.TravelMesh.TMFeatures}`

One line per account feature the travel data can require (the expansion Friends and Family features), with this character's answer: YES or no, and whether it was scanned or set by you, or unanswered. A no from a scan is checked again after a week, a YES or your own answer is kept, and the lines are read by the travel engine about once a second while you are in the world.

**Returns:** string: one line per account feature

```text
echo ${ISXOgreEQ2.TravelMesh.TMFeatures}
```

### `TMGoal`

`${ISXOgreEQ2.TravelMesh.TMGoal}`

The short zone name of the destination of the current or last route, such as antonica. Empty before any route has started.

**Returns:** string: the destination zone short name; empty before the first route

```text
echo ${ISXOgreEQ2.TravelMesh.TMGoal}
```

### `TMHop`

`${ISXOgreEQ2.TravelMesh.TMHop}`

The number of the hop the route is on, counting from 1. It reads 1 before any route has run and one more than TMHops once the route has arrived.

**Returns:** int: the current hop number, 1-based

```text
echo ${ISXOgreEQ2.TravelMesh.TMHop}
```

### `TMHops`

`${ISXOgreEQ2.TravelMesh.TMHops}`

How many hops the current plan has. After a re-plan this is the hop count of the new plan for the rest of the trip, not the original total.

**Returns:** int: the hop count of the current plan; 0 before any route

```text
echo ${ISXOgreEQ2.TravelMesh.TMHops}
```

### `TMParty`

`${ISXOgreEQ2.TravelMesh.TMParty}`

For the current or last route: the route id, how many group members it counted, and either "everyone is here" or the names of members not yet in this zone and settled. It is empty before any route has started, and read by the travel engine about once a second while you are in the world.

**Returns:** string: the group status line; empty before the first route

```text
echo ${ISXOgreEQ2.TravelMesh.TMParty}
```

### `TMReason`

`${ISXOgreEQ2.TravelMesh.TMReason}`

Why the last route stopped, or what its last step reported, such as "stopped by request" or "replaced by a new route". Empty while a route runs normally.

**Returns:** string: the stop reason or last step message; empty when there is none

```text
echo ${ISXOgreEQ2.TravelMesh.TMReason}
```

### `TMReplans`

`${ISXOgreEQ2.TravelMesh.TMReplans}`

How many times the current route has re-planned around a hop that failed. A route gives up after 3 re-plans.

**Returns:** int: the re-plan count for the current or last route

```text
echo ${ISXOgreEQ2.TravelMesh.TMReplans}
```

### `TMRoute`

`${ISXOgreEQ2.TravelMesh.TMRoute}`

The whole current plan as text, one numbered hop per line in the same form as TMCurrentHop. It still holds the last plan after the route ends.

**Returns:** string: the plan, one hop per line; empty before any route

```text
echo ${ISXOgreEQ2.TravelMesh.TMRoute}
```

### `TMStagger`

`${ISXOgreEQ2.TravelMesh.TMStagger}`

The start delay in milliseconds per group member for group travel, so members do not all set off at once. The default is 10000, and 0 means everybody starts at once.

**Returns:** int: milliseconds of start delay per group member

```text
echo ${ISXOgreEQ2.TravelMesh.TMStagger}
```

### `TMState`

`${ISXOgreEQ2.TravelMesh.TMState}`

The step the route is on: idle, hop-start, walk, wait-for-group, ride, act, verify, done or failed. It keeps done or failed after a route ends until the next route starts.

**Returns:** string: the current route step name

```text
echo ${ISXOgreEQ2.TravelMesh.TMState}
```

### `TMValidate`

`${ISXOgreEQ2.TravelMesh.TMValidate}`

A health check of the loaded travel data, one issue per line. Empty when no issues are found, or until the travel data has loaded.

**Returns:** string: the issues, one per line; empty when there are none

```text
echo ${ISXOgreEQ2.TravelMesh.TMValidate}
```

### `TMZones`

`${ISXOgreEQ2.TravelMesh.TMZones}`

How many zones the loaded travel data knows. It reads 0 until the travel data has loaded.

**Returns:** int: the number of zones in the travel data

```text
echo ${ISXOgreEQ2.TravelMesh.TMZones}
```

## Methods

### `Go`

`ISXOgreEQ2.TravelMesh:Go[destination,poi]`

Starts a route like OgreBotAPI.Travel:Mesh, from your current zone to the destination, walking and using doors, zone lines, bells, spires, druid rings, the fast-travel map, guild hall amenities and travel items in your bags as needed; it replaces a running route, whoever started it, only when the new one can be planned. Problems (no destination, unknown destination with suggestions, current zone not in the travel data, no route) are echoed to the console, a Go made while zoning waits for the zone to settle, and the route moves with OgreBot closed too - TravelMesh:Stop ends it.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `destination` | string |  | the zone to travel to - its display name, an alias or its short name, any case |
| `poi` | string | `none` | optional point of interest in the destination zone to finish at; one the zone data does not list is reported and the trip still goes to the zone |

```text
ISXOgreEQ2.TravelMesh:Go[Antonica,"Druid Rings"]
```

### `GoGroup`

`ISXOgreEQ2.TravelMesh:GoGroup[destination,poi]`

Like OgreBotAPI.Travel:MeshGroup: starts your own route as Go does, then sends -TravelMesh for the same destination to the rest of your group through OgreConsole, so each member plans its own route from where it stands, with starts staggered by TMStagger. If your own route cannot be planned the error is echoed and nothing is sent; the other members' copies run as OgreBot routes, so they are stopped with -TravelMeshStop.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `destination` | string |  | the zone to travel to - its display name, an alias or its short name, any case |
| `poi` | string | `none` | optional point of interest in the destination zone to finish at; one the zone data does not list is reported and the trip still goes to the zone |

```text
ISXOgreEQ2.TravelMesh:GoGroup[Antonica]
```

### `Preview`

`ISXOgreEQ2.TravelMesh:Preview[destination]`

Plans a route from your current zone to the destination and prints it to the console without moving: a summary line with the hop count and rough time in seconds, then one numbered hop per line. An unknown destination prints an "unknown destination" line with suggestions, and no destination prints an error.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `destination` | string |  | the zone to plan to - its display name, an alias or its short name, any case |

```text
ISXOgreEQ2.TravelMesh:Preview[Antonica]
```

### `Reload`

`ISXOgreEQ2.TravelMesh:Reload`

Re-reads the travel data from Ogre/EQ2/Travel/default and your own OgreSave/EQ2/Travel/custom files and echoes a summary of zones, connections, files and errors. Any running route is stopped first, whoever started it; if the first load has not finished within 5 seconds it says so and changes nothing.

```text
ISXOgreEQ2.TravelMesh:Reload
```

### `ScanFeatures`

`ISXOgreEQ2.TravelMesh:ScanFeatures`

Runs the game's show_account_features command to answer this character's unanswered or expired account features, and echoes a status line. Each feature is scanned at most once per session, a scan also starts by itself when a route is planned, and when nothing is scanned (out of the world included) the line says every feature is already answered.

```text
ISXOgreEQ2.TravelMesh:ScanFeatures
```

### `SetBias`

`ISXOgreEQ2.TravelMesh:SetBias[kind,multiplier]`

Sets how much the planner likes one kind of hop: 1 is neutral, below 1 prefers it, above 1 avoids it, 0 or less forbids it, and the new value is echoed. It applies to the next plan and is not saved; a multiplier that is not a number sets the normal bias of 1 and says so.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `kind` | string |  | the hop kind: door, bell, spire, druid, map, amenity or item; anything else is refused with a console error |
| `multiplier` | float |  | the cost multiplier: 1 neutral, below 1 prefer, above 1 avoid, 0 or less forbid; a word is 1 |

```text
ISXOgreEQ2.TravelMesh:SetBias[druid,0.5]
```

### `SetFeature`

`ISXOgreEQ2.TravelMesh:SetFeature[flag,value]`

Saves your own answer for one account feature for this character in OgreSave/EQ2/Travel/account-features.json; it is permanent and never scanned over, and the answer is echoed. A feature name the travel data does not use is refused with a line naming the ones it does, a blank value prints an error, and a word that is not yes or no leaves the feature as it is and says so.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `flag` | string |  | the account feature name as TMFeatures shows it, such as roc_friends_and_family, in any case |
| `value` | bool |  | TRUE, 1, yes or on means this character has the feature; FALSE, 0, no or off means it does not |

```text
ISXOgreEQ2.TravelMesh:SetFeature[roc_friends_and_family,TRUE]
```

### `SetStagger`

`ISXOgreEQ2.TravelMesh:SetStagger[ms]`

Sets the start delay in milliseconds per group member for group travel (0 = everybody at once) and echoes it. A negative number is stored as 0, a value that is not a number counts as 0, and the setting is not saved.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `ms` | int |  | milliseconds of start delay per group member; 0 starts everybody at once |

```text
ISXOgreEQ2.TravelMesh:SetStagger[5000]
```

### `Stop`

`ISXOgreEQ2.TravelMesh:Stop[-force]`

Cancels a route started with this object's Go or GoGroup, including one still waiting for a zone to settle. A route someone else started is refused with one line naming the owner and how to stop it, and -force stops it anyway.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `-force` | switch |  | stop the route whoever started it |

```text
ISXOgreEQ2.TravelMesh:Stop
```

# ISXOgreEQ2.Watcher

## Methods

### `End`

`ISXOgreEQ2.Watcher:End`

Turns off both the name watch (Find) and the shiny watch (TrackShiny), closes the Watcher window and prints which of them were on; the off state is saved, so they stay off on the next load. This is what `ogre end watcher` and the window's close button do.

```text
ISXOgreEQ2.Watcher:End
```

### `Find`

`ISXOgreEQ2.Watcher:Find[word...]`

Watches for actors by exact name, case not mattering (`ogre find`): given names it replaces the watch list, arms and checks the zone once, then each time a watched name spawns it prints where, broadcasts '&lt;you>: APPEARED: &lt;name>' to your bot sessions and sets an in-game waypoint on it, and it prints when one despawns (these alerts are skipped in a guild hall). A first word that is an option does that instead (-add or -remove &lt;name>, -clear, -list, -on, -off, -scan, -status, -panel opens the Watcher window, -rorr adds the four Renewal of Ro researchers to the names), no words prints the usage, and the list and armed state are saved and restored on the next load.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `word...` | string | `none (prints the usage)` | the names to watch (quote a name that has spaces), or one option first followed by its value |

```text
ISXOgreEQ2.Watcher:Find[${Target.Name}]
```

### `TrackShiny`

`ISXOgreEQ2.Watcher:TrackShiny[word...]`

Watches for shiny harvest nodes of one colour within 100 units, every 500 ms by default (`ogre trackshiny`): when it finds one it did not just announce, it prints '&lt;colour> shiny!', broadcasts it to your bot sessions and sets an in-game waypoint on it. No word arms it on Purple, a colour name (White, Green, Purple, Red, BlueShimmer, Blue) arms that colour and an unknown one is refused with the list, the options are -off, -status, -colours (or -colors), -interval &lt;ms> (held to 250..30000) and -panel, and the settings are saved and restored on the next load.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `word...` | string | `Purple` | a colour to watch for, or one option first followed by its value |

```text
ISXOgreEQ2.Watcher:TrackShiny[Red]
```

| `value` | string |  | the new value: TRUE/FALSE for a checkbox or radio, otherwise the text or value to put in |

Sizes the open window `name` (yours or any other) to width by height pixels on screen with its scale applied - the same numbers the Window object's Width and Height read back. | Parameter | Type | Default | Meaning |

## ISXOgreX.Patch

### Members

#### `Enabled`

`${ISXOgreX.Patch.Enabled}`

Whether the Ogre patcher may update this PC, as the patcher last read its setting. The setting is read again whenever an update starts or Status runs, so a change shows here after that.

**Returns:** bool: TRUE when patching is on; FALSE when it is off for this PC, its setting cannot be read, or before the patcher has started.

```text
echo ${ISXOgreX.Patch.Enabled}
```

#### `InProgress`

`${ISXOgreX.Patch.InProgress}`

Whether an update run is going on in this session, including the short wait before the update check at load and a reload queued after an extension was updated. Background navmesh downloads do not count.

**Returns:** bool: TRUE while an update run is active in this session; FALSE when none is.

```text
echo ${ISXOgreX.Patch.InProgress}
```

#### `LastResult`

`${ISXOgreX.Patch.LastResult}`

The one-line result of the last update run on this PC, the same text the run printed after 'patch:' (for example a line starting 'up to date' or 'done - release', which counts the files updated and failed). It is kept in OgreSave/patcher-state.json, so it survives a restart.

**Returns:** string: the last run's result line; "" when no run has finished on this PC or patching was off when the session started.

```text
echo ${ISXOgreX.Patch.LastResult}
```

#### `ReleaseId`

`${ISXOgreX.Patch.ReleaseId}`

The id of the release the last update run on this PC checked against, kept in OgreSave/patcher-state.json. For the release name players see, use ${ISXOgreX.Release}.

**Returns:** string: the last run's release id; "" when this PC has never been patched or patching was off when the session started.

```text
echo ${ISXOgreX.Patch.ReleaseId}
```

#### `Tier`

`${ISXOgreX.Patch.Tier}`

The release channel number the update server sent with the release the last update run on this PC checked against, kept with ReleaseId in OgreSave/patcher-state.json.

**Returns:** int: that number; -1 when no update run has recorded one.

```text
echo ${ISXOgreX.Patch.Tier}
```

### Methods

#### `Ignore`

`ISXOgreX.Patch:Ignore[op,path]`

Manages the list of files the patcher never writes, kept in OgreSave/patcher-ignore.json, so your own copy of a file is left alone: add or remove a path, or list them. Paths are relative to the InnerSpace folder with forward slashes (backslashes are turned into them), and every change prints a confirmation line.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `op` | string | `list` | add, remove or list; leave it out to list. |
| `path` | string | `""` | The file for add or remove, relative to the InnerSpace folder, such as Scripts/Ogre/EQ2/x.json; not used by list. |

```text
ISXOgreX.Patch:Ignore[add,"Scripts/Ogre/EQ2/Commands/everquest2.json"]
```

#### `Mesh`

`ISXOgreX.Patch:Mesh[mode]`

Sets how navmeshes download and applies it at once: all (every zone in the background), ondemand (a zone's mesh when you need it) or off. With no argument it prints the navmesh download summary, and an unknown word prints the usage line.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `mode` | string | `""` | all, ondemand or off; leave it out to print the summary instead. |

```text
ISXOgreX.Patch:Mesh[ondemand]
```

#### `RevertExt`

`ISXOgreX.Patch:RevertExt`

Puts back the previous ISXOgreX DLL kept after a self-update (the .prev file) and reloads the extension, keeping the replaced one beside it as .reverted. It is refused while a run is in progress, says there is nothing to revert when no .prev exists, and the next update run installs the current release again.

```text
ISXOgreX.Patch:RevertExt
```

#### `Status`

`ISXOgreX.Patch:Status`

Prints the patcher's state to the console: whether patching is on, your login state, your file switches, the last release and run, whether this session runs older DLLs than the ones on disk, any run in progress and the navmesh download summary. It changes nothing.

```text
ISXOgreX.Patch:Status
```

#### `TestCorrupt`

`ISXOgreX.Patch:TestCorrupt`

A diagnostic switch: each call arms or disarms a one-time fault that flips one byte of the next downloaded file before it is checked, so you can see the check refuse it and keep the old file. It prints ARMED or disarmed and fires on the next update or navmesh download.

```text
ISXOgreX.Patch:TestCorrupt
```

#### `Update`

`ISXOgreX.Patch:Update`

Checks for an Ogre update now and installs it: fetches the current release, downloads every changed file, checks each one and swaps them in, reloading the extension if one of its DLLs changed, and afterwards every other session on this PC that runs older files reloads too. It runs in the background, prints 'patch: &lt;result>' when done, and refuses with a console line when a run is already going, patching is off or you are not logged in to Ogre.

```text
ISXOgreX.Patch:Update
```

# Commands

What a user types: the `ogre` commands (the in-game Commands panel lists them all) and the console commands (`oc !c` / `oc !ci`).

A console command is sent as `oc !c <command> <who> ...` - typed in the console, put on an MCP button or run from a script. It goes to the sessions on this PC, this one included, and the [for-who](../ogrebotapi/ForWho.md) in `<who>` picks which of them act: `igw:${Me.Name}` is your whole group, `igwbn:${Me.Name}` your group without you. Left out, or `auto`, it uses the For Who window. `oc !ci` does the same as `oc !c`.
