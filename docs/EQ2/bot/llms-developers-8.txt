# OgreBotAPI.Windows

## Members

### `CastingWindowVisible`

`${OgreBotAPI.Windows.CastingWindowVisible}`

Whether the game's casting bar is on screen. Always FALSE while you are not in the world.

**Returns:** bool: TRUE when the casting bar is visible; FALSE when it is hidden or you are not in the world.

```text
echo ${OgreBotAPI.Windows.CastingWindowVisible}
```

*Was (OldBot):* `OgreBotAPI.IsCastingWindowVisible`

### `ReplyExists`

`${OgreBotAPI.Windows.ReplyExists[text]}`

Which reply of the open reply dialog (the window a clicked item or object opens) contains the text, in any case. It answers a number, not TRUE/FALSE, so test it with > 0; it does not look at the NPC conversation window.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `text` | string |  | Text to look for inside each reply. Matches anywhere in the reply, any case. |

**Returns:** int: the 1-based number of the first reply that contains the text; 0 when no reply dialog is open, nothing matches, or the text is empty.

```text
echo ${OgreBotAPI.Windows.ReplyExists[Yes]}
```

*Was (OldBot):* `OgreBotAPI.ReplyDialog_ReplyExists`

### `RewardID`

`${OgreBotAPI.Windows.RewardID[num|name,windowId]}`

The number of one reward on a reward window, picked by number or by item name the same way AcceptReward picks it. A number past the window's reward count, a name that matches no row, an empty selection, or no reward window all answer 0.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `num\|name` | number or text |  | The reward to pick: its number on the window (1 = the first), or its item name (trimmed, any case, first match). Empty or 0 picks nothing. |
| `windowId` | int | `0` | The reward window id to read. Empty or 0 = the active reward window (the oldest one the bot saw open that is still up). |

**Returns:** int: the 1-based reward number; 0 when there is no reward window or nothing matches.

```text
echo ${OgreBotAPI.Windows.RewardID[2,0]}
```

*Was (OldBot):* `OgreBotAPI.Get_RewardID`

### `RewardLinkID`

`${OgreBotAPI.Windows.RewardLinkID[num|name,windowId]}`

The LinkID of one reward on a reward window, picked by number or by item name the same way AcceptReward picks it. Empty when there is no reward window, nothing matches, or the game has no LinkID for that row.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `num\|name` | number or text |  | The reward to pick: its number on the window (1 = the first), or its item name (trimmed, any case, first match). Empty or 0 picks nothing. |
| `windowId` | int | `0` | The reward window id to read. Empty or 0 = the active reward window (the oldest one the bot saw open that is still up). |

**Returns:** string: that reward's LinkID; empty when there is no window or no match.

```text
echo ${OgreBotAPI.Windows.RewardLinkID[1,0]}
```

*Was (OldBot):* `OgreBotAPI.Get_RewardLinkID`

### `RewardName`

`${OgreBotAPI.Windows.RewardName[num|name,windowId]}`

The item name of one reward on a reward window, picked by number or by item name. Empty when there is no reward window, nothing matches, or the row does not read.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `num\|name` | number or text |  | The reward to pick: its number on the window (1 = the first), or its item name (trimmed, any case, first match). Empty or 0 picks nothing. |
| `windowId` | int | `0` | The reward window id to read. Empty or 0 = the active reward window (the oldest one the bot saw open that is still up). |

**Returns:** string: that reward's item name; empty when there is no window or no match.

```text

```

*Was (OldBot):* `OgreBotAPI.Get_RewardName`

### `RewardWindowID`

`${OgreBotAPI.Windows.RewardWindowID}`

The id of the active reward window: the oldest reward window the bot saw open that is still up, or with none held, the one open now. It reads 0 when no reward window is up.

**Returns:** int64: the active reward window's id; 0 when none is open or you are not in the world.

```text
echo ${OgreBotAPI.Windows.RewardWindowID}
```

*Was (OldBot):* `OgreBotAPI.RewardWindow_Get_WindowID`

### `SelectOption`

`${OgreBotAPI.Windows.SelectOption[n]}`

Which option of the open select window matches, without clicking anything and without printing anything, so a script may read it as often as it likes. Options count from 1 (OldBot's numbers were one higher).

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `search...` | number or text |  | The option to find: a number is that option's position; text must match the option name exactly (any case). Add -substring as another argument to match text anywhere in the name. |

**Returns:** int: the 1-based option position; 0 when no select window is open, nothing matches, or no argument is given.

```text
echo ${OgreBotAPI.Windows.SelectOption[1]}
```

*Was (OldBot):* `OgreBotAPI.Select_Window_GetOption`

## Methods

### `AcceptNoChoiceReward`

`OgreBotAPI.Windows:AcceptNoChoiceReward[fw, windowId=0]`

Presses Receive on a reward window that offers no choice. It refuses, with a console line, a window that offers a choice, a 'New Quest!' offer, or a window whose reward pack is not shown.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `windowId` | int | `0` | The reward window id. Empty or 0 = the active reward window (the oldest one the bot saw open that is still up). |

```text
OgreBotAPI.Windows:AcceptNoChoiceReward[${Me.Name},0]
```

*Was (OldBot):* `OgreBotAPI:AcceptNoChoiceReward`

### `AcceptReward`

`OgreBotAPI.Windows:AcceptReward[fw, num|name=0, windowId=0]`

Takes a reward from a reward window: on a choice window it accepts the reward you name, and on a single or no-choice window it presses Receive whatever you pass, but never on a 'New Quest!' offer. Each outcome, including no window or no match, prints a line to the console.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `num\|name` | number or text | `0` | The reward to take on a choice window: its number (1 = the first) or its item name (any case). Ignored on a single-reward window. |
| `windowId` | int | `0` | The reward window id. 0 = the active reward window (the oldest one the bot saw open that is still up). |

```text
OgreBotAPI.Windows:AcceptReward[${Me.Name},1,0]
```

*Was (OldBot):* `OgreBotAPI:AcceptReward`, `Obj_OgreIH:AcceptReward`

### `Choice`

`OgreBotAPI.Windows:Choice[fw, option=1]`

Clicks one of the choice window's buttons: 1 is the first button, 2 the second. Another number is clamped to the nearer of the two, with a console line saying which it chose; does nothing when no choice window is open.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `option` | int | `1` | Which button to click: 1 or 2 (below 1 is 1, above 2 is 2). |

```text

```

*Was (OldBot):* `OgreBotAPI:ChoiceWindow`

### `Select`

`OgreBotAPI.Windows:Select[fw, search...]`

Picks an option in the open select window and then presses its OK. The match happens at once but the clicks are queued: the option first, then OK about 0.3 seconds later; each pick and each miss prints a line to the console.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `search...` | number or text |  | The option to pick: a number is its position (1 = the first real option); text must match the option name exactly, any case. Flags may come before or after it as their own arguments: -substring (match text anywhere in the name), -test (click the option but not OK), -reportonly (say which option matches, click nothing) and -spew (list the options). |

```text
OgreBotAPI.Windows:Select[${Me.Name},1]
```

*Was (OldBot):* `OgreBotAPI:Select_Window`

# OgreBotAPI.Zone

## Members

### `CityRestrictions`

`${OgreBotAPI.Zone.CityRestrictions}`

TRUE in one of the bot's 17 city zones, such as The City of Freeport or Qeynos Province District, unless Allow City Casting is ticked. FALSE out of world.

**Returns:** bool: TRUE in a listed city with Allow City Casting unticked; FALSE otherwise or out of world.

```text
echo ${OgreBotAPI.Zone.CityRestrictions}
```

*Was (OldBot):* `OgreBotAPI.CityRestrictions`

### `CleanName`

`${OgreBotAPI.Zone.CleanName[name]}`

The same cleaned name as Name, made safe for file and setting names: spaces become underscores and the characters , [ ] : ' and ` are removed. Reads "" out of world when no name is passed.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | text | `${Zone.Name}` | a zone name to clean; blank means the zone you are in |

**Returns:** string: the cleaned zone name with underscores for spaces; "" out of world when no name is given.

```text
echo ${OgreBotAPI.Zone.CleanName}
```

*Was (OldBot):* `OgreBotAPI.CleanZoneName`, `Ogre_Instance_Controller.CleanZoneName`

### `InGuildHall`

`${OgreBotAPI.Zone.InGuildHall}`

TRUE when the zone's short name contains guildhall, except the Island of Mara Estate (guildhall_mara). FALSE out of world.

**Returns:** bool: TRUE in a guild hall; FALSE elsewhere or out of world.

```text
echo ${OgreBotAPI.Zone.InGuildHall}
```

*Was (OldBot):* `GetInfoOb.InGuildHallZone`, `Obj_OgreUtilities.InGuildHallZone`, `OgreBotAPI.InGuildHallZone`

### `InHouse`

`${OgreBotAPI.Zone.InHouse}`

TRUE when you look to be inside a house: not in a guild hall, and a Magic Door to the Guild Hall or a market bulletin board is in the zone. It is a guess from those two objects; FALSE out of world.

**Returns:** bool: TRUE when either object is in the zone and it is not a guild hall; FALSE otherwise or out of world.

```text
echo ${OgreBotAPI.Zone.InHouse}
```

*Was (OldBot):* `GetInfoOb.InHouseZone`, `OgreBotAPI.InHouseZone`

### `InHouseAccess`

`${OgreBotAPI.Zone.InHouseAccess}`

TRUE in one of the eight zones the bot treats as house-access zones: Antonica, Halas, the two Qeynos zones, Timorous Deep, Greater Faydark, Neriak and Freeport. This is the outdoor zone, not the house itself; FALSE out of world.

**Returns:** bool: TRUE when the zone's short name is antonica, halas, qeynos_combined01, qeynos_combined02, exp04_rgn_timorous_deep, exp03_rgn_greater_faydark, neriak or freeport_combined; FALSE otherwise or out of world.

```text
echo ${OgreBotAPI.Zone.InHouseAccess}
```

*Was (OldBot):* `GetInfoOb.InHouseAccessZone`, `OgreBotAPI.InHouseAccessZone`

### `InInstance`

`${OgreBotAPI.Zone.InInstance}`

TRUE when the zone name contains a [ (instances are named like that, such as [Heroic] or [Solo]) and you are not in a guild hall. FALSE out of world.

**Returns:** bool: TRUE in an instance; FALSE in an open zone, a guild hall, or out of world.

```text
echo ${OgreBotAPI.Zone.InInstance}
```

*Was (OldBot):* `GetInfoOb.InAInstance`, `OgreBotAPI.InInstance`

### `Name`

`${OgreBotAPI.Zone.Name[name]}`

| Parameter | Type | Default | Meaning |

*Was (OldBot):* `OgreBotAPI.ZoneName`

`${OgreBotAPI.Zone.ResetReady}`

TRUE once the Zone Reuse table has been read at least once and no re-read is asked for or running. Wait for it after ResetUpdateInfo before reading ResetZoneData.

**Returns:** bool: TRUE when the table is in and not being re-read; FALSE before the first read or while a re-read is pending.

```text

```

*Was (OldBot):* `OgreBotAPI.ZoneReset_IsReady`

### `ResetUpdating`

`${OgreBotAPI.Zone.ResetUpdating}`

TRUE while a Zone Reuse re-read is asked for or running.

**Returns:** bool: TRUE while a re-read is pending or running; FALSE otherwise.

```text

```

*Was (OldBot):* `OgreBotAPI.ZoneReset_IsUpdating`

### `ResetZoneData`

`${OgreBotAPI.Zone.ResetZoneData[zone,field]}`

One zone's entry from the Zone Reuse window, as last read by ResetUpdateInfo. A zone that is not in the table reads FALSE, and an unknown field prints a console line and reads FALSE.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `zone` | text |  | the zone name exactly as the Zone Reuse window shows it, any case |
| `field` | text |  | blank reads TRUE when the zone has an entry; otherwise ZoneName, IsSet (TRUE when its timer state is known), Resettable, TimeLeft (seconds) or TextTimeLeft |

**Returns:** bool, int64 or string by field: TRUE/FALSE for blank, IsSet and Resettable; seconds for TimeLeft; text for ZoneName and TextTimeLeft. FALSE when the zone is not in the table.

```text
echo ${OgreBotAPI.Zone.ResetZoneData["${OgreBotAPI.Zone.Name}",Resettable]}
```

*Was (OldBot):* `OgreBotAPI.ZoneReset_Get_ZoneData`

# ISXOgreEQ2.AbilityEfficiency

## Methods

### `Close`

`ISXOgreEQ2.AbilityEfficiency:Close`

Closes the Ability Efficiency window. This is what `ogre end ae` and the window's X do; nothing else is running to stop.

```text
ISXOgreEQ2.AbilityEfficiency:Close
```

### `Run`

`ISXOgreEQ2.AbilityEfficiency:Run[-nogui,-targets,n,-list]`

Scores every ability in your loaded ability export as the damage in its description divided by cast plus recovery time (recast is not counted), and with no argument opens the Ability Efficiency window, one column per number of targets (the same as `ogre ae`). With no export loaded it says to run `ogre export`, -h or help prints the usage, and any other word is refused.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `-nogui` | switch |  | write the report file instead of opening the window, best first, to Scripts/OgreSave/EQ2/OgreBot/AbilityEfficiency/&lt;name>_&lt;subclass>_&lt;server>_AbilityEfficiency.txt, and print the top 20 (classic OgreBot's `ae`) |
| `-targets` | switch |  | followed by n: the window opens with n target columns; with -nogui the file gets one column per number of targets, best first at n |
| `n` | int | `4 in the window (or its saved choice); none in the file` | the number of targets after -targets, 1 to 20 |
| `-list` | switch |  | the list layout: one line per ability and number of targets, best first (an AE repeats once per count); the window opens in it, and with -nogui the file is written in it |

```text
ISXOgreEQ2.AbilityEfficiency:Run[-nogui,-targets,6,-list]
```

# ISXOgreEQ2.AbilityUpgrades

## Methods

### `Run`

`ISXOgreEQ2.AbilityUpgrades:Run[minLevel]`

With a container window open it reads that one and leaves it open; otherwise it opens each Scroll Depot within 30 units in turn, reads it and closes it, and either way reports which spell scrolls upgrade an ability you already know, both in your console and to your other sessions through the Ogre console with your name in front (the same as `ogre oau`). It is queued, scribes or uses nothing, and is refused with a console line when you are not in the world, no ability export is loaded, a scan is already running or the level is not a whole number from 1 to 1000.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `minLevel` | int | `121` | ignore scrolls below this level (1 to 1000); -h prints the usage instead |

```text
ISXOgreEQ2.AbilityUpgrades:Run[125]
```

### `Toon`

`ISXOgreEQ2.Codex:Toon[word]`

Inspects your own character and uploads its snapshot to Codex - the same as ogre codextoon: it sends the game an inspect request for you (a server request), then uploads over the web and prints the result when the upload answers. With status (or ?) it only prints the Codex status line, and it refuses with a message when Codex is not set up, you are not in the world, or an upload is already running.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `word` | string | `""` | status or ? prints the Codex status line instead of uploading; leave it out to upload |

```text
ISXOgreEQ2.Codex:Toon[status]
```

# ISXOgreEQ2.Collection

## Members

### `Running`

`${ISXOgreEQ2.Collection.Running}`

TRUE while an `ogre cm` collection run is in progress, from the depot or from your bags. Starting another while one runs is refused with a busy warning.

**Returns:** bool: TRUE while a collection run is going; FALSE when idle.

```text
echo ${ISXOgreEQ2.Collection.Running}
```

### `Status`

`${ISXOgreEQ2.Collection.Status}`

Progress of the running collection run, or "idle". It is the same text `${ISXOgreEQ2.Collection}` returns.

**Returns:** string: "idle", "cm (done/total, n added)" for a depot run or "cm -inventory (done/total, n added)" for a bag scan.

```text
echo ${ISXOgreEQ2.Collection.Status}
```

## Methods

### `Run`

`ISXOgreEQ2.Collection:Run[flags...]`

The engine behind `ogre cm`: opens the collectible depot within 10 m, turns Hide Grey on, then withdraws each listed piece one at a time, examines it and clicks the quest journal's Add button; the final result line goes to OgreConsole prefixed with your name. With -inventory it scans your bags instead and MAKES A SERVER CALL PER ITEM (`.ToItemInfo.IsCollectible` and `.AlreadyCollected`, waiting up to 5 s for each item's info), so it is slow.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `flags...` | string |  | none = the nearest depot whose name contains Collectible Depot, else a Personal Collectible Stash; -small = exactly Collectible Depot; -large = exactly Collectible Depot (Large) (a named depot that is not found refuses the call); -inventory (also 1 or -1) scans your bags instead; unknown words are ignored |

```text
ISXOgreEQ2.Collection:Run[-large]
```

### `Stop`

`ISXOgreEQ2.Collection:Stop`

Stops a running collection run, closes the depot window if it is open and prints "cm: stopped.". Does nothing when idle.

```text
ISXOgreEQ2.Collection:Stop
```
