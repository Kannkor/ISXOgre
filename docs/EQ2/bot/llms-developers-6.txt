# OgreBotAPI.Loot

## Members

### `ItemCount`

`${OgreBotAPI.Loot.ItemCount}`

How many distinct item names have a SmartLoot cap in the loaded loot files. It is 0 until the loot files have been loaded.

**Returns:** int: the number of capped item names; 0 when nothing is loaded.

```text
echo ${OgreBotAPI.Loot.ItemCount}
```

### `Loaded`

`${OgreBotAPI.Loot.Loaded}`

TRUE once the SmartLoot item caps file has been read, which happens on every profile load and on :Load or :Reload. Answers about this session only.

**Returns:** bool: TRUE when the item caps file (ItemLootData) was read; FALSE before a load or when that file is missing or unreadable.

```text
echo ${OgreBotAPI.Loot.Loaded}
```

### `WindowExists`

`${OgreBotAPI.Loot.WindowExists}`

Whether a loot window is open on this session. With two loot windows open it answers about the topmost one.

**Returns:** bool: TRUE when a loot window is open; FALSE when none is.

```text
echo ${OgreBotAPI.Loot.WindowExists}
```

*Was (OldBot):* `OgreBotAPI.LootWindowExists`

### `WindowID`

`${OgreBotAPI.Loot.WindowID}`

The id of the open loot window, or 0 when there is none. With two loot windows open it is the topmost one.

**Returns:** int64: the loot window id; 0 when no loot window is open.

```text
echo ${OgreBotAPI.Loot.WindowID}
```

*Was (OldBot):* `OgreBotAPI.Get_LootWindowID`

## Methods

### `BuildToonItemsToBeZeroed`

`OgreBotAPI.Loot:BuildToonItemsToBeZeroed[fw, toon, item, ...]`

Adds character and item pairs to a list of SmartLoot counts to reset to 0, ready for :ProcessToonItemsToBeZeroed. It can be called several times to build a long list, and a character left without an item is dropped with a warning.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `toon` | string |  | the character whose count for the item is reset |
| `item` | string |  | the item name for that character; colour codes are removed |
| `...` | string |  | more character and item pairs, in the same order |

```text
OgreBotAPI.Loot:BuildToonItemsToBeZeroed[${Me.Name},${Me.Name},"Gleaming Crown",${Group[1].Name},"Gleaming Crown"]
```

*Was (OldBot):* `OgreBotAPI:SmartLoot_BuildToonItemsToBeZeroed`

### `Config`

`OgreBotAPI.Loot:Config[fw, mode=open]`

Opens the SmartLoot config panel, or closes it when mode is close. Opening a panel that is already open does nothing, so unsaved edits in it are kept.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `mode` | string | `open` | close closes the panel; any other value opens it |

```text
OgreBotAPI.Loot:Config[${Me.Name},close]
```

### `Decide`

`OgreBotAPI.Loot:Decide[fw, execute=FALSE]`

Works out what SmartLoot would do with every open loot window in turn and prints the plan for each item of a Leader Only one; by default it is a dry run that clicks nothing. With execute it records the counts and assigns or loots for real on the next pulse, and it does nothing but print a line when OgreBot has no profile, is paused or has no loot window open, or for each window that is not Leader Only.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `execute` | bool | `FALSE` | execute, force or a true word (TRUE, 1, yes, on) performs the plan; anything else, or nothing, is a dry run |

```text
OgreBotAPI.Loot:Decide[${Me.Name},execute]
```

### `LootAll`

`OgreBotAPI.Loot:LootAll[fw]`

Clicks Loot All on the open loot window. Does nothing when no loot window is open.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |

```text
OgreBotAPI.Loot:LootAll[${Me.Name}]
```

*Was (OldBot):* `OgreBotAPI:LootWindowLootAll`

### `Migrate`

`OgreBotAPI.Loot:Migrate[fw, overwrite=FALSE]`

Converts the older XML loot files into the JSON loot store and prints how many files were written, blocked or missing. JSON files that already exist are left alone unless overwrite is given, and the loot data is reloaded when anything was written.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `overwrite` | bool | `FALSE` | overwrite, force or a true word (TRUE, 1, yes, on) replaces JSON files that already exist; anything else leaves them alone |

```text
OgreBotAPI.Loot:Migrate[${Me.Name},overwrite]
```

### `ProcessToonItemsToBeZeroed`

`OgreBotAPI.Loot:ProcessToonItemsToBeZeroed[fw]`

Sets every collected character and item count to 0, which makes those characters eligible for the item again, saves the loot counts file and empties the list. It prints how many were reset, and with nothing collected or an unreadable counts file it saves nothing and says so.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |

```text
OgreBotAPI.Loot:ProcessToonItemsToBeZeroed[${Me.Name}]
```

*Was (OldBot):* `OgreBotAPI:SmartLoot_ProcessToonItemsToBeZeroed`

### `Reload`

`OgreBotAPI.Loot:Reload[fw]`

Reads the SmartLoot item caps and per-character loot counts from the saved loot files again and prints the cap count. Use it after editing the loot files by hand.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |

```text

```

### `ResetLootedActors`

`OgreBotAPI.Loot:ResetLootedActors[fw]`

Forgets which actors auto-loot has already looted or opened, so the next scan can try them again. The same reset happens by itself on every zone change.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |

```text
OgreBotAPI.Loot:ResetLootedActors[${Me.Name}]
```

*Was (OldBot):* `OgreBotAPI:ResetActorsLooted`

### `SetAutoLootMode`

`OgreBotAPI.Loot:SetAutoLootMode[fw, mode]`

Sets this character's own auto-loot mode in the game, 0 none, 1 auto-greed or 2 auto-decline; out of the world nothing is sent. A missing mode prints a console line and sends nothing, and any other value sets 0 with a line saying so.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `mode` | text |  | 0, 1 or 2, or the words AN, AG or AD that Loot:SetOptions takes |

```text
OgreBotAPI.Loot:SetAutoLootMode[${Me.Name},1]
```

*Was (OldBot):* `OgreBotAPI:SetAutoLootMode`

### `SetOptions`

`OgreBotAPI.Loot:SetOptions[fw, token, ...]`

Sets the group loot method, rarity and auto-loot mode from short loot words, one per argument and in any order; a kind you do not name is left as it is. The group leader opens the group options window and applies them through the action queue, while anyone else only sets their own auto-loot mode; out of the world nothing is sent.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `token` | string |  | one loot word: method LO, FFA, Lotto, NBG or RR (the long names such as Leader Only or Round Robin work too); rarity All, T, L or F (with or without +); auto-loot AN, AG or AD. An unknown word is ignored with a console warning |
| `...` | string |  | more loot words of the same kinds |

```text
OgreBotAPI.Loot:SetOptions[${Me.Name},LO,T+,AN]
```

*Was (OldBot):* `OgreBotAPI:ChangeLootOptions`

# OgreBotAPI.Merchant

## Methods

### `Buy`

`OgreBotAPI.Merchant:Buy[fw, item, qty=1]`

With a merchant window already open, buys qty of the named item from the merchant's list, right away, and accepts the purchase prompt if one comes up. No item, no merchant window, or an item the merchant does not carry each get one line.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `item` | string |  | Name of the item on the merchant's list |
| `qty` | int | `1` | How many to buy |

```text
OgreBotAPI.Merchant:Buy[${Me.Name},"Fishing Bait",20]
```

*Was (OldBot):* `OgreBotAPI:BuyFromMerchant`, `Obj_OgreIH:BuyFromMerchant`

### `OpenAndBuy`

`OgreBotAPI.Merchant:OpenAndBuy[fw, merchant, item, qty=1]`

Queued: opens the merchant window by double-clicking the nearest actor whose name contains merchant (unless a merchant window is already open), waits up to 3 seconds for it, buys qty of item and accepts the purchase confirmation. A missing name prints a console line, a window that never opens or an item the merchant does not carry prints a line and buys nothing, and no matching actor stops it silently.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `merchant` | string |  | Name (or part of the name) of the merchant to open |
| `item` | string |  | Name of the item on the merchant's list |
| `qty` | int | `1` | How many to buy |

```text
OgreBotAPI.Merchant:OpenAndBuy[${Me.Name},"Provisioner","Fishing Bait",20]
```

*Was (OldBot):* `OgreBotAPI:OpenAndBuyFromMerchant`

### `OpenAndBuyXTimes`

`OgreBotAPI.Merchant:OpenAndBuyXTimes[fw, merchant, item, qty, times]`

Queued: does OpenAndBuy times times in a row - each round opens the merchant if needed, buys qty of item and accepts the confirmation. A missing merchant or item name, or times of 0 or less, prints a console line and nothing runs.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `merchant` | string |  | Name (or part of the name) of the merchant to open |
| `item` | string |  | Name of the item on the merchant's list |
| `qty` | int |  | How many to buy each round (1 when blank) |
| `times` | int |  | How many rounds to buy (1 when blank) |

```text
OgreBotAPI.Merchant:OpenAndBuyXTimes[${Me.Name},"Provisioner","Fishing Bait",100,3]
```

*Was (OldBot):* `OgreBotAPI:OpenAndBuyFromMerchantXTimes`

### `Repair`

`OgreBotAPI.Merchant:Repair[fw, force=FALSE]`

Queued: unless force is TRUE, checks your primary and chest items and stops with "no repair needed" when both are at 100% condition. Otherwise finds a known mender within 10m (prints "no mender within 10m" if none), stops auto-attack, opens it, repairs everything and closes the window.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `force` | bool | `FALSE` | TRUE to repair even when primary and chest are already at 100% |

```text
OgreBotAPI.Merchant:Repair[igw:${Me.Name},FALSE]
```

*Was (OldBot):* `OgreBotAPI:RepairGear`

### `Sell`

`OgreBotAPI.Merchant:Sell[fw, item, qty=1]`

With a merchant window already open, sells qty of the named item from your bags, right away. No item, no merchant window, or an item not in the sell list each get one line.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `item` | string |  | Name of the item in your bags |
| `qty` | int | `1` | How many to sell |

```text
OgreBotAPI.Merchant:Sell[${Me.Name},"Rough Ruby",5]
```

*Was (OldBot):* `OgreBotAPI:SellToMerchant`, `Obj_OgreIH:SellToMerchant`

# OgreBotAPI.Movement

## Members

### `Active`

`${OgreBotAPI.Movement.Active}`

TRUE while the bot's mover is driving your character anywhere. That includes Movement:ToLoc, Come2Me and Move2Area, but also follow, the camp spot and nav trips.

**Returns:** bool: TRUE while a move is in progress; FALSE when the mover is idle.

```text
echo ${OgreBotAPI.Movement.Active}
```

### `AllowMovement`

`${OgreBotAPI.Movement.AllowMovement}`

TRUE when no movement block is held, the exact opposite of Blocked with no reason. It does not count the camp spot holds left by Come2Me, Move2Area or JoustIn.

**Returns:** bool: TRUE when no block is held; FALSE when at least one is.

```text
echo ${OgreBotAPI.Movement.AllowMovement}
```

*Was (OldBot):* `Obj_CampSpot.AllowCampSpot`, `Obj_Movement.AllowCampSpot`, `Ogre_CampSpot.AllowCampSpot`

### `AlreadyFacing`

`${OgreBotAPI.Movement.AlreadyFacing[id]}`

TRUE when your heading is within 45 degrees of the heading to the actor with this ID. FALSE when you are not in the world or the actor is not known.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `id` | int64 |  | The actor ID to measure against (a number, such as ${Target.ID}). A name is not looked up. |

**Returns:** bool: TRUE when you are roughly facing the actor; FALSE when you are not, are not in the world, or the actor is not known.

```text
echo ${OgreBotAPI.Movement.AlreadyFacing[${Target.ID}]}
```

### `BehindLoc`

`${OgreBotAPI.Movement.BehindLoc[id,dist]}`

A point the given distance directly behind the actor, based on the way the actor is facing, at the actor's height. Returns an empty string when the actor is not found.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `id` | int64 |  | The actor ID to measure against (a number, such as ${Target.ID}). A name is not looked up. |
| `dist` | float | `5` | How far from the actor the point is, in meters. |

**Returns:** string: "x,y,z" behind the actor; "" when the actor is not found.

```text
echo ${OgreBotAPI.Movement.BehindLoc[${Target.ID},5]}
```

### `BlockCount`

`${OgreBotAPI.Movement.BlockCount}`

How many different movement blocks are held right now. Adding the same reason twice counts once.

**Returns:** int: the number of distinct block reasons held; 0 when movement is free.

```text
echo ${OgreBotAPI.Movement.BlockCount}
```

*Was (OldBot):* `Obj_CampSpot.uAllowMovement`, `Obj_Movement.uAllowMovement`, `Ogre_CampSpot.uAllowMovement`

### `Blocked`

`${OgreBotAPI.Movement.Blocked[reason]}`

With a reason, TRUE when that named movement block is held; with the reason left blank, TRUE when any block is held. Reason names are case-sensitive, and the bot's own movers add blocks too while they run.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `reason` | string |  | The block name to check, as given to Movement:Block. Leave it blank to ask whether any block is held. |

**Returns:** bool: TRUE when the named block (or, with no reason, any block) is held; FALSE otherwise.

```text
echo ${OgreBotAPI.Movement.Blocked[MyScript]}
```

*Was (OldBot):* `Obj_CampSpot.Disabled`, `Obj_Movement.Disabled`, `Ogre_CampSpot.Disabled`

### `BlockReasons`

`${OgreBotAPI.Movement.BlockReasons}`

The names of every movement block held right now, so you can see what is stopping a character. This includes blocks the bot's own movers hold while they run.

**Returns:** string: the block reasons separated by commas; "" when no block is held.

```text
echo ${OgreBotAPI.Movement.BlockReasons}
```

*Was (OldBot):* `Obj_CampSpot.sc_ItemsAffectingMovement`, `Obj_Movement.sc_ItemsAffectingMovement`, `Ogre_CampSpot.sc_ItemsAffectingMovement`

### `Distance2DTo`

`${OgreBotAPI.Movement.Distance2DTo[id]}`

The flat distance from you to the actor with this ID, ignoring height (X and Z only). Returns -1 when the ID is 0, is not a number, or no such actor is nearby.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `id` | int64 |  | The actor ID to measure against (a number, such as ${Target.ID}). A name is not looked up. |

**Returns:** float: the ground distance in meters; -1 when the actor is not found.

```text
echo ${OgreBotAPI.Movement.Distance2DTo[${Target.ID}]}
```

### `DistanceTo`

`${OgreBotAPI.Movement.DistanceTo[id]}`

| Parameter | Type | Default | Meaning |

### `Block`

`OgreBotAPI.Movement:Block[fw, reason]`

Adds a named movement block and stops the move in progress. While any block is held the camp spot, follow, new nav trips and queued moves all stay still, but a direct Movement:ToLoc, Come2Me or Move2Area still moves; a blank reason prints a line and adds nothing.

| Parameter | Type | Default | Meaning |


### `CallGH`

`OgreBotAPI.Movement:CallGH[fw]`

| Parameter | Type | Default | Meaning |

| Parameter | Type | Default | Meaning |
|---|---|---|---|

### `Come2Me`

`OgreBotAPI.Movement:Come2Me[fw, toWho=me, precision=3]`

Runs to where the named character is standing at the moment of the call, stopping within the precision; it needs OgreBot open (or Movement:UseWithoutOgreBot) and prints a line when it is not, and a character with Allow Camp Spot off stays put and prints a line. On arrival the character stays there instead of going back to its camp spot until JoustOut or LetsGo, a name that matches nobody here prints a line and does nothing, and after 10 seconds stuck the move stops with one line.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `toWho` | string | `me` | Who to run to: a name (part of a name works), an actor ID or an @ alias. Blank means yourself. |
| `precision` | float | `3` | How close counts as arrived, in meters. |

```text
OgreBotAPI.Movement:Come2Me[${Me.Name},${Group[1].Name},3]
```

*Was (OldBot):* `OgreBotAPI:Come2Me`

### `Crouch`

`OgreBotAPI.Movement:Crouch[fw]`

Presses your crouch key once (Z unless you have bound another).

| Parameter | Type | Default | Meaning |

It accepts whether or not the Settings Do not auto accept quests box is ticked, since that box stops only the automatic accept; given a name, a group leader with auto share on shares that quest two seconds later.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters this runs on |
| `questName` | string | `""` | the quest to share after accepting; blank accepts with no share |

```text
OgreBotAPI.Quest:Accept[${Me.Name}]
```

*Was (OldBot):* `OgreBotAPI:AcceptQuest`, `Obj_OgreUtilities:AcceptQuest`

### `CompareUpdate`

`OgreBotAPI.Quest:CompareUpdate[fw, questName, sender]`

Reads your own steps for a quest and asks other characters to compare theirs; a character on a different step says so in its own console and you get a tally. The character that runs it asks, the for-who is who is asked, and all or blank asks the rest of your group.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | for-who: which characters are asked; all or blank is your group but you |
| `questName` | string |  | the quest to compare; a missing one prints a console line |
| `sender` | character name |  | the character that asks; the -CompareQuest console line fills it. Leave it out in a script: the character running it asks, and any other name makes the call do nothing |

```text
OgreBotAPI.Quest:CompareUpdate[all,"Feathers For Sethis"]
```

*Was (OldBot):* `OgreBotAPI:CompareQuestUpdate`
