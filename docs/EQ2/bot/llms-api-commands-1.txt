== ogre commands ==

What a user types in the game's chat box (or a script runs): ogre <word> ...

ogre abilitydetails [name or id]
  kind: ogre command (typed in the game's chat box or a script)
  what: Show every field your ability export holds for an ability, with a search
  arg <name or id> (text, default: the window opens with nothing picked): An ability's name or ID: a base name picks the rank the bot uses, a rank's full name or an ID picks exactly that rank, and the search box is filled in with it.
  example: ogre abilitydetails Kick

ogre account
  kind: ogre command (typed in the game's chat box or a script)
  what: Show this session's account and access level
  example: ogre account

ogre ae [-nogui] [-targets <n>] [-list]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre abilityefficiency
  what: Your abilities' damage / (cast + recovery), at 1 to n targets: a window, or -nogui for the report file
  example: ogre ae

ogre afk [0|on|off]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre antiafk
  what: Keep the session alive (bare = silent; 0 = noisy; off = stop)
  arg 0 (word, default: bare `ogre afk` turns it on silent): Turn the keepalive on in noisy mode: it prints a line each time it sends its /who all (every 10 to 15 minutes).
  arg on (word): Turn the keepalive on and keep the silent or noisy choice it already has.
  arg off (word): Stop the keepalive (the same as `ogre end afk`); invite accepting is not changed.
  arg invites (word, default: off at load): `invites on` or `invites off`: auto-accept group invites from names on your characters list; separate from the keepalive.
  example: ogre afk off

ogre analysis [scan|monitor|taps|export|import|end]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre anal
  what: Watch actors, record what changes and when, and diff two of them
  arg scan (word, default: bare `ogre analysis` opens the window): Scan the zone's actors; add `<member>=<value>` terms (`<member><<value>` and `<member>><value>` too) to keep only matching ones, none reuses the window's terms or scans everything.
  arg monitor (word): `monitor on|off|clear|list`, or `monitor add <id|target|cursor>` / `monitor remove <id>`: pick the actors to watch and record their changes.
  arg taps (word): `taps on` or `taps off`: log the choice and reward windows that appear (any word but off turns them on).
  arg export (word): `export [<name>]`: save what was recorded to a file.
  arg import (word): `import <name|path>`: load a saved session back in.
  arg end (word): Stop sampling, the taps and any scan, then close the window (the same as `ogre end analysis`).
  arg panel (word): Open the window.
  arg close (word): Close the window only; recording goes on.
  arg status (word): Print what is monitored, the sample count, the scan and the taps.
  arg rate (word): `rate <ms>`: how often monitored actors are sampled, 100 to 10000 ms.
  arg sessions (word): List the saved sessions you can import.
  example: ogre analysis monitor add target

ogre bgrender [on|off|draw <ms>|hz <n>|force on|off|hold <name>|release <name>|clear]
  kind: ogre command (typed in the game's chat box or a script)
  what: Skip drawing while this client is in the background (once a second; full drawing when active)
  arg on (word, default: off at load; bare `ogre bgrender` prints the status): Turn background render skipping on.
  arg off (word): Turn it off - full drawing again (the same as `ogre end bgrender`).
  arg draw (word): Set how often a background client still draws a frame, the `<ms>` after it.
  arg <ms> (number, default: 1000): The background draw interval in milliseconds; 0 means never draw in the background.
  arg hz (word): Set the background loop cap, the `<n>` after it.
  arg <n> (number, default: 100): Loops per second while in the background; 0 means no cap.
  arg hold (word): `hold <name>`: keep every frame drawn until that name is released (for scripts that need the screen drawn).
  arg release (word): `release <name>`: drop that hold.
  arg clear (word): Drop every hold.
  example: ogre bgrender on

ogre bot [<toon>] [-s <server>] [-c <class>]
  kind: ogre command (typed in the game's chat box or a script)
  what: Load OgreBot (logs <toon> in first if given, on that server and as that class if given)
  arg <toon> (name, default: OgreBot loads on the character you are on now): Log this character in first, then load OgreBot.
  arg -s (flag): Log in on the server named next (`-server` works too); needed when the character is on more than one server and none is the default.
  arg <server> (name, default: the character's default server): The server for `-s`; `ogre login -?` lists the short forms.
  arg -c (flag): Log in as the class named next (`-class` works too).
  arg <class> (name, default: whatever class it was): The class for `-c`.
  example: ogre bot Mytoon

ogre buycrate [-r|-h|-all]
  kind: ogre command (typed in the game's chat box or a script)
  what: Buy this zone's heroic/raid crates (-r raid, -h heroic, -all)
  arg -r (flag, default: with no flag both crates are bought): Buy only the raid crate (`-raid` works too).
  arg -h (flag): Buy only the heroic crate (`-heroic` works too).
  arg -all (flag, default: on): Buy both the heroic and the raid crate.
  example: ogre buycrate -r

ogre buyfuel [amount]
  kind: ogre command (typed in the game's chat box or a script)
  what: Buy the EXAMINED fuel up to <amount> in the guild fuel depot
  arg <amount> (number, default: 90000): Buy the examined fuel until the guild Fuel Depot holds this many.
  example: ogre buyfuel 50000

ogre buyoverseermissions [flags] | stop | status
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre bom
  what: Buy Overseer missions from the Administrator agent
  arg -season (flag, default: bare = the options on this character's Overseer Buy tab): `-season <n>`: only missions of season 1 to 7 (`-s` works too).
  arg -colour (flag, default: any colour): `-colour <name>`: only Blue, Yellow, Purple or Green missions (`-c` / `-color` work too).
  arg -num (flag, default: 10): `-num <n>`: how many different missions to buy (`-n` works too).
  arg -amount (flag, default: 10): `-amount <n>`: how many of each to buy, at most 20 (`-a` works too).
  arg -replenishonly (flag, default: off): Only top up missions you already have (`-r` / `-ro` work too).
  arg -noscribe (flag, default: scribe is on): Do not scribe the bought missions (`-scribe` turns it back on).
  arg -destroy (flag, default: off): Destroy the copies left over after scribing (`-nodestroy` turns it off).
  arg -gettogh (flag, default: off): Go to the guild hall when the run finishes (`-gh`; `-nogettogh` / `-nogh` turn it off).
  arg stop (word): Stop a running buy (`abort` works too).
  arg status (word): Print how the buy run is going.
  example: ogre buyoverseermissions -num 5 -amount 2

ogre camp [charselect]
  kind: ogre command (typed in the game's chat box or a script)
  what: Camp out to login+exit ('charselect' stays at char select)
  arg charselect (word, default: camps to the login screen, then exits the game): Camp to character select and stay there (`cs` / `select` work too).
  example: ogre camp charselect

ogre chatcmd [off|status|debug [on|off]|reloadauth|test <chattype> <speaker> [message]]
  kind: ogre command (typed in the game's chat box or a script)
  what: Run the commands your own characters send you in chat
  arg off (word, default: bare `ogre chatcmd` turns it on): Stop running commands sent to you in chat (the same as `ogre end chatcmd`).
  arg status (word): Print whether it is on, how many names it trusts, and how many lines it ran or rejected.
  arg reloadauth (word): Re-read the names of your own characters whose chat lines it will obey.
  example: ogre chatcmd status

ogre cm [-small|-large]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre collection, ogre collections
  what: Add collectibles from your collectible depot to your collections
  arg -small (flag, default: the nearest Collectible Depot, else your Personal Collectible Stash): Use the Collectible Depot (the small one) only.
  arg -large (flag): Use the Collectible Depot (Large) only.
  arg -inventory (flag, default: off): Add the collectibles in your bags instead of a depot (`1` / `-1` work too).
  example: ogre cm -large

  arg reset (word): Reset your active raid on eq2codex.com.

ogre craft [status|start|writs|tinker|lll|stop|end|minimize|scan|add|set|shop|?]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre craft2
  what: Open the crafting panel
  arg status (word, default: bare `ogre craft` opens the panel and turns on craft reactions): Print what crafting is doing, how many are crafted and the last error.
  arg start (word): Craft what is in the queue.
  arg writs (word): Run the writ flow.
  arg tinker (word): Run auto tinkering.
  arg lll (word): Run low level leveling.
  arg stop (word): Stop the run; the panel stays open.
  arg end (word): Stop everything and close the window (the same as `ogre end craft`).
  arg minimize (word): Roll the window up to its title bar; crafting goes on, bare `ogre craft` brings it back.
  arg scan (word): Re-read your recipe book.
  arg add (word): `add <recipe name|id|lastknownrecipe> [<quantity>]`: put a recipe in the queue; a trailing whole number is the quantity (default 1), lastknownrecipe is the last one you scribed.
  arg set (word): `set <key> <value>`: change one craft setting (saved a second later).
  arg shop (word): `shop books`, `shop sell <name>...` or `shop destroy <name>...`: run one merchant errand by hand (not while a craft runs).
  arg ? (word): Print the word list (`help` works too).
  arg pause (word): `pause` or `pause on` pauses the run; `pause off` resumes it.
  arg clear (word): Empty the queue.
  arg queue (word): List what is in the queue.
  arg quest (word): Craft the recipe steps of your current quest until none is left.
  arg save (word): Save the craft settings now.
  arg reload (word): Re-read the craft settings and the data files.
  example: ogre craft writs

ogre craftgm [<range>] | scan [<range>] | start [<range>] | queue [<range>] | status | stop | end | close  [depot|nodepot]
  kind: ogre command (typed in the game's chat box or a script)
  what: Open the Grandmaster crafting panel ((Master) scrolls -> (Grandmaster) crafts)
  arg <range> (text, default: bare opens the panel and does nothing else): A level (`131`), a range (`131-135` or `131 135`), or `all`; on its own it opens the panel with the range filled in and scans nothing.
  arg scan (word): `scan [<range>]`: open the panel and find the (Master) scrolls to craft, crafting nothing.
  arg start (word): `start [<range>]`: open the panel and scan, queue and craft the (Grandmaster) recipes.
  arg queue (word): `queue [<range>]`: scan and replace the Craft queue with the (Grandmaster) recipes, then stop; never uses the Scroll Depot.
  arg status (word): Print the state; does not touch the panel.
  arg stop (word): Stop a run; the panel stays as it is.
  arg end (word): Stop a run and close the panel (the same as `ogre end craftgm`).
  arg close (word): The same as end.
  arg depot (word, default: as last set (off to start)): Also pull scrolls from the Scroll Depot; sticks, and works with any word that takes a range.
  arg nodepot (word): Use your bags only (`bagsonly` works too); sticks.
  example: ogre craftgm start 131-135 depot

ogre craftingmats [-<expansion> -<category> ...] | ogre craftingmats plan|help|end
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre cmats
  what: Edit the crafting-mats lists; with flags, pull a craft's mats from the harvest depot
  arg -<expansion> (flag, default: with only a category, Visions of Vetrovia): Which list to pull from: -vov, -cd, -mm, -pop or -ka (any list file's key); several may be given.
  arg -<category> (flag, default: the list's own line (signature; for -ka daily and weekly)): -sig (or -s), -daily (or -d) or -weekly (or -w).
  arg plan (word): `plan [-<expansion> -<category> ...]`: print the shopping list and stop, without the depot (`preview` and `-plan` work too).
  arg help (word): Print the usage (`?` works too).
  arg end (word): Stop a pull and close the editor (the same as `ogre end craftingmats`).
  arg panel (word, default: bare `ogre craftingmats` opens the editor): Open the list editor (`config` / `edit` work too).
  example: ogre craftingmats -vov -sig

ogre dets [m|target] [-noinfo]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre detrimentals
  what: Dump your detrimentals, with Name and Description (a server read each; -noinfo skips them)
  arg m (word, default: your own detrimentals): Dump your maintained effects instead (`maintained` works too).
  arg target (word): Dump your target's effects instead (`t` works too).
  arg -noinfo (flag, default: Name and Description are read (one server read each)): Skip the Name and Description - a cheap dump with the icon pair only.
  example: ogre dets target -noinfo

ogre effecttracker [on|off|npc on|merge|status|end]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre oet
  what: Capture what every detrimental and NPC effect says it does, into the shared zone dataset
  arg on (word, default: bare opens the window): Start capturing your detrimental effects.
  arg off (word): Stop both captures (players and NPCs); the window stays open.
  arg npc (word): `npc on` or `npc off`: also capture NPC effects.
  arg merge (word): Merge every character's captures for the zone you are in into the zone's one dataset file.
  arg status (word): Print what is armed and how much was captured.
  arg end (word): Stop both captures and close the window (the same as `ogre end effecttracker`).
  arg panel (word): Open the window.
  arg close (word): Close the window only.
  arg reload (word): Re-read the capture files from disk; anything not yet saved is dropped.
  arg describe (word, default: on): `describe on` or `describe off`: read each new effect's info once from the server (off loses only the Description).
  arg closewindow (word): `closewindow [all]`: close one leftover examine window, or all of them.
  example: ogre effecttracker on

ogre encounter [reload|debug comms|steps on|off|sequences]
  kind: ogre command (typed in the game's chat box or a script)
  what: Encounter authoring: reload the json from disk, toggle the debug echoes, list live sequences
  arg reload (word, default: bare prints the word list): Re-read the encounter json from disk and swap it in; a line follows with the loaded, scanned and error counts.
  arg debug (word): `debug comms on|off` or `debug steps on|off`: console echo for comms or step changes; `debug` alone prints the current switches.
  arg sequences (word): List every live sequence: its step, how long it has been there and what holds it (`seq` works too).
  example: ogre encounter reload

ogre examine [on|off|reset]
  kind: ogre command (typed in the game's chat box or a script)
  what: Examine each NEW detrimental signature once and report it
  arg on (word, default: bare turns it on): Examine each new detrimental once and report its Name and Description (`start` works too).
  arg off (word): Stop examining (`stop` works too; the same as `ogre end examine`).
  arg reset (word): Forget the ones already seen, so each is examined again (`clear` works too).
  arg status (word): Print whether it is on and what it has seen.
  example: ogre examine reset

ogre experiment [-<stat> <n>]... | items | run <row> ...
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre experimentui
  what: Boost item stats on the tradeskill Experiment tab
  arg -<stat> (flag, default: bare prints the status and the usage): A stat to boost on the item already selected on the Experiment tab: -potency (or -p), -critbonus (or -cb), or any other option's label.
  arg <n> (number): How many times to boost the stat before it; a count of 0 or less adds nothing.
  arg items (word): List the item rows on the Experiment tab.
  arg run (word): `run <row> -<stat> <n> ...`: the same boost on item row `<row>` from `items`.
  arg stop (word): Stop and put the window size back (`off` works too; the same as `ogre end experiment`).
  arg status (word): Print the state and the usage.
  example: ogre experiment -potency 3

ogre export [flags]
  kind: ogre command (typed in the game's chat box or a script)
  also: ogre abilityexport
  what: Open the export panel; with export flags (-passive, -new, -maxlevel 130 ...) run the export now with them; -start runs the panel's options, -default the defaults
  arg -default (flag, default: the current saved options): Use the default options for this run only; the saved ones are not changed.
  arg -start (flag, default: bare opens the options panel): Run the export now, without the options panel.
  arg -stop (flag): Stop an export that is running.
  arg <export flags> (string): Any flag ISXOgreEQ2.Export:Abilities takes (-passive, -tradeskill, -NoAscension, -AscensionOnly, -nodesc, -j/-a/-e/-m/-gm/-ancient, -minlevel <n>, -maxlevel <n>, -new, -nonew, -NewAbilities, -nosave, -noreloadbot, -consolidate, -consolidateOnly, -clearcache, -path <file>), or an ability name or ID: runs the export now with exactly these.
  example: ogre export -new -maxlevel 130

ogre find <name> [-rorr]
  kind: ogre command (typed in the game's chat box or a script)
  what: Watch for named actors and waypoint them when they spawn
  arg <name> (name, default: bare prints the usage and the built-in options): Watch for actors with exactly this name (any case); each word is one name, and the list replaces the old one and does one scan now.
  arg -rorr (flag): Watch for the four Renewal of Ro researchers.
  arg -add (flag): `-add <name>`: add a name to the list.
  arg -remove (flag): `-remove <name>`: take a name off the list.
  arg -clear (flag): Empty the list.
  arg -list (flag): Print the list.
  arg -on (flag): Start watching.
  arg -off (flag): Stop watching (the same as `ogre end find`).
  arg -scan (flag): Look for the listed names now.
  arg -status (flag): Print whether it is watching and how many names.
  arg -panel (flag): Open the window.
  example: ogre find Gorenaire

ogre ghtohouse [flags]
  kind: ogre command (typed in the game's chat box or a script)
  what: Move the guild-hall depots into your house ones (-all, -scroll, ...)
  arg -all (flag, default: no depot = refused): Move all eight shared depots (harvest, ammo, adorn, food, lore, potion, collectible, fuel); not scroll.
  arg -harvest (flag): Move the harvest depot (`-h` works too).
  arg -ammo (flag): Move the ammo depot.
  arg -adorn (flag): Move the adornment depot.
  arg -food (flag): Move the food and drink depot.
  arg -lore (flag): Move the lore and legend depot.
  arg -potion (flag): Move the poison, potion and totem depot.
  arg -collectible (flag): Move the collectible depot (`-collect` / `-c` work too).
  arg -fuel (flag): Move the fuel depot.
  arg -scroll (flag): Move the scroll depot (only this direction has one).
  arg -no<depot> (flag): Turn one depot back off, e.g. `-nofuel` after `-all` (also `-nh`, `-nc`).
  arg <owner> (name, default: your own house): Whose house to deposit into.
  example: ogre ghtohouse -all -scroll

ogre hideeffects [panel|clear|end]

  arg reload (word): Re-read the effect list files.
  arg reset (word): Delete your own edits so the list is back to what shipped.

== ISXOgreX console commands ==

Sent as `oc !c <command> <who> ...` to the sessions on this PC, this one included; the for-who in <who> picks which act. `oc !ci` does the same without showing the line.

oc !c -auth <nick>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: IRC only: authorizes an IRC nick to send this hub commands.
  arg nick (string): The IRC nick to authorize
  example: irc !c -auth SomeNick

oc !c -authlist
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: IRC only: says which IRC nicks are authorized.
  example: irc !c -authlist

oc !c -KillSession <target>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: IRC only, authorized senders only: ends one InnerSpace session on this PC, or all of them.
  arg target (string): The session name (is1, is2, ...) or all
  example: irc !c -KillSession is3

oc !c -LaunchAutoLogin <profile>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: From IRC, authorised senders only: runs an auto-login profile.
  arg profile (one): The auto-login profile to run.
  example: irc !c -LaunchAutoLogin MyProfile

oc !c -List_AutoLoginProfiles
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: From IRC, authorised senders only: lists the auto-login profiles. -details adds each row, -profile <name> shows one.
  example: irc !c -List_AutoLoginProfiles

oc !c -List_Sessions
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: IRC only, authorized senders only: lists this PC's InnerSpace sessions.
  example: irc !c -List_Sessions

oc !c -LoadCharacter <toon>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: From IRC, authorised senders only: logs one toon in, using the first auto-login profile that holds it.
  arg toon (one): The toon, or toon:isN to name the session.
  example: irc !c -LoadCharacter MyToon

oc !c -unauth <nick>
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: IRC only: removes an IRC nick from the authorized list.
  arg nick (string): The IRC nick to remove
  example: irc !c -unauth SomeNick

oc !c -unauthall
  kind: console command (oc !c / oc !ci - a line, an MCP button or a script)
  what: IRC only: clears the authorized list.
  example: irc !c -unauthall
