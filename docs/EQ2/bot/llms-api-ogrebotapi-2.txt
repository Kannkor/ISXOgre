== OgreBotAPI.AutoTarget ==

${OgreBotAPI.AutoTarget.Active}
  kind: member of OgreBotAPI.AutoTarget
  what: TRUE when the master checkbox is on, no Suppress reason is held, the working list has at least one entry, and the scanner may scan now: out of combat that needs Out Of Combat Scanning on or something hating you. It reads FALSE whenever nothing would be picked.
  returns: bool: TRUE when enabled, not suppressed, the list is not empty and the scanner may scan now; FALSE otherwise.
  example: echo ${OgreBotAPI.AutoTarget.Active}

${OgreBotAPI.AutoTarget.Count}
  kind: member of OgreBotAPI.AutoTarget
  what: The number of entries in the working list - the list auto-target picks from right now.
  returns: int: the number of entries; 0 when the list is empty.
  example: echo ${OgreBotAPI.AutoTarget.Count}
  oldbot: Ob_AutoTarget.Items

${OgreBotAPI.AutoTarget.Enabled}
  kind: member of OgreBotAPI.AutoTarget
  what: Reads the master auto-target checkbox from the profile. When it is off, auto-target never picks a target, whatever the list holds.
  returns: bool: TRUE when the auto-target checkbox is ticked; FALSE when it is unticked or was never set.
  example: echo ${OgreBotAPI.AutoTarget.Enabled}
  oldbot: OgreBotAPI.AutoTarget_Enabled

${OgreBotAPI.AutoTarget.Entry[n]}
  kind: member of OgreBotAPI.AutoTarget
  what: The working-list entry at position n, counting from 1, as JSON text with its fields: ActorName, MinHPToTarget, CheckCollision, AggroOnGroupOnly, MaxHPToTarget, AggroOnNonFighterOnly, AggroOnNotMe, and KeepLast when set.
  arg n (int): Position in the working list, 1 = top.
  returns: string: the entry as a JSON object; "{}" when n is out of range.
  example: echo ${OgreBotAPI.AutoTarget.Entry[1]}
  oldbot: Ob_AutoTarget.AggroOnGroupOnly, Ob_AutoTarget.AggroOnGroupOnlyOrderedItem, Ob_AutoTarget.AggroOnNonFighterOnly

${OgreBotAPI.AutoTarget.EntryName[n]}
  kind: member of OgreBotAPI.AutoTarget
  what: The name of the working-list entry at position n, counting from 1 at the top.
  arg n (int): Position in the working list, 1 = top.
  returns: string: that entry's actor name; "" when n is out of range.
  example: echo ${OgreBotAPI.AutoTarget.EntryName[1]}
  oldbot: Ob_AutoTarget.ActorName, Ob_AutoTarget.ActorNameOrderedItem, Ob_AutoTarget.OrderedItem

${OgreBotAPI.AutoTarget.HasActor[name]}
  kind: member of OgreBotAPI.AutoTarget
  what: Asks whether the working list has an entry with exactly this name, case not mattering. It compares entry names only - it does not test whether an entry would match a nearby actor.
  arg name (string): The entry name to look for (case does not matter).
  returns: bool: TRUE when an entry's name equals the given name; FALSE when none does or no name is given.
  example: echo ${OgreBotAPI.AutoTarget.HasActor["a gnoll guard"]}
  oldbot: Ob_AutoTarget.HasActor

${OgreBotAPI.AutoTarget.JSON}
  kind: member of OgreBotAPI.AutoTarget
  what: The whole working list as JSON text, top entry first, each entry with the same fields Entry shows.
  returns: string: a JSON array of entries; "[]" when the list is empty.
  example: echo ${OgreBotAPI.AutoTarget.JSON}
  oldbot: Ob_AutoTarget.Ob_AutoTargetList

${OgreBotAPI.AutoTarget.ListName}
  kind: member of OgreBotAPI.AutoTarget
  what: The name of the saved list or built-in list the working list is: set by LoadSaved, Save and LoadPreset. It is blank after Clear, and after any entry is added, changed or removed, since the list then matches no saved list.
  returns: string: the saved-list or built-in list name; "" when none.
  example: echo ${OgreBotAPI.AutoTarget.ListName}

${OgreBotAPI.AutoTarget.OutOfCombatScanning}
  kind: member of OgreBotAPI.AutoTarget
  what: Reads the out-of-combat scanning checkbox. When it is off, auto-target only looks for a target while you are in combat or something hates you.
  returns: bool: TRUE when out-of-combat scanning is ticked; FALSE when it is unticked or was never set (unset counts as off).
  example: echo ${OgreBotAPI.AutoTarget.OutOfCombatScanning}

${OgreBotAPI.AutoTarget.PresetCount}
  kind: member of OgreBotAPI.AutoTarget
  what: The number of built-in lists LoadPreset can load. There are two today: Named and AddsThenNamed.
  returns: int: the number of built-in lists.
  example: echo ${OgreBotAPI.AutoTarget.PresetCount}

${OgreBotAPI.AutoTarget.PresetName[n]}
  kind: member of OgreBotAPI.AutoTarget
  what: The name of built-in list n, counting from 1.
  arg n (int): Which built-in list, 1 = first.
  returns: string: the built-in list's name; "" when n is out of range.
  example: echo ${OgreBotAPI.AutoTarget.PresetName[1]}

${OgreBotAPI.AutoTarget.SavedCount}
  kind: member of OgreBotAPI.AutoTarget
  what: The number of saved lists for the zone (lists are kept per zone), loading the current zone's lists first. Reads 0 out of the world.
  returns: int: the number of saved lists; 0 when the zone has none.
  example: echo ${OgreBotAPI.AutoTarget.SavedCount}

${OgreBotAPI.AutoTarget.SavedName[n]}
  kind: member of OgreBotAPI.AutoTarget
  what: The name of saved list n for the zone, counting from 1, in file order, from the same lists as SavedCount. Reads "" out of the world.
  arg n (int): Which saved list, 1 = first.
  returns: string: the saved list's name; "" when n is out of range.
  example: echo ${OgreBotAPI.AutoTarget.SavedName[1]}

${OgreBotAPI.AutoTarget.ScanHeight}
  kind: member of OgreBotAPI.AutoTarget
  what: Reads the scan height setting as stored - the largest height difference an actor may have from you and still be picked (it must be less than this). An unset or 0 value reads 0 here, but auto-target then uses 5.
  returns: int: the stored scan height; 0 when unset.
  example: echo ${OgreBotAPI.AutoTarget.ScanHeight}

${OgreBotAPI.AutoTarget.ScanRadius}
  kind: member of OgreBotAPI.AutoTarget
  what: Reads the scan radius setting as stored. An unset or 0 value reads 0 here, but auto-target then scans 50.
  returns: int: the stored scan radius; 0 when unset.
  example: echo ${OgreBotAPI.AutoTarget.ScanRadius}

${OgreBotAPI.AutoTarget.Suppressed[key]}
  kind: member of OgreBotAPI.AutoTarget
  what: Asks whether auto-targeting is paused by Suppress. With no key it asks whether any reason is holding it; with a key it asks about that reason only (case does not matter).
  arg key (string): Optional. The reason name given to Suppress; leave it out to ask about any reason.
  returns: bool: TRUE when the reason (or, with no key, any reason) is holding targeting paused; FALSE otherwise.
  example: echo ${OgreBotAPI.AutoTarget.Suppressed[myscript]}
  oldbot: OgreBotAPI.AutoTarget_Disabled

${OgreBotAPI.AutoTarget.WhenHated}
  kind: member of OgreBotAPI.AutoTarget
  what: Reads the auto-target-when-hated checkbox. When it is on and the character has nothing to fight, the bot about once a second targets an NPC within 30 that is attacking the group, and says so in the console.
  returns: bool: TRUE when the checkbox is ticked; FALSE when it is unticked or was never set.
  example: echo ${OgreBotAPI.AutoTarget.WhenHated}

OgreBotAPI.AutoTarget:AddActor[fw, name, minHP=0, checkCollision=FALSE, aggroOnGroupOnly=TRUE, maxHP=0, aggroOnNonFighterOnly=FALSE, aggroOnNotMe=FALSE, keepLast=FALSE]
  kind: method of OgreBotAPI.AutoTarget
  what: Adds one entry to the working list (with no name it does nothing, and the same name can be added twice) and blanks ListName; auto-target tries entries top-down and takes the first entry that matches anything, keeping your current target if it matches. The working list lasts for this session only (it survives zoning) - use Save to keep it.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): What to target: part of an actor name (matches any actor whose name contains it, case not mattering), NPC (any normal NPC), NamedNPC or Named (any named NPC), or a number for an actor ID.
  arg minHP (int, default: 0): Only pick the actor while its health is at least this percent; 0 = no limit.
  arg checkCollision (bool, default: FALSE): TRUE to only pick actors you have a clear line to.
  arg aggroOnGroupOnly (bool, default: TRUE): TRUE to only pick actors whose target is in your group. A word that is not yes/no keeps the default, TRUE.
  arg maxHP (int, default: 0): Only pick the actor while its health is below this percent; 0 = no limit.
  arg aggroOnNonFighterOnly (bool, default: FALSE): TRUE to only pick actors targeting a player who is not a fighter.
  arg aggroOnNotMe (bool, default: FALSE): TRUE to skip actors that are targeting you.
  arg keepLast (bool, default: FALSE): TRUE to keep this entry at the bottom: later adds go in above it.
  example: OgreBotAPI.AutoTarget:AddActor[igw:${Me.Name},"a gnoll guard",0,FALSE,TRUE]
  oldbot: OgreBotAPI:AutoTarget_AddActor, Ob_AutoTarget:AddActor

OgreBotAPI.AutoTarget:Clear[fw]
  kind: method of OgreBotAPI.AutoTarget
  what: Empties the working list and blanks ListName. Saved lists on disk are not touched.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.AutoTarget:Clear[igw:${Me.Name}]
  oldbot: OgreBotAPI:AutoTarget_Clear, OgreBotAPI:AutoTarget_ClearActors, Ob_AutoTarget:Clear

OgreBotAPI.AutoTarget:DeleteSaved[fw, name]
  kind: method of OgreBotAPI.AutoTarget
  what: Deletes a saved list from the current zone's file on disk; a blank name, or one that is not found, deletes nothing and says so on the console. The working list is not touched, but ListName is blanked when it named that list; it needs the character in the world.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): The saved list to delete, matched whole, case not mattering.
  example: OgreBotAPI.AutoTarget:DeleteSaved[${Me.Name},"Trash"]
  oldbot: Ob_AutoTarget:DeleteList

OgreBotAPI.AutoTarget:LoadPreset[fw, name]
  kind: method of OgreBotAPI.AutoTarget
  what: Replaces the working list with a built-in list, reading nothing from disk, and sets ListName to it. An unknown name prints a message to the Inner Space console and leaves the list as it was.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): The built-in list's name (see PresetName): Named (any named NPC) or AddsThenNamed (normal NPCs first, then the named), matched whole, case not mattering.
  example: OgreBotAPI.AutoTarget:LoadPreset[igw:${Me.Name},AddsThenNamed]

OgreBotAPI.AutoTarget:LoadSaved[fw, name]
  kind: method of OgreBotAPI.AutoTarget
  what: Replaces the working list with a saved list for the current zone and sets ListName. A blank name, or a name the zone has no list for, changes nothing and says so on the console; it needs the character in the world.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): The saved list's name (see SavedName), matched whole, case not mattering.
  example: OgreBotAPI.AutoTarget:LoadSaved[igw:${Me.Name},"Trash"]
  oldbot: OgreBotAPI:LoadAutoTargetList, Ob_AutoTarget:LoadListFromSaveList, Ob_AutoTarget:LoadListFromSaveListForWho

OgreBotAPI.AutoTarget:Release[fw, reason]
  kind: method of OgreBotAPI.AutoTarget
  what: Releases the pause held under this reason name (case does not matter); a blank reason gets one line and a name that is not held does nothing. Targeting resumes only when no other reason is still held.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg reason (string): The reason name given to Suppress.
  example: OgreBotAPI.AutoTarget:Release[${Me.Name},myscript]
  oldbot: OgreBotAPI:AutoTarget_Enable

OgreBotAPI.AutoTarget:RemoveActor[fw, name]
  kind: method of OgreBotAPI.AutoTarget
  what: Removes every working-list entry whose name is exactly this name, case not mattering. Nothing happens when no entry matches or the name is blank.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): The entry name to remove (whole name, case does not matter).
  example: OgreBotAPI.AutoTarget:RemoveActor[igw:${Me.Name},"a gnoll guard"]
  oldbot: OgreBotAPI:AutoTarget_RemoveActor, Ob_AutoTarget:RemoveActor

OgreBotAPI.AutoTarget:Save[fw, name]
  kind: method of OgreBotAPI.AutoTarget
  what: Saves the working list to disk as a named list for the current zone and sets ListName; an existing list whose name matches, case not mattering, is replaced and moves to the end. A blank name, or a write that fails, saves nothing and says so on the console; it needs the character in the world.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): The name to save the list under, kept as you typed it.
  example: OgreBotAPI.AutoTarget:Save[${Me.Name},"Trash"]
  oldbot: Ob_AutoTarget:SaveList

OgreBotAPI.AutoTarget:SetEnabled[fw, bool=TRUE]
  kind: method of OgreBotAPI.AutoTarget
  what: Turns the master auto-target checkbox on or off and prints the change to the OgreConsole when the value changes. The change goes to this profile's setting (the same one the panel shows) and reaches disk the next time the profile is saved; nothing is written when no profile is loaded.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg bool (bool, default: TRUE): TRUE to turn auto-target on, FALSE to turn it off. Blank turns it on; a word that is not yes/no leaves it as it is.
  example: OgreBotAPI.AutoTarget:SetEnabled[igw:${Me.Name},TRUE]
  oldbot: ogre autotarget

OgreBotAPI.AutoTarget:SetOutOfCombatScanning[fw, bool=TRUE]
  kind: method of OgreBotAPI.AutoTarget
  what: Turns out-of-combat scanning on or off and prints the change to the OgreConsole when the value changes. The change goes to this profile's setting (the same one the panel shows) and reaches disk the next time the profile is saved; nothing is written when no profile is loaded.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg bool (bool, default: TRUE): TRUE to let auto-target look for targets out of combat, FALSE to wait for combat or aggro. Blank turns it on; a word that is not yes/no leaves it as it is.
  example: OgreBotAPI.AutoTarget:SetOutOfCombatScanning[igw:${Me.Name},TRUE]

  arg fw (for-who): for-who: this runs only when this character is one it names

OgreBotAPI.AutoTarget:Suppress[fw, reason]
  kind: method of OgreBotAPI.AutoTarget
  what: Pauses automatic targeting under a reason name and holds the current target without touching the master checkbox; a direct target command still works, and a blank reason gets one line. Each reason lasts for this session only, until Release is called with the same name (case does not matter), LetsGo runs or you change zones.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg reason (string): A name for this pause, so it can be released on its own.
  example: OgreBotAPI.AutoTarget:Suppress[${Me.Name},myscript]
  oldbot: OgreBotAPI:AutoTarget_Disable


== OgreBotAPI.Bot ==

${OgreBotAPI.Bot.Paused}
  kind: member of OgreBotAPI.Bot
  what: TRUE while the bot is paused, whether by Pause, the mini toolbar's pause button or a camp in progress. The bot starts out paused, so this is also TRUE before OgreBot has been loaded.
  returns: bool: TRUE when the bot is paused or has not been loaded yet; FALSE when it is running.
  example: echo ${OgreBotAPI.Bot.Paused}
  oldbot: OgreBotAPI.Paused

${OgreBotAPI.Bot.ScriptBaseName[path,removeExtension]}
  kind: member of OgreBotAPI.Bot
  what: Returns the last part of a script path with its folders removed; back slashes count as forward slashes. A trailing .iss (any case) is removed unless removeExtension is FALSE.
  arg path (string): The script path or file name.
  arg removeExtension (bool, default: TRUE): TRUE strips a trailing .iss; FALSE keeps it. A word that is not a yes word reads as FALSE.
  returns: string: the file name, without .iss unless removeExtension is FALSE; the whole text when it has no slash.
  example: echo ${OgreBotAPI.Bot.ScriptBaseName["${LavishScript.HomeDirectory}/Scripts/EQ2OgreBot/OgreBotDev.iss"]}
  oldbot: OgreBotAPI.Get_ScriptBaseName

OgreBotAPI.Bot:CampToDesktop[fw, loginOnly=FALSE]
  kind: method of OgreBotAPI.Bot
  what: Queues a camp out: it stops following, pauses the bot for the camp and camps to the login screen, then closes the session unless loginOnly is TRUE. It refuses with a console line while you are in combat mode, and if the camp fails the bot's run state is put back.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg loginOnly (bool, default: FALSE): TRUE stops at the login screen and keeps the session open; FALSE camps out and then closes the session.
  example: OgreBotAPI.Bot:CampToDesktop[${Me.Name},TRUE]
  oldbot: OgreBotAPI:CampToDesktop

OgreBotAPI.Bot:End[fw]
  kind: method of OgreBotAPI.Bot
  what: Closes OgreBot on the next frame, the same as typing ogre end bot. Closing also clears the no-offensive, no-defensive and threat ignore settings.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Bot:End[all]
  oldbot: OgreBotAPI:End_Bot

OgreBotAPI.Bot:EndScript[fw, script]
  kind: method of OgreBotAPI.Bot
  what: Ends a running script on each selected character, matched by its file name with folders and .iss removed, and shows the name in OgreConsole. Does nothing when no script of that name is running, and needs the character in the world.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg script (string): The script's name or path. Only the file name counts, with .iss removed.
  example: OgreBotAPI.Bot:EndScript[all,"MyScripts/hello"]

OgreBotAPI.Bot:ExitClient[fw, seconds=30]
  kind: method of OgreBotAPI.Bot
  what: Queues an exit of this game client: a message box warns that the client closes in the given number of seconds, and clicking OK on it cancels. If the time runs out with the box still open, the session is closed with the character still in the world (no camp).
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg seconds (int, default: 30): Seconds to wait before the exit. Anything that is not a whole number of at least 1 uses the default.
  example: OgreBotAPI.Bot:ExitClient[${Me.Name},60]
  oldbot: OgreBotAPI:ExitClient

OgreBotAPI.Bot:Load[fw]
  kind: method of OgreBotAPI.Bot
  what: Starts OgreBot on the next frame, the same as typing ogre: it opens resumed with its main window hidden. Unlike Reload it also runs when OgreBot is not running, and on a running bot it reopens it the way Reload does.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Bot:Load[igw:${Me.Name}]

OgreBotAPI.Bot:OgreCommand[fw, cmd...]
  kind: method of OgreBotAPI.Bot
  what: Runs an Ogre sub-command (ogre, the name, then each remaining argument quoted) on each selected character, and shows the line it ran in OgreConsole. Needs the character in the world; with no command name it says so in OgreConsole and runs nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg cmd... (string): The sub-command name, then its arguments. Each argument is passed on as its own quoted argument.
  example: OgreBotAPI.Bot:OgreCommand[igw:${Me.Name},quiver]
  oldbot: OgreBotAPI:OgreCommand

OgreBotAPI.Bot:OnDeactivate[fw]
  kind: method of OgreBotAPI.Bot
  what: Releases the Alt key, so an Alt held down when the game window lost focus does not stay stuck. When Alt reads as pressed it first prints a line saying so to the console.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Bot:OnDeactivate[${Me.Name}]
  oldbot: OgreBotAPI:OnDeactivate

OgreBotAPI.Bot:Pause[fw]
  kind: method of OgreBotAPI.Bot
  what: Pauses the bot so it stops casting and its other automatic actions until Resume. Takes effect at once and also works while zoning.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Bot:Pause[igw:${Me.Name}]
  oldbot: OgreBotAPI:Pause, Obj_OgreIH:Pause

OgreBotAPI.Bot:RawCommand[fw, cmd...]
  kind: method of OgreBotAPI.Bot
  what: Runs the arguments as one console command line on each selected character, and shows the line in OgreConsole. Needs the character in the world; an argument holding a space is quoted again, and an empty line runs nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg cmd... (string): The command and its arguments, joined by single spaces into one line.
  example: OgreBotAPI.Bot:RawCommand[all,echo,hello]
  oldbot: OgreBotAPI:RawCommand

OgreBotAPI.Bot:Reload[fw]
  kind: method of OgreBotAPI.Bot
  what: Reloads OgreBot on the next frame: it reopens resumed with its main window hidden, and the no-offensive, no-defensive and threat ignore settings are cleared. Does nothing on a session where OgreBot is not running - it never starts the bot (Load does that).
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Bot:Reload[igw:${Me.Name}]
  oldbot: OgreBotAPI:Reload_Bot

OgreBotAPI.Bot:Resume[fw]
  kind: method of OgreBotAPI.Bot
  what: Resumes a paused bot so it acts again. Takes effect at once and also works while zoning.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Bot:Resume[igw:${Me.Name}]
  oldbot: OgreBotAPI:Resume, Obj_OgreIH:Resume

OgreBotAPI.Bot:RunScript[fw, script, args...]
  kind: method of OgreBotAPI.Bot
  what: Runs a script on each selected character, passing each later argument as its own quoted parameter, and shows the line in OgreConsole. It refuses with an OgreConsole line when the script is not found or a script of the same name is already running, and needs the character in the world.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg script (string): The script path, relative to the Scripts folder; the .iss ending is optional. A path containing a colon is used as it is.
  arg args... (string): The script's parameters. Every argument after script is passed on, each as its own quoted parameter.
  example: OgreBotAPI.Bot:RunScript[${Me.Name},"MyScripts/hello","126","TRUE"]

OgreBotAPI.Bot:SetUpFor[fw, what="", restart=TRUE]
  kind: method of OgreBotAPI.Bot
  what: Sets up for an encounter on the next pulse: the fight of the named mob given in what, or with what blank the nearest or engaged named in this zone. Needs the character in the world; a name no encounter owns prints a warning to the console.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg what (string, default: ""): The named mob whose encounter to set up. Blank picks the nearest or engaged named in this zone.
  arg restart (bool, default: TRUE): TRUE re-runs a setup that is already running; FALSE only sets up an encounter that is not running yet.
  example: OgreBotAPI.Bot:SetUpFor[igw:${Me.Name},"${Target.Name}",TRUE]
  oldbot: OgreBotAPI:SetUpFor


== OgreBotAPI.CampSpot ==

${OgreBotAPI.CampSpot.Active}
  kind: member of OgreBotAPI.CampSpot
  what: The camp spot slot the leash is using now, 1 to 8. It starts at 1 and only SetActive or ResetAll change it.
  returns: int - the active slot number (1 to 8).
  example: echo ${OgreBotAPI.CampSpot.Active}

${OgreBotAPI.CampSpot.AnchorLoc}
  kind: member of OgreBotAPI.CampSpot
  what: The active slot's own spot as one "x,y,z" text without the relative layer, or "" when the active slot has no spot. Use it as the fixed reference when a relative layer may be in play; EffectiveLoc is where the character will actually go.
  returns: string - "x,y,z", or "" when there is no spot.
  example: echo ${OgreBotAPI.CampSpot.AnchorLoc}
  oldbot: Ogre_CampSpot.AbsoluteCampSpotLoc, Ogre_CampSpot.Get_AbsoluteCampSpot

${OgreBotAPI.CampSpot.AnchorX}
  kind: member of OgreBotAPI.CampSpot
  what: The X coordinate of the active slot's own spot, without the relative layer. It reads 0 when the active slot has no spot.
  returns: float - the X coordinate, or 0 when there is no spot.
