## Methods

### `Close`

`ISXOgreEQ2.TagTimers:Close`

Closes the Tag Timers window, the same as `ogre end tags` or its X, and does nothing while it is closed. A ticked Show Tag Timers window box stays ticked and opens it again on the next profile load.

```text
ISXOgreEQ2.TagTimers:Close
```

### `Open`

`ISXOgreEQ2.TagTimers:Open`

Opens the Tag Timers window, the same as `ogre tags`, and does nothing while it is already up. The Show Tag Timers window box on the Tags tab opens it with the profile.

```text
ISXOgreEQ2.TagTimers:Open
```
