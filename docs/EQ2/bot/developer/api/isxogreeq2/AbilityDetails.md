## Methods

### `Close`

`ISXOgreEQ2.AbilityDetails:Close`

Closes the Ability Details window (the same as `ogre end abilitydetails`) and drops any clicks it had not acted on yet. The window is opened with OgreBotAPI.Abilities:AbilityDetails.

```text
ISXOgreEQ2.AbilityDetails:Close
```
