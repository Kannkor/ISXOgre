# ISXOgreEQ2.ForWhoGroups

## Methods

### `Close`

`ISXOgreEQ2.ForWhoGroups:Close`

Closes the ForWho Groups editor, the same as `ogre end forwhogroups`.

```text
ISXOgreEQ2.ForWhoGroups:Close
```

### `List`

`ISXOgreEQ2.ForWhoGroups:List`

Prints your ForWho groups and their members to the console, the same as bare `ogre forwhogroups`.

```text
ISXOgreEQ2.ForWhoGroups:List
```

### `Open`

`ISXOgreEQ2.ForWhoGroups:Open`

Opens the ForWho Groups editor.

```text
ISXOgreEQ2.ForWhoGroups:Open
```

### `Reload`

`ISXOgreEQ2.ForWhoGroups:Reload`

Re-reads the group files, for a file you edited by hand.

```text
ISXOgreEQ2.ForWhoGroups:Reload
```
