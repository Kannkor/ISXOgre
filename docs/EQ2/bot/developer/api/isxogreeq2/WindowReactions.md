# ISXOgreEQ2.WindowReactions

## Methods

### `Status`

`ISXOgreEQ2.WindowReactions:Status`

Prints the window reaction counters to the console: loot, choice and quest-offer windows seen, acted on and deferred, then how each loot window is being read. It makes no game read.

```text
ISXOgreEQ2.WindowReactions:Status
```
