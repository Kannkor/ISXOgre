# ISXOgreEQ2.Commands

## Methods

### `Close`

`ISXOgreEQ2.Commands:Close`

Closes the Commands window and drops any clicks it had not run yet.

```text
ISXOgreEQ2.Commands:Close
```

### `Open`

`ISXOgreEQ2.Commands:Open`

Opens the Commands window, which lists the ogre console commands with their usage and lets you run or end one with a click. If the window cannot open, a warning goes to the console.

```text
ISXOgreEQ2.Commands:Open
```
