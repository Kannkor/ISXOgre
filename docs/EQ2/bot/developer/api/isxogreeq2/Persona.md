## Methods

### `Close`

`ISXOgreEQ2.Persona:Close`

Closes the Persona window, the same as `ogre end persona` or the window's X.

```text
ISXOgreEQ2.Persona:Close
```

### `Open`

`ISXOgreEQ2.Persona:Open`

Opens the Persona window, the same as bare `ogre persona`; already open, it does nothing. Given a word it does not open: changing class with this command is not built yet, so it prints one line saying so.

```text
ISXOgreEQ2.Persona:Open
```
