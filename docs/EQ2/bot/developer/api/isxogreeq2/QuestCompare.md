# ISXOgreEQ2.QuestCompare

## Methods

### `Close`

`ISXOgreEQ2.QuestCompare:Close`

Closes the Quest Compare window, the same as `ogre end questcompare`.

```text
ISXOgreEQ2.QuestCompare:Close
```

### `Open`

`ISXOgreEQ2.QuestCompare:Open`

Opens the Quest Compare window, the same as bare `ogre questcompare`.

```text
ISXOgreEQ2.QuestCompare:Open
```
