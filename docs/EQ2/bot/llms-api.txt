# OgreBot for EverQuest II - API reference, plain text for AI assistants

> Every public member, method, command and event of the new OgreBot (in beta testing): what it does, its arguments, what it returns and a real example. 2060 entries, generated from the same tables as https://kannkor.github.io/ISXOgre/EQ2/bot/developer/api/ (the same text, without the website's tables and links). The rest of the documentation for assistants: https://kannkor.github.io/ISXOgre/EQ2/bot/llms.txt

## How to read an entry

Each entry is the call form on its own line, then indented `key: value` lines:
  kind      member / method of <object>, ogre command, console command, or event
  what      what it does
  arg X     one line per argument, in order: (type, default) and what it means; an argument with a default is optional
  returns   what a member hands back; "returns object" = a member whose value is an object listed under its own heading
  example   a real call (LavishScript, the InnerSpace script language; `wait 10` waits one second)
  more      a page with the details
  oldbot    the OgreBot Classic name(s) it replaced

A member is read as ${Object.Member} and may take [arguments]; a method is a line of its own, Object:Method[arguments] - to read a result, use a member. A first argument `fw` is the for-who: the call runs only when this character is one it names (all, me, a name, igw:${Me.Name} = my whole group, igwbn:${Me.Name} = my group without me, fighter, ...). A script's call never reaches another session; to make other characters act, send the console command with oc !c. ${Me}, ${Target}, ${Zone}, ${Group[1]} in the examples are ISXEQ2's own objects, not the bot's.
