# OgreBotAPI.Position

## Members

### `ActorModelSize`

`${OgreBotAPI.Position.ActorModelSize[nameOrId]}`

Returns an actor's model size: its collision radius times its collision scale. Returns 0 when the argument is blank or the actor cannot be found.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `nameOrId` | string |  | the actor: an actor id, an @alias or *alias, pet:&lt;owner>, a class word (the first group or raid member it fits) me or your own name (you), or a name (the nearest actor whose name contains it) |

**Returns:** float: the actor's collision radius times its collision scale; 0 when it is not found.

```text
echo ${OgreBotAPI.Position.ActorModelSize[${Target.ID}]}
```

*Was (OldBot):* `OgreBotAPI.GetActorModelSize`

### `AtAngle`

`${OgreBotAPI.Position.AtAngle[angle,actorNameOrId,dist=3]}`

Returns the point at angle degrees around an actor, measured from the actor's heading, dist plus your model size plus the actor's model size away, at the actor's height plus 0.5. Returns "" when the actor cannot be found; it only computes a point and moves nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `angle` | int |  | whole degrees around the actor from its heading: 0 is directly behind it and 180 directly in front, 90 and -90 its two sides (a fraction is dropped) |
| `actorNameOrId` | string |  | the actor: an actor id, an @alias or *alias, pet:&lt;owner>, a class word (the first group or raid member it fits) me or your own name (you), or a name (the nearest actor whose name contains it) |
| `dist` | float | `3` | the gap between the two bodies, before the model sizes are added |

**Returns:** string: "x,y,z" with two decimals; "" when the actor is not found.

```text
echo ${OgreBotAPI.Position.AtAngle[90,${Target.ID},5]}
```

*Was (OldBot):* `OgreBotAPI.PointAtAngle`

### `AtAngleNoTargetSize`

`${OgreBotAPI.Position.AtAngleNoTargetSize[angle,actorNameOrId,dist=3]}`

Same as Position.AtAngle, but the distance adds only your own model size, not the actor's. Returns "" when the actor cannot be found.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `angle` | int |  | whole degrees around the actor from its heading: 0 is directly behind it and 180 directly in front, 90 and -90 its two sides (a fraction is dropped) |
| `actorNameOrId` | string |  | the actor: an actor id, an @alias or *alias, pet:&lt;owner>, a class word (the first group or raid member it fits) me or your own name (you), or a name (the nearest actor whose name contains it) |
| `dist` | float | `3` | the distance before your model size is added |

**Returns:** string: "x,y,z" with two decimals; "" when the actor is not found.

```text
echo ${OgreBotAPI.Position.AtAngleNoTargetSize[180,${Target.ID},3]}
```

*Was (OldBot):* `OgreBotAPI.PointAtAngleNoSize`

### `DistanceToActor`

`${OgreBotAPI.Position.DistanceToActor[nameOrId=Target]}`

Returns your distance to an actor as the game reports it (the actor's Distance), using your current target when no actor is given. Returns -1 when the actor cannot be found or you are not in the world.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `nameOrId` | string | `Target` | the actor: an actor id, an @alias or *alias, pet:&lt;owner>, a class word (the first group or raid member it fits) me or your own name (you), or a name (the nearest actor whose name contains it); blank = your current target |

**Returns:** float: the distance to the actor; -1 when it is not found or you are not in the world.

```text
echo ${OgreBotAPI.Position.DistanceToActor[${Target.ID}]}
```

*Was (OldBot):* `OgreBotAPI.GameDistanceToActor`

### `FarthestActorFrom`

`${OgreBotAPI.Position.FarthestActorFrom[anchorNameOrId,actorName,minDist=20]}`

Returns the id of the actor named exactly actorName (any case) that is farthest, in straight-line 3D distance, from an anchor actor, as long as it is more than minDist away. Returns 0 when the anchor or no actor of that name is found, or when even the farthest one is not past minDist.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `anchorNameOrId` | string |  | the actor to measure from: an actor id, an @alias or *alias, pet:&lt;owner>, a class word or a name (the nearest actor whose name contains it) |
| `actorName` | string |  | the full name of the actors to choose among (whole-name match, any case) |
| `minDist` | float | `20` | the winner must be farther than this from the anchor, or the answer is 0 |

**Returns:** int64: the chosen actor's id; 0 when there is none.

```text
echo ${OgreBotAPI.Position.FarthestActorFrom[${Target.ID},"a void tentacle",20]}
```

*Was (OldBot):* `OgreBotAPI.GetFarthestActorFrom`, `OgreBotAPI.GetFarthestActorFrom_ref`

### `FarthestGroupDistance`

`${OgreBotAPI.Position.FarthestGroupDistance}`

Returns the distance to the farthest other member of your group. Returns 0 when you are solo or not in the world.

**Returns:** float: the largest distance from you to another group member; 0 when there is none.

```text
echo ${OgreBotAPI.Position.FarthestGroupDistance}
```

*Was (OldBot):* `OgreBotAPI.GetFarthestGroupDistance`, `Obj_OgreUtilities.GroupWithinDistance`

### `MyModelSize`

`${OgreBotAPI.Position.MyModelSize}`

Returns your model size: your collision radius times your collision scale, the body edge the bot adds to its distances.

**Returns:** float: your collision radius times your collision scale.

```text
echo ${OgreBotAPI.Position.MyModelSize}
```

*Was (OldBot):* `OgreBotAPI.GetMyModelSize`

### `Toward`

`${OgreBotAPI.Position.Toward[fx,fy,fz,tx,ty,tz,dist=15]}`

Returns the point dist away from the first point in the direction of the second, measured flat (x and z only), with the second point's y. It does not stop at the second point when dist is longer than the gap, and returns "" when fewer than six coordinates are given.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fx` | float |  | the starting point's x |
| `fy` | float |  | the starting point's y (not used in the result) |
| `fz` | float |  | the starting point's z |
| `tx` | float |  | the point to head toward, x |
| `ty` | float |  | the point to head toward, y (becomes the result's y) |
| `tz` | float |  | the point to head toward, z |
| `dist` | float | `15` | how far from the starting point to go |

**Returns:** string: "x,y,z" with two decimals; "" when fewer than six coordinates are given.

```text
echo ${OgreBotAPI.Position.Toward[${Me.X},${Me.Y},${Me.Z},${Target.X},${Target.Y},${Target.Z},10]}
```

*Was (OldBot):* `OgreBotAPI.PointTowardDist`

# OgreBotAPI.Quest

## Members

### `ActorHas`

`${OgreBotAPI.Quest.ActorHas[actorId]}`

Whether the actor with this id is within a distance of 10 and offers a quest or has a quest update or hand-in for you. With no id it prints a console line and answers FALSE.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `actorId` | int64 |  | the actor id to check; required |

**Returns:** bool: TRUE when that actor is within 10 and has a quest offer, update or hand-in; FALSE otherwise.

```text
echo ${OgreBotAPI.Quest.ActorHas[${Target.ID}]}
```

*Was (OldBot):* `OgreBotAPI.ActorHasQuest`

### `Have`

`${OgreBotAPI.Quest.Have[name]}`

Whether a quest with this exact name, in any case, is in your active quest journal. No name, or not being in the world, answers FALSE.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | the full quest name to look for; case does not matter |

**Returns:** bool: TRUE when the quest is in your active journal; FALSE otherwise.

```text
echo ${OgreBotAPI.Quest.Have["Feathers For Sethis"]}
```

*Was (OldBot):* `OgreBotAPI.HaveQuest`, `Obj_OgreIH.Check_Quest_Exists`

## Methods

### `Accept`

`OgreBotAPI.Quest:Accept[fw, questName=""]`

Clicks Accept on an offered new quest window, never a quest reward window, and does nothing when none is offered. It accepts whether or not the Settings Do not auto accept quests box is ticked, since that box stops only the automatic accept; given a name, a group leader with auto share on shares that quest two seconds later.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `questName` | string | `""` | the quest to share after accepting; blank accepts with no share |

```text
OgreBotAPI.Quest:Accept[${Me.Name}]
```

*Was (OldBot):* `OgreBotAPI:AcceptQuest`, `Obj_OgreUtilities:AcceptQuest`

### `CheckKunarkAscending`

`OgreBotAPI.Quest:CheckKunarkAscending[fw]`

Opens and closes the quest journal, then prints which Kunark Ascending prerequisite quests you have not completed: the languages, the heritage quest, the signature line and an Epic 1.0 quest. It runs in turn on the action queue and ends with a completed line.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.Quest:CheckKunarkAscending[${Me.Name}]
```

*Was (OldBot):* `OgreBotAPI:CheckKunarkAscendingRequirements`

### `CompareUpdate`

`OgreBotAPI.Quest:CompareUpdate[fw, questName, sender]`

Reads your own steps for a quest and asks other characters to compare theirs; a character on a different step says so in its own console and you get a tally. The character that runs it asks, the for-who is who is asked, and all or blank asks the rest of your group.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): which characters are asked; all or blank is your group but you |
| `questName` | string |  | the quest to compare; a missing one prints a console line |
| `sender` | character name |  | the character that asks; the -CompareQuest console line fills it. Leave it out in a script: the character running it asks, and any other name makes the call do nothing |

```text
OgreBotAPI.Quest:CompareUpdate[all,"Feathers For Sethis"]
```

*Was (OldBot):* `OgreBotAPI:CompareQuestUpdate`

### `Delete`

`OgreBotAPI.Quest:Delete[fw, questName]`

Deletes one quest from your own journal straight away and prints the result. There is no group leader check, and a quest that is not in the journal or has moved in it is not deleted.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `questName` | string |  | the exact quest name, any case |

```text

```

*Was (OldBot):* `OgreBotAPI:DeleteQuest`, `Obj_OgreUtilities:DeleteQuest`, `Obj_OgreUtilities:DeleteQuestActual`

# OgreBotAPI.Roster

## Members

### `ArchetypeOf`

`${OgreBotAPI.Roster.ArchetypeOf[class]}`

The archetype of a subclass name, in lower case: fighter, priest, mage or scout. An actor ID is also accepted and that actor's class is used; a class tier name such as warrior, or anything unknown, reads an empty string.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `class` | string |  | A subclass name such as templar (any case), or an actor ID. |

**Returns:** string - fighter, priest, mage or scout, empty when unknown.

```text
echo ${OgreBotAPI.Roster.ArchetypeOf[${Target.ID}]}
```

*Was (OldBot):* `ClassInfo.Archetype`, `GetArchetypeFromClass`, `GetInfoOb.Archetype`

### `BaseClassOf`

`${OgreBotAPI.Roster.BaseClassOf[class]}`

The class tier of a subclass name, in lower case: templar reads cleric, berserker reads warrior. An actor ID is also accepted and that actor's class is used; anything that is not a subclass reads an empty string.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `class` | string |  | A subclass name such as berserker (any case), or an actor ID. |

**Returns:** string - the class tier (warrior, cleric, bard and so on), empty when unknown.

```text
echo ${OgreBotAPI.Roster.BaseClassOf[berserker]}
```

*Was (OldBot):* `GetInfoOb.GetBaseClass`, `GetInfoOb.GetClass`, `OgreBotAPI.Get_BaseClass`

### `CountGroupBy`

`${OgreBotAPI.Roster.CountGroupBy[mode,search]}`

Counts the members of your group, you included, that match mode and search. Only player characters count: a member whose type reads as anything else (a corpse, for example) is skipped; with no mode it matches by Class, and a mode word the list does not know matches nobody.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `mode` | string | `Class` | How to match: All (everyone; search ignored), Class (exact subclass, e.g. templar), RawClass or ParentClass (class tier, e.g. cleric), Archetype, NotArchetype, Role (tank, priest, enchanter, bard, dps), Cursed (search ignored), KraletusCharmers (coercers and troubadors, search ignored). Empty means Class; any other word matches nobody. |
| `search` | string |  | The class, tier, archetype or role name to match, any case. |

**Returns:** int - number of matching group members, 0 when none match.

```text
echo ${OgreBotAPI.Roster.CountGroupBy[Archetype,priest]}
```

*Was (OldBot):* `OgreBotAPI.CountGroupBy`, `GetInfoOb.CountGroupBy_`, `CheckGroupSetup`

### `CountRaidBy`

`${OgreBotAPI.Roster.CountRaidBy[mode,search]}`

Counts the members of your raid, you included, that match mode and search; in a raid every member counts, corpses too. When you are not in a raid it answers exactly as CountGroupBy does.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `mode` | string | `Class` | How to match: All, Class, RawClass or ParentClass, Archetype, NotArchetype, Role, Cursed, KraletusCharmers. Empty means Class; any other word matches nobody. |
| `search` | string |  | The class, tier, archetype or role name to match, any case. |

**Returns:** int - number of matching raid members (group members when not in a raid).

```text
echo ${OgreBotAPI.Roster.CountRaidBy[Role,priest]}
```

*Was (OldBot):* `OgreBotAPI.CountRaidBy`, `GetInfoOb.CountRaidBy_`

### `GroupIDBy`

`${OgreBotAPI.Roster.GroupIDBy[mode,search,rank=1]}`

The actor ID of the rank-th group member, you included, that matches mode and search, with matches sorted alphabetically by name. Only player characters are considered (a corpse is skipped); reads 0 when nobody matches or rank is past the last match.

| Parameter | Type | Default | Meaning |
|---|---|---|---|


*Was (OldBot):* `OgreBotAPI.GetGroupIDBy`, `GetInfoOb.GetGroupIDBy_`

### `GroupIDPreferred`

`${OgreBotAPI.Roster.GroupIDPreferred[search,rank=1]}`

The actor ID of the rank-th group member, you included, whose archetype or role matches search, ordered by how useful that class is to spare (for dps the order is flipped so pure damage classes come first). | Parameter | Type | Default | Meaning |
|---|---|---|---|

| `rank` | int | `1` | Which match to return, counting from 1 in preferred order. |

**Returns:** int64 - the member's actor ID, 0 when there is no such match.

```text
echo ${OgreBotAPI.Roster.GroupIDPreferred[scout|mage,1]}
```

*Was (OldBot):* `GetInfoOb.GetGroupIDPreferred_`, `OgreBotAPI.GetGroupIDPreferred`

```text

```

*Was (OldBot):* `GetInfoOb.GetGroupInformation`, `GetInfoOb.GetGroupNameBy_`, `OgreBotAPI.GetGroupNameBy`

### `OnScreenTimer`

`OgreBotAPI.Util:OnScreenTimer[fw, time=30, slot=1, message="Timer:", minUpdate=1]`

Shows a message with a live countdown in one of the ten on-screen timer slots, opening the on-screen display if it is closed; the line is removed 5 seconds after the countdown ends. A slot below 1 uses slot 1 and one above 10 uses slot 10, and a slot that was set less than minUpdate seconds ago silently keeps its old timer.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

| `slot` | int | `1` | Which timer line to use, 1 to 10. A number outside is moved to the nearest of them. |
| `message` | string | `"Timer:"` | The text shown before the countdown. Empty uses "Timer:". |
| `minUpdate` | int | `1` | Seconds after this call during which a new timer for the same slot is refused. 0 allows an immediate replacement. |

# OgreBotAPI.Vars

## Members

### `Bool`

`${OgreBotAPI.Vars.Bool[name]}`

Reads the script variable name as a yes/no: TRUE only when its whole value is 1, true, yes or on in any case. A missing variable, an empty value or any other text (2, enabled, a value with spaces around it) reads FALSE.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | The variable name, case-sensitive. |

**Returns:** bool: TRUE when the stored value is a yes word; FALSE otherwise, including when the variable is missing.

```text

```

*Was (OldBot):* `OgreBotAPI.Get_Variable_Bool`

### `Exists`

`${OgreBotAPI.Vars.Exists[name]}`

TRUE when a variable called name is in this session's script variable store, even if its value is empty. Use it to tell a missing variable from an empty one, since Get returns an empty string for both.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | The variable name, case-sensitive. |

**Returns:** bool: TRUE when the variable is stored; FALSE when it is missing or name is blank.

```text

```

*Was (OldBot):* `OgreBotAPI.Get_VariableExists`

### `Get`

`${OgreBotAPI.Vars.Get[name]}`

The value stored under name in this session's script variable store (set with OgreBotAPI.Vars:Set), or an empty string when there is no such variable. Names ignore case, and the store lives in memory on this session only: it is not shared with other characters, not saved, and lasts until it is cleared or the extension is unloaded.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `name` | string |  | The variable name; case does not matter. |

**Returns:** string: the stored value; empty when the variable is missing or was set to an empty value.

```text
echo ${OgreBotAPI.Vars.Get[PullCount]}
```

*Was (OldBot):* `OgreBotAPI.Get_Variable`, `OgreBotAPI.Variables`
