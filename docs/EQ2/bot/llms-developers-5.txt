# OgreBotAPI.Craft

## Methods

### `AddLastScribedRecipe`

`OgreBotAPI.Craft:AddLastScribedRecipe[fw, qty=1]`

Adds the recipe you last scribed this session (by the bot or by hand) to the craft setup queue. With nothing scribed yet it prints a warning and adds nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `qty` | int | `1` | How many to craft; 0 or less becomes 1. |

```text
OgreBotAPI.Craft:AddLastScribedRecipe[${Me.Name},5]
```

*Was (OldBot):* `OgreCraft:AddLastScribedRecipe`, `OgreCraftAPI:AddLastScribedRecipe`

### `AddRecipe`

`OgreBotAPI.Craft:AddRecipe[fw, nameOrID|lastknownrecipe, qty=1]`

Adds a recipe to the craft setup queue by full name, by part of a name that matches only one recipe (4 letters or more), by recipe ID, or lastknownrecipe for the recipe last scribed this session. A recipe not in your recipe book prints a warning and adds nothing; if the book has not been read yet the add waits and runs once it has.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `nameOrID\|lastknownrecipe` | string |  | The recipe name, its ID (plain digits), or lastknownrecipe. A name may also be passed as several arguments; they are joined with spaces. |
| `qty` | int | `1` | How many to craft. Read only when it is the last argument and a whole number; 0 or less becomes 1. |

```text
OgreBotAPI.Craft:AddRecipe[${Me.Name},"Tempered Iron",2]
```

*Was (OldBot):* `OgreCraft:AddRecipeNameForWho`, `OgreCraftAPI:AddRecipeNameForWho`

### `BuyAllTinkeringRecipes`

`OgreBotAPI.Craft:BuyAllTinkeringRecipes[fw]`

Buys every tinkering recipe book you do not already know or carry from Fizza Cogsworth. It is refused unless you carry at least 3 platinum, are in Steamfont Mountains and are within 10 meters of her, and also while a crafting flow or merchant errand is running.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.Craft:BuyAllTinkeringRecipes[${Me.Name}]
```

### `CompleteNavigation`

`OgreBotAPI.Craft:CompleteNavigation[fw]`

Answers craft's OgreCraft_NavigationRequired event (sent only when the craft setting to use events for movement is on) to say your script has moved the character; craft then checks the distance again and carries on. If no request is waiting it prints a warning.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.Craft:CompleteNavigation[${Me.Name}]
```

### `ScribeRecipe`

`OgreBotAPI.Craft:ScribeRecipe[fw, name|all=all]`

Scribes recipe scrolls from your bags one at a time, then opens and closes the tradeskill book. A name scribes only scrolls whose full item name matches it in any case (a name with a comma arrives whole), nothing matching prints a line and does nothing, and a call while scribing adds the new scrolls to the run.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `name\|all` | string | `all` | The scroll's full item name in any case, or all for every scribeable scroll in your bags. Left empty it scribes all. |

```text
OgreBotAPI.Craft:ScribeRecipe[${Me.Name},all]
```

*Was (OldBot):* `OgreCraft:ScribeRecipe`, `OgreCraftAPI:ScribeRecipe`

### `StartLLL`

It stops at tradeskill level 9 or 19, and is refused when a crafting flow is already running or you are not in the world.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

| Parameter | Type | Default | Meaning |

It stops if the character has no tinkering skill, and is refused when a crafting flow is already running or you are not in the world.

### `Stop`

`OgreBotAPI.Craft:Stop[fw]`

Stops the running crafting run (queue, writs, quest, Low Level Leveling or Auto Tinkering) on the characters the for-who names, the same as ISXOgreEQ2.Craft:Stop. With nothing running it drops a pause and prints that nothing was running.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text

```

# OgreBotAPI.Cures

## Members

### `CurseCalled`

`${OgreBotAPI.Cures.CurseCalled[victim]}`

TRUE while a cure-curse call is open for that character, made by RequestCurse or by Request with kind curse. With no argument it asks about you, and any asks whether a call is open for anyone.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `victim` | character name |  | who to ask about; blank means you; any means anyone |

**Returns:** bool: TRUE while a cure-curse call is open (a call lasts at most 8 seconds); FALSE otherwise, and FALSE out of world when no name is given.

```text
echo ${OgreBotAPI.Cures.CurseCalled[${Group[1].Name}]}
```

*Was (OldBot):* `Obj_CureCurseCalled.CastCureCurse`

### `CursedID`

`${OgreBotAPI.Cures.CursedID[-archetype X...,-uncurable,-uncurableonly,-GroupOnly]}`

The actor ID of the first cursed member found, searching the raid when you are in one and otherwise the group with you first. By default only curable curses count; 0 when nobody matches.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `-archetype X...` | flag + word |  | only members of this archetype: fighter, priest, mage or scout, any case. Repeat the switch to allow more than one archetype. |
| `-uncurable` | flag |  | also accept a member whose curse cannot be cured |
| `-uncurableonly` | flag |  | accept only a member whose curse cannot be cured |
| `-GroupOnly` | flag |  | search your group even when you are in a raid |

**Returns:** int64: the actor ID of the first matching member; 0 when nobody matches.

```text
echo ${OgreBotAPI.Cures.CursedID[-archetype,priest,-uncurable]}
```

*Was (OldBot):* `Obj_CureCurseCalled.GetID_CursedMember`, `Obj_CureCurseCalled.GetID_GroupCursedMember`, `Obj_CureCurseCalled.GetID_RaidCursedMember`

### `Detrimental`

`${OgreBotAPI.Cures.Detrimental[main,back,actorId,field]}`

One field of a detrimental, found by its main and backdrop icon IDs, on you or another actor, as a number. The default field, exists, reads 1 or 0; a detrimental that is not there reads 0.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `main` | int | `0` | the detrimental's main icon ID |
| `back` | int | `0` | the detrimental's backdrop icon ID |
| `actorId` | int64 | `0` | whose effects to look at: 0 or your own ID is you. Any other actor ID reads only that actor's first 10 effects, and there duration and maxduration always read 0. |
| `field` | text | `exists` | exists, iseffectinfoavailable, id, mainiconid, backdropiconid, currentincrements, duration or maxduration, any case. Any other word is read from the effect's examine info, and text such as Name reads 0 here - use DetrimentalText. cancel removes the detrimental from you and reads 0. |

**Returns:** float: the field's value; exists reads 1 or 0; 0 when the detrimental is not found or the field is text.

```text
echo ${OgreBotAPI.Cures.Detrimental[279,315,${Target.ID},exists]}
```

*Was (OldBot):* `GetInfoOb.CurrentIncrements`, `GetInfoOb.CurrentIncrements_ref`, `GetInfoOb.DetrimentalInfo`

### `DetrimentalText`

`${OgreBotAPI.Cures.DetrimentalText[main,back,actorId,field]}`

The same read as Detrimental, returned as text, so examine-info fields such as Name and Description can be read. Reads "" when the detrimental is not found.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `main` | int | `0` | the detrimental's main icon ID |
| `back` | int | `0` | the detrimental's backdrop icon ID |
| `actorId` | int64 | `0` | whose effects to look at: 0 or your own ID is you. Any other actor ID reads only that actor's first 10 effects, and there duration and maxduration always read 0. |
| `field` | text | `exists` | exists (1 or 0), iseffectinfoavailable, id, mainiconid, backdropiconid, currentincrements, duration, maxduration, or an examine-info field such as Name or Description. Examine-info text can be empty on the first read, so wait for iseffectinfoavailable to read 1. cancel removes the detrimental from you and reads "". |

**Returns:** string: the field's value; "" when the detrimental is not found.

```text
echo ${OgreBotAPI.Cures.DetrimentalText[279,315,0,exists]}
```

*Was (OldBot):* `GetInfoOb.DottedDescription_ref`, `GetInfoOb.DottedName_ref`, `OgreBotAPI.DetrimentalInfo_String`

### `GroupCurses`

`${OgreBotAPI.Cures.GroupCurses}`

How many living group members, you included, have a curse that can be cured. Uncurable curses are not counted here - GroupUncurable counts those.

**Returns:** int: the number of living group members with a curable curse; 0 when nobody has one.

```text

```

*Was (OldBot):* `GetInfoOb.CursesInGroup`, `GroupCureOb.NumOfPCsCursed`, `Obj_CureCurseCalled.GroupCurseCount`

### `PotionAvailable`

`${OgreBotAPI.Cures.PotionAvailable[type]}`

TRUE when you carry a Cure &lt;type> potion that is ready to use. It does not check whether you are afflicted.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `type` | text |  | arcane, elemental, noxious or trauma, matched as part of the item name. Any other word answers FALSE. |

### `PotionNeeded`

`${OgreBotAPI.Cures.PotionNeeded}`

The cure type to drink a potion for right now: the first of arcane, elemental, noxious and trauma that is ticked in the cure potion settings, is on you, and has a ready Cure &lt;type> potion in your bags. Reads "" when none qualifies or out of world.

**Returns:** string: arcane, elemental, noxious or trauma; "" when no potion is both needed and ready.

```text
echo ${OgreBotAPI.Cures.PotionNeeded}
```

### `Uncurable`

`${OgreBotAPI.Cures.Uncurable[type,-GroupOnly]}`

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `type` | text | `Cursed` | the affliction to check, as the game names it: Cursed, Arcane, Noxious, Elemental or Trauma. Blank means Cursed. |
| `-GroupOnly` | flag |  | search your group even when you are in a raid |

**Returns:** int64: the actor ID of the first member with an uncurable affliction of that type; 0 when nobody has one or out of world.

```text

```

*Was (OldBot):* `OgreBotAPI.Get_Uncurable`

### `ItemCure`

`OgreBotAPI.Cures:ItemCure[fw, type]`

Drinks a cure potion now on each matching character, if a ready one is in their bags. With a type it drinks that potion whether or not you are afflicted or the type is ticked; with no type, or any, it drinks the one PotionNeeded names.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `type` | text |  | arcane, elemental, noxious or trauma; blank or any drinks whatever the cure potion settings need. Any other word prints a console line and does nothing. |

```text

```

*Was (OldBot):* `OgreBotAPI:AutoItemCure`

### `ReplenishPotions`

`OgreBotAPI.Cures:ReplenishPotions[fw, all|arcane|elemental|noxious|trauma]`

Tops up cure potions, up to a full stack, from a Poison, Potion, & Totem Depot within 11 meters, on each matching character. A type is restocked only if one of its potions is already in your bags; a blank or unknown type prints a console line and does nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `all\|arcane\|elemental\|noxious\|trauma` | word |  | all four cure types, or just one of them, any case |

```text
OgreBotAPI.Cures:ReplenishPotions[igw:${Me.Name},all]
```

*Was (OldBot):* `OgreBotAPI:CurePotions_Replenish`, `OgreBotAPI:Get_CurePotions`

### `Request`

`OgreBotAPI.Cures:Request[fw, victim, kinds...]`

Records a cure request for the victim on each character the for-who matches, and their cure casting serves it. A request lasts 8 seconds unless -AutoRemove says otherwise, and is not sent anywhere else, so use oc !c to reach other characters.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `victim` | character name |  | who to cure; a blank one is refused with one console line |
| `kinds...` | words |  | which cures: arcane (a), noxious (n), elemental (e), trauma (t), curse, confrontfear or sickness, one per argument or comma-separated. None means the four basic kinds (arcane, noxious, elemental, trauma). Then the options -AutoRemove &lt;seconds> (how long the request lasts, 1 to 600, default 8) and -tag &lt;name> (a name Cures:CancelRequests can cancel it by). Any other word refuses the whole request with one console line naming it. confrontfear and sickness are kept only on a dirge. |

```text
OgreBotAPI.Cures:Request[igw:${Me.Name},${Group[1].Name},noxious,trauma,-AutoRemove,20]
```

*Was (OldBot):* `OgreBotAPI:AutoCure`, `Obj_CureCalled:AutoAdd`, `Obj_CurseCalled:AutoAdd`

### `RequestCurse`

`OgreBotAPI.Cures:RequestCurse[fw, victim, options...]`

Records a cure-curse request for the victim on each character the for-who matches, for their cure casting to serve. The request lasts 8 seconds unless -AutoRemove says otherwise, and is not sent anywhere else; a blank victim, or a word it does not know, refuses it with one console line.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `victim` | character name |  | who to cure of the curse; a blank one is refused with one console line |
| `options...` | words |  | -AutoRemove &lt;seconds> (how long the request lasts, 1 to 600, default 8) and -tag &lt;name> (a name Cures:CancelRequests can cancel it by). Any other word refuses the request with one console line naming it. |

```text
OgreBotAPI.Cures:RequestCurse[igw:${Me.Name},${Group[1].Name},-AutoRemove,20]
```

*Was (OldBot):* `OgreBotAPI:AutoCurse`, `OgreBotAPI:Cursed`, `Obj_CureCurseCalled:Add`

### `RequestGroup`

`OgreBotAPI.Cures:RequestGroup[fw]`

Asks each matching character to cast its class group cure within the next 2 seconds, when that ability is ready and someone in the group, you included, has an arcane, noxious, elemental or trauma detrimental. Curses are not group cured.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.Cures:RequestGroup[igw:${Me.Name}]
```

*Was (OldBot):* `OgreBotAPI:GroupCure`

### `RequestGroupWatch`

`OgreBotAPI.Cures:RequestGroupWatch[fw, words...]`

Watches for a group cure on each matching character: the class group cure goes out as soon as it is ready and enough of the group, you included, carry one of the named kinds, each counted on its own (curses are not group cured). The watch lasts 8 seconds unless -AutoRemove says otherwise, and several can run at once.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `words...` | words |  | kinds: arcane (a), noxious (n), elemental (e), trauma (t), one per argument or comma-separated; none means any of the four. Options: -count &lt;n> (at least n of you and the group carry the kind, 1 to 6, default 1), -AutoRemove &lt;seconds> (how long to watch, 1 to 600, default 8), -tag &lt;name> (a name Cures:CancelRequests can cancel it by). Any other word refuses the request with one console line naming it. |

```text
OgreBotAPI.Cures:RequestGroupWatch[igw:${Me.Name},arcane,trauma,-count,3]
```

*Was (OldBot):* `OgreBotAPI:AutoGroupCure`

### `RequestItem`

`OgreBotAPI.Cures:RequestItem[fw, type]`

Queues a potion cure on each matching character, drunk once the cast bar is free; a potion only ever cures the one who drinks it. The request waits up to 8 seconds for a ready potion.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

# OgreBotAPI.IM

## Members

### `EndWhenFinished`

`${OgreBotAPI.IM.EndWhenFinished}`

Whether -end is armed, so the Inventory Manager window closes itself once the work has been idle for about 1.5 seconds. Only the console arms it (the -end flag of an `ogre im` line); there is no method for it, and closing the window clears it.

**Returns:** bool: TRUE while -end is armed; FALSE otherwise.

```text
echo ${OgreBotAPI.IM.EndWhenFinished}
```

### `IsOpen`

`${OgreBotAPI.IM.IsOpen}`

Whether the Inventory Manager window is up on this session - the window is the session, so this is what a script waits on after starting it with -end. It reads FALSE when the UI host is not available, even while modes run from the console.

**Returns:** bool: TRUE while the Inventory Manager window really exists; FALSE when it is closed or could not open.

```text
echo ${OgreBotAPI.IM.IsOpen}
```

### `IsRunning`

`${OgreBotAPI.IM.IsRunning}`

Whether the Inventory Manager is doing work right now - a mode (depot, sell, destroy, tse, restock, trade, quiver), a chain of them, or a depot withdraw started anywhere. It is FALSE while the window sits open and idle and can be FALSE just before a mode starts, so to wait for work to finish poll IsOpen with -end instead.

**Returns:** bool: TRUE while any Inventory Manager mode or chain is working; FALSE when idle.

```text
echo ${OgreBotAPI.IM.IsRunning}
```

### `Mode`

`${OgreBotAPI.IM.Mode}`

The Inventory Manager mode working right now: depot, sell, destroy, tse, restock, trade, quiver or withdraw (a depot withdraw from anywhere). It reads chain when only a chain is busy between modes, and empty when idle.

**Returns:** string: the busy mode's name, "chain", or "" when nothing is running.

```text
echo ${OgreBotAPI.IM.Mode}
```

### `Status`

`${OgreBotAPI.IM.Status}`

One line saying what the Inventory Manager is doing, the same line `echo ${OgreBotAPI.IM}` prints. It reads "closed", "open, idle", "open, running sell", "open, running withdraw" or "closed (running headless), running restock", with "; will close when finished (-end)" added while -end is armed.

**Returns:** string: the status line, such as "open, idle" or "closed".

```text
echo ${OgreBotAPI.IM.Status}
```

### `Probe`

`OgreBotAPI.IM:Probe[fw]`

Prints what the open depot's tier dropdown holds, for checking a depot window against the depot tables. It changes nothing.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.IM:Probe[all]
```

### `Queue`

`OgreBotAPI.IM:Queue[fw, mode]`

Adds a mode to the run queue and brings the window up: it runs when the current work finishes. With no mode it prints what is waiting, and a word that is not a mode is refused.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `mode` | string |  | depot, sell, destroy, tse, restock, trade or quiver. Optional. |

```text
OgreBotAPI.IM:Queue[all,sell]
```

### `Reload`

`OgreBotAPI.IM:Reload[fw]`

Reloads the depot tables from disk: the depot kinds, the ammo rows and the shared resource table.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.IM:Reload[all]
```

### `Restock`

`OgreBotAPI.IM:Restock[fw, words...]`

The restock mode: with no words, or a profile name, it brings the window up and tops up from the depots, and -forwho &lt;expr> runs it only on the characters named. A word short of its arguments is read as a profile name.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `words...` | string |  | A profile, or one of stop, status, reload, list (or profiles), show &lt;profile>, preview (or plan) [profile], set &lt;profile> &lt;qty> &lt;item>, forwho &lt;profile> &lt;who> &lt;item>, drop &lt;profile> &lt;item>. Optional. |

```text
OgreBotAPI.IM:Restock[all,"Raid night",-forwho,${Me.Name}]
```

### `Sell`

`OgreBotAPI.IM:Sell[fw, words...]`

The sell mode: with no words it brings the window up and sells what is on the sell list, opening a nearby merchant if none is open. The other first words are in the param; any other words go to the run.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `words...` | string |  | stop, status, reload, preview (or plan), list [all], add &lt;name> or remove &lt;name>, then its arguments. Optional. |

```text
OgreBotAPI.IM:Sell[all,preview]
```

### `Settings`

`OgreBotAPI.IM:Settings[fw, words...]`

With no words, prints the saved settings; too few words prints the usage and changes nothing. Otherwise it changes one setting, as the param says.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `words...` | string |  | One of: bag &lt;tse\|destroy> &lt;1-6\|overseer\|harvest\|sharedtradeskill> &lt;on\|off>; tse &lt;option> &lt;on\|off\|number>; quiver &lt;arrow\|bolt\|throwing> &lt;name\|clear\|examine>; depot &lt;flags>; reload. One argument each. Optional. |

```text
OgreBotAPI.IM:Settings[all,tse,minlevel,120]
```

### `Status`

`OgreBotAPI.IM:Status[fw]`

Prints the session line to the console, then the chain if one runs and one summary line each for depot, sell, destroy, restock and trade. For one line a script can read, use ${OgreBotAPI.IM.Status}.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.IM:Status[all]
```

### `Stop`

`OgreBotAPI.IM:Stop[fw]`

Stops whatever the Inventory Manager is running (the chain, every busy mode, or a depot withdraw still in flight) and leaves the window open. When nothing is running it prints "im: nothing is running." to the console.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |

```text
OgreBotAPI.IM:Stop[igw:${Me.Name}]
```

### `Trade`

`OgreBotAPI.IM:Trade[fw, words...]`

The trade mode: with no words it brings the window up and runs the queue. The other first words are in the param.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `words...` | string |  | add &lt;player> &lt;qty\|all> &lt;item>, remove &lt;n> (or delete), list, clear, preview (or plan), status or stop, then its arguments. Optional. |

```text
OgreBotAPI.IM:Trade[all,add,Tobbin,5,"Rare Ore"]
```

### `Transmute`

`OgreBotAPI.IM:Transmute[fw, words...]`

Brings the window up and transmutes one named item, or an item by id.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `words...` | string |  | The item name or id. A name may be several arguments; they are joined with spaces. |

```text
OgreBotAPI.IM:Transmute[all,"Rusted Greatsword"]
```

### `Tse`

`OgreBotAPI.IM:Tse[fw, words...]`

The transmute, salvage and extract mode: `stop` stops it, and anything else brings the window up and runs. It starts from the options saved on the TSE tab, and flags such as -salvage or -stopafter 5 change that run.

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `fw` | for-who |  | [for-who](ForWho.md): this runs only when this character is one it names |
| `words...` | string |  | stop, or the run's flags, one argument each. Optional. |

```text
OgreBotAPI.IM:Tse[all,-stopafter,5]
```
