== ISXOgreX ==

${ISXOgreX.Auth}
  kind: member of ISXOgreX
  what: The login status object. Read its members: Authenticated, AccessLevel, Username and Status.
  returns: ogrexauth: the login status object; as text it reads ISXOgreX.Auth.
  returns object: ISXOgreX.Auth (its members and methods are listed under it)
  example: echo ${ISXOgreX.Auth.Status}

${ISXOgreX.Console}
  kind: member of ISXOgreX
  what: The Ogre console object. It has no members of its own; call its methods, such as ISXOgreX.Console:Toggle.
  returns: ogrexconsole: the console object (methods only); as text it reads ISXOgreX.Console.
  returns object: ISXOgreX.Console (its members and methods are listed under it)
  example: echo ${ISXOgreX.Console}

${ISXOgreX.Login}
  kind: member of ISXOgreX
  what: The login box object. ISXOgreX.Login:Show opens the login box, and ISXOgreX.Login:Submit[username,password] saves a login and logs in again with it.
  returns: ogrexlogin: the login box object (methods only); as text it reads ISXOgreX.Login.
  returns object: ISXOgreX.Login (its members and methods are listed under it)
  example: echo ${ISXOgreX.Login}

${ISXOgreX.Options}
  kind: member of ISXOgreX
  what: The Ogre options window object. Its methods are Open, Save, Close and Ready (fill the open window's fields again).
  returns: ogrexoptions: the options window object (methods only); as text it reads ISXOgreX.Options.
  returns object: ISXOgreX.Options (its members and methods are listed under it)
  example: echo ${ISXOgreX.Options}

${ISXOgreX.Patch}
  kind: member of ISXOgreX
  what: The patcher object: its members report the patcher's state and its methods run the patcher's commands. See the ISXOgreX.Patch rows.
  returns: ogrexpatch: the patcher object; as text it reads ISXOgreX.Patch.
  returns object: ISXOgreX.Patch (its members and methods are listed under it)
  example: echo ${ISXOgreX.Patch}

${ISXOgreX.Release}
  kind: member of ISXOgreX
  what: The name of the release this PC was last patched to, the same name the What's new page uses. It is empty when this PC has never been patched or the last release had no name.
  returns: string: the release name (like 2026.10.16.005); empty when there is none.
  example: echo ${ISXOgreX.Release}

${ISXOgreX.UI}
  kind: member of ISXOgreX
  what: The in-game UI object: windows, their values and the UI store. See the ISXOgreX.UI rows for its members and methods.
  returns: ogrexui: the in-game UI object; as text it reads ISXOgreX.UI.
  returns object: ISXOgreX.UI (its members and methods are listed under it)
  example: echo ${ISXOgreX.UI}

${ISXOgreX.Version}
  kind: member of ISXOgreX
  what: The build date of the loaded core extension. It is not the release name - use Release for that.
  returns: string: the core's build date as yyyymmdd.
  example: echo ${ISXOgreX.Version}

ISXOgreX:ReloadExtension[reason]
  kind: method of ISXOgreX
  what: Reloads this session's core (the game adapter reloads under it) when the core or adapter file on disk is newer than the one this session loaded; otherwise it prints that this session already runs the files on disk. It does nothing while a patch run is in progress on this session, and nothing before the patcher has started.
  arg reason (string, default: another session on this PC patched): Text shown in the reload message, saying why the reload was asked for.
  example: ISXOgreX:ReloadExtension["files updated"]

ISXOgreX:ShowVersion
  kind: method of ISXOgreX
  what: Prints the release this PC was patched to and the core's build date to the InnerSpace console, with a link to what changed. When this PC was never patched it says so, and when the release has no name it shows the release id instead.
  example: ISXOgreX:ShowVersion


== ISXOgreX.Auth ==

${ISXOgreX.Auth.AccessLevel}
  kind: member of ISXOgreX.Auth
  what: The access level name the Ogre server sent for this account at login. Before a login reply arrives it reads a default value.
  returns: string: the access level name from the server; a default value before a login reply arrives or when the server sent none.
  example: echo ${ISXOgreX.Auth.AccessLevel}

${ISXOgreX.Auth.Authenticated}
  kind: member of ISXOgreX.Auth
  what: Whether this session's login to the Ogre server succeeded. It is FALSE while the login is still waiting for the server.
  returns: bool: TRUE when the login succeeded; FALSE when it has not started, is waiting, failed, or no login is saved.
  example: echo ${ISXOgreX.Auth.Authenticated}

${ISXOgreX.Auth.Status}
  kind: member of ISXOgreX.Auth
  what: Where this session's login stands, as one word.
  returns: string: idle (not started), pending (waiting for the server), authenticated, failed, or nocreds (no saved login).
  example: echo ${ISXOgreX.Auth.Status}

${ISXOgreX.Auth.Username}
  kind: member of ISXOgreX.Auth
  what: The account name of the saved login this session logs in with. It is filled from the saved login before the server answers, so use Authenticated to know whether the login succeeded.
  returns: string: the saved login's account name; empty when no login is saved.
  example: echo ${ISXOgreX.Auth.Username}


== ISXOgreX.Console ==

ISXOgreX.Console:Clear
  kind: method of ISXOgreX.Console
  what: Clears the Ogre console's output and the lines it keeps on this session. New lines show as normal afterwards.
  example: ISXOgreX.Console:Clear

ISXOgreX.Console:Close
  kind: method of ISXOgreX.Console
  what: Closes the Ogre console window on this session. It stays closed until opened again, even if the UI reloads.
  example: ISXOgreX.Console:Close

ISXOgreX.Console:Open
  kind: method of ISXOgreX.Console
  what: Opens the Ogre console window on this session. Opening a console that is already open does nothing.
  example: ISXOgreX.Console:Open

ISXOgreX.Console:ReloadSchema[game]
  kind: method of ISXOgreX.Console
  what: Reads the console command lists again from disk on this session: the common list, the game's list and any command packs. A missing file just leaves its commands out, and pack problems are shown in the console's Commands tab.
  arg game (string, default: everquest2): The game id whose command list to load, such as everquest2 or pantheon.
  example: ISXOgreX.Console:ReloadSchema[everquest2]

ISXOgreX.Console:Send[message,-tab,tab,-rg,group,-cfw,who,-kind,kind]
  kind: method of ISXOgreX.Console
  what: Sends message through the uplink to every session in the relay group: a message starting !c or !ci is a command that each session parses, anything else is a chat line. With no arguments it sends the line typed in the console's input box instead.
  arg message (string, default: the input box line): The literal line to send; a leading !c or !ci makes it a command. Leave out every argument to send the input box line.
  arg -tab (switch, default: (none)): Also show the line in the console tab named by the next argument; may be given more than once.
  arg tab (string, default: (none)): The console tab name that follows -tab.
  arg -rg (switch, default: (none)): Send to the relay group named by the next argument instead of the bot's own relay group.
  arg group (string, default: the bot's relay group): The relay group name that follows -rg.
  arg -cfw (switch, default: (none)): Give a command a for-who, used by its commands whose own for-who is left as auto.
  arg who (for-who, default: all): for-who: this runs only when this character is one it names, for the commands in the line that leave theirs as auto.
  arg -kind (switch, default: (none)): Show a chat line as a status line of the kind named by the next argument; ignored for a command.
  arg kind (string, default: (none)): error, warn or system; the line then shows only in its -tab tabs and All, in that kind's colour.
  example: ISXOgreX.Console:Send["Pulling now",-tab,Raid]

ISXOgreX.Console:Sessions[mode]
  kind: method of ISXOgreX.Console
  what: With on or off, turns the uplink's session watch (it says when a session freezes, recovers or closes) on or off until the uplink restarts. With no argument it prints the sessions the uplink has heard from to this session's console; any other word prints the usage.
  arg mode (string, default: (none - print the table)): on or off to switch the watch; leave it out to print the session table.
  example: ISXOgreX.Console:Sessions[on]

ISXOgreX.Console:SetOption[key,value]
  kind: method of ISXOgreX.Console
  what: Saves one console setting to the console's settings file (the same as the console's settings panel). It does nothing with fewer than two arguments, and an unknown key is ignored with nothing on screen.
  arg key (string): hide_on_load, send_to_irc, show_timestamps, verb_trace, or a colour key starting color_.
  arg value (string): 1 or true (lower case) for on, anything else (TRUE included) for off; for a color_ key, a hex colour of up to six digits.
  example: ISXOgreX.Console:SetOption[show_timestamps,1]

ISXOgreX.Console:Toggle
  kind: method of ISXOgreX.Console
  what: Opens the Ogre console window when it is closed, and closes it when it is open.
  example: ISXOgreX.Console:Toggle


== ISXOgreX.Login ==

ISXOgreX.Login:Show
  kind: method of ISXOgreX.Login
  what: Opens the small Windows login box where you type your Ogre account username and password; if it is already open it is brought to the front instead. Its Login button saves what you typed and logs in, and Cancel just closes it (the Account tab of Ogre Options is the usual place for this - the box is the fallback when that window cannot load).
  example: ISXOgreX.Login:Show

ISXOgreX.Login:Submit[username,password]
  kind: method of ISXOgreX.Login
  what: Saves the given Ogre account username and password on this PC, closes the login box if it is open and logs in again on the next frame - even when you are already logged in. With either argument missing or blank nothing is saved and one console warning says so.
  arg username (string): Your Ogre account name.
  arg password (string): Your Ogre account password.
  example: ISXOgreX.Login:Submit["MyOgreAccount","MyOgrePassword"]


== ISXOgreX.Options ==

ISXOgreX.Options:Close
  kind: method of ISXOgreX.Options
  what: Closes the Ogre Options window without saving anything.
  example: ISXOgreX.Options:Close

ISXOgreX.Options:Open
  kind: method of ISXOgreX.Options
  what: Opens the Ogre Options window and fills its fields from the saved settings. If the window is already open it does nothing, so what you typed in it stays (the same as `ogre config`).
  example: ISXOgreX.Options:Open

ISXOgreX.Options:Save
  kind: method of ISXOgreX.Options
  what: Saves the values the Ogre Options window's Save button hands over (this is the call that button makes): UI scale, the console setting, session watch, navmesh downloads and your Ogre login, which tries to log in again if you are not logged in. The window's status line then shows 'Saved.', 'Saved - logging in...' or 'Save FAILED', or 'Save failed (no data)' or 'Save failed (bad JSON)' when nothing usable was handed over.
  example: ISXOgreX.Options:Save


== ISXOgreX.Patch ==

${ISXOgreX.Patch.Enabled}
  kind: member of ISXOgreX.Patch
  what: Whether the Ogre patcher may update this PC, as the patcher last read its setting. The setting is read again whenever an update starts or Status runs, so a change shows here after that.
  returns: bool: TRUE when patching is on; FALSE when it is off for this PC, its setting cannot be read, or before the patcher has started.
  example: echo ${ISXOgreX.Patch.Enabled}

${ISXOgreX.Patch.InProgress}
  kind: member of ISXOgreX.Patch
  what: Whether an update run is going on in this session, including the short wait before the update check at load and a reload queued after an extension was updated. Background navmesh downloads do not count.
  returns: bool: TRUE while an update run is active in this session; FALSE when none is.
  example: echo ${ISXOgreX.Patch.InProgress}

${ISXOgreX.Patch.LastResult}
  kind: member of ISXOgreX.Patch
  what: The one-line result of the last update run on this PC, the same text the run printed after 'patch:' (for example a line starting 'up to date' or 'done - release', which counts the files updated and failed). It is kept in OgreSave/patcher-state.json, so it survives a restart.
  returns: string: the last run's result line; "" when no run has finished on this PC or patching was off when the session started.
  example: echo ${ISXOgreX.Patch.LastResult}

${ISXOgreX.Patch.ReleaseId}
  kind: member of ISXOgreX.Patch
  what: The id of the release the last update run on this PC checked against, kept in OgreSave/patcher-state.json. For the release name players see, use ${ISXOgreX.Release}.
  returns: string: the last run's release id; "" when this PC has never been patched or patching was off when the session started.
  example: echo ${ISXOgreX.Patch.ReleaseId}

${ISXOgreX.Patch.Tier}
  kind: member of ISXOgreX.Patch
  what: The release channel number the update server sent with the release the last update run on this PC checked against, kept with ReleaseId in OgreSave/patcher-state.json.
  returns: int: that number; -1 when no update run has recorded one.
  example: echo ${ISXOgreX.Patch.Tier}

ISXOgreX.Patch:Ignore[op,path]
  kind: method of ISXOgreX.Patch
  what: Manages the list of files the patcher never writes, kept in OgreSave/patcher-ignore.json, so your own copy of a file is left alone: add or remove a path, or list them. Paths are relative to the InnerSpace folder with forward slashes (backslashes are turned into them), and every change prints a confirmation line.
  arg op (string, default: list): add, remove or list; leave it out to list.
  arg path (string, default: ""): The file for add or remove, relative to the InnerSpace folder, such as Scripts/Ogre/EQ2/x.json; not used by list.
  example: ISXOgreX.Patch:Ignore[add,"Scripts/Ogre/EQ2/Commands/everquest2.json"]

ISXOgreX.Patch:Mesh[mode]
  kind: method of ISXOgreX.Patch
  what: Sets how navmeshes download and applies it at once: all (every zone in the background), ondemand (a zone's mesh when you need it) or off. With no argument it prints the navmesh download summary, and an unknown word prints the usage line.
  arg mode (string, default: ""): all, ondemand or off; leave it out to print the summary instead.
  example: ISXOgreX.Patch:Mesh[ondemand]

ISXOgreX.Patch:RevertExt
  kind: method of ISXOgreX.Patch
  what: Puts back the previous ISXOgreX DLL kept after a self-update (the .prev file) and reloads the extension, keeping the replaced one beside it as .reverted. It is refused while a run is in progress, says there is nothing to revert when no .prev exists, and the next update run installs the current release again.
  example: ISXOgreX.Patch:RevertExt

ISXOgreX.Patch:Status
  kind: method of ISXOgreX.Patch
  what: Prints the patcher's state to the console: whether patching is on, your login state, your file switches, the last release and run, whether this session runs older DLLs than the ones on disk, any run in progress and the navmesh download summary. It changes nothing.
  example: ISXOgreX.Patch:Status

ISXOgreX.Patch:TestCorrupt
  kind: method of ISXOgreX.Patch
  what: A diagnostic switch: each call arms or disarms a one-time fault that flips one byte of the next downloaded file before it is checked, so you can see the check refuse it and keep the old file. It prints ARMED or disarmed and fires on the next update or navmesh download.
  example: ISXOgreX.Patch:TestCorrupt

ISXOgreX.Patch:Update
  kind: method of ISXOgreX.Patch
  what: Checks for an Ogre update now and installs it: fetches the current release, downloads every changed file, checks each one and swaps them in, reloading the extension if one of its DLLs changed, and afterwards every other session on this PC that runs older files reloads too. It runs in the background, prints 'patch: <result>' when done, and refuses with a console line when a run is already going, patching is off or you are not logged in to Ogre.
  example: ISXOgreX.Patch:Update


== ISXOgreX.UI ==

${ISXOgreX.UI.Get[key]}
  kind: member of ISXOgreX.UI
  what: Reads the value a UI page stored under `key` with ogreCall('set',key,value); there is one store, shared by every page, and the UI host is loaded first if needed. Returns NULL when the key was never stored, its value is empty, or the UI host is not loaded.
  arg key (string): the store key the page used (case as the page wrote it)
  returns: string: the stored value; NULL when the key is absent, its value is empty, or the UI host is not loaded
  example: echo ${ISXOgreX.UI.Get[radar_cfg]}

${ISXOgreX.UI.Value[name,id]}
  kind: member of ISXOgreX.UI
  what: Reads element `id` of the open window `name` as the page last published it: a checkbox or radio reads TRUE or FALSE, an input or textarea its value (an empty box reads an empty string), any other element its text. NULL when the window is not open or the element never published - only windows opened with ISXOgreX.UI:Open publish, and a read right after your own ISXOgreX.UI:Set waits up to 50 ms for the page to apply it.
  arg name (string): the window name given to ISXOgreX.UI:Open (case-sensitive)
  arg id (string): the element's HTML id inside that window
  returns: string: the element's published value; NULL when the window is not open or the element never published a value
  example: echo ${ISXOgreX.UI.Value[hello,hello-name]}

${ISXOgreX.UI.Window[name]}
  kind: member of ISXOgreX.UI
  what: Gives the open window `name` - your own, OgreBot's or a help window - as an ogrexuiwindow object (Name, Visible, X, Y, Width, Height) that prints as the window's name. NULL when no window by that name is open, so (exists) answers "is it open"; a window counts as open from the moment OgreUI_Opened fires for it.
  arg name (string): the window name (case-sensitive)
  returns: ogrexuiwindow: the open window; NULL when no window with that name is open
  returns object: ISXOgreX.UI.Window (its members and methods are listed under it)
  example: echo ${ISXOgreX.UI.Window[hello](exists)}

ISXOgreX.UI:Close[name]
  kind: method of ISXOgreX.UI
  what: Closes the window `name` - your own or any other open UI window - and OgreUI_Closed fires with reason "closed". Nothing happens when no window by that name is open; a missing name is refused with one console warning.
  arg name (string): the window's name (case-sensitive)
  example: ISXOgreX.UI:Close[hello]

ISXOgreX.UI:Drain
  kind: method of ISXOgreX.UI
  what: Runs, right now and in order, the commands UI pages have queued for the script side, stopping after about 1,000 in one call. The extension already does this every frame, so a script rarely needs it.
  example: ISXOgreX.UI:Drain

ISXOgreX.UI:Eval[js]
  kind: method of ISXOgreX.UI
  what: Runs the JavaScript js in the UI page, loading the UI host first if needed. Nothing comes back to the script, and without js it is refused with one console warning.
  arg js (string): the JavaScript to run in the UI page
  example: ISXOgreX.UI:Eval["radarSaveNow()"]

ISXOgreX.UI:EvalFile[path]
  kind: method of ISXOgreX.UI
  what: Reads the JavaScript file `path` from disk and runs it in the UI page, loading the UI host first if needed. A file that cannot be read writes a warning to the log file only, not the console, and a missing path is refused with one console warning.
  arg path (string): full path of the .js file to run
  example: ISXOgreX.UI:EvalFile["${LavishScript.HomeDirectory}/Scripts/Ogre/Common/OgreUI/common/WindowReset/windowreset.js"]

ISXOgreX.UI:Focus[name,id]
  kind: method of ISXOgreX.UI
  what: Gives the text field `id` in the open window `name` the keyboard, so keys go to that field and not the game until Escape or a click elsewhere; every call is logged. A hidden window, a missing element or anything that is not a text field is refused (logged only), and leaving out either argument prints a warning to the console.
  arg name (string): the open window's name (case-sensitive)
  arg id (string): the HTML id of a text input, textarea or editable element in that window
  example: ISXOgreX.UI:Focus[hello,hello-name]

ISXOgreX.UI:Help
  kind: method of ISXOgreX.UI
  what: Opens, in the default web browser, the online documentation page of the window whose Full documentation button was pressed; the window name comes from what the help window stored under help_name. It takes no arguments, and a window with no documentation page only writes a warning to the log file.
  example: ISXOgreX.UI:Help

ISXOgreX.UI:Host
  kind: method of ISXOgreX.UI
  what: Loads the UI host if it is not loaded yet; it does not open or show anything. Safe to call any number of times.
  example: ISXOgreX.UI:Host

ISXOgreX.UI:KeyboardDump
  kind: method of ISXOgreX.UI
  what: Prints a keyboard report to the console: Shift (as the game and the hardware see it), Caps Lock, Ctrl, Alt, the keys held down, whether the game window is in front, and the UI host's keyboard state. It is meant for pasting into a report about a key that seems stuck.
  example: ISXOgreX.UI:KeyboardDump

ISXOgreX.UI:Load[path]
  kind: method of ISXOgreX.UI
  what: Loads the UI host, then replaces the whole UI page with the HTML file path, which takes away the desktop and every window on it: each window closes with OgreUI_Closed reason "reload", as UI:Reload does, and nothing waiting for the desktop runs until a page says it is ready. Without path it is refused with one console warning (ISXOgreX.UI:Host loads the host alone).
  arg path (string): full path of the HTML file to show as the UI page
  example: ISXOgreX.UI:Load["${LavishScript.HomeDirectory}/Scripts/Ogre/Common/OgreUI/common/Desktop/desktop.html"]

ISXOgreX.UI:Move[name,x,y]
  kind: method of ISXOgreX.UI
  what: Moves the open window `name` (yours or any other) so its top-left corner sits at x,y in desktop pixels - the same numbers the Window object's X and Y read back. The move is not saved, so the window opens at its saved spot next time; anything but two whole numbers prints a warning to the console, and a window that is not open is left alone.
  arg name (string): the open window's name (case-sensitive)
  arg x (int): left edge in desktop pixels (a whole number)
  arg y (int): top edge in desktop pixels (a whole number)
  example: ISXOgreX.UI:Move[hello,200,150]

ISXOgreX.UI:Open[name,path,helpPath]
  kind: method of ISXOgreX.UI
  what: Opens your own window `name` from one HTML file `path`, with an optional markdown file `helpPath` as the text of the title bar's help (?) button; both files are read when you call it, and the window appears once the UI desktop is up, when OgreUI_Opened fires. If a window by that name is already open only its help text is refreshed, and a file that cannot be read prints a warning to the console and opens nothing; a missing name or path is refused with one console warning.
  arg name (string): the window's name, used by every other window call (case-sensitive)
  arg path (string): full path of the HTML file: style, markup and <script> blocks, plus an optional <script type="ogre/window"> block holding the window's options as JSON (title, w, h ...)
  arg helpPath (string, default: "" (no help text)): full path of a markdown file shown by the title bar's ? button
  example: ISXOgreX.UI:Open[hello,"${LavishScript.HomeDirectory}/Scripts/Ogre/Common/OgreUI/examples/hello/hello.html","${LavishScript.HomeDirectory}/Scripts/Ogre/Common/OgreUI/examples/hello/hello.md"]

ISXOgreX.UI:Reload
  kind: method of ISXOgreX.UI
  what: Reloads the UI page: every open window goes away at once and OgreUI_Closed fires for each with reason "reload", which is the cue for a script to re-open its own window. The UI host is loaded first if needed; if it cannot load, nothing happens.
  example: ISXOgreX.UI:Reload

ISXOgreX.UI:SavePref
  kind: method of ISXOgreX.UI
  what: Saves a UI page's own preferences: the JSON the page stored under uipref_blob is written into the saved UI state (UIState.json in the Common save folder) under the name it stored in uipref_name, replacing what that name held. Pages call it themselves; it takes no arguments, and missing or invalid values only write a warning to the log file.
  example: ISXOgreX.UI:SavePref

ISXOgreX.UI:SaveWindow
  kind: method of ISXOgreX.UI
  what: Saves one window's position, size, scale and lock settings, read from the blob the page stored under wm_save_blob, into the saved UI state (UIState.json in the Common save folder), replacing what that window had. The window manager calls it from a window's Save Position; it takes no arguments, and a missing or invalid blob only writes a warning to the log file.
  example: ISXOgreX.UI:SaveWindow

ISXOgreX.UI:Set[name,id,value]
  kind: method of ISXOgreX.UI
  what: Changes element `id` in the open window `name` as if the user did it: a checkbox or radio is checked for TRUE, 1, on or yes and unchecked for anything else, an input, textarea or dropdown takes the value, any other element shows it as its text, and a form element's change event fires. A missing window, id or value is refused with one console warning (a blank value is a value); nothing happens when the window is not open or no element has that id.
  arg name (string): the open window's name (case-sensitive)
  arg id (string): the element's HTML id inside that window
  arg value (string): the new value: TRUE/FALSE for a checkbox or radio, otherwise the text or value to put in
  example: ISXOgreX.UI:Set[hello,hello-status,"Said hello"]

ISXOgreX.UI:Size[name,width,height]
  kind: method of ISXOgreX.UI
  what: Sizes the open window `name` (yours or any other) to width by height pixels on screen with its scale applied - the same numbers the Window object's Width and Height read back. The size is not saved, so the window opens at its saved size next time; anything but two whole numbers above 0 prints a warning to the console, and a window that is not open is left alone.
  arg name (string): the open window's name (case-sensitive)
  arg width (int): width in on-screen pixels (a whole number above 0)
  arg height (int): height in on-screen pixels (a whole number above 0)
  example: ISXOgreX.UI:Size[hello,320,200]

ISXOgreX.UI:WindowResetPanel
  kind: method of ISXOgreX.UI
  what: Opens the Reset UI Windows window, centered on the screen, which lists the open windows and lets the player put each one back at its default spot. It waits for the desktop if that is not up yet, and does nothing if the Reset UI Windows window is already open.
  example: ISXOgreX.UI:WindowResetPanel

== ogretimer ==

${T.DeciLeft}
  kind: member of ogretimer
  what: Seconds left before the timer runs out, as text with one decimal, as Object_Timer's DeciLeft: 1500 ms left reads 1.5. It reads 0.0 once the timer has run out or was stopped.
  returns: string: seconds left with one decimal; "0.0" when the timer ran out, was stopped or was never set
  example: variable ogretimer T
           echo ${T.DeciLeft}

${T.MinutesLeft}
  kind: member of ogretimer
  what: Whole minutes left before the timer runs out, rounded down, as Object_Timer's MinutesLeft: 119 seconds left reads 1. It reads 0 in the last minute as well as once the timer has run out or was stopped.
  returns: int64: whole minutes left (rounded down); 0 when under a minute is left, or the timer ran out, was stopped or was never set
  example: variable ogretimer T
           echo ${T.MinutesLeft}

${T.Running}
  kind: member of ogretimer
  what: Whether the timer still has time left. A timer set to 0, run out, stopped or never set is not running.
  returns: bool: TRUE while TimeLeft is above 0; FALSE when it has run out, was stopped or was never set
  example: variable ogretimer T
           echo ${T.Running}

${T.SecondsLeft}
  kind: member of ogretimer
  what: Whole seconds left before the timer runs out, rounded down, so 1999 ms left reads 1. It reads 0 in the last second as well as once the timer has run out or was stopped.
  returns: int64: whole seconds left (rounded down); 0 when under one second is left, or the timer ran out, was stopped or was never set
  example: variable ogretimer T
           echo ${T.SecondsLeft}

${T.TimeLeft}
  kind: member of ogretimer
  what: Milliseconds left before the timer runs out - 0 once it has run out, and 0 for a timer that was stopped or never set. Reading the variable itself (${T}) gives the same number, so `if ${T}` means still running.
  returns: int64: milliseconds left; 0 when the timer has run out, was stopped or was never set
  example: variable ogretimer T
           echo ${T.TimeLeft}

T:Dec[ms]
  kind: method of ogretimer
  what: Takes ms milliseconds off the time left - taking off as much as is left (or more) stops the timer, and a timer that is not running stays stopped. A missing or non-number argument prints a warning and leaves the timer unchanged, and zero or a negative number counts as 0.
  arg ms (number): milliseconds to take off (fractions are rounded)
  example: variable ogretimer T
           T:Dec[1000]

T:DecMinutes[minutes]
  kind: method of ogretimer
  what: Takes that many minutes off the time left - taking off as much as is left (or more) stops the timer, and a timer that is not running stays stopped. A missing or non-number argument prints a warning and leaves the timer unchanged, and zero or a negative number counts as 0.
  arg minutes (number): minutes to take off (fractions allowed)
  example: variable ogretimer T
           T:DecMinutes[1]

  arg seconds (number): seconds to take off (fractions allowed)

T:Inc[ms]

T:Set[ms]
  kind: method of ogretimer
  what: Starts the timer so it runs out ms milliseconds from now, replacing any time it had, and Set[0] makes it read as already run out. A missing or non-number argument prints a warning and leaves the timer unchanged, and zero or a negative number counts as 0.
  arg ms (number): milliseconds from now until the timer runs out (fractions are rounded)
  example: variable ogretimer T
           T:Set[5000]

T:SetHours[hours]
