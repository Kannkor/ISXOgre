== OgreBotAPI.Comms ==

${OgreBotAPI.Comms.Dispatched}
  kind: member of OgreBotAPI.Comms
  what: How many received events at least one of the bot's own handlers acted on. Events no handler wants, and events dropped by for-who, are not counted.
  returns: int64: events handled
  example: echo ${OgreBotAPI.Comms.Dispatched}

${OgreBotAPI.Comms.Errors}
  kind: member of OgreBotAPI.Comms
  what: How many received events were thrown away as unreadable: bad base64, bad JSON, not an event, a newer envelope version, no name, or a name unfit for a script event. For-who drops and a full inbox are not counted here.
  returns: int64: unreadable events
  example: echo ${OgreBotAPI.Comms.Errors}

${OgreBotAPI.Comms.GroupQuery[fw,question...]}
  kind: member of OgreBotAPI.Comms
  what: With arguments, starts a groupQuery on this session and returns it - every read of this form asks again; with no arguments it is the handle whose .Last, .Done[id] and .Result[id] read queries. Answers come over this PC's relay group only, so group or raid members on other PCs show as missing, and a bad question prints a groupQuery error.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg question... (string): one JSON object, or -key,value pairs: -question (itemCount, abilityReady, slotResolve or LavishScript["${...}"]), -item, -ability or -slot, -compare with -value, -sendTo (default igw:<me>), -limitMs (default 3000), -askAgainIfBlank
  returns: groupquery object: its text is the new query id (read .Done and .Result on it); NULL when the for-who does not name this character or the question is refused. With no arguments: the handle with .Last, .Done[id], .Result[id]
  returns object: OgreBotAPI.Comms.GroupQuery (its members and methods are listed under it)
  example: echo ${OgreBotAPI.Comms.GroupQuery[all,-question,itemCount,-item,"Mechanized Platinum Repository of Reconstruction"]}
  oldbot: OgreBotAPI.Ask, OgreBotAPI.Ask_AllFalse, OgreBotAPI.Ask_AllTrue

${OgreBotAPI.Comms.Query_Active[id]}
  kind: member of OgreBotAPI.Comms
  what: TRUE while a query is still collecting replies, before its timeout. An empty id reads the last query (Query_Last); an unknown or cleared id reads FALSE.
  arg id (string): the query id from Query_Last; empty = the last query
  returns: bool: TRUE while the query is collecting replies; FALSE once it is done, or for an unknown id
  example: echo ${OgreBotAPI.Comms.Query_Active[${OgreBotAPI.Comms.Query_Last}]}

${OgreBotAPI.Comms.Query_Count[id]}
  kind: member of OgreBotAPI.Comms
  what: How many characters have replied to a query; an unknown id reads 0. Only in-world sessions on this PC answer, and this session answers its own question.
  arg id (string): the query id from Query_Last; empty = the last query
  returns: int: replies so far (final once Query_Done); 0 for an unknown id
  example: echo ${OgreBotAPI.Comms.Query_Count[${OgreBotAPI.Comms.Query_Last}]}

${OgreBotAPI.Comms.Query_Done[id]}
  kind: member of OgreBotAPI.Comms
  what: TRUE once a query's timeout has passed and its tally is final. The tally stays readable for 60 seconds after that, then the query is forgotten and this reads FALSE again.
  arg id (string): the query id from Query_Last; empty = the last query
  returns: bool: TRUE when the query has finished; FALSE while it runs, after it is forgotten, or for an unknown id
  example: echo ${OgreBotAPI.Comms.Query_Done[${OgreBotAPI.Comms.Query_Last}]}

${OgreBotAPI.Comms.Query_Json[id]}
  kind: member of OgreBotAPI.Comms
  what: Every reply to a query as one JSON object of responder name to raw answer: the item count, seconds until the ability is ready, the equipped item name, or the expression's text. An empty id reads the last query.
  arg id (string): the query id from Query_Last; empty = the last query
  returns: string: JSON such as {"Name1":"5","Name2":"0"}; {} when nobody replied or the id is unknown
  example: echo ${OgreBotAPI.Comms.Query_Json[${OgreBotAPI.Comms.Query_Last}]}

${OgreBotAPI.Comms.Query_Last}
  kind: member of OgreBotAPI.Comms
  what: The id of the last query this session started with Comms:Query; the bot's own group, loot and quest questions do not change it, and a refused :Query leaves the previous id in place.
  returns: string: the query id; empty before any query started
  example: echo ${OgreBotAPI.Comms.Query_Last}

${OgreBotAPI.Comms.Query_TrueCount[id]}
  kind: member of OgreBotAPI.Comms
  what: How many replies to a query answered TRUE: has the item, ability ready, slot filled, or the expression read true. An empty id reads the last query; an unknown id reads 0.
  arg id (string): the query id from Query_Last; empty = the last query
  returns: int: TRUE replies so far; 0 for an unknown id
  example: echo ${OgreBotAPI.Comms.Query_TrueCount[${OgreBotAPI.Comms.Query_Last}]}

${OgreBotAPI.Comms.Queued}
  kind: member of OgreBotAPI.Comms
  what: How many received events are waiting to be handled right now. They are handled on the next pulse, so this is normally 0.
  returns: int64: events waiting
  example: echo ${OgreBotAPI.Comms.Queued}

${OgreBotAPI.Comms.Received}
  kind: member of OgreBotAPI.Comms
  what: How many events this session has received from its relay group since it loaded or since the last ResetStats, counting its own events and events its for-who then dropped. It stays 0 when the uplink's OgreConsoleHub is not loaded, because then nothing comes back.
  returns: int64: events received
  example: echo ${OgreBotAPI.Comms.Received}

${OgreBotAPI.Comms.Stats}
  kind: member of OgreBotAPI.Comms
  what: This session's comms counters as one line: received, queued, handled, dropped by for-who, sent, and errors by kind. It is a local read that sends nothing, and echo ${OgreBotAPI.Comms} prints the same line.
  returns: string: the counter line, e.g. recv=12 q=0 proc=12 disp=10 nosub=2 refired=12 cfwdrop=0 emit=5 err[b64=0 json=0 type=0 ver=0 name=0 refname=0] of=0 tid[recv=... pulse=...]
  example: echo ${OgreBotAPI.Comms.Stats}

${OgreBotAPI.Comms.UplinkName}
  kind: member of OgreBotAPI.Comms
  what: Inner Space's uplink name for this PC, read from ${InnerSpace.Uplink}. A local read; every session on the PC reads the same text.
  returns: string: the value of ${InnerSpace.Uplink}
  example: echo ${OgreBotAPI.Comms.UplinkName}
  oldbot: GetInfoOb.UplinkName, OgreBotAPI.UplinkName

OgreBotAPI.Comms:AddAnnounce[fw, ability, to, text]
  kind: method of OgreBotAPI.Comms
  what: Adds a row to this character's Announce tab and saves it in the loaded profile like a panel edit; from then on, casting the ability sends text to the to place (group or raid chat, a tell to the target, a game command, or a console command). An unknown ability or place, empty text, a duplicate row or no loaded profile is refused with a console line, and nothing announces while the Announce tab is switched off.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg ability (string): the ability's name (any rank) or id, from this character's ability export
  arg to (string): where to announce: Group, Raid, Tell To Target, In-Game Command or Execute In Console (any case)
  arg text (string): the announce text; everything after to is joined back with commas, so it need not be quoted
  example: OgreBotAPI.Comms:AddAnnounce[${Me.Name},Rescue,Group,"Rescue on *Target*"]
  oldbot: OgreBotAPI:Announce_AddEntry

OgreBotAPI.Comms:Broadcast[fw, text, -tab name..., -sound ding|alarm]
  kind: method of OgreBotAPI.Comms
  what: Sends the text to every session in this PC's relay group, this one included; each shows "[Notify] <sender>: <text>" in its OgreConsole (and the -tab tab) and plays the -sound. fw picks which sessions send, not who receives; it never leaves the PC, and with no OgreConsoleHub in the uplink nobody shows it, not even this session.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg text (string): the line to show; commas in it are kept
  arg -tab name... (string): followed by an OgreConsole tab name - each receiver also puts the line in that tab; may be repeated
  arg -sound ding|alarm (string): followed by ding or alarm - each receiver plays that sound; a bare -sound is ding
  example: OgreBotAPI.Comms:Broadcast[${Me.Name},"Named is up",-sound,alarm]
  oldbot: OgreBotAPI:Message_Relay

OgreBotAPI.Comms:ConversationBubble[fw, num=1]
  kind: method of OgreBotAPI.Comms
  what: Clicks reply number num in the NPC conversation window open on this session; needs a character in the world. When no conversation is open or it has no such reply nothing is clicked, and only the log file says so.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg num (int, default: 1): which reply to click, counting from 1 as SpewConversationBubbles numbers them
  example: OgreBotAPI.Comms:ConversationBubble[igw:${Me.Name},2]
  oldbot: OgreBotAPI:ConversationBubble, OgreBotAPI:OptNum, call Obj_OgreUtilities.DoConversation

OgreBotAPI.Comms:Emit[fw, name, cfw="", dest="", ev=1, dataJson=""]
  kind: method of OgreBotAPI.Comms
  what: Sends a named event to every session in this session's relay group on this PC, this one included; each session whose for-who matches cfw runs its handlers and fires the script event OgreComms_<name> with the event JSON. It never leaves the PC and needs OgreConsoleHub in the uplink - without it nothing arrives anywhere and, a few seconds on, a "comms egress is BLIND" warning prints; an empty name gets a refusal line and invalid dataJson is refused (log file only).
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): the event name (required); letters, digits and _ up to 64 characters, or no OgreComms_ script event fires
  arg cfw (string, default: ""): for-who checked by each receiving session; empty = every session. A session not in the world (login screen, character select, zoning) takes in only what needs no game - messages, tag changes, group and key-bind updates - and throws momentary requests (casts, script events) away; a changed MCP file is kept once and read when it reaches the world; the OgreComms_ script event fires only in the world
  arg dest (string, default: ""): the relay group to deliver to; empty = this session's relay group (Relay Groups tab)
  arg ev (int, default: 1): the data version number stamped on the event
  arg dataJson (string, default: ""): a JSON value carried as the event's data; must be valid JSON
  example: OgreBotAPI.Comms:Emit[${Me.Name},MyEvent]

OgreBotAPI.Comms:ExecuteEvent[fw, name, ...]
  kind: method of OgreBotAPI.Comms
  what: Runs Event["name"]:Execute[...] on this session with the remaining arguments joined by commas, as written (not quoted). Local only - nothing is sent; needs a character in the world.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg name (string): the LavishScript event to fire
  arg ... (string): arguments passed to the event, in order
  example: OgreBotAPI.Comms:ExecuteEvent[${Me.Name},MyScript_Pull,${Target.ID}]
  oldbot: OgreBotAPI:ExecuteEvent_JSON, OgreBotAPI:ExecuteEvent

OgreBotAPI.Comms:GroupQuery[fw, question...]
  kind: method of OgreBotAPI.Comms
  what: Starts a groupQuery: asks group or raid members a question and judges the answers; read the id from ${OgreBotAPI.Comms.GroupQuery.Last} and the result JSON from .Result[id], which also fires OgreEvent_GroupQueryDone. Answers come over this PC's relay group only, so members on other PCs show as missing, and a bad question prints a groupQuery error to the console.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg question... (string): one JSON object, or -key,value pairs: -question (itemCount, abilityReady, slotResolve or LavishScript["${...}"]), -item, -ability or -slot, -compare with -value, -sendTo (default igw:<me>), -limitMs (default 3000), -askAgainIfBlank
  example: OgreBotAPI.Comms:GroupQuery[${Me.Name},-question,abilityReady,-ability,Rescue,-sendTo,igw:${Me.Name}]

OgreBotAPI.Comms:Ingest[fw, wire]
  kind: method of OgreBotAPI.Comms
  what: Hands a base64 event envelope to this session's comms receiver as if it had arrived from the relay group; it is handled on the next pulse. Nothing is sent anywhere, and unreadable input only adds to Errors.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg wire (string): the base64-encoded event envelope JSON
  example: OgreBotAPI.Comms:Ingest[${Me.Name},eyJ2IjoxLCJmcm9tIjoiaXMxIiwiZGVzdGluYXRpb24iOiJvZ3JlX2V2ZXJxdWVzdDIiLCJ0eXBlIjoiZXZlbnQiLCJhcmdzIjp7Im5hbWUiOiJNeUV2ZW50IiwiZXYiOjF9fQ==]

OgreBotAPI.Comms:InjectChat[fw, chat=Nothing]
  kind: method of OgreBotAPI.Comms
  what: Feeds the text into this session's own chat handling as a raid-chat line from the bot's built-in speaker OgreIRCSession, on the next pulse, so chat triggers and chat commands act on it. Nothing is said in game or sent anywhere; needs a character in the world.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg chat (string, default: Nothing): the chat text to inject
  example: OgreBotAPI.Comms:InjectChat[${Me.Name},"burn now"]
  oldbot: OgreBotAPI:InjectChat

OgreBotAPI.Comms:IrcAuthIfInRaid[nick, toon]
  kind: method of OgreBotAPI.Comms
  what: If toon is in this character's raid, tells this PC's IRC bridge to accept commands from the IRC nick nick, marked as learned through the raid so IrcRaidUnauth can take it back. There is no for-who - every in-world session checks and prints a line saying whether toon is in its raid; nothing happens if the IRC bridge is not loaded in the uplink.
  arg nick (string): the IRC nick to accept, as written
  arg toon (string): the character whose raid membership decides it
  example: OgreBotAPI.Comms:IrcAuthIfInRaid[${Me.Name}_IRC,${Group[1].Name}]
  oldbot: OgreBotAPI:OgreIRC_AuthIfInRaid

OgreBotAPI.Comms:IrcConnect[fw]
  kind: method of OgreBotAPI.Comms
  what: Loads the IRC bridge (OgreIRCHub) in this PC's uplink if it is not loaded and connects it to IRC with the saved settings; already connected = no change. It prints "irc: connecting" either way, and if the settings file cannot be read the bridge says so and does not connect.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Comms:IrcConnect[${Me.Name}]

OgreBotAPI.Comms:IrcDisconnect[fw]
  kind: method of OgreBotAPI.Comms
  what: Asks this PC's IRC bridge to disconnect from IRC; the bridge stays loaded and idle. It prints "irc: asking the uplink OgreIRCHub to disconnect (it stays loaded)." and the bridge reports the result on the uplink.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Comms:IrcDisconnect[${Me.Name}]

OgreBotAPI.Comms:IrcRaidAuth[fw]
  kind: method of OgreBotAPI.Comms
  what: Asks, over IRC, every IRC bridge whose PC has a character in this raid to accept commands from each other's nicks; characters outside the raid take no part. Needs a character in a raid and IRC connected - otherwise it prints why and asks nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Comms:IrcRaidAuth[${Me.Name}]

OgreBotAPI.Comms:IrcRaidCheck[fw, ask, toon]
  kind: method of OgreBotAPI.Comms
  what: Answers this PC's IRC bridge: if toon is in this character's raid, it reports this character's name back for question number ask. It says nothing when toon is not in the raid, when ask is not all digits, or out of the world; the bridge calls this itself.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg ask (int): the bridge's question number (digits only)
  arg toon (string): the character that asked; must be a plain name
  example: OgreBotAPI.Comms:IrcRaidCheck[all,12,${Group[1].Name}]

OgreBotAPI.Comms:IrcRaidUnauth[fw]
  kind: method of OgreBotAPI.Comms
  what: Asks, over IRC, every IRC bridge in this raid to drop the nicks it accepted through the raid; nicks accepted any other way stay. Needs a character in a raid and IRC connected - otherwise it prints why and asks nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Comms:IrcRaidUnauth[${Me.Name}]

OgreBotAPI.Comms:IrcReload[fw]
  kind: method of OgreBotAPI.Comms
  what: Makes this PC's IRC bridge re-read its settings and reconnect with them, but only if it is connected - an idle bridge stays idle. It prints "irc: reloading the uplink hub config."; a settings file that does not read is only written to the bridge's log.
  arg fw (for-who): for-who: this runs only when this character is one it names
  example: OgreBotAPI.Comms:IrcReload[${Me.Name}]

OgreBotAPI.Comms:Message[fw, text, -tab name..., -sound ding|alarm]
  kind: method of OgreBotAPI.Comms
  what: Prints "[Message] <text>" in this session's OgreConsole (the Inner Space console when OgreConsole is not available); nothing goes to other sessions, IRC or game chat. -tab also puts it in that OgreConsole tab and -sound plays the sound here; an unknown sound name warns and plays nothing, and an empty text does nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg text (string): the line to show; commas in it are kept
  arg -tab name... (string): followed by an OgreConsole tab name - the line also lands in that tab; may be repeated

OgreBotAPI.Comms:Pushover[fw, message..., -title t, -priority n]
  kind: method of OgreBotAPI.Comms
  what: Sends a push notification through the Pushover service from this session; every word that is not a flag becomes the message. Not configured (no app token or user key), switched off in the profile, or no message = nothing sent and a warning, and -sound, -device, -retry and -expire are accepted but ignored.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg message... (string): the notification text; unflagged words are joined with spaces
  arg -title t (string): followed by the notification title
  arg -priority n (int, default: 0): followed by a Pushover priority, -2 to 2
  example: OgreBotAPI.Comms:Pushover[${Me.Name},"Raid wiped",-title,EQ2,-priority,1]
  oldbot: OgreBotAPI:Pushover, Obj_Pushover.PushoverSendMsg, Obj_Pushover

OgreBotAPI.Comms:Query[fw, kind, cfw="", timeoutMs=0, paramsJson=""]
  kind: method of OgreBotAPI.Comms
  what: Asks every in-world session in this PC's relay group a typed question and tallies the replies; read the new id from Query_Last, then Query_Count, Query_TrueCount and Query_Json once Query_Done. Sessions on other PCs never answer (it does not use IRC), with no OgreConsoleHub in the uplink nobody answers, not even this session, and an unknown kind or one of the bot's own (lootBid, questSteps) is refused (log file only).
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg kind (string): the question: itemCount, abilityReady, slotResolve or eval (required)
  arg cfw (string, default: ""): for-who checked by each session before it answers; empty = every session
  arg timeoutMs (int, default: 0): how long to collect replies in milliseconds; 0 or less = 3000, capped at 60000
  arg paramsJson (string, default: ""): the question's JSON: itemCount {"item":"name"}, abilityReady {"ability":"name or id"}, slotResolve {"slot":"slot name or number"}, eval {"expr":"a LavishScript expression"}; missing or wrong = nobody answers
  example: OgreBotAPI.Comms:Query[${Me.Name},itemCount,all,5000,{"item":"Mechanized Platinum Repository of Reconstruction"}]

OgreBotAPI.Comms:Query_Clear[fw, id=""]
  kind: method of OgreBotAPI.Comms
  what: Forgets a query and its tally on this session; its Query_* reads go back to FALSE, 0 and {}. Leave id empty for the last Comms:Query - an unknown id does nothing.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg id (string, default: ""): the query id to forget; empty = the last query (the word last itself is not recognised)
  example: OgreBotAPI.Comms:Query_Clear[${Me.Name}]

Needs a character in the world; while IRC is not connected the IRC bridge holds the line and sends it once it connects.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg compareTo (string): the version to compare against; empty = just report the version
  example: OgreBotAPI.Comms:ReportVersion[all,""]

== OgreBotAPI.Comms.GroupQuery ==

${OgreBotAPI.Comms.GroupQuery.Done[id]}
  kind: member of OgreBotAPI.Comms.GroupQuery
  what: Whether a group query has finished. With no id it reads the query this object was started as, else the last one; an id from another session matches nothing.
  arg id (string): The query id from Last (like gq:is1:4); blank reads the bound or last query
  returns: bool: TRUE once the query has finished; FALSE while it runs, for an id this session did not start, and again 60 seconds after it finished, when the result is dropped.
  example: echo ${OgreBotAPI.Comms.GroupQuery.Done[${OgreBotAPI.Comms.GroupQuery.Last}]}

${OgreBotAPI.Comms.GroupQuery.Last}
  kind: member of OgreBotAPI.Comms.GroupQuery
  what: The id of the last group query this session started, from ${OgreBotAPI.Comms.GroupQuery[fw,...]} or OgreBotAPI.Comms:GroupQuery. Pass it to Done and Result to read that query.
  returns: string: the id, like gq:is1:4; "" when this session has not started one.
  example: echo ${OgreBotAPI.Comms.GroupQuery.Last}

${OgreBotAPI.Comms.GroupQuery.Result[id]}
  kind: member of OgreBotAPI.Comms.GroupQuery
  what: The result of a finished group query, as JSON. With no id it reads the query this object was started as, else the last one; the result stays readable for 60 seconds after the query finishes.
  arg id (string): The query id from Last (like gq:is1:4); blank reads the bound or last query
  returns: string: the result JSON once finished; "" while it runs, for an id this session did not start, and after the 60 seconds are up.
  example: echo ${OgreBotAPI.Comms.GroupQuery.Result[${OgreBotAPI.Comms.GroupQuery.Last}]}


== OgreBotAPI.Consumables ==

OgreBotAPI.HOs:DoSetEnabled[fw, on=TRUE, option...]
  kind: method of OgreBotAPI.HOs
  what: Turns OgreBot's solo HO on or off on this character without clearing its record (use DoSetup to set the target and count); calling it with the state it already has does nothing unless -Force, and a value that is not a yes/no word does nothing. On/off is session only, and the settings it writes are profile options in memory, kept on disk only if the profile is saved before they are put back.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg on (bool, default: TRUE): TRUE to run the solo HO here: makes this character the HO'er, tells the rest of the group to stand down, cancels another archetype's starter if one is up, writes the group's HO settings, cancels group casts with more than 0.5 seconds left, holds the first start for -DelayStart seconds (default 1) and extends the timeout to at least 25 seconds (or sets it to -TimeOut n). FALSE to stop it: puts back this character's HO settings and asks the group to put back theirs.
  arg option... (flags): Any of -Force (run even if already in that state), -NoEnable / -PrimeOnly / -NoStart (set the group up but leave this character's HO settings off), -NoHoAbilities (on FALSE, keep HO abilities disabled on the rest of the group), -TimeOut n, -DelayStart n. Unknown words are ignored.
  example: OgreBotAPI.HOs:DoSetEnabled[${Me.Name},FALSE]
  oldbot: OgreBotAPI:DoHO_Set_Enable

OgreBotAPI.HOs:DoSetup[fw, option...]
  kind: method of OgreBotAPI.HOs
  what: Starts OgreBot's solo HO with this character as the one who starts it (no HO needs to be up): it clears the previous record, starts a 25 second timeout and enables it as DoSetEnabled[fw,TRUE,...] with the same options, turning HO Start, Starter and Wheel off for the group and on for this character and setting the group's HO helper settings. It ends after -NumHOsToComplete completions (default 1), on timeout, or when the -TargetID mob dies or goes away, and every session then puts back the HO settings it had; the record is session only, and the changed HO settings are profile options in memory, written to disk only if the profile is saved while they are changed.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg option... (flags): Any of -TargetID id, -NumHOsToComplete n, -TimeOut n (instead of 25 seconds), -LeaveStartOpen, -LeaveWheelOpen, -AllowCastStack (keep this character's cast stack on), -NoModifyOptions (change no settings), -Force (when the solo HO is already running, apply the settings again instead of only recording the new options), -NoEnable, -DelayStart n, -NoHoAbilities, in any order; the DoSetEnabled options work here too. Unknown words are ignored.
  example: OgreBotAPI.HOs:DoSetup[${Me.Name},-TargetID,${Target.ID},-NumHOsToComplete,1,-TimeOut,30]
  oldbot: OgreBotAPI:DoHO_Setup

OgreBotAPI.HOs:Start[fw, -ActorID id, -SkipTimer]
  kind: method of OgreBotAPI.HOs
  what: Casts this character's archetype HO starter ability (Fighting Chance, Lucky Break, Divine Providence or Arcane Augur) once, immediately, even while the bot is paused, and tells the group which actor the HO is on. Nothing happens within 1 second of the last start unless -SkipTimer is given, or when the ability is not ready, out of range or the cast bar is busy - call it again to retry.
  arg fw (for-who): for-who: this runs only when this character is one it names
  arg -ActorID id (flag + number): Start the HO on this actor ID instead of the current target; -TargetID id is the same flag. Without it the cast goes at the current target and does nothing while any heroic opportunity is already up. With it, nothing happens if that actor is gone or a wheel is already running, and if another archetype's starter is up it is cancelled and the cast goes on the actor once the starter closes and the ability is ready (giving up after about 8 seconds).
  arg -SkipTimer (flag): Ignore the 1 second wait after the last start.
  example: OgreBotAPI.HOs:Start[${Me.Name},-ActorID,${Target.ID}]
  oldbot: OgreBotAPI:HO_Start
