# Ogre Craft 3

> **:bulb: In game - the ? button on this window says**
>
> The crafting bot. It crafts a queue of recipes, runs writs, levels tinkering or a new crafter, and casts the reaction arts for you.
>
> **What you can do here**
>
> - **Recipes** tab: filter your recipe book, pick a recipe, set a Quantity and **Add Recipe** (or double-click).
> - **Start Queue** crafts the setup queue. **Stop** ends any run. **Pause** holds it.
> - **Queues** tab: change amounts, and save or load named queues.
> - **Crafting Options** and **Navigation**: quality, power, buying, movement.
> - **Writs**, **Auto Tinkering** and **Low Level Leveling** tabs each have their own Start button.
>
> **Good to know**
>
> - Settings save by themselves a second after a change.
> - `ogre end craft` stops everything crafting is doing, not just this window.
> - The list shows at most 200 recipes - use the filters to narrow it.

**Open it:** Type `ogre craft` (also `ogre craft2` or `ogre ogrecraft`). `ogre end craft` closes the window AND ends all crafting: the run, craft's own movement, a summoned station and Craft Lite.

## What it is for

The crafting bot. Pick recipes from your recipe book into a queue and craft them; or let it run rush-order writs, level tinkering, level a new crafter from 1 to 19, or craft the steps of a crafting quest. It walks to the right station, buys missing fuel, and while crafting it casts the reaction arts for you. Opening the window also turns on Craft Lite (the part that casts the reaction arts); the footer shows whether it is on. Settings save by themselves.

## Run controls (top of the window)

Always visible. The green text next to OGRE CRAFT is what the bot is doing right now. Under it: 'Crafted N of M' for the current (or last) run, plus 'Writ N of M' during a writ run or 'Quest: <name>' during a quest run.

| Control | What it does | Default |
|---|---|---|
| **Start Queue** | Crafts everything in the setup queue (Queues tab). The setup queue moves into the Active queue, the bot works out the resources, buys missing fuel, walks to each station and crafts.<br>*Refused if the setup queue is empty. Needs at least 2 free bag slots. The queue you started is also saved as 'LastRecipeQueue' so you can load it again.* |  |
| **Start Writs** | Runs rush-order writs using the settings on the Writs tab. Same as the Start Writs button on that tab.<br>*Needs tradeskill level 20 or higher.* |  |
| **Stop** | Stops whatever is running (queue, writs, quest, tinkering or leveling). A walk in progress stops too.<br>*Stop also cancels a Pause. After a writ or quest run your own setup queue is put back.* |  |
| **Pause** | Holds the run where it is without ending it: a craft already begun finishes, nothing new starts and craft's walking stands still. Untick to carry on.<br>*A pause with nothing running is dropped when the next run starts.* | off |

## Save and Reload (bottom of the window)

The grey text on the right: how many recipes are in your recipe book, how many reaction arts were cast, which server type (live or Origins), and whether Craft Lite is on (green) or off (red).

| Control | What it does |
|---|---|
| **Save Settings** | Writes the settings to disk now. You rarely need it: every change saves by itself about a second later.<br>*Settings live in OgreSave/EQ2/Craft/settings.json.* |
| **Reload** | Re-reads the settings from disk, throwing away any change that has not been saved yet. |
| **Tab list (left)** | Switches between the seven tabs. Display only. |

## Recipes tab - Show, Sort and Filter

These decide which recipes from your book appear in the list below. They are also what Auto Tinkering and Low Level Leveling pick from when their Auto Sort box is off.

| Control | What it does | Default |
|---|---|---|
| **Show Standard Recipes** | Lists normal recipes (anything not advanced, imbued, tinkering or adorning). | on |
| **Show Imbue Recipes** | Lists imbue recipes (the name contains 'imbued' or the technique is imbuing). | off |
| **Show Advanced Recipes** | Lists recipes from advanced or mastercraft recipe books. | off |
| **Show Tinker Recipes** | Lists tinkering recipes. | off |
| **Show Adornment Recipes** | Lists adorning recipes. | off |
| **Name** | Sorts the list A to Z. Ticking it unticks Level. | off |
| **Level** | Sorts the list highest level first (ties A to Z). Ticking it unticks Name. | on |
| **Limit Levels:** | Only lists recipes whose level is between Min and Max (inclusive). | off |
| **Min** | Lowest recipe level shown when Limit Levels is ticked. 1 to 999.<br>*Min and Max can be typed either way round.* | 1 |
| **Max** | Highest recipe level shown when Limit Levels is ticked. 1 to 999. | 999 |
| **Search with:** | Only lists recipes whose name contains the text in the box. Not case-sensitive. | off |
| **part of a recipe name (search box)** | The text to search for when Search with is ticked. | empty |
| **C** | Clears the search box. |  |

## Recipes tab - adding to the setup queue

| Control | What it does | Default |
|---|---|---|
| **Quantity:** | How many to craft when you add a recipe. 1 to 9999. | 1 |
| **Add Recipe** | Adds the highlighted recipe to the setup queue with the Quantity. If it is already queued, the quantity is added on top.<br>*Click a recipe in the list first. Double-clicking a recipe does the same.* |  |
| **Start quest** | Crafts the quest that is selected in your quest journal: one of each recipe the quest's steps ask for, then re-reads the quest and goes again, until no craft step is left. Your setup queue is put aside and given back at the end.<br>*Select the quest in your journal first. Greyed out while anything is running.* |  |
| **Rescan recipe book** | Reads every recipe in your recipe book again. Use it after learning new recipes if they do not show up. |  |

## Recipes tab - the recipe list

Level, name and technique of each recipe that passes the filters. Click a row to highlight it; double-click to add it with the current Quantity. Hover a row for its tradeskill. The line under the list says 'Showing X of Y recipes'.

| Control | What it does |
|---|---|
| **Click / double-click a recipe row** | Click highlights the recipe for Add Recipe. Double-click adds it straight away. |

## Queues tab - the setup queue

The recipes waiting to be crafted by Start Queue.

| Control | What it does |
|---|---|
| **− (one fewer)** | Lowers that row's quantity by 1. At 0 the row is removed. |
| **+ (one more)** | Raises that row's quantity by 1. |
| **× (remove from the queue)** | Removes the recipe from the setup queue. |
| **Clear Queue** | Empties the setup queue. No confirmation. |

## Queues tab - save and load a queue

| Control | What it does | Default |
|---|---|---|
| **Queue name** | The name to save the setup queue under, or to load. | empty |
| **Save Queue** | Saves the setup queue to disk under that name (overwrites a queue with the same name).<br>*Queues live in OgreSave/EQ2/Craft/queues. A failed save shows a red message at the top.* |  |
| **Load Queue** | Replaces the setup queue with the saved queue of that name. Recipes this character does not know are left out and named in the console. |  |
| **Saved queue names (buttons)** | One button per saved queue. Click one to put its name in the Queue name box. It does not load it. |  |

## Queues tab - the active queue

What the running (or last) queue is crafting, with 'done / wanted' per recipe. A recipe the bot had to skip says 'skipped'; hover it to see why.

## Queues tab - resources

Built when a queue starts: every component and fuel the queue needs, how many it needs and how many you have. Red rows are short. Rows marked FUEL are bought from the fuel merchant; missing components are only reported - the bot crafts anyway.

## Crafting Options tab - craft targets

| Control | What it does | Default |
|---|---|---|
| **Quality Level** | The bot clicks Stop on a craft once its quality climbs past this level. At 4 every craft runs to the end. | 4 |
| **Min. Durability** | When to switch to durability-saving reactions. The value is times 10 on the game's 0-1000 durability scale: at 100 the bot protects durability as soon as it drops below full; at 50 only once it is down to 500. | 100 |
| **Power to craft** | The bot waits before starting each craft until your power is at least this much. The status shows 'waiting for power'. | 40 |
| **Power to save** | Reaction arts that cost power are not used while your power is at or below this, so you keep a reserve. | 20 |

## Crafting Options tab - behaviour

| Control | What it does | Default |
|---|---|---|
| **Buy standard recipes prior to crafting** | During writs and Low Level Leveling: once at the start of the run and again each time your tradeskill level goes up, walk to the recipe merchant and buy the standard recipe books for your level range that you do not know or have in your bags.<br>*Not used by a normal Start Queue.* | off |
| **Buy advanced recipes prior to crafting** | Same as above for the advanced recipe books. | off |
| **Scribe recipes** | On that same recipe-book trip, scribe the books you bought and any other book of your series and level already in your bags.<br>*Only happens when a recipe-book trip happens (one of the Buy boxes on, or tinkering).* | off |
| **Use Mass Production** | On a normal queue craft of 5 or more, if you know Mass Production, set the largest batch size that fits what is left.<br>*Not used for writs, quest or leveling runs.* | off |
| **Use Blueprint** | Ticks the game's Blueprint box on a normal queue craft. Writs and the loops always untick it. | off |
| **If ADORNING is NOT max level, do quality 1 while adorning** | While your adorning skill is not maxed, adorning crafts are stopped as soon as they reach quality 1 (faster skill-ups). | off |
| **If TINKERING is NOT max level, do quality 1 while tinkering** | Same for tinkering crafts while your tinkering skill is not maxed. | off |
| **Do not process resources. Just craft.** | Skips the resource step when a queue starts: no resource tally and no fuel buying. The bot just crafts with what you have. It still looks up which station each recipe needs. | off |
| **Skip Fuel Merchant** | Never walks to the fuel merchant to buy missing fuel. | off |
| **Do NOT load recipes on startup** | Opening the window no longer reads your recipe book automatically. It is read when a run or Rescan needs it. | off |

## Crafting Options tab - commissions and server calls

| Control | What it does | Default |
|---|---|---|
| **Accept commissions** | When someone opens a commissioned-work window on you and accepts the terms, the bot accepts too and crafts it.<br>*Only while the craft window is open (`ogre craft` until `ogre end craft`); Craft Lite alone does not accept.* | off |
| **Only from characters in your account list** | Only accepts commissions from characters in your saved account list (the same list that may send the bot chat commands). Off = anyone who opens a commission on you is accepted. | on |
| **Allow recipe-info server call (required to craft)** | Lets the bot ask the game server for a recipe's station and component list (the station and list are remembered per recipe; how many you have is read each time a queue is planned). Off: a queue stops because it cannot plan resources. With 'Do not process resources' ticked it still crafts, but skips any recipe whose station it has not remembered yet.<br>*Turning it off shows an orange warning at the top of the window.* | on |

## Navigation tab

| Control | What it does | Default |
|---|---|---|
| **Use OgreNav (Recommended)** | Walk to stations and merchants with OgreNav's navigation mesh.<br>*Both boxes on = OgreNav first, then a straight line if OgreNav cannot get there. Both off = the bot never moves and skips anything out of reach.* | on |
| **Use direct line (Recommended)** | Walk in a straight line to the station or merchant. | on |
| **Use the closest station** | On = the nearest station that can make the recipe. Off = the first one in the order the station list gives. | on |
| **[SCRIPTERS] Use EVENTS to manage movement yourself** | For script writers: before walking, craft fires an event and waits for your script to move the character (or hand the walk back).<br>*Leave off unless you have a script that answers it - otherwise craft waits until you press Stop or untick this box.* | off |

## Writs tab

| Control | What it does | Default |
|---|---|---|
| **Writ Count** | How many rush-order writs to do in one run. 1 to 200. | 10 |
| **Writ Option** | Which reply to click at the rush order agent, counted from the top (1 to 4). It is a position, not a level - if you get the wrong tier of writ, change it. | 1 |
| **Camp when finished writs** | Camps to the desktop when a writ run ends by itself (finished or failed).<br>*Never camps after you press Stop, or after a death.* | off |
| **Start Writs** | Starts the writ run. Your setup queue is put aside during the run and given back at the end.<br>*Greyed out while anything is running. Needs tradeskill level 20+.* |  |

## Auto Tinkering tab

| Control | What it does | Default |
|---|---|---|
| **Recipe Count** | How many of the chosen tinkering recipe to craft each round. 1 to 50. | 10 |
| **Auto Sort Recipe list** | On = each round crafts your highest tinkering recipe. Off = it uses your own Recipes-tab filter and crafts its highest-level recipe (with the Name sort ticked: the name last in the alphabet, which is the bottom of the list, not the top). | on |
| **Sell to a vendor what is crafted** | Sells the items the run made. | on |
| **Destroy what is crafted (selling wins if both are set)** | Destroys the items the run made. If Sell is also ticked, they are sold instead. | off |
| **Sell/Destroy after each round instead of at the end** | On = get rid of the items after every round. Off = keep them until the run ends, then sell/destroy them all in one trip. | on |
| **Start Auto Tinkering** | Repeats rounds (buy tinkering books, craft, sell/destroy) until tinkering is maxed.<br>*Greyed out while anything is running.* |  |

## Low Level Leveling tab

| Control | What it does | Default |
|---|---|---|
| **Recipe Count** | How many of the chosen recipe to craft each round. 1 to 20. | 5 |
| **Auto Sort Recipe list** | On = each round crafts your highest standard recipe at or below your level. Off = it uses your own Recipes-tab filter and crafts its highest-level recipe (with the Name sort ticked: the name last in the alphabet). | on |
| **Sell to a vendor what is crafted** | Sells the items the run made. | on |
| **Destroy what is crafted (selling wins if both are set)** | Destroys the items the run made. If Sell is also ticked, they are sold instead. | off |
| **Sell/Destroy after each round instead of at the end** | On = after every round. Off = once at the end of the run. | on |
| **Start Low Level Leveling** | Levels a crafter from 1 to 9 and from 10 to 19. It stops at level 9 and at 19 - go see a crafting trainer, then start it again.<br>*Greyed out while anything is running.* |  |

## What the window shows

- Status text (green, top): what the bot is doing, e.g. 'crafting <recipe>', 'waiting for power', 'scanning recipes'; 'idle' when nothing runs.
- Crafted N of M: the running queue's progress, or the last run's totals once it has ended.
- Orange banner 'Recipe info is gated off...': you turned off the recipe-info server call on the Crafting Options tab.
- Red banner 'settings.json is unreadable...': the settings file is damaged; the bot runs on defaults and will not overwrite it.
- Red banner with any other text: the last error, e.g. 'craft queue: the setup queue is empty - add recipes first.'
- Recipe list: at most 200 rows are shown; the line under it says how many recipes match in total.
- Footer: recipes indexed from your book, reaction arts cast, server type (live / Origins), Craft Lite on (green) or off (red).

## Good to know

- `ogre end craft` is not just 'close the window' - it stops the run, craft's movement, a summoned station and Craft Lite.
- Start Queue moves the setup queue into the Active queue, so the setup queue looks empty afterwards. Load 'LastRecipeQueue' to get it back.
- The list shows at most 200 recipes. Narrow it with the filters or the search box if the one you want is missing.
- Clear Queue has no confirmation.
- Buy recipes / Scribe recipes only happen during writs and the two leveling loops, not during Start Queue.
- The [SCRIPTERS] events box makes craft wait for a script before every walk. Without a script, the run just waits until you press Stop or untick the box.
- Accepting commissions with 'Only from characters in your account list' off accepts a commission from anyone.

# Craft Grandmasters

> **:bulb: In game - the ? button on this window says**
>
> Turns the (Master) spell scrolls in your bags into (Grandmaster) crafts, one craft per scroll.
>
> **What you can do here**
>
> - **All levels**, or untick it and set a recipe **Level** range.
> - **Also pull from Scroll Depot** withdraws matching scrolls from the depot first, in batches that fit your bags.
> - **Scan** shows what would be crafted. **Start** queues it and crafts it. **Stop** ends the run.
>
> **Good to know**
>
> - Start adds to Ogre Craft's setup queue, so anything already there is crafted too.
> - With the depot box ticked, Scan only looks in the depot; Start withdraws. Withdrawn scrolls are never put back.
> - It never walks - stand at the Scroll Depot for a depot run.

**Open it:** Type `ogre craftgm`. `ogre craftgm 131-135` opens it with that level range already filled in (it does not scan). `ogre end craftgm` stops a run and closes the window.

## What it is for

Turns (Master) spell scrolls into (Grandmaster) crafts. It looks through your bags for every spell scroll named '... (Master)', works out the matching '... (Grandmaster)' recipe, and queues one craft per scroll you hold. Then it starts the Ogre Craft queue and watches until it is done. You can limit it to a range of recipe levels, and it can first pull (Master) scrolls out of your Scroll Depot.

## Status readout

State is what it is doing (idle, reading your recipe book, opening / withdrawing from the Scroll Depot, scanning your bags, starting the queue, crafting). Level filter is the range in use. Admits shows how many found recipes the range lets through, e.g. '3 of 6 recipe(s) (4 of 9 craft(s)) [2 outside] [1 no level]' - orange when some levels could not be read. Queued, Crafted and Recipe book are the run's progress; Last is the latest message.

## Level range

| Control | What it does | Default |
|---|---|---|
| **All levels** | Ticked = craft every Grandmaster found, whatever its level. Untick to use the two level boxes.<br>*Nothing is sent when you tick it; the range is used the next time you press Scan or Start.* | on |
| **Level** | The lowest RECIPE level to craft (inclusive). 1 to 999.<br>*Only used when All levels is unticked. Locked while a run is going.* | 131 |
| **to** | The highest recipe level to craft (inclusive). 1 to 999.<br>*A range typed backwards (e.g. 135 to 131) is refused, not swapped.* | 135 |

## Scroll Depot

Once a Scan or Start has run with the box ticked (ticking it alone does not show it), a grey box shows the depot progress: which batch, how many (Master) scrolls the depot holds and how many your range admits, how many fit in your bags this batch, and how many were withdrawn.

| Control | What it does | Default |
|---|---|---|
| **Also pull from Scroll Depot** | Before looking in your bags, withdraw (Master) scrolls that your range admits from the Scroll Depot, as many as fit in your free bag slots. After crafting those it goes back for the next batch, until the depot has none left or nothing more fits.<br>*Stand next to the Scroll Depot - it never walks. Scrolls withdrawn and not crafted stay in your bags; it never puts them back. The setting stays as you left it for the next run.* | off |

## Scan, Start, Stop, Refresh

| Control | What it does |
|---|---|
| **Scan** | Looks through your bags and fills the table with what the range would craft. It queues and crafts nothing.<br>*With Also pull from Scroll Depot ticked, Scan also opens the Scroll Depot and shows what a Start would withdraw - it withdraws nothing.* |
| **Start** | Scans, adds every admitted Grandmaster recipe to the Ogre Craft setup queue (one craft per scroll held), starts the craft queue and watches it to the end.<br>*Refused if an Ogre Craft run is already going. Anything already in the setup queue is crafted too. Recipes you have not learned are skipped and marked 'not in your recipe book'.* |
| **Stop** | Stops the run. If this window started the craft queue, that is stopped too; a craft run somebody else started is left alone.<br>*Only active while a run is going. The window stays open.* |
| **Refresh** | Redraws the window. It changes nothing. |
| **Title bar close (X)** | Closes the window only - a run keeps going. `ogre end craftgm` closes it and stops the run. |

## The scan table

One row per (Master) scroll found: the scroll, the Grandmaster recipe it becomes, how many you hold (= how many crafts), the recipe's level ('?' if it could not be read from your recipe book), and what happened to it: queued, not in your recipe book, outside the level range, or level could not be read.

## What the window shows

- Dot and phase (top right): green dot = running.
- Orange 'Recipe levels unavailable' note: shown when no level could be read for any scroll found; with a level range set, none of them will be queued.
- Rows marked 'outside the level range' or 'level could not be read' are not queued. With All levels ticked every row is admitted, even one with an unknown level.
- 'Nothing scanned yet - press Scan.' before the first scan; 'No (Master) spell scrolls found in your bags (N carried item(s) scanned).' when there are none.

## Good to know

- Start adds to Ogre Craft's setup queue, so anything already waiting there gets crafted in the same run.
- With the Scroll Depot box ticked, Scan only looks in the depot; Start withdraws. Withdrawn scrolls are never put back.
- Withdrawn scrolls that are not crafted (not learned, out of range) stay in your bags.
- It never walks: stand at the Scroll Depot for a depot run. If it is not nearby the run stops and does nothing (it does not quietly fall back to bags only).
- A range typed backwards (e.g. 135 to 131) is refused - the run does not start. A blank or 0 box is filled in for you instead (Level becomes 1, to becomes the Level value).
- The run has no time limit while crafting; use Stop if it is stuck.

# Crafting Mats

> **:bulb: In game - the ? button on this window says**
>
> Edits the shopping lists `ogre craftingmats` uses: the mats it pulls from the Harvesting Supply Depot and the fuel it buys.
>
> **What you can do here**
>
> - **Pick a list** (one per expansion) and a **category**.
> - **Change an amount** in its box, or remove a row with the x.
> - **Add an item**: type the name (or use **Item name via examine window**), set how many, then **Add to mats** or **Add to fuel**.
> - **+ new list** and **+ category** use the name in the item name box.
> - **Save** writes your changes; **Revert** throws them away (on a new list you never saved, it discards the list).
>
> **Good to know**
>
> - Amounts are how many to be holding, not how many to add.
> - Your changes go in your own folder; the shipped lists are never changed.
> - Removing a row from a shipped list stops that list getting future updates.
> - Closing the window keeps unsaved changes; switching to another list throws them away.

**Open it:** Type `ogre craftingmats` (or `ogre cmats`) with nothing after it. With options (e.g. `ogre craftingmats -sig -vov`) it RUNS instead: pulls those mats out of the Harvesting Supply Depot and buys the fuel. `ogre end craftingmats` closes the window.

## What it is for

Edits the shopping lists that `ogre craftingmats` uses. Each list (one per expansion, e.g. vov = Visions of Vetrovia) has categories such as signature, daily or weekly, and each category has Mats (withdrawn from the Harvesting Supply Depot) and Fuel (bought from the Guild Fuel Merchant), each with the amount you want to be holding. Your edits are saved to your own folder; the shipped lists are never changed, and a Save is used by the very next run.

## Choosing a list

One button per list. A small badge says where it comes from: no badge = the shipped list, 'merged' = the shipped list with your changes on top, 'custom' = a list only you have.

| Control | What it does |
|---|---|
| **List buttons (cd, ka, mm, pop, vov, ...)** | Opens that list for editing. Unsaved changes to the list you were on are thrown away. |
| **+ new list** | Starts a new list of your own. Type its short name in the item name box first - that name is what you will type after `ogre craftingmats` to use it. The new list gets one category, 'all'.<br>*With the name box empty it only shows a message.* |

## Choosing a category

| Control | What it does |
|---|---|
| **Category buttons (signature, daily, weekly, all ...)** | Shows that category's Mats and Fuel below. An 'all' category is always used, whatever categories a run asks for. |
| **+ category** | Adds a category named whatever is in the item name box to this list.<br>*A run can only ask for signature, daily or weekly (and always uses 'all'), so a category with any other name is never used by `ogre craftingmats`. With the name box empty a message says where to type the name; a name the list already has just selects that category.* |

## Mats and Fuel

Left: materials withdrawn from the Harvesting Supply Depot. Right: fuel bought from the Guild Fuel Merchant. The number is how many you want to be HOLDING - a total, not an amount added each time.

| Control | What it does |
|---|---|
| **Quantity box on a row** | Changes that item's amount. It is applied when you press Enter or click away.<br>*0, blank or text is ignored and the old number comes back.* |
| **× (remove this row)** | Removes the item from this category.<br>*Removing something from a shipped list turns your saved copy into a full replacement (see below).* |

## Adding an item

| Control | What it does | Default |
|---|---|---|
| **item name** | The item's name, exactly as the game spells it (capitals do not matter). Also used as the name for + new list and + category. | empty |
| **Item name via examine window** | Copies the item name from the examine window you have open into the name box.<br>*Examine the item in game first; otherwise a red message says no examine window is open.* |  |
| **Quantity (next to the name)** | How many of the item to hold. | 1 |
| **Add to mats** | Adds the item to the Mats side of the selected category. If it is already there, its amount is replaced with the new one. |  |
| **Add to fuel** | Same, on the Fuel side. |  |

## Save and Revert

The grey text shows the folder your edits are written to.

| Control | What it does |
|---|---|
| **Revert** | Throws away unsaved changes and shows the list as it is on disk. On a brand-new list you have not saved yet, there is nothing on disk to go back to: Revert discards the new list and says so.<br>*Only active when there are unsaved changes.* |
| **Save** | Writes your changes to your own folder (OgreSave/EQ2/CraftingMats/custom) and reloads the lists, so the next `ogre craftingmats` run uses them. Only what you changed is written, so later updates to the shipped list still reach the rest. If your changes match the shipped list exactly, your file is deleted.<br>*Only active when there are unsaved changes.* |
| **Title bar close (X)** | Closes the window. Unsaved changes are kept: the next time it opens they are still there, with a reminder to Save or Revert. Without unsaved changes the list is read fresh from disk.<br>*`ogre craftingmats` while the window is already open does nothing.* |

## Removing a row from a shipped list

Your saved file can only ADD to or CHANGE a shipped list. The moment you remove a row (or category) that came with the shipped list, this orange warning appears: Save will then write the whole list as a full replacement ('noMerge'), and that list will no longer pick up future shipped updates.

## What the window shows

- Badges on list buttons: none = shipped, 'merged' = shipped plus your changes, 'custom' = your own list.
- Green line after Save: 'saved - only your changes were written, so shipped updates still reach the rest.' Red when something went wrong or after a replacement save.
- Orange warning: you removed a row, so Save will write a full replacement.

## Good to know

- Plain `ogre craftingmats` opens this window. Add options (like `-sig -vov`) to actually pull mats; `ogre craftingmats help` lists them.
- Amounts are totals to hold, not top-ups.
- Removing any row from a shipped list stops that list getting future shipped updates.
- Switching to another list throws away unsaved changes without asking. Closing and reopening the window keeps them.
- + new list and + category take their name from the item name box. A run only ever uses the signature, daily, weekly and all categories, so a category with another name does nothing.
- A new list is not in the list buttons until you Save it.

# Auto-Login

> **:bulb: In game - the ? button on this window says**
>
> Builds auto-login profiles: which character goes into which session. Start makes your sessions match the profile and loads OgreBot on each character once it is in the world.
>
> **What you can do here**
>
> - **Profiles** - click one to open it. **+ New** starts a blank one; **Import** copies your old OgreBot profiles.
> - **Character rows** - pick the PC (ThisUplink), the session (is1, is2, or any) and the character.
> - **Settings** - the game to launch and the pauses between launches and logins (in tenths of a second).
> - **Save** the profile, **Delete** the one selected in the list, or make a **Desktop shortcut** that runs it.
> - **Start** runs the selected saved profile. Tick **Dry run** to only list what it would do.
>
> **Good to know**
>
> - Saving over an existing profile needs **Overwrite** ticked.
> - Start runs the saved profile, so Save first.
> - No passwords are stored; characters must be in your saved account list.

**Open it:** Type `ogre autologin`. `ogre end autologin` closes it.

## What it is for

Auto-Login builds **profiles**: a named list of which character goes into which InnerSpace session. Press **Start** and InnerSpace itself (the uplink, not the game window) makes your sessions match the profile: characters already in the right place are left alone, a wrong character is camped out, missing sessions are launched, and each character is logged in with a pause between logins. Once a character is in the world, OgreBot is loaded for it. Profiles hold no account names or passwords; those come from your saved account list when the profile runs, so a profile is safe to share.

## Profiles list

Your saved profiles, in name order. The number after a name is how many characters it has. A red name with a warning sign is a profile file that could not be read.

| Control | What it does | Default |
|---|---|---|
| **Click a profile** | Opens that profile on the right so you can check it, change it, start it or delete it.<br>*Clicking a red (broken) profile only shows why it could not be read, in the log at the bottom.* |  |
| **+ New** | Clears the right side for a brand new profile: no name, one character row (ThisUplink, any), and the default settings.<br>*Nothing is saved until you click Save.* |  |
| **Import** | Copies your auto-login profiles from the old OgreBot into this window. It reads the old bot's AutoLoginProfiles.xml and AutoLoginSettings.xml (in Scripts\EQ2OgreCommon\OgreAutoLogin) and writes one new profile per old one. The log shows how many were written, skipped or failed.<br>*The old bot's timing settings are copied into every imported profile. Characters not in your saved account list are counted as warnings but still imported.* |  |
| **Overwrite on import** | When ticked, Import replaces a profile you already have with the same name. When not ticked, those are skipped and your existing profile is kept. | off |

## Profile name

| Control | What it does | Default |
|---|---|---|
| **Profile name** | The name of the profile. Save uses it. The file on disk is named after it, with anything that is not a letter or number turned into an underscore.<br>*Spaces are fine. Renaming a saved profile and clicking Save moves it to the new name.* | empty |

## Character assignments

One row per character. Each field is pick-or-type: click it for a list, or type anything. Typing narrows the list.

| **Session** | Which InnerSpace session the character must be in: is1, is2 and so on. "any" means any session is fine: if the character is already in the world somewhere it is left alone, otherwise a free session is used or a new one is launched.<br>*The list offers any and is1 to is24. Left empty, it saves as any.* | any |
| **Character** | The character to log in. The list shows the characters in your saved account list.<br>*A character that is not in your saved account list gets a warning when the profile runs, because its account cannot be looked up.* | empty |

At the opening window size these buttons are below the fold: scroll the right side down to reach Start.

# Inventory Manager

> **:bulb: In game - the ? button on this window says**
>
> Tidies your bags: deposit to depots, sell, destroy, transmute or salvage (TSE), restock from depots, trade to players, and fill your quiver.
>
> **What you can do here**
>
> - **Run tab** - Look shows in the console what a mode would do; Run starts it. While something runs, Run becomes Queue.
> - **Sell list / Destroy list** - double-click a left row to add it; right-click a right row to remove it.

>
> - The bag boxes on the Destroy list and TSE tabs decide which bags those runs touch.

**Open it:** Type `ogre im` (or `ogre inventorymanager`). Any `ogre im` command that starts work (for example `ogre im sell` or `ogre im -depot -sell -end`) also opens it. `ogre end im` stops the work and closes it.

## What it is for

The Inventory Manager (IM) tidies your bags. # TaskRunner Lists

> **:bulb: In game - the ? button on this window says**
>
> Builds the lists TaskRunner works through: which characters it logs in, in what order, and which timed chores each one does. Run a list with `ogre taskrunner -list <list>` (`run <list>` works too).
>
> **What you can do here**
>
> - **Run** - starts the selected list on this session (save first). The bar shows what it is doing: which character, which chore, and the last result. **Stop** stops it and leaves the character where it is.
> - **List** - click the box and type to find a list (they are in alphabetical order). Type a name that is not a list yet and pick **+ New list** (or press Enter) to make it.
> - **New / Duplicate / Rename / Delete** act on the selected list. Duplicate copies the members, their order and the run mode.
> - **Click a character** on the left to add it to the selected list. Use the **search** box to find a character or account. In **By account**, right-click an account and pick **Add all toons** (or open it and press **Add all**) to add the whole account - anyone already in the list is skipped.
> - **Drag the grip** at the left of a member to change the order the list runs in.
> - **Chore buttons** on a row turn a chore on or off for that character. The **Everyone in** row does it for the whole list.
> - **When run** - **Keep looping** (stays running and picks chores up as they come due - leave it overnight) or **One pass** (does what is due now, then stops).
> - **Stagger start** - each session waits before its first login (is2 30 seconds, is3 60 seconds, and so on). Leave it on when one command starts lists on every session, or the server turns some logins away.
> - **Chore options** - one row per chore. **Guild hall first** travels to the guild hall unless the character is already in one or in a house. **Harvest depot after** puts all harvests into the nearest harvest depot afterwards. **Bushels** (Plant): the harvest gives a bushel - leave it packed, take the latest reward (a new expansion is picked up on its own), or a chosen reward number. A bushel is lore, so the plant is never harvested while one is still in the bags - with "leave it packed" that character skips the plant until you unpack it. (Pack Pony always loads OgreBot first - it reads its answers from your profile.)
> - **Save** writes your changes (what you set by hand in your own TaskRunner files is kept). **Discard** throws them away and reads the files again.
>
> **Good to know**
>
> - Never run two lists that share a character on two sessions at once.
> - A character's chores are the same in every list they are in.
> - **Overseer** never logs a character in by itself: it runs when the character is logged in for another chore (the pack pony). Its status says "next login" while it waits.
> - A character in a raid is never logged out: the run stops and leaves everyone where they are.
> - A character that cannot do a chore at all (no Pack Pony) is marked with an error and skipped until you clear it: `ogre taskrunner clear <name>`.
> - Closing the window loses unsaved changes without asking.

**Open it:** Type `ogre taskrunner panel` (or `ogre tr panel`). `ogretaskrunner panel`, `gui` or `config` also open it.

## What it is for

TaskRunner logs your characters in one after another and does their timed chores, such as the Artisan's Pack Pony and the Goblin House Plant. This window builds the named lists it works through. Pick characters from the ones you have a stored login for, put them in a list, and choose which chores each one does. Then run a list in one session with `ogre taskrunner run <list>`. Nothing is written until you press Save.

## Header

| Control | What it does |
|---|---|
| **Refresh roster** | Reads your stored logins again, so characters you have added since the window opened show up on the left.<br>*Your unsaved list edits are kept.* |

## Lists

Each list name is a button showing how many characters are in it. The highlighted one is the list you are editing.

| Control | What it does | Default |
|---|---|---|
| **<list name> (list button)** | Picks which list you are editing on the right. | the first list |
| **new list name (placeholder)** | Type a name here for Add list or Rename. Pressing Enter does the same as Add list.<br>*One word, no spaces or quotes, up to 40 characters: you type it after `ogre taskrunner run`.* | empty |
| **Add list** | Makes a new, empty list with the typed name and selects it.<br>*A name that is already used (in any letter case) is refused with a red message.* |  |
| **Rename** | Renames the selected list to the name typed in the box.<br>*Does nothing if the box is empty.* |  |
| **Delete** | Deletes the selected list. The characters keep their chore choices.<br>*No confirmation, but nothing is written until Save; Discard brings it back.* |  |

## Your characters (left side)

Every character you have a stored login for, with its account and server. 'in 2' means the character is already in two lists; those rows are dimmed.

| Control | What it does | Default |
|---|---|---|
| **All toons** | Shows every character in one alphabetical list. Display only. | on |
| **By account** | Groups the characters under their accounts. Display only. | off |
| **Click a character** | Adds that character to the end of the selected list. A character new to TaskRunner starts with every chore turned on.<br>*A character already in the list gets a red 'already in' message. With no list yet you are told to make one first.* |  |
| **Click an account (By account view)** | Opens the account to show its characters. Click again to close it. Display only. | all closed |
| **Add all** | Adds every character on that account to the selected list. Characters already in it are skipped.<br>*Only shown on an opened account.* |  |

## How the list runs, and chores for everyone

| Control | What it does | Default |
|---|---|---|
| **Keep looping** | When this list runs, it keeps going: it does everything due, then waits and picks up chores as they come due again. For leaving it on overnight. |  |
| **One pass** | When this list runs, it does what is due right now for each character, then stops. |  |
| **Default (loop) / Default (once)** | The list follows the general TaskRunner setting. The word in brackets is what that setting is now.<br>*Typing `ogre taskrunner run <list> once` or `... loop` still overrides this for that run.* | selected (the shipped setting is loop) |
| **<chore> (Everyone in <list>: row)** | Gives that chore to every character in the list. If everyone already has it (lit up), a click takes it away from everyone instead. 'partial' means only some have it.<br>*The message line says how many characters actually changed.* |  |

## List members (right side)

The characters in the selected list, in the order they are logged in.

| Control | What it does | Default |
|---|---|---|
| **<chore> (on a character row)** | Turns that chore on (lit up) or off for just this character.<br>*A character's chores are the same in every list they are in.* | on for a newly added character |
| **▲** | Moves the character one place earlier in the login order. |  |
| **▼** | Moves the character one place later in the login order. |  |
| **Remove** | Takes the character out of this list. Their chore choices are kept in case you add them again. |  |
| **Tidy** | Forgets the chore choices of characters that are no longer in any list.<br>*Nothing is written until Save.* |  |

## Warnings, messages, Save and Discard

| Control | What it does |
|---|---|
| **Save / Save *** | Writes your lists and chore choices to OgreSave/EQ2/TaskRunner/custom/lists.json, and TaskRunner starts using them straight away. Only what differs from your other TaskRunner files is written, and anything you set by hand for a character there (a chore's own timer, or switching the character off) is kept. 'Save *' means there are unsaved changes.<br>*Greyed out when nothing changed. If a list is running right now, the new lists are used when that batch ends.* |
| **Discard** | Throws away every unsaved change and reads the lists again from the files on disk (so a hand edit made while the window was open shows up). |
| **Title bar close (X)** | Closes the window. Unsaved changes are lost: opening it again reads the saved lists.<br>*There is no 'unsaved changes' prompt.* |

## What the window shows

- List buttons: the list name and how many characters are in it. The highlighted one is being edited.
- Left side: your characters with account and server. 'in N' = in N lists already (row dimmed). A yellow 'dup' = that name is on more than one account, and TaskRunner cannot tell which one you mean.
- Right side heading: the list name, how many characters, and 'run order' - characters are logged in top to bottom.
- Character row badges: yellow 'also in N' = the character is in other lists too (hover to see which). Red 'no login' = there is no stored login for that name, so TaskRunner cannot log it in.
- Chore buttons: lit up (the theme colour, green by default) = the character does that chore, plain = it does not. Each button shows the chore's name, e.g. Artisan's Pack Pony and Goblin House Plant (the shipped ones).
- Yellow warnings above the footer: a character in two lists, an empty list, a character with no stored login, or a character with every chore turned off.
- The message line: green for what your last click did, red when it was refused and why.

## Good to know

- Never run two lists that share a character on two sessions at the same time. The window warns you, but nothing stops it.
- Chore choices belong to the character, not the list: turning a chore off for Kannkor in one list turns it off in every list Kannkor is in.
- Nothing is saved until you press Save. Closing the window loses unsaved changes without asking. Typing the open command again while the window is open does nothing (your edits stay).
- The left side only lists characters with a stored login. If it is empty, set up your logins first, then press Refresh roster.

Click **By account**, then click an account to open it. **Add all** puts every character on that account into the selected list.

## Before your first list

![No lists yet](../assets/trlists/empty.png)

Type a name in the box and press **Add list**, then click characters on the left to fill it.

# Watcher

> **:bulb: In game - the ? button on this window says**
>
> Two small alert tools. **Find** tells you when a named creature or NPC shows up in your zone. **Track Shiny** tells you when a shiny of one colour appears near you. When one turns up it drops a waypoint and tells your other sessions.
>
> **What you can do here**
>
> - **Add** a name to watch, or add the **-rorr** preset (the four epic ability researchers).
> - **Click the idle pill** next to Find or Track Shiny to turn it on or off.
> - **Scan now** checks the zone once for every name on the list and writes what it finds in Hits (no waypoint).
> - **Colour**: click the shiny colour to track. Purple is chosen to start with.
> - **Clear log** empties the Hits list.
>
> **Good to know**
>
> - Names must match exactly: "Wanderer" will not find "The Wanderer". Find is silent in a guild hall.
> - Closing the window does not stop either tool. Set them back to idle, or type `ogre end find` / `ogre end trackshiny`.
> - Open this window with `ogre watcher`.

**Open it:** Type `ogre watcher`. `ogre find -panel` and `ogre trackshiny -panel` open the same window.

## What it is for

The Watcher has two small tools in one window. **Find** watches for named creatures or NPCs: when one on your list appears in your zone, you get a message, an in-game waypoint on it, and every other session is told. **Track Shiny** looks for a shiny (a harvestable collectible) of one colour within 100 metres of you and does the same when a new one shows up. Both keep working after you close the window.

## Header

| Control | What it does |
|---|---|
| **Clear log** | Empties the Hits list below. It does not change the watch list or turn anything off. |
| **Title bar close (X)** | Closes the window only. Find and Track Shiny keep running if they are armed.<br>*To stop them, click the armed pills to idle first.* |

## Find - the watch list

Names must match the whole name exactly (capital letters do not matter). "Wanderer" will not match "The Wanderer".

| Control | What it does | Default |
|---|---|---|
| **idle / armed (pill next to Find)** | Turns Find on or off. When you turn it on it also checks the zone once for anything already on your list. While on, a listed name that appears gets a message, a waypoint and a note to your other sessions; one that leaves gets a DISAPPEARED line.<br>*With an empty list it stays idle and the console says "nothing to watch - add a name first". The on/off choice is remembered after a restart.* | idle |
| **Actor name (exact)... (placeholder)** | Type a creature or NPC name to watch. Pressing Enter does the same as Add. | empty |
| **Add** | Adds the typed name to the watch list. It does not turn Find on.<br>*A name already on the list is not added twice.* |  |
| **+ -rorr preset** | Adds the four Renewal of Ro researchers (the NPCs that upgrade your epic abilities): The Wanderer, Filowen Curetouch, Angrus Silentfang and Balkot Stonefury.<br>*Only names not already on the list are added. It does not turn Find on.* |  |
| **Scan now** | Checks the zone once, right now, for every name on the list. Each one found is added to Hits as a FOUND line with its location.<br>*Works even while Find is idle. A scan result is a Hits line only: no waypoint and no message to other sessions. It also works in a guild hall.* |  |
| **Clear list** | Removes every name from the watch list and turns Find off.<br>*No confirmation.* |  |

## Find - names and hits

| Control | What it does |
|---|---|
| **x (remove name)** | Removes that one name from the watch list.<br>*Removing the last name turns Find off.* |

## Track Shiny

| Control | What it does | Default |
|---|---|---|
| **idle / armed (pill next to Track Shiny)** | Turns Track Shiny on or off. While on, it looks around you (100 metres) every half second for a shiny of the chosen colour. When it finds a new one it adds a line to Hits, puts a waypoint on it and tells your other sessions. The same shiny is only reported once. The on/off choice is remembered after a restart. | idle |
| **Colour (White / Green / Purple / Red / BlueShimmer / Blue buttons)** | Which shiny colour to look for. Click a colour; the lit one is in use.<br>*Changing the colour clears Last seen. It does not turn tracking on.* | Purple |

## What the window shows

- Hits: the latest 50 alerts, newest at the bottom. FOUND = seen by a scan. APPEARED = a listed name just showed up. Both are green. DISAPPEARED = it left (grey). "Purple shiny!" = a shiny of that colour was found (yellow). The number after Hits is how many lines there are.
- The pills: green 'armed' means that tool is on; grey 'idle' means it is off.
- polls every 500 ms: how often Track Shiny looks around. It can be changed with `ogre trackshiny -interval <ms>` (250 to 30000).
- Last seen: the name and location of the last shiny found.
- The footer is a fixed reminder of how names and shinies are matched.

## Good to know

- Find names must match exactly. "Wanderer" does not find "The Wanderer".
- Find alerts are silenced while you are in a guild hall. Scan now still works there.
- Closing the window does not stop anything. Set both pills to idle to stop watching, or type `ogre end find` / `ogre end trackshiny`. Opening it again while it is already open does nothing.
- The watch list, colour and on/off choices are saved and come back after a restart. The Hits list is not saved.
- Typing `ogre find <name>` in the console REPLACES the whole watch list with that name and turns Find on. Use the Add box to add a name instead.
- Track Shiny only looks 100 metres around you.

# Ability Export

> **:bulb: In game - the ? button on this window says**
>
> Makes the ability file OgreBot needs to cast your abilities, by reading your knowledge book one ability at a time.
>
> **What you can do here**
>
> - **Choose what to include**: passives, ascension abilities, a minimum tier or level range, or just a few named abilities.
> - **Merge** into the file you have, write a **Fresh file**, or add **Only abilities I don't have yet** (much faster).
> - **Tradeskill export instead** makes the files Ogre Craft uses.
> - **Run export** starts it. This window steps aside while it runs; the small Exporting Abilities window shows progress and can stop it.
>
> **Good to know**
>
> - A full export takes a while. OgreBot reloads your abilities when it finishes, unless it was a dry run or you ticked **Don't reload OgreBot when finished**.
> - `ogre export -start` runs with the options set here, without opening this window.
> - Your choices are saved as you make them.
> - If none of the abilities in **Just these abilities** is found, nothing is exported and the top line says so.

**Open it:** Type `ogre export` (or `ogre abilityexport`); typing it again while the window is open does nothing. `ogre export -start` runs an export straight away with the options set in this window, without opening it. `ogre export -default -start` does the same with the default options. `ogre end export` closes the window.

## What it is for

OgreBot needs a list of your character's abilities to cast them. This window makes that list: it reads your knowledge book, one ability at a time, and writes the file OgreBot loads. You pick what to include, then press Run export. While it runs, this window steps aside and the small Exporting Abilities window shows progress. When it finishes, OgreBot reloads your abilities and cast stack from the new file (unless you turn that off).

## Top row

The yellow text left of the buttons is the result of the last thing you did (for example 'Export finished.', 'Export stopped - nothing was written.' or 'Options reset to defaults.').

| Control | What it does | Default |
|---|---|---|
| **Help** | Shows or hides a short explanation under every option. Display only - changes what you see, not what the bot does.<br>*The explanations are the same plain-language text as this page.* | off |
| **Reset** | Puts every option back to its default and saves that straight away. |  |
| **Run export / Run (dry run) / Run cache action / Running…** | Starts the export with the options shown. The label tells you what will happen: 'Run (dry run)' when nothing will be written, 'Run cache action' when you picked a cache action that does not export. While the export runs this window steps aside; the small Exporting Abilities window shows the progress and has the Stop button.<br>*Greyed out while the red 'can't run' box is showing, and while an export is already running.* |  |
| **Title bar close (X)** | Closes this window. It does not stop an export that is already running. |  |

## What to export

| Control | What it does | Default |
|---|---|---|
| **Include passive abilities** | Adds your passive abilities to the file. They are left out unless you tick this.<br>*Has no effect on a tradeskill export.* | off |
| **Tradeskill export instead** | Exports ONLY your tradeskill abilities, for Ogre Craft, instead of your combat abilities. It writes up to three files (your crafting class, plus tinkering and adorning if you have them) into the EQ2OgreCraft TSExports folder.<br>*It opens and closes the Examine window once per ability - leave the game window alone while it runs.* | off |
| **Skip ascension abilities** | Leaves your ascension abilities out of the file.<br>*Cannot be ticked together with 'Ascension abilities ONLY' - the window refuses to run.* | off |
| **Ascension abilities ONLY** | Exports nothing but your ascension abilities. | off |
| **Include effect descriptions** | Keeps each ability's effect text in the file. Untick for a smaller file. OgreBot works out what an ability does either way. | on |

## Minimum tier

Pick one. Only abilities at or above the chosen tier are exported.

| Control | What it does | Default |
|---|---|---|
| **All tiers** | Exports every tier. | selected |
| **Journeyman+** | Leaves out Apprentice abilities. |  |
| **Adept+** | Keeps Adept and higher. |  |
| **Expert+** | Keeps Expert and higher. |  |
| **Master+** | Keeps Master and higher. |  |
| **Grandmaster+** | Keeps Grandmaster and higher. |  |

## Level range

| Control | What it does | Default |
|---|---|---|
| **Minimum level** | Skips abilities whose class level is below this number. 0 means no minimum.<br>*AA and ascension abilities count as level 0, so any minimum above 0 drops all of them (the window warns you).* | 0 |
| **Maximum level** | Skips abilities whose class level is above this number. 999 means no maximum.<br>*Must be a whole number and not below the minimum, or the window refuses to run.* | 999 |

## Export file

| Control | What it does | Default |
|---|---|---|
| **Merge into existing export** | Starts from the file you already have and adds or updates abilities in it. Abilities not rescanned this time are kept.<br>*On a tradeskill export, only the recorded highest tradeskill level carries over - the ability list is rebuilt from this run.* | selected |
| **Fresh file (replace)** | Ignores the file you already have and writes a brand-new one from this run only. |  |
| **Only abilities I don't have yet** | Merges, but skips every ability already in your file without looking it up again. The quick way to add newly learned abilities.<br>*Abilities already in the file are not refreshed.* |  |
| **Dry run (do not write)** | Does the whole scan but writes nothing, and OgreBot is not reloaded.<br>*The category cache (below) is still updated.* | off |
| **Don't reload OgreBot when finished** | Normally, when an export finishes, OgreBot reloads your abilities and cast stack from the new file. Tick this to leave them as they are. | off |

## Category cache

The cache only makes exports faster: it remembers which abilities an export would throw away anyway, so they are not looked up again. It never changes what ends up in the file. Leave it on Normal unless something is wrong.

| Control | What it does | Default |
|---|---|---|
| **Normal (load + use + record)** | Uses the shared cache and adds anything new it learns. | selected |
| **Consolidate, then export** | Folds the cache notes your other sessions left into the main cache first, then exports as normal. Normally only the first session (is1) does this. |  |
| **Consolidate only (no export)** | Folds the other sessions' cache notes into the main cache and stops. No export runs.<br>*Run it after your other characters have exported.* |  |
| **Clear the cache (no export)** | Empties the cache and stops. No export runs. The next normal export rebuilds it.<br>*Only needed if the cache has gone bad.* |  |

## Just these abilities

| Control | What it does | Default |
|---|---|---|
| **Ability names or IDs** | Leave blank to export everything. Otherwise type ability names (spelled as in your knowledge book) or ability ID numbers, separated by commas or new lines, and only those are exported. With 'Merge' the rest of your file is kept as it was.<br>*Names that are not found are listed on the console. If none of them is in your knowledge book, nothing is exported and the window's top row says so.* | empty |

## What the window shows

- Grey text next to each option (like -passive) is the matching script word, for the command at the bottom. Display only.
- Yellow 'Heads up' box: things worth knowing about the options you picked. You can still run.
- Red 'These options can't run' box: something must be fixed first. Run export is greyed out until it is.
- Green command line: the same export as a one-line script command (ISXOgreEQ2.Export:Abilities[...]). Display only.
- Saves to: where the file will be written - normally OgreSave/EQ2/OgreBot/AbilityExports/V3_<name>_<class>_<server>_AbilityExport.json. For a tradeskill export it shows the folder instead ('up to 3 files in').
- Footer: a reminder that `ogre export -start` skips this window.

## Good to know

- A full export looks up every ability one at a time and takes a while. 'Only abilities I don't have yet' is much faster.
- Every option change is saved as you make it, so the window opens the same way next time.
- `ogre export -start` uses the options set in this window. `ogre export -default` (without -start) shows the defaults here without saving them - they are saved as soon as you change an option or press Run export.
- Stopping an export (Stop, or closing the small progress window) writes nothing - the old file is untouched, and this window's top row says 'Export stopped - nothing was written.'
- If none of the abilities in 'Just these abilities' is in your knowledge book, nothing is exported and the top row says so. Names that are not found are listed on the console.
- Typing `ogre export` while this window is open does nothing.
- Options file: OgreSave/EQ2/OgreBot/AbilityExports/export-gui.json. Delete it to go back to defaults.

### While an export runs

Pressing Run export hides this window and opens the small **Exporting Abilities** window (see its own page). When the export ends, this window comes back with the result in the top row.

# Exporting Abilities

> **:bulb: In game - the ? button on this window says**
>
> Shows the progress of an ability export. It opens by itself when an export starts and closes by itself when it ends.
>
> **What you can do here**
>
> - **Watch progress**: the ability being read, how many of your abilities have been looked at, and how many were kept or skipped.
> - **Stop** ends the export. Closing this window does the same.
>
> **Good to know**
>
> - Stopping writes nothing - your old ability file is left as it was.
> - On a tradeskill export the Examine window opens and closes for each ability. Leave the game window alone until it finishes.

**Open it:** Opens by itself when an ability export starts - from Run export in the Ability Export window, or `ogre export -start`. It closes by itself shortly after the export ends.

## What it is for

A small progress window for an ability export. It shows which ability is being read, how far through the list the export is, and how many abilities were kept or skipped. It is the only way to see (and stop) an export while it runs - the big Ability Export window steps aside until the export ends.

## Progress

Top line: the ability being read right now. It says '(cached)' for an ability the export already knows it would skip, so it is not looked up again, and 'Complete' on the last frame.

| Control | What it does |
|---|---|
| **Stop** | Stops the export. Nothing is written - your old file stays as it was - and OgreBot does not reload its abilities. If the big Ability Export window stepped aside for the export, it comes back. |
| **Title bar close (X)** | Closing this window also stops the export, exactly like Stop.<br>*The window closes itself about a second and a half after a finished export - that does not stop anything.* |

## What the window shows

- Top line: the ability being read, '(cached)' for one the export skips without a lookup, 'Starting…' before the first one, and 'Complete' at the end.
- n / total: abilities looked at so far out of all the abilities in your knowledge book.
- The bar: the same progress as a percentage.
- added · skipped: how many abilities this run kept for the file, and how many it passed over (passives, wrong tier or level, not in your selection, and so on). With 'Only abilities I don't have yet', the ones already in your file count as skipped - they stay in the file.

## Good to know

- The count is every ability in your knowledge book, not just the ones that end up in the file - most exports skip a lot of them.
- On a tradeskill export the game's Examine window flickers open and shut for each tradeskill ability. Leave the game window alone until it finishes.
- When the export finishes, OgreBot reloads your abilities and cast stack from the new file (unless you ticked 'Don't reload OgreBot when finished' or ran a dry run).
