# OgreBot Manager

> **:bulb: In game - the ? button on this window says**
>
> The main OgreBot window. Every bot setting for this character lives here, one tab per topic.
>
> **What you can do here**
>
> - **Pick a tab** on the left. Your class has its own tab. Struck-through tabs are not finished yet.
> - **Change a setting** - it takes effect right away.
> - **Save** writes this profile to disk. **Reload** throws away unsaved changes and reads the profile again.
> - **Search** finds a setting on any tab by its name.
> - **Profiles** tab - load, create, delete or set the default profile. A new profile copies the current one as last saved.
> - **Right-click a setting** to copy its name (for commands) or send it to your group.
>
> **Good to know**
>
> - A yellow star (*) in the title bar means there are unsaved changes. Closing OgreBot without saving loses them.
> - The X stops OgreBot. **Hide Main** on the small OgreBot window just hides this one.
> - Hover a setting or button to see what it does.

**Open it:** Type `ogre`. OgreBot loads running, with this window hidden: click **Show Main** on the small OgreBot window to see it (if the character's ability export is missing or out of date, the window is shown instead so you see the export prompt). `ogre -p` loads OgreBot paused with this window shown. `ogre end bot` closes OgreBot.

## What it is for

This is the main OgreBot window. Every bot setting for this character lives here, one tab per topic. The window opens on the Settings tab. A change takes effect as soon as you make it, but it is only kept if you press Save. Your settings are grouped into profiles (for example Solo and Raid), and the Profiles tab switches between them. This page covers the frame of the window: the header, the tab list, searching, right-click and the Profiles tab. Each settings tab has its own page.

## Title bar

The title bar has the usual ? (help), lock and X buttons. When the profile has changes that are not saved yet, a yellow star (*) appears next to them.

| Control | What it does | Default |
|---|---|---|
| *** (yellow star)** | Shows that this profile has changes that are not saved yet. It appears on the small OgreBot window too. It goes away after a Save or a Reload.<br>*It counts every change, including ones made by commands or encounter scripts, not only clicks in this window.* | hidden |
| **Title bar close (X)** | Shuts OgreBot down completely, not just this window. Both OgreBot windows close. The Unload tab's list runs. Camp spot, follow and other movement are cleared, HUDs go away, travel routes and codex scans stop, and the profile is unloaded. Unsaved changes are thrown away and a warning is printed in the console.<br>*To get the window out of the way without stopping the bot, use Hide Main on the small OgreBot window instead.* |  |

## Header: class, profile, Save and Reload

| Control | What it does |
|---|---|
| **<Class> MANAGER** | Your class, for example BERSERKER MANAGER. It is the class of the character whose profile is loaded. |
| **Profile: <name>** | The name of the profile that is loaded right now. |
| **Save** | Asks 'Save current settings to <profile>?', then writes the loaded profile to disk. A message at the bottom says 'Profile saved', or 'No changes to save' if there was nothing to write.<br>*Nothing is saved automatically. Close OgreBot without saving and your changes are gone.* |
| **Reload** | Throws away unsaved changes and reads the profile from disk again. The cast stack and every tab are refreshed. Settings that run when a profile loads run again.<br>*It only asks first if you changed something in this window. Changes made by commands or scripts are dropped without asking.* |

## Search

Type part of a setting's name to find it on any tab. The list shows each match with the tab it lives on, and you can change the setting right there in the list.

| Control | What it does | Default |
|---|---|---|
| **Search (Search options...)** | Lists every setting, on every tab, whose name contains what you type (upper or lower case does not matter). Each match shows its tab name, for example '↪ Settings'. Click the tab name to jump to that tab, where the setting flashes.<br>*It searches setting names, not tab names. Settings for another archetype are not shown.* | empty |
| **x (clear search)** | Clears the search and shows the tab you were on. Esc in the search box does the same. Clicking any tab also clears the search. |  |

## The tab list

The tabs down the left are in three blocks. At the top: Auto Target, Cast Stack, Settings, Setup, then your class tab. In the middle: every other tab, A to Z. At the bottom: Admin, Debug, EQ2Chars, Key Binds, OgreConsole, Profiles, Relay Groups and Uplink Info. Each block is in A to Z order, except that the class tab is always last in the top block.

| Control | What it does | Default |
|---|---|---|
| **A tab (click)** | Shows that tab's settings on the right. The tab you are on is outlined. | Settings |
| **A struck-through tab (for example Auto-Hunt, Crowd Control)** | Not finished yet. Some of its settings do nothing yet, even though you can change and save them. That tab's own page says which ones work. The tab itself also says NOT FINISHED at the top. |  |

## Your class tab

One tab is named after your class (Berserker in the picture). It holds the options that only your class has. If your class has none, the tab says so.

| Control | What it does |
|---|---|
| **<Your class> tab** | Options for your class only. Each class's options are described on the class tab pages.<br>*It follows the class of the loaded profile's character.* |

## Hover text

| Control | What it does |
|---|---|
| **Hover a setting or a struck-through tab** | After a short pause a box explains what the setting does, or why a tab is struck through.<br>*Buttons and list rows all over the window have hover text too - for example why a greyed Delete cannot be used, and what the yellow star means.* |

## Right-click a setting

Right-click a checkbox, text box, dropdown or slider to get two extra choices. They are not offered for lists or buttons.

| Control | What it does |
|---|---|
| **Copy <setting name>** | Copies the setting's internal name (for example checkbox_settings_disablecaststack) to the clipboard. That is the name commands and scripts use, such as `-ChangeOgreBotUIOption`. |
| **Apply this to my group (igw) via OC** | Sends this setting, with the value it has here, to everyone in your group, you included. If the For Who window is open, it goes to whoever that window has picked instead, and by IRC if it is set to IRC. If that window has nobody or everyone picked, it still goes to your group.<br>*Other characters get the change in memory only. They still have to Save.* |

## Profiles tab

A profile is a complete set of settings. One character can have several, for example Solo, Raid and Heroic Duo, and switch between them. The line at the top says which profile is loaded and whether you have unsaved changes. Each profile has a row with three buttons, and under the list you can make a new profile.

| Control | What it does | Default |
|---|---|---|
| **Loaded: <name>** | The profile in use right now. '• unsaved changes' is added whenever the profile has changes that are not saved - the same thing the yellow star shows, including changes made by commands or encounters. |  |
| **A profile row** | One row per profile. The loaded one is outlined and tagged LOADED. |  |
| **Default** | Makes this the profile OgreBot loads when it starts. The current default's button is lit up and does nothing when clicked. | the profile named Default, on a new character |
| **Load** | Switches to this profile. Every tab and the cast stack change to its settings. If the profile has unsaved changes, it asks first, because they are thrown away.<br>*Greyed out on the profile that is already loaded.* |  |
| **Delete** | Asks 'Permanently delete <name>? This cannot be undone.', then removes the profile from disk.<br>*Greyed out on the loaded profile and on the default profile. You also cannot delete a character's last profile.* |  |
| **New profile name... (box)** | Type a name for a new profile. Press Enter or click Create. | empty |
| **Create** | Makes a new profile that is a copy of the loaded one as it was last saved, and saves it to disk at once. You stay on the profile you had. Load the new one to use it.<br>*Unsaved changes are not copied: Save first if the copy should include them. Names are not case-sensitive, so 'raid' is refused if 'Raid' exists.* |  |
| **Confirm box: OK / Cancel** | Save, Reload, Load and Delete ask here first. OK goes ahead (red for Delete). Cancel does nothing. |  |

## What the window shows

- The header shows your class and the loaded profile's name.
- A yellow * in the title bar means there are unsaved changes.
- Struck-through tabs are not finished: some of their settings are saved but do nothing yet.
- A message at the bottom of the window confirms things like 'Profile saved' or 'Loaded profile <name>'.

## Good to know

- Changes take effect at once but are not saved until you press Save. Closing OgreBot (the X on either OgreBot window, or `ogre end bot`) throws unsaved changes away.
- The X does not just hide the window, it stops OgreBot. Use Hide Main on the small OgreBot window to hide it.
- Commands and encounter scripts change settings too. They turn on the star, but Reload and Load only ask before throwing away changes you made in this window.
- All of a character's profiles are kept in one file, normally `Scripts\OgreSave\EQ2\OgreBot\Profiles\Main\<server>_<character>.json`. Back that file up to keep your profiles safe.

# Auto Target

Auto Target lets the bot pick its own targets from a list, instead of assisting someone. Tick 'Enable Auto Target' and build the working list: each row says what to target (a name, NPC, Named or an actor ID) plus optional health limits and aggro rules. About three times a second the bot goes down the list from the top, and the first row that matches any nearby mob wins; it targets that mob, or keeps your current target if it also matches that row. The left half of the editor builds a row (type or fill the name, set the HP sliders and tick boxes, press Add actor). The right half is the working list, and under it the lists saved for this zone, which you can load, save and delete. The collapsed Balance generator at the bottom adds a ladder of rows that spreads your damage across up to three mobs.

## Auto Target

| Option | What it does | Default |
|---|---|---|
| **Enable Auto Target** | The bot picks its own targets from the working list below instead of assisting. It targets the first nearby match for the highest row on the list, and keeps your current target if it matches that same row.<br>*While on, the Assist tab list is ignored.* | off |
| **Allow Out of Combat Scanning** | Lets Auto Target pick a target while nothing is fighting you. Unticked, it only picks once a mob has aggro on you or you are in combat.<br>*It only stops new picks; your current target is kept.* | off |

## General Options

| Option | What it does | Default |
|---|---|---|
| **Scan Radius:** | How far Auto Target looks for targets, measured straight-line around you. | 0 (counts as 50) |
| **Rescan time (MS):** | Not used by the new bot. Auto Target re-checks every 0.25 seconds whatever this says - a fixed rate, fast enough for every fight. | 0 |
| **Scan Height:** | Only mobs whose height differs from yours by less than this are considered, so mobs on a floor above or below are ignored. | 0 (counts as 5) |
| **Auto-Target List Editor** | The editor below: build rows on the left, the working list and this zone's saved lists on the right, and the Balance generator underneath. | empty |

## Add an actor

| Control | What it does | Default |
|---|---|---|
| **Actor name / NPC / Named / id** | What this row matches. Any part of a name matches (not case-sensitive). 'NPC' means any ordinary mob, 'Named' any named mob, and a number matches that one actor ID.<br>*Add actor does nothing while this box is empty.* |  |
| **NPC** | Puts 'NPC' in the name box: match any ordinary (not named) mob. |  |
| **Named** | Puts 'Named' in the name box: match any named mob. |  |
| **Current target** | Puts your current target's name in the name box. Nothing is added until you press Add actor.<br>*With nothing targeted you get the message 'AutoTarget: no current target'.* |  |
| **Target by ID** | Puts your current target's actor ID in the name box, so the row matches only that one spawn. |  |
| **Min. HP To Target:** | Only match mobs whose health is at or above this percent. 'any' (0) means no lower limit. | any |
| **Max. HP To Target:** | Only match mobs whose health is below this percent. 'any' (0) means no upper limit.<br>*At 100, a mob at full health does not match, because it must be below the value.* | any |
| **[CC] Check Collision** | Only match mobs you have a clear line of sight to. | off |
| **[AG] Aggro On Ally Only** | Only match mobs that are targeting someone in your group. | off |
| **[ANF] Aggro On Non Fighter Only** | Only match mobs that are targeting a player who is not a fighter class. | off |
| **[ANMe] Aggro On Not Me** | Skip mobs that are targeting you. | off |
| **Add actor** | Adds a row with these settings to the bottom of the working list; the bot uses it straight away. While editing a row it adds a NEW row, leaves the edited one alone and keeps your settings in the form. |  |
| **Update actor** | Only while editing: replaces the selected row with these settings and leaves edit mode. |  |
| **Cancel** | Only while editing: leaves edit mode without changing the row and clears the form. |  |

## Working list

| Control | What it does | Default |
|---|---|---|
| **Working list — what the bot auto-targets (N)** | The rows Auto Target uses right now, top first. Each row shows its number, the name ('(any)' if blank), the health range ('HP any' or e.g. 'HP 20–80', ∞ for no upper limit) and badges for the ticked options (CC, AG, ANF, ANMe). | empty |
| **Drag a row** | Drag a row up or down to change its priority. |  |
| **Click a row's name** | Loads that row into the form on the left for editing; the row is highlighted. |  |
| **Double-click a row** | Switches that row off or back on. A switched-off row is struck through and skipped, but keeps its place. |  |
| **✎ (edit)** | Loads that row into the form for editing, the same as clicking its name. |  |
| **✕ (remove)** | Removes that row from the working list. |  |
| **Clear** | Empties the working list at once, with no confirmation, and removes the '(loaded)' mark. Your saved lists are not touched.<br>*With the working list empty, the bot falls back to the profile's own auto-target list, if it has one.* |  |

## Saved lists

| Control | What it does | Default |
|---|---|---|
| **Saved lists for <zone>** | The lists saved for the zone you are in. The one currently in the working list is shown in green with '(loaded)'.<br>*They are stored per zone in Scripts\OgreSave\EQ2\OgreBot\AutoTarget\autotarget_<zone>.json; the old bot's lists are read if the new folder has none.* | empty |
| **▶ (load)** | Copies that saved list into the working list, replacing what was there. The bot uses it straight away. |  |
| **✕ (delete)** | Deletes that saved list from this zone's file, after you confirm. |  |
| **Save current list as…** | The name to save the working list under. It starts with the name of the list you loaded. |  |
| **💾 Save list** | Saves the working list to this zone's file under the typed name. A saved list with the same name is overwritten.<br>*Nothing happens if the name box is empty.* |  |

## Balance generator

| Control | What it does | Default |
|---|---|---|
| **▸ Balance generator — staggered HP ladder across up to 3 actors** | Click to open or close the Balance generator. It adds rows that make the bot switch between up to three mobs as their health drops, so they go down together. |  |
| **#1 / #2 / #3 + Actor name 1-3** | Up to three mob names. Only ticked rows are used; typing a name ticks its box for you.<br>*A ticked row with no name gives an error message and is left out.* |  |
| **step %** | How many percent of health between one row and the next.<br>*Must be 1 or more.* | 5 |
| **Alternating** | The mobs take turns down one shared ladder: #1 at 95, #2 at 90, #3 at 85, #1 at 80, and so on. | selected |
| **Static** | Every mob gets a row at every step: all at 95, all at 90, all at 85, and so on. |  |
| **Check collision** | Gives every generated row the [CC] Check Collision option. | off |
| **Aggro on ally only** | Gives every generated row the [AG] Aggro On Ally Only option. | off |
| **Generate list** | Adds the generated rows (each with a minimum HP) to the bottom of the working list. It does not replace or save anything; check the rows, then use Save list. |  |

## Good to know

- While Auto Target is on, the Assist tab is ignored completely.
- With 'Allow Out of Combat Scanning' unticked, the bot picks nothing until a mob has aggro on you or you are in combat. Your current target is never dropped by this.
- The working list lasts for this game session only. It survives zoning, but not a restart, and the Save button at the top does NOT save it. Use 'Save list' to keep it.
- If the working list is empty, the bot falls back to the auto-target list stored in your profile, if the profile has one (for example from an old bot profile).
- Saved lists belong to one zone. Loading one never happens by itself: after zoning, the old working list stays until you load or clear it.
- A name matches any part of a mob's name, not case-sensitive, so 'orc' also matches 'an orc pawn'. It can match players too; pets never match.
- 'NPC' matches only ordinary mobs, not named ones. Use 'Named' for named mobs, or add both rows.
- Row order is priority. Disabling a row (double-click) keeps its place, so you can switch it back on without rebuilding the order.
- Auto Target only works while the bot is running, not while paused.
- Rescan time is not used: the list is always re-checked every 0.25 seconds, which is fast enough for every fight.

# Cast Stack

The Cast Stack is the bot's main casting list. Every turn the bot walks the Cast order from the top and casts the FIRST entry that is allowed right now, so the order is your priority. The tab has three columns. Abilities (left) lists this character's abilities plus your registered items; click one to start a new entry. The entry editor (middle) sets the entry's Type, Target and optional conditions and options; only fields marked with a red * are required, and the fields shown change with the ability and the Type you pick. Press Add to put it at the bottom of the Cast order, ↑ Top to put it at the top, or Place and then click a row to put it just above that row. The Cast order (right) shows every entry coloured by its Type: click an entry to select it and open it in the editor, double-click to switch it off, drag an entry to move it, and click ▶ to see its settings. The filter above the Cast order shows only the entries that match any mix of their own settings and their ability's export fields, and the Enable / Disable buttons switch what it shows (or what you selected) on or off together. Ctrl+click or Shift+click entries to select several, then drag any one of them to move them all. Edits reach the running bot at once, but press Save at the top to keep them.

## Abilities (left column)

| Control | What it does |
|---|---|
| **Search abilities** | Type part of a name to show only matching abilities and items. The ✕ at the right clears the search. |
| **↔** | Makes the Abilities column wider or narrower. Hovering a cut-off name shows it in full. |
| **Ability or item names** | Click one to start a new entry. A green name already has an entry in the Cast order. Ctrl+click a name to filter the Cast order to that ability or item. |

## Entry editor (middle column)

| Control | What it does |
|---|---|
| **↑ Top** | Adds the entry to the TOP of the Cast order instead, so it is checked first. |
| **Place** | Choose where the entry goes: press Place (it reads Placing…), then click any row in the Cast order and the entry is added just above it. Press it again, or Cancel, to stop. |
| **Update** | Shown while editing an existing entry: saves your changes to it. |
| **+ New** | Shown while editing: adds a copy with your changes as a new entry at the bottom, leaving the original as it was. |
| **Cancel** | Throws away what is in the editor without changing the Cast order. |

## Cast order (right column)

| Control | What it does |
|---|---|
| **Filter: [field] [value] Add** | Shows only the Cast order entries that match. Pick a field, then a value: a name or text field takes what you type (it matches anywhere in the text; put it in double quotes, like "Assault", to match the whole text only), a Yes/No field takes TRUE or FALSE, a list field (Type, Target, the tags and roles) offers the values in use, and a number field takes 30, >30, <30, >=30, <=30 or !=30. Every field also takes (set) or (not set). The field list and the value lists have a box at the top: type in it to show only the matching choices, and press Enter to pick the first one. The fields are everything an entry can have (Name, Type, Target, Disabled, Item, every option and flag, the embargo, allow and custom tags) and then every field of the ability's export, listed as Export: ... (for example Export: IsStun, Export: IsAE, Export: RecastTime, Export: Effects - the ability's effect lines). The filter applies as you type or pick, even before you press Add; the ✕ after Add (or picking — (none) as the field) clears it and shows every entry again. Add keeps it and starts another, and every added filter must match. |
| **Added filters** | Each added filter, e.g. Type = CA or Export: IsStun = TRUE. The x removes one; Clear all removes them all. |
| **Enable / Disable shown (N), or selected (N)** | Switches several entries on or off at once. With two or more entries selected it acts on those; otherwise, with a filter on, it acts on every entry the filter shows. The number is how many it would change. The buttons are hidden when there is no filter and no multi-selection, so the whole Cast Stack is never one stray click away from being switched off. |
| **Drag a row** | Press an entry and drag it up or down to change its priority - anywhere on the row; the drag starts once the mouse moves a few pixels, so a click is never taken for a drag. Dragging a selected entry moves every selected entry, kept in their order. |
| **▶ / ▼** | Shows or hides the entry's settings under the row, or '(no options set)'. |
| **Click an entry** | Selects the entry at once and, a moment later (after the double-click wait), opens it in the editor, where Update saves your changes. The entry being edited is always part of the selection: selecting a different entry closes the edit. |
| **Ctrl+click / Shift+click a name** | Ctrl+click adds or removes one entry from the selection; Shift+click selects every entry from the last one you clicked. Selected entries are outlined and the heading counts them. Drag any selected entry to move them all together. A plain click selects just that entry. |
| **Double-click an entry** | Switches the entry off or back on. A switched-off entry is struck through and never cast, but keeps its place. |
| **✕ (remove)** | Removes the entry. The Undo button below can put it back. |
| **↶ Undo remove (N)** | Puts the last removed entry back where it was. It remembers up to 25 removals. |

## Good to know

- Types, in short. Buff: kept up, re-cast when it drops. NonCombatBuff: the same, but only while you are out of combat. Combat: only while the target is in combat. Heal / PowerHeal: when the target's health / power is at or below the HP / Mana %. Cure / CureCurse: when someone has something that ability can remove / a curse. Res: resurrects a dead player. CA and Debuff: attacks on your target; NamedCA and NamedDebuff only on named mobs, NonNamedCA only on non-named mobs. Special / Custom: advanced types that are cast when ready.
- The Type list only offers the types that fit the ability (a resurrection only offers Res, a buff offers Buff or NonCombatBuff). Items offer the 12 basic types. If your ability export is missing, every type is offered.
- Fields appear and disappear with the Type: Target only shows where you can choose one (attacks always go at your target), '# of ppl' / '# of mobs' only for group or area abilities, HP / Mana % only for heals, Savagery only for Beastlords, Diss only for Channelers. Items get Type, Target, HP / Mana %, Requires Item Equipped and the tags.
- When you press Add or Update, values in fields that are hidden for the chosen Type are thrown away.
- If a required field is missing, Add / Update does nothing and a message lists what is wrong.
- Cast order colours: gold = Buff or NonCombatBuff, blue = Combat, light red = CA, red = NamedCA, pink = NonNamedCA, orange = Debuff, dark orange = NamedDebuff, magenta = Res, dark green = Cure, teal = CureCurse, bright green = Heal, cyan = PowerHeal, light cyan = Custom, lavender = Special. Pale yellow means this character does not have that ability (or the item is not in your bags or gear) right now. A switched-off entry keeps its colour but is struck through and dimmed.
- In the Target list, an alias shown in red points at nobody right now (for example @Healer2 with only one healer in the group).
- The Setup tab's '% Health / % Power req. to use CAs' and '% NPC HP to attack' apply to CA and Debuff entries unless the entry has its own My HP, My MP or NPC HP condition.
- The Disable CS_ boxes on the Settings tab switch whole Types off without touching this list.
- Edits apply to the running bot straight away, but only Save (top of the window) writes them to your profile. Reload throws unsaved edits away.
- '+ separator' lines are only for your eyes; the bot skips them.

# Settings

Settings holds the master controls for what the bot is allowed to cast. Column 1 switches whole groups of the Cast Stack off (buffs, heals, cures, combat arts, items, and so on), and holds a few overrides: treating every target as named, the line-of-sight check, and item zone limits. Column 2 sets the area-attack rules (the Smart CAs minimum target counts, plus the "Dynamic Ignore" boxes, which are not saved and which scripts tick and untick during fights) and the per-category bans, such as no stuns or no roots. Column 3 controls Heroic Opportunities (HOs): which HO steps this character does, how it aims them, Heroic Surge, and which HO-icon abilities the normal rotation must leave alone. Column 4 limits threat abilities, but only when the bot picks an ability for a script, a command or an HO. The normal Cast Stack ignores column 4.

Settings covers cures and combat behaviour. Column 1 controls cures: switching group or single-target cures off, limiting cures to chosen types (arcane, elemental, noxious, trauma), and drinking cure potions automatically. Columns 2 and 3 cover how the bot fights: camp spot, assisting, facing the mob, melee and ranged auto-attack, moving behind, in front or into melee range, turning attack off, sending the pet and mercenary, Bulwark of Order, NPC cast monitoring, raid and heroic encounter setups, the stun checks and the Destiny of Velious (DoV) raid debuff. Column 4 holds the on/off switches for other OgreBot tabs: Chat Events, Spawn and Despawn Events, Announce, Consume Items, Aliases and Ability Tracker. Several boxes here are saved but have no effect yet; each is marked 'Not active yet'.

Settings covers the bot's everyday conveniences outside combat. 'Pop up windows' decides which game pop-ups it answers for you: loot windows, looting corpses and chests, group invites, rezzes, zone-in lockout prompts, raid ready checks, dungeon finder prompts and quest offers. 'On Load' covers what happens when a profile loads: opening the On Screen Assistant and OgreMCP, and checking ability research. 'On Zone' covers zone-in behaviour, such as the list of available encounter setups and auto-sharing missions. 'Unorganized' holds the rest: native auto-follow, flying with the leader, Quest Compare and the automatic Overseer. About a third of the boxes on this tab are saved but have no effect yet; each is marked 'Not active yet'.

## Cast Stack (1 of 5)

# Setup

Setup holds the numbers that tune when the bot fights: how hurt a mob must be before you attack it, move to it or send your pet, how much health and power you keep before using attacks, and how many mobs an area attack needs. It also names who the Force Follow command follows. The right-hand column controls how tells and guild chat reach OgreConsole. Blank boxes use the default shown in each description.

## Setup

| Option | What it does | Default |
|---|---|---|
| **% NPC HP to attack** | The bot only attacks a mob once its health is at or below this percent. It covers Cast Stack attacks (CA and Debuff types), moving into combat position, Turn Off Attack and Cancel Invis After Combat.<br>*A Cast Stack entry with its own 'NPC HP' condition ignores this box.* | blank (counts as 100 - any health) |
| **% NPC HP to move into attack range** | The move options on Settings (move behind, in front, or into melee range) only start once the mob's health is at or below this percent. Once movement has started for a fight, it carries on until there is nothing left to attack.<br>*'Ignore NPC HP to move' on Settings skips this check.* | blank (counts as 100 - any health) |
| **% NPC HP for pet to attack** | Your pet and your mercenary are only sent in once the mob's health is at or below this percent.<br>*'Do not send pet to attack' on Settings stops the pet entirely.* | blank (counts as 100 - any health) |
| **% Power req. to use CAs** | The Cast Stack uses no attack abilities (CA and Debuff types) while your power is below this percent.<br>*A Cast Stack entry with its own 'My MP' condition ignores this box.* | blank (0 - no limit) |
| **% Health req. to use CAs** | The Cast Stack uses no attack abilities (CA and Debuff types) while your health is below this percent.<br>*A Cast Stack entry with its own 'My HP' condition ignores this box.* | blank (0 - no limit) |
| **Wait __ 10ths/second to accept RES** | When someone offers you a resurrection and 'Accept Res' on Settings is ticked, the bot waits this long before accepting, in tenths of a second (10 = 1 second). It then accepts only if you are still dead and the offer is still open. | blank (accepts straight away) |
| **Targets for Smart AEs** | How many mobs must be in range before the bot uses a point-blank or targeted area attack, while 'AE Smart CAs' on the Settings tab is ticked.<br>*A Cast Stack entry's own '# of mobs' overrides this.* | blank (counts as 2) |

A single mob never qualifies.<br>*A Cast Stack entry's own '# of mobs' overrides this; a '# of mobs' of 1 always allows it.* | blank (counts as 2) |
| **Melee move when less (40)** | The move options on Settings only move you when the mob is closer than this distance. 'Face mob in combat' only turns you toward mobs within this distance too. | blank (counts as 40) |

Nothing follows automatically; the command has to be sent.* | empty |

# Aliases

An alias is a nickname for one character, so your setup can say `*MainTank` instead of a real name. Type the alias and who it is for, then Add. The bot puts a star in front, so 'MainTank' becomes `*MainTank`, and you use that in a Cast Stack target or in a command's 'for who'. 'For' can be a character name or a class word (a class, subclass or archetype such as Fury or Priest). The bot checks you first, then your group, then your raid, and picks the first character that fits. Aliases only work while 'Enable Aliases' on the Settings tab is ticked.

| Option | What it does | Default |
|---|---|---|
| **Aliases** | Your aliases, in the order they are tried. Drag to reorder, double-click to switch one off, x to delete. The colour shows whether the alias is used on the Cast Stack and whether this row is the one that wins right now. | empty |

## Add an alias

| Control | What it does | Default |
|---|---|---|
| **Alias (e.g. RaidMT)** | The nickname. The bot adds a star in front, so you use it as `*RaidMT`. | empty |
| **For (player / class / role)** | Who the alias means: a character name, or a class word such as a class, subclass or archetype. The first match wins: you, then your group, then your raid.<br>*An alias with an empty For never points at anyone.* | empty |
| **No-Raid** | Only look in your own group for this alias, never the rest of the raid. | off |

## Good to know

- The alias list is drawn by its own code. Each row shows the alias, an arrow, and who it is for; NR means 'no raid'. Drag a row to reorder, double-click a row to switch it off, and the x deletes it (after a confirm).
- Several rows can share one alias name. The first row, from the top, that finds a character in your group or raid wins, so later rows are backups. Drag rows to choose which one is tried first.
- The name colour tells you two things. Green: used on the Cast Stack, and this row is the one the alias points to now. Yellow: used on the Cast Stack, but a different row (or nobody) wins right now. Orange: not used on the Cast Stack, but this row wins. Red: not used on the Cast Stack, and this row does not win.
- With 'Enable Aliases' (Settings tab) off, no alias resolves: every row shows yellow or red and a line above the list says so.
- Adding, removing or switching an alias off takes effect at once, but it is only kept if you press Save at the top.
- An alias picks ONE character. To aim at several characters with one word, use Team Groups (the button under the list) instead.

# Announce

Announce says something, or runs a command, whenever one of your abilities goes off. Each row is an ability, where to send it (Group, Raid, a tell to the target, an in-game command or a console command) and the text. In the text, *Target* becomes the name of whoever the ability was cast on and *Ability* becomes the ability's name. Nothing is announced unless 'Enable Announce Tab' on the Settings tab is ticked.

| Option | What it does | Default |
|---|---|---|
| **Full Ability list** | All of this character's abilities. Click one to choose it for the next announce; its name appears next to the Add button. |  |
| **Announces** | Your announce rows, shown as ability, destination and text. Every switched-on row whose ability matches goes out, at any rank.<br>*Click a row to edit it, double-click to switch it off.* | empty |

## Announce

| Control | What it does | Default |
|---|---|---|
| **Announce To** | Where the text goes. Group: group chat. Raid: raid chat. Tell To Target: a tell to whoever the ability was cast on. In-Game Command: runs the text as a game command, so it must start with /. Execute In Console: runs the text as a console command. | Group |
| **Text to announce** | What to say or run. *Target* becomes the target's name and *Ability* the ability's name.<br>*Case matters: *target* is not replaced, and the row is then skipped.* | empty |
| **Add** | Adds a row for the ability you clicked, with this destination and text. When you are editing a row it says Update and saves your changes to that row instead. |  |

## Good to know

- To add a row: click an ability in the Full Ability list (its name shows next to Add), pick 'Announce To', type the text, then press Add or Enter.
- Click a saved row to load it back into the form; the button then says Update, and Cancel leaves it unchanged. Double-click a row to switch it off, and the x removes it. The list is shown A to Z.
- Instant abilities announce when the bot casts them. Abilities with a cast time announce when they appear on your cast bar, which includes casts you make by hand.
- For a cast you made by hand the bot does not know the target, so a row that uses *Target* or 'Tell To Target' is skipped for it.
- *Target* and *Ability* must be typed exactly like that, with the capitals. A text that still contains them, or contains NULL or ${, is not sent.
- 'In-Game Command' text must start with / (for example `/shout *Ability* is up!`). 'Execute In Console' text must NOT start with /; it runs as a console command, for example an `oc` line.
- Group rows only go out while you are grouped, Raid rows only while you are in a raid.
- Only abilities are listed, not items.

# Ascension

The Ascension tab has one option. Etherflash normally teleports you to your target when it lands. With 'Etherflash - Prevent Port' ticked, the bot targets you yourself just before the cast finishes, so the damage still lands but you do not move. About a second after the cast ends it lets go, and your normal target comes back.

| Option | What it does | Default |
|---|---|---|
| **Etherflash - Prevent Port** | When the bot casts Etherflash, it switches your target to yourself once the cast is over 90% done, so the teleport takes you nowhere. About a second after the cast ends, your normal target returns.<br>*Only for Etherflash casts made by the bot, any rank.* | off |

## Good to know

- It only works when the bot casts Etherflash (for example from the Cast Stack). If you press Etherflash yourself, nothing changes.
- If nothing else is choosing your target (no assist, no auto-target), the bot puts back the target you had before the cast.

# Assist

Assist tells the bot whose fight to join. Pick people (or aliases such as @Tank) from the dropdown and they go into the Assist order list. While the bot is running, it uses the FIRST person on the list who is in your group or raid and in your zone: it targets that player, so your attacks go at whatever they are fighting. With 'Direct Assist Targeting' on Settings ticked, it targets that player's target directly instead. Drag names to change the priority, double-click a name to switch it off, and click x to remove it.

| Option | What it does | Default |
|---|---|---|
| **Choose whom to assist** | Pick a group or raid member, or an alias such as @Tank, to add them to the bottom of the Assist order list. The dropdown then resets; a name already on the list is not added twice.<br>*The choices are refreshed every time you open the dropdown.* | n/a (it adds a name, it stores nothing itself) |
| **Assist order — drag to set priority, double-click to disable** | The people to assist, in priority order. The bot uses the first one who is in your group or raid and in this zone, and ignores the rest until that person is gone.<br>*Disabled names stay in place (struck through) and are skipped.* | empty |

## Assist

| Control | What it does |
|---|---|
| **Drag a row** | Drag a row up or down to change who is assisted first. |
| **Double-click a row** | Switches that name off or back on. A switched-off name is struck through and skipped, but keeps its place. |
| **x (remove)** | Removes that name from the list. |

## Good to know

- The list is used whenever the bot is running and Auto Target is off, even if 'Auto Assist' on Settings is unticked. To stop assisting, disable or remove the names here.
- When 'Enable Auto Target' is ticked on the Auto Target tab, this list is ignored completely.
- An assist set by the `-assist` command takes priority over this list until it is turned off.
- Someone in your group but in another zone is skipped, and the next name down is used.
- Aliases are looked up each time, so @Tank follows whoever is your tank right now. An alias that points at nobody is skipped.
- Changes take effect straight away. Press Save at the top to keep them after a reload.
- Type `ogre assist` to see who the bot is assisting right now and why.
