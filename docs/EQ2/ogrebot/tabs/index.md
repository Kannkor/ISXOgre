# OgreBot Tabs Overview

OgreBot's interface is organized into tabs, each controlling a different aspect of bot behavior. This page provides a quick reference to all available tabs.

---

## Core Tabs

| Tab | Description |
|-----|-------------|
| [Settings](settings.md) | Main bot toggles - combat, healing, buffs, loot, resurrection |
| [Setup](setup.md) | Initial character setup and configuration |
| [Settings 2](settings2.md) | Additional settings and toggles |
| [Assist](assist.md) | Assist target configuration and combat engagement |
| [Loot](loot.md) | Loot rules, filters, and automation |

## Casting Tabs

| Tab | Description |
|-----|-------------|
| [Cast Stack](cast-stack.md) | Ability priority ordering for combat |
| [Pre-Cast](pre-cast.md) | Abilities to cast before engaging combat |
| [Post-Cast](post-cast.md) | Abilities to cast after combat ends |
| [Ascension](ascension.md) | Ascension ability configuration |
| [Ability Embargo](ability-embargo.md) | Temporarily disable specific abilities |

## Targeting & Control

| Tab | Description |
|-----|-------------|
| [Auto Target](auto-target.md) | Automatic target selection rules |
| [Crowd Control](crowd-control.md) | Mez, stun, and crowd control management |
| [Items](items.md) | Item usage during combat (potions, poisons, etc.) |

## Communication & Events

| Tab | Description |
|-----|-------------|
| [Announce](announce.md) | Combat announcements and notifications |
| [Chat Events](chat-events.md) | Respond to chat triggers |
| [Spawn Events](spawn-events.md) | React when NPCs spawn |
| [Despawn Events](despawn-events.md) | React when NPCs despawn |
| [On Zone](on-zone.md) | Actions to perform when zoning |

## Configuration & Management

| Tab | Description |
|-----|-------------|
| [Aliases](../aliases.md) | Target aliases (@Tank, @Healer, etc.) |
| [OSA](osa.md) | Ogre Script Automation |

| [Relay Groups](relay-groups.md) | Communication group setup |
| [Load](load.md) | Load profiles and settings |
| [Unload](unload.md) | Unload the bot |
