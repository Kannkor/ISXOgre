# Load

<!-- TODO: Add screenshot -->

The Load tab determines what settings and actions activate when OgreBot initializes.

## Settings

### Radar on

Enables radar functionality upon bot startup if this option is selected.

### Radar off

Disables radar when the bot loads, provided radar is currently active.

### Executes

Runs specified script commands and other operations during the bot's initialization sequence. This allows you to automate setup tasks that should occur every time OgreBot loads.

### Button test

Validates user-entered key inputs by displaying confirmation messages in the console window to verify proper functionality.
