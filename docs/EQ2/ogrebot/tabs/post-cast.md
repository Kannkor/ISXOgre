# Post-Cast

<!-- TODO: Add screenshot -->

The Post-Cast tab is the inverse of the Pre-Cast tab. It will cast a spell after a specified spell is cast.

## Configuration

The configuration works the same as the Pre-Cast tab, but in reverse order -- you specify a trigger spell and an ability to cast after it.

For additional details about the configuration options, refer to the [Pre-Cast](pre-cast.md) tab documentation.
