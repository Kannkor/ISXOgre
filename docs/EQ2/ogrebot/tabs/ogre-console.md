# Ogre Console

The Ogre Console tab configures the Ogre Console window and IRC settings.

## Ogre Console Settings

| Setting | Description |
|---------|-------------|
| **OgreConsole X Coord** | Sets the X (horizontal) position of the Ogre Console window |
| **OgreConsole Y Coord** | Sets the Y (vertical) position of the Ogre Console window |
| **OgreConsole Width** | Sets the width of the Ogre Console window |
| **OgreConsole Height** | Sets the height of the Ogre Console window |

### Console Visibility Checkboxes

| Checkbox | Description |
|----------|-------------|
| **Show Console on load** | Opens the console window when the bot loads |
| **Hide Console on load** | Hides the console window when the bot loads |
| **Never auto open ogreconsole** | Prevents the Ogre Console from ever opening automatically (not recommended) |

## IRC Settings

These settings are saved globally (not per-profile).

| Setting | Description |
|---------|-------------|
| **Connect to IRC** | Automatically connects to IRC on bot load |
| **OgreIRC uplink name** | The name of your PC for IRC identification |
| **OgreIRC Server** | The name of your IRC server |
| **OgreIRC User** | The user name you use in IRC |
| **OgreIRC Channel** | The name of your IRC channel |
| **OgreIRC Password** | The password for your IRC channel |
