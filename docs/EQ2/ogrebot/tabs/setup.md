# Setup

The Setup tab manages various miscellaneous options that control bot behavior. Many of these settings require corresponding checkboxes on the Settings tab to be enabled in order to take effect.

## Combat Engagement Settings

- **NPC HP threshold for attacking** - Sets the percentage of NPC health at which the bot will begin attacking
- **NPC HP threshold for moving into attack range** - Sets the percentage of NPC health at which the bot will move into attack range
- **Pet engagement HP threshold** - Sets the NPC health percentage at which pets will engage

## Resource Management

- **Mana requirement percentage to use Combat Arts** - Minimum mana percentage required before the bot will use combat arts
- **Health requirement percentage to use Combat Arts** - Minimum health percentage required before the bot will use combat arts (helps prevent deaths from health-draining effects)

## Ability Casting

- **Delay time for accepting resurrections** - Time delay (measured in tenths of seconds) before accepting a resurrection
- **Target count threshold for Smart AoE abilities (Blue)** - Minimum number of targets required before casting blue AE abilities
- **Target count threshold for Smart Encounter abilities (Green)** - Minimum number of targets required before casting green encounter abilities
- **Stealth/invisibility ability configuration** - Configure stealth or invisibility abilities for classes that require stealth prerequisites

## Movement & Following

- **Maximum melee engagement distance** - Maximum distance at which the bot will attempt melee engagement (default: 40)
- **Auto-follow target selection** - Select which character to follow
- **Auto-follow activation range** - Distance at which auto-follow activates (default: 35)

## Communication Features

- **Broadcast unauthorized private tells through Uplink** - Forwards unauthorized tells via the Uplink system
- **Broadcast guild/officer chat through Uplink** - Forwards guild and officer chat via the Uplink system
- **Display broadcast messages on-screen** - Shows broadcast messages as on-screen notifications
- **Audio notification for incoming broadcast tells** - Plays a sound when a broadcast tell is received
