# How to Copy from the Console

You can select and copy text from the InnerSpace console to paste it elsewhere.

---

## Steps

1. Click and hold the **left mouse button** at the start of the text you want to copy
2. Drag your mouse to the end of the text to highlight it
3. Release the mouse button -- the highlighted text is automatically copied to your clipboard
4. Paste it anywhere using **Ctrl+V**

> **:memo: Note**
>
> You do not need to press Ctrl+C. Releasing the mouse button after selecting text automatically copies it.
