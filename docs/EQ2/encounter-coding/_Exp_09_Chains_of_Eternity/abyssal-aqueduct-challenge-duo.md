## Tuatog the Tidal Lord

Setup is automatic when engaged.

### Overview

A fight with tidal wave knockbacks and portal spawns on timers.

### What the Module Does

**Tidal Wave Timer:**

- When Tuatog's Tidal Wave fires, starts a 40-second HUD countdown for the next knockback AE

**Portal Spawn Timer:**

- When a "summon location" actor spawns, starts a 40-second HUD countdown for the next portal

### Player Notes

- Timer-based awareness module with no positioning or movement
