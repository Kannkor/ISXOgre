## K'zan

Setup is automatic when engaged.

### Overview

A fight with color attunement mechanics, a force cure using an inventory item, and a memwipe mechanic.

### What the Module Does

**Color Attunement:**

- When attuned to a color, announces the color via text-to-speech and displays it on the HUD for 12 seconds

**Mental Shield Cure (Unbearable Force):**

- When K'zan's Unbearable Force hits, cancels the current cast and uses the "Mental Shield" inventory item on the affected group member

**Memwipe (Soulshatterer):**

- When the innovative mechanic says "Get over here!", cancels the current cast and uses the "Soulshatterer" inventory item on it

**Soulshard Alert:**

- Announces via text-to-speech when a Soulshard spawns

### Player Notes

- Requires "Mental Shield" and "Soulshatterer" inventory items
