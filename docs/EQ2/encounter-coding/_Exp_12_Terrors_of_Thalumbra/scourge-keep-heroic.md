**Expansion:** Terrors of Thalumbra (Exp 12)

## Available Setups

| Feature | Description |
|---------|-------------|

---

## Rope Usage

### Overview

The zone has ropes that can be used to traverse between areas.

### What the Module Does

**Rope Interaction:**

- Stand next to a rope, then press `Special_ZoneSpecific` in MCP to use it

### Player Notes

- You must be standing next to the rope before pressing the button
