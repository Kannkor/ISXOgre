## Trakanon

Setup is automatic when engaged.

### Overview

A fight with dot-based positioning that swaps characters between two locations.

### What the Module Does

**Dot-Based Positioning:**

- When dotted by Trakanon, moves to the dot spot via campspot
- When the dot clears, returns to the raid spot

### Player Notes

- Positioning is fully automatic based on dot detection
