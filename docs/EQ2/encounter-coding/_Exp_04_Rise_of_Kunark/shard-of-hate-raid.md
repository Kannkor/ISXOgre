# Shard of Hate [Raid]

**Expansion:** Rise of Kunark (Exp 04)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Malevolence](#malevolence) | Auto-targets named based on required tank type |
| [Maestro](#maestro) | Priest self-cure on curse |

---

## Malevolence

Setup command: `Set up for Malevolence`

### Overview

A fight where the boss calls out specific fighter subclasses that must tank.

### What the Module Does

**Tank-Type Targeting:**

- When the boss calls out Brawlers ("brawling insects" or "brawling filth"), Brawlers auto-target the named
- When the boss calls out Crusaders ("Crusading fools" or "crusading zealots"), Crusaders auto-target the named
- When the boss calls out Warriors ("warrior's creed" or "warrior scum"), Warriors auto-target the named
- Targeting switches between the ire mob and Malevolence based on the callout text

### Player Notes

- Only affects Fighter subclasses (Brawler, Crusader, Warrior)

---

## Maestro

Setup command: `Set up for Maestro`

### Overview

A fight where cursed Priests must self-cure.

### What the Module Does

**Priest Self-Cure:**

- When a Priest is cursed, automatically casts cure curse on self

### Player Notes

- Only affects Priests
