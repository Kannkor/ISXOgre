# Plane of Disease: The Source [Heroic]

**Expansion:** Planes of Prophecy (Exp 14)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Blighthorn](#blighthorn) | Hoof Rot jousting with tank/DPS split |
| [Gryme](#gryme) | Auto Bite calf verb to remove stacks |

---

## Blighthorn

Setup is automatic when engaged. Or you can use `Obj_OgreMCP:PasteButton[SetUpFor__,SetUpFor]` to do the set up immediately.

### Overview

A fight with a Hoof Rot joust mechanic.

### What the Module Does

**Hoof Rot Jousting:**

- When Hoof Rot takes hold, all characters shift their camp spot away from the boss
- Camp spot returns to normal when the rot is cured or the character dies from lingering

### Player Notes

- Fighters and non-fighters have separate camp spots

---

## Gryme

Setup is automatic when engaged. Or you can use `Obj_OgreMCP:PasteButton[SetUpFor__,SetUpFor]` to do the set up immediately.

### Overview

A fight where the boss exposes himself and must be exploited.

### What the Module Does

**Auto Bite Calf:**

- When Gryme's calves are exposed, automatically uses the "Bite calf" verb on the boss to remove stacks

### Player Notes

- The verb is applied automatically for all characters when the window opens
