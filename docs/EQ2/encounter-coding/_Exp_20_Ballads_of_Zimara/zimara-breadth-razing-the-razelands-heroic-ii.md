## Doda K'Bael / Queen Era'selka

Setup is automatic when engaged. Or you can use `Obj_OgreMCP:PasteButton[SetUpFor__,SetUpFor]` to do the set up immediately.

### Overview

A fight with the Auriac Toxin detriment that requires Intercept to be used on the affected player.

### What the Module Does

**Auriac Toxin:**

- Detects the Auriac Toxin detriment on a player
- Automatically requests Intercept on the affected player

**Ability Management:**

- Intercept and Guardian are managed in the cast stack for proper usage during the fight

### Player Notes

- Intercept is handled automatically when Auriac Toxin is detected
- Make sure Intercept is available for use
