# Zimara Breadth: Strungstone Ascent [Heroic II]

**Expansion:** Ballads of Zimara (Exp 20)

This heroic zone contains 2 boss encounters.

## Available Setups

| Boss | Description |
|------|-------------|
| [Barlanka](#barlanka) | Auto intercept |
| [Fuejenyrus](#fuejenyrus) | Auto intercept |

---

## Barlanka

Setup is automatic when engaged. Or you can use `Obj_OgreMCP:PasteButton[SetUpFor__,SetUpFor]` to do the set up immediately.

### Overview

A fight with the Test of Magic detriment that requires Intercept to be used on the affected player.

### What the Module Does

**Test of Magic:**

- Detects the Test of Magic detriment on a player
- Automatically requests Intercept on the affected player

### Player Notes

- Intercept is handled automatically when Test of Magic is detected
- Make sure Intercept is available for use
