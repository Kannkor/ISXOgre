## Mungo the Misshapen

Setup is automatic when engaged. Or you can use `Obj_OgreMCP:PasteButton[SetUpFor__,SetUpFor]` to do the set up immediately.

### Overview

A fight with a curse mechanic triggered by a text message.

### What the Module Does

**Fungal Aroma:**

- Detects the "They have a fungal aroma like no other" text trigger
- Automatically requests a cure curse

### Player Notes

- Cure curse is handled automatically when the text trigger is detected
