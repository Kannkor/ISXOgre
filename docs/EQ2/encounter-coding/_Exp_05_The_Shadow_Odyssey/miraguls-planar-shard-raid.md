# Miragul's Planar Shard [Raid]

**Expansion:** The Shadow Odyssey (Exp 05)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Qxectus](#qxectus) | Curse-based statue positioning |
| [Miragul](#miragul) | Archetype-specific wand usage on debuff |

---

## Qxectus

Setup is automatic when engaged.

### Overview

A fight with curse-based movement to and from a statue.

### What the Module Does

**Curse-Based Positioning:**

- When "a shadowy bolt strikes", non-cursed characters navigate to the statue
- When "Cursed and turned into a CUBE", non-cursed characters navigate away from the statue
- Uses navigation waypoints for movement

### Player Notes

- Movement is nav-based, not campspot-based

---

## Miragul

Setup is automatic when engaged.

### Overview

A fight with archetype-specific debuff handling using the Aubraks Wand of Shifting.

### What the Module Does

**Archetype-Specific Wand Usage:**

- Fighters and Scouts with the physical debuff use "aubraks wand of shifting"
- Priests and Mages with the arcane debuff use "aubraks wand of shifting"
- While cursed, no action is taken (waits for curse to clear)

### Player Notes

- Requires "aubraks wand of shifting" inventory item
- Same item for all archetypes, but the triggering debuff differs
