## Dagarn

Setup is automatic when engaged.

### Overview

A fight with a curse notification mechanic.

### What the Module Does

**Curse Notification:**

- When cursed with the Dagarn curse detriment, calls out "Need a cure curse!" in group chat
- Only calls out once per curse application to prevent spam

### Player Notes

- Call-out only, no positioning or movement
