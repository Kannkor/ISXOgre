# Lyceum of the Recondite [Heroic]

**Expansion:** Destiny of Velious (Exp 07)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Ovilas Ironwing](#ovilas-ironwing) | Add management with role-based positioning |
| [Arch-Necranaut Yolth](#arch-necranaut-yolth) | Fighter add targeting |

---

## Ovilas Ironwing

Setup is automatic when engaged.

### Overview

A fight with add management and role-based repositioning.

### What the Module Does

**Add Management (Blistered Soul Sphere):**

- When the add spawns, fighters target it and move to a separate position
- Non-fighters move to a different safe spot
- When the add despawns, fighters retarget the boss

### Player Notes

- Positions shift automatically during add phases

---

## Arch-Necranaut Yolth

Setup is automatic when engaged.

### Overview

A fight with fighter add targeting.

### What the Module Does

**Add Targeting:**

- Fighters automatically target the reanimated eradinaut add when it spawns
- Retargets the boss when the add despawns

### Player Notes

- Fighter-only mechanic, other roles unaffected
