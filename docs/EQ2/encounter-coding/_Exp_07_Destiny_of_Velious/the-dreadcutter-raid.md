# The Dreadcutter [Raid]

**Expansion:** Destiny of Velious (Exp 07)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Zzalazziz](#zzalazziz) | Troubador add splitting |
| [Tuzerk](#tuzerk) | AE timer |

---

## Zzalazziz

Setup command: `Set up for Zzalazziz`

### Overview

A fight with troubador-specific add handling.

### What the Module Does

**Troubador Add Splitting:**

- When tempest mage adds spawn, troubadors are split by even/odd sorting
- Even troubadors move to the left mage spawn; odd troubadors move to the right
- Returns to camp after 4 seconds

### Player Notes

- Troubadors are automatically split between add spawn points

---

## Tuzerk

Setup command: `Set up for Tuzerk`

### Overview

A fight with an AE timer.

### What the Module Does

**AE Timer:**

- Tap Veins — 60-second HUD countdown

### Player Notes

- Timer-only module with positioning
