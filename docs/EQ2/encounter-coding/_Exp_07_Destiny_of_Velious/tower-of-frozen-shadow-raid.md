# Tower of Frozen Shadow [Raid]

**Expansion:** Destiny of Velious (Exp 07)

This zone has 3 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Necretia Widowmaker](#necretia-widowmaker) | Cocoon clicking, corpse targeting |
| [Corpsemonger](#corpsemonger) | Automated corpse destroying |
| [Cara](#cara) | Navigation trigger |

---

## Necretia Widowmaker

Setup is automatic when engaged.

### Overview

A fight with automated cocoon clicking and corpse targeting.

### What the Module Does

**Cocoon Clicking:**

- When a quivering cocoon spawns, immediately attacks it

**Corpse Targeting:**

- When a Half-Drained Corpse spawns, fighters target it

### Player Notes

- Cocoon interaction is fully automated

---

## Corpsemonger

Setup is automatic when engaged.

### Overview

A fight with automated corpse destroying.

### What the Module Does

**Corpse Destroying:**

- Scans for mostly drained corpses within 20 meters
- Automatically applies "Destroy Corpse" on corpses that reach 0% health

### Player Notes

- Corpse destruction is automatic when in range

---

## Cara

Setup is automatic when engaged.

### Overview

A fight with a navigation trigger.

### What the Module Does

**Navigation Trigger:**

- When the player is below a certain height threshold, triggers navigation to the boss area

### Player Notes

- Minimal automation module
