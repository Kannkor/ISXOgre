# Zavith'loa: The Molten Pools [Raid]

**Expansion:** Altar of Malice (Exp 11)

This zone has 3 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Teraradus the Gorer](#teraradus-the-gorer) | Mighty roar HUD warning |
| [Kerridicus Searskin](#kerridicus-searskin) | Lava titan timer, auto-joust |
| [Crumbling Icon](#crumbling-icon) | Add spawn timer |

---

## Teraradus the Gorer

Setup is automatic when engaged.

### Overview

A fight with a mighty roar mechanic that requires jousting.

### What the Module Does

**Mighty Roar Warning:**

- HUD warning "JOUST!" shown for 15 seconds when the roar is being prepared
- HUD confirmation when the roar hits (5 seconds)

### Player Notes

- No automatic joust -- the HUD provides warnings for manual jousting

---

## Kerridicus Searskin

Setup is automatic when engaged.

### Overview

A fight with lava titan adds that trigger jousting.

### What the Module Does

**Lava Titan Tracking:**

- HUD timer showing 45 seconds until next lava titan spawn

**Auto-Joust:**

- When a lava titan spawns, automatically jousts the raid out

### Player Notes

- Jousting is automatic when raid options are enabled

---

## Crumbling Icon

Setup is automatic when engaged.

### Overview

A fight with periodic add spawns.

### What the Module Does

**Add Spawn Timer:**

- HUD timer showing 55 seconds until the next Allu'thoa worshiper adds spawn

### Player Notes

- Timer-only tracking for add spawns
