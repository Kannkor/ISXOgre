# Castle Highhold: Insider Treachery [Event Heroic]

**Expansion:** Altar of Malice (Exp 11)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Insider T'Shal](#insider-tshal) | Portal guidance (no automation needed) |
| [Zom/Zona Centi'Kaas](#zomzona-centikaas) | Green crystal auto-use, force target tracking |

---

## Insider T'Shal

Setup command: `Set up for Insider` (also accepts `Set up for T'Shal`)

### Overview

A fight where orbs must reach the portal on their own.

### What the Module Does

**Guidance Only:**

- The module provides positioning but no active mechanic automation
- The portal interaction code is disabled as it does not affect the encounter

### Player Notes

- Do not touch the orbs -- let them reach the portal naturally and the boss will eventually leave

---

## Zom/Zona Centi'Kaas

Setup is automatic when engaged.

### Overview

A fight with green crystal coordination and force targeting mechanics.

### What the Module Does

**Green Crystal Coordination:**

- When a green crystal notification appears, the lowest-ID character in the group automatically uses the Zov'Dyn Crystal item
- Coordinates crystal usage across all group members to prevent duplicates

**Force Target Tracking:**

- Monitors the Draw Attention detriment to track force targeting
- Prevents single-target abilities while force targeted

### Player Notes

- Only works in groups run entirely by you
- Purple crystals still require manual use
