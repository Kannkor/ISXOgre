# Ossuary: Choir of T'Vyl [Event Heroic]

**Expansion:** Altar of Malice (Exp 11)

!!! warning "Requires Elite 2"
    This module requires Elite 2 access to activate. Without it, no events are attached and the module does nothing.

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Prime Inquisitor Lazon](#prime-inquisitor-lazon) | Spell timers |
| [Legion of Many](#legion-of-many) | Knockback timer |

---

## Prime Inquisitor Lazon

Setup is automatic when engaged.

### Overview

A fight tracked with on-screen timers for the boss's spell abilities.

### What the Module Does

**Spell Timers:**

- HUD countdown for Strategic Incantation (35-second timer)
- HUD countdown for Spoken Shadows (70-second timer)

### Player Notes

- This is a timer-only module with no positioning or mechanic automation

---

## Legion of Many

Setup is automatic when engaged.

### Overview

A fight with a periodic knockback ability.

### What the Module Does

**Knockback Timer:**

- HUD countdown for Exert knockback (45-second timer)

### Player Notes

- Timer-only tracking
