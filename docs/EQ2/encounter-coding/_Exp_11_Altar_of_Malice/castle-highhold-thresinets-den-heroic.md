## Vexven / Mucktail

Setup is automatic when engaged.

### Overview

A fight where you must kill 48 Mucktail spirits.

### What the Module Does

**Kill Counter:**

- Tracks Mucktail spirit deaths and displays a HUD showing progress (X of 48)

### Player Notes

- This is a progress tracking module only -- no positioning or mechanic automation
