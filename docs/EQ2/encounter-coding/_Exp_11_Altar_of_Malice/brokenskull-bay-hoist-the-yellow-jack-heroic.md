## Captain

Setup command: `Set up for Captain`

### Overview

A fight where the group must spread out in a circular pattern.

### What the Module Does

**Spread Positioning:**

- Assigns each group member to one of 6 predefined positions arranged in a circle
- Positions are assigned based on sort order

### Player Notes

- Use MCP Special_ZoneSpecific to use the zip line while standing next to it
