## Fitzpitzle

Setup command: `Set up for Fitzpitzle`

### Overview

A fight with book minion adds whose deaths provide temporary immunity to specific AE abilities.

### What the Module Does

**AE Immunity Tracking:**

- When a psychotic book minion dies, displays a 10-second immunity window for Psychocontrapulation
- When an astral book minion dies, displays a 10-second immunity window for Supermeganova

**AE Cycle Timers:**

- Tracks the AE cycle with HUD timers (30/60-second display)

### Player Notes

- Kill the correct book minion type to gain immunity before the corresponding AE fires
