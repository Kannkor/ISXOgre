# The Fabled Laboratory of Lord Vyemm [Raid]

**Expansion:** Tears of Veeshan (Exp 10)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [The Uncaged Alzid](#the-uncaged-alzid) | Timed curse callout |
| [Lord Vyemm](#lord-vyemm) | Timed curse callout |

---

## The Uncaged Alzid

Setup is automatic when engaged.

### Overview

A fight with a timed implosion curse that requires coordinated curing.

### What the Module Does

**Timed Curse Callout:**

- Monitors the Uncaged Implosion curse duration
- When duration drops below 7 seconds, calls for cure curse in raid chat

### Player Notes

- Cure timing is critical -- the callout helps coordinate the cure window
