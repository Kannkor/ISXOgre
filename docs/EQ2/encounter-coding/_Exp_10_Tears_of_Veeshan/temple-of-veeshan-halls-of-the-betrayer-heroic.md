# Temple of Veeshan: Halls of the Betrayer [Heroic]

**Expansion:** Tears of Veeshan (Exp 10)

This zone has 2 boss encounters with OgreBot automation modules.

## Available Setups

| Boss | Description |
|------|-------------|
| [Captain](#captain) | Hexagonal spread positioning, curse joust |
| [Fherin](#fherin) | Positioning |

---

## Captain

Setup command: `Set up for Captain`

### Overview

A fight with spread positioning and a curse joust mechanic.

### What the Module Does

**Spread Positioning:**

- 6 campspot positions arranged in a hexagonal pattern around a center point
- Each group member gets a unique position based on sorted ID order

**Curse Joust:**

- When cursed, automatically jousts to the joust spot
- When the curse clears, returns to the assigned spread position

### Player Notes

- Each player has a unique position to prevent stacking

---

## Fherin

Setup command: `Set up for Fherin`

### Overview

A positioning-only setup.

### What the Module Does

**Positioning:**

- Sets a single raid spot for everyone

### Player Notes

- Positioning only, no mechanic automation
