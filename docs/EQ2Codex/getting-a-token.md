# Getting an API Token

To upload data with the ACT plugin (or the upcoming standalone scanner), you need an **eq2codex API token**. Tokens are created from your account dashboard.

## Steps

1. **Create an account.** Go to [eq2codex.com](https://eq2codex.com/). In the top-right corner, click **Sign in** if you already have an account, or create one if you don't.

2. **Open your dashboard.** Once signed in, click **Dashboard** in the top-right corner.

3. **Open the token manager.** Click **Manage Tokens**.

4. **Generate a token.** Give it a **Name** and pick a **Client Kind** (these don't really matter — any value is fine for your own reference). Click **Generate Token**.

You can now use the token to configure a capture client.
